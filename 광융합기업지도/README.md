## 체험 시나리오

**지도 탐색**
1. **클러스터링** — 처음엔 큰 원(클러스터) 19개가 보입니다. `＋`로 확대하면 원이 쪼개지고, 최대 줌에서 **168개 개별 마커**가 모두 드러납니다.
2. **다중 필터** — 필터 칩을 누를 때마다 값이 바뀝니다(지역 → 산업분류 → 규모 → 매출구간). 조합이 적용됩니다.
3. **현재 영역 재검색** — 지도를 드래그하면 상단에 버튼이 나타납니다. 누르면 **보이는 영역 안의 기업만** 남습니다.
4. **재무 출처 배지 ★** — 기업을 클릭해 보세요. 재무 항목에 `API 연동` / `엑셀 입력` / `재무제표 미공개 기업` 배지가 붙습니다. **값이 없는 게 오류가 아니라 공개 대상이 아니라서**임을 알려 줍니다.
5. **가상 스크롤** — 좌측 목록 상단에 `DOM N개 렌더`가 표시됩니다. 168건이어도 **실제로 그려지는 건 11~15개**입니다.

**관리자**
6. **커버리지 진단 ★** — 재무 API로 실제 조회되는 비율을 계산해 보여줍니다. **대기업 100% / 중견 77.3% / 중소기업 12.3%**.
7. **지오코딩 보정** — 변환 실패·근사 건을 지도에서 보정합니다. "지도에서 보정"을 누르면 좌표가 확정됩니다.
8. **범위 구분 ★** — 15일 프로토타입(1차)과 본구축(2차)을 나눈 표입니다.

## ⚠️ 착수 전 확인이 필요한 항목

- **과업지시서 전체 범위와 15일이 맞지 않습니다** — 검수 조건이 "기능 100% 구현"이라 그대로 계약하면 전체 범위가 기준이 됩니다. → **1차 프로토타입 범위를 문서로 확정**하고 계약하시길 권합니다(관리자 [범위 구분] 화면이 초안).
- **금융공공데이터 API로 재무를 받을 수 있는 기업이 소수입니다** — 법인등록번호 기준 조회이고 재무제표 공개 대상만 값이 있는데, 광융합기업은 비상장 중소기업이 대부분입니다(표본 기준 **중소기업 12.3%**). → 출처 배지 + 커버리지 진단 화면으로 대응했습니다.
- **국민연금 "종업원 수"는 사업장 단위**이고 법인 3인 이상만 공개됩니다. → 사업장 합산 + "미공개" 표기.
- **산업단지 주소는 지오코딩 실패율이 높습니다** → 신뢰도 3단계 판정 + 수동 보정 파이프라인.

> 참고로 지오코딩 무료 쿼터는 월 300만건이라 **비용 문제는 없습니다.** 근거 없이 리스크를 만들지 않기 위해 확인했습니다.

자세한 근거는 [분석/기획_설계.md](분석/기획_설계.md) 2장을 참고하세요.

## 기술 구성 (데모)

- 순수 HTML/CSS/JS — 빌드 불필요. 지도 API 없이 **CSS/DOM으로 지도·클러스터링 직접 구현**
- 168개사를 **결정론적 시드로 생성**해 필터·클러스터·커버리지가 실제로 계산됩니다 (하드코딩 아님)
- 가상 스크롤·클러스터링은 실제 알고리즘으로 동작
- CSV는 Blob으로 **실제 파일 생성**(11컬럼, UTF-8 BOM)
- 모든 기업·좌표·재무는 **가상 데이터**입니다

실서비스 제안 스택: React + Spring Boot + MySQL(SPATIAL 인덱스) + 카카오맵 API ([기획_설계.md](분석/기획_설계.md) 5장)
