**데모에서 바로 확인되는 것 (요구사항 전 항목):**

1. 전역 관심사 필터(스포츠카드·원피스·포켓몬·기타) — 홈·게시판·장터 전체 적용 + 재접속 시 유지
2. 이중 말머리 게시판 — 성격(자유·쇼케이스·질문·정보·팝니다·삽니다) × 주제 필수 선택, 텍스트 리스트형 / 쇼케이스 갤러리형 분리
3. 장터 — 카드형 레이아웃, 가격·상태·거래방식 구조화 입력(2차 시세 DB 확장 대비), 판매중/예약중/거래완료, 카카오 오픈채팅 연결
4. 소셜 로그인 온리(카카오·네이버·구글) + 봇 방지 + 60초 도배 차단
5. 관리자 — 통계 대시보드, 신고 처리, 스팸 회원 강제 탈퇴, 광고 슬롯 6개 존 수동 등록(Phase 1)
6. AI 카드 인식(협의 기능) — 사진 업로드 → 카드명·시세 자동 인식 흐름 시연

여기에 카드 커뮤니티 리서치를 바탕으로 **거래 사기 방지 장치(판매자 거래후기·더치트 조회 연결·자동 감지 규칙)** 와 **시세 인덱스 화면(2차 페이즈 미리보기)** 을 제안으로 얹었습니다. 장터 구조화 데이터가 그대로 시세 서비스의 원천이 되는 설계입니다.

**저희가 잘하는 것**

- 웹디자이너 출신이라 **디자인 완성도(1순위 요건)에 강합니다.** 데모의 다크 프리미엄 디자인과 인터랙션이 그 증거이며, 디자인 원본 파일(산출물)도 직접 제작합니다.
- **피드백 반영이 빠릅니다.** AI 도구를 반복 작업(화면 퍼블리싱·목록 UI·테스트 데이터)에 활용해 수정 요청을 대개 **당일 반영**합니다. 커뮤니티는 오픈 후 화면을 계속 손보게 되므로 이 속도가 중요합니다.
- 공고에 적어 주신 **월 단위 유지보수·고도화**를 이어서 맡을 의향이 있습니다. 2차 시세 DB와 광고주 셀프 등록까지 같은 팀이 하는 편이 구조가 흔들리지 않습니다.

> 공고 예산 1,000만원 기준으로 여유가 있습니다. **AI 카드 인식(협의 항목)을 포함하거나, 2차 예정인 시세 DB 스키마를 미리 설계**해 두는 쪽으로 범위를 넓힐 수 있습니다. 어느 쪽이 더 필요하신지 미팅에서 정하면 그에 맞춰 조정하겠습니다.

**의뢰자 부담 영역 (견적 외 실비):**

- 서버·호스팅·도메인 비용 (월 실비, 초기 트래픽 기준 월 3~5만원 수준)
- 카카오·네이버·구글 소셜 로그인 앱 등록 (사업자 명의 필요, 등록 절차는 저희가 대행)
- AI 카드 인식 채택 시 클라우드 비전/LLM API 사용료 (사용량 과금)
- 유료 폰트·이미지 라이선스 구매 시 해당 비용

제안 스택은 Next.js(SSR/SEO) + NestJS + PostgreSQL이며, 월 유지보수·고도화(2차 시세 DB, 광고주 셀프 등록) 장기 협업을 희망합니다. 미팅에서 데모를 함께 보며 논의드리고 싶습니다. 감사합니다.
