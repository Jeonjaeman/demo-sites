[프로젝트 개요]
- 스포츠카드 및 TCG 올인원 통합 커뮤니티 사이트 1차 구축

[프로젝트 배경 및 목표]
- 국내 스포츠카드, 원피스, 포켓몬 카드 콜렉터들이 네이버 카페나 오픈채팅에 분산되어 있는 문제를 해결하기 위해, 구조화된 정보와 직거래 중심의 독립된 커뮤니티 사이트를 구축합니다. 유저 경험을 최우선으로 하여 가볍고 빠른 게시판 중심의 인터페이스를 제공하며, 장기적으로 매장 및 딜러들의 광고 플랫폼으로 성장시키는 것을 목표로 합니다.

[과업 범위]
1. 수행 범위
- 상세 기획: 화면 설계, 서비스 정책 정의, 데이터베이스 스키마 설계
- UI/UX 디자인: 반응형 웹 화면 디자인, 광고 배너 슬롯 디자인
- 프런트엔드 웹 개발: 모바일 우선 반응형 퍼블리싱 및 클라이언트 로직 구현
- 백엔드 개발: 관리자 페이지, API 서버 개발, 소셜 로그인 연동
- 서버/DB/인프라 구성: 웹 호스팅 환경 설정, 자동 백업 구성, 검색엔진최적화 환경 설정

2. 상세 기능 요구 사항
2-1. 공통 및 회원 시스템
- 소셜 로그인 연동 기능: 자체 이메일 가입 절차 없이 카카오, 네이버, 구글 소셜 로그인만 허용
- 전역 관심사 필터 기능: 상단에서 주제 태그(스포츠카드, 원피스, 포켓몬, 기타) 선택 시 홈 피드, 게시판, 장터 전체 목록을 해당 주제 글만 필터링하여 노출
- 필터 상태 유지 기능: 사용자가 선택한 관심사 주제를 브라우저 로컬 스토리지에 저장하여 재접속 시 유지
- 스팸 방지 기능: 회원 가입 시 봇 방지 로직 적용 및 단시간 내 연속 게시글 등록 제한 처리

2-2. 홈 메인 화면
- 게시글 통합 피드 노출 기능: 별도 랜딩 페이지 없이 접속 즉시 전체 게시판의 최신 글 목록을 텍스트 리스트 형태로 노출
- 직관적 글쓰기 진입 기능: 메인 화면을 포함한 모든 화면에서 두 번의 클릭 이내로 글쓰기 폼으로 이동하는 버튼 배치
- 탭 네비게이션 기능: 화면 상단 탭을 통해 게시판, 정보, 장터 메뉴 간 이동 처리

2-3. 이중 말머리 게시판 (자유, 쇼케이스, 질문, 정보)
- 이중 말머리 선택 기능: 글 작성 시 게시판 성격(자유, 쇼케이스, 질문, 팝니다, 삽니다, 정보)과 주제 태그(스포츠카드, 원피스, 포켓몬, 기타)를 필수 단일 선택으로 지정
- 목록 UI 구성 기능: 자유, 질문, 정보 게시판은 말머리, 제목, 댓글 수, 작성 시간을 조합한 텍스트 목록형으로 노출
- 갤러리 UI 구성 기능: 쇼케이스 게시판은 카드형 레이아웃 또는 매거진형 레이아웃으로 이미지 섬네일 노출
- 게시글 공통 기능: 제목, 본문 데이터를 텍스트로 입력받고 다중 이미지를 업로드받아 데이터베이스에 저장 및 수정, 삭제 처리
- 사용자 상호작용 기능: 댓글 및 대댓글 텍스트 정보를 수신하여 출력하고, 게시글 좋아요 클릭 횟수 연산 및 사용자 신고 정보를 데이터베이스에 저장
- 게시판 검색 기능: 제목 및 본문 텍스트 기반 키워드 검색 결과 리스트 노출

2-4. 장터 (직거래 게시판: 팝니다, 삽니다)
- 장터 목록 UI 구성 기능: 텍스트 목록형이 아닌 카드형 레이아웃 적용
- 거래 정보 구조화 입력 기능: 가격, 상태, 거래 방식 정보를 개별 입력 폼으로 받아 데이터베이스에 구조화하여 저장 (2차 페이즈 시세 데이터베이스 확장을 대비한 관계형 스키마 설계 적용)
- 오픈채팅 연결 기능: 사이트 내 자체 쪽지 기능 없이 판매자가 등록한 카카오톡 오픈채팅 URL을 하이퍼링크 버튼으로 제공
- 거래 상태 변경 기능: 판매중, 예약중, 거래완료 3단계 상태 변경 처리

2-5. 관리자 페이지 및 광고 시스템
- 대시보드 통계 기능: 전체 회원 수, 게시글 수, 사용자 신고 누적 내역 조회
- 게시물 및 회원 관리 기능: 규정 위반 게시글 강제 삭제 및 스팸 회원 강제 탈퇴 처리
- 광고 슬롯 관리 기능: Phase 1에서는 광고 슬롯 구조와 관리자 수동 등록까지만 만들고, 광고주 셀프 등록·과금은 Phase 2에서 진행
- AI 카드 인식 등록 기능 (협의 가능)

[기술/제조 스택]
- 제안 요청

[지원 자격 및 우대 사항]
1. 지원 자격
- 반응형 웹 커뮤니티 사이트 구축 경험
- 외부 클라우드 비전 API 또는 대규모 언어 모델 API 연동 개발 경험
2. 우대 사항
- 검색엔진 최적화 구축 및 서버사이드 렌더링 환경 구축 경험
- 스포츠카드, 포켓몬 카드 수집 문화 및 시장에 대한 높은 이해도
