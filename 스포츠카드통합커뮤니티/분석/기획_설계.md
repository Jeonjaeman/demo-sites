### 1-2. 문서 행간의 숨은 니즈

- **"네이버 카페·오픈채팅 분산 문제 해결"** → 이탈 비용을 낮춰야 함: 소셜 3초 가입, 접속 즉시 피드, 가벼운 게시판. 무거운 포털형 랜딩은 오히려 역효과.
- **"장기적으로 매장·딜러 광고 플랫폼"** → Phase 1부터 광고 슬롯이 *보이는 곳에* 존재해야 광고주 영업이 가능. 데모에 AD 표기 슬롯을 실제 배치(홈 배너·피드 네이티브·사이드바·장터 상단)하고 관리자에서 존 단위로 관리.
- **"2차 페이즈 시세 데이터베이스 확장 대비 관계형 스키마"** → 장터의 구조화 입력(가격·상태·방식)이 곧 시세 데이터의 원천. 데모에 '시세' 탭을 제안 기능으로 넣어 **거래 데이터 → 시세 서비스**로 이어지는 성장 스토리를 화면으로 증명.
- **"IT PM 경험 있음 + 월 유지보수 후속"** → 산출물 완성도(1순위)를 화면으로 먼저 보여주는 제안이 유효. Phase 1/2 경계를 데모 곳곳에 명시해 범위 협상 리스크를 줄임.

| 갭 | 근거 | 데모 반영 |
|---|---|---|
| **거래 사기 방지 장치** | 국내 중고거래 커뮤니티의 최대 리스크. 더치트/사이버캅 조회, 판매자 거래이력 확인이 사실상 표준 관행 | 매물 카드에 **판매자 거래후기 수** 노출, 상세에 **더치트 조회 링크** + 안전거래 안내 위젯, 관리자에 사기 제보 신고 유형 |

## 4. 화면 구성

```
index.html (SPA)
├─ 시세 틱커 (마퀴)
├─ 헤더 GNB: 홈·게시판·쇼케이스·장터·시세
├─ 전역 관심사 필터바 (sticky, localStorage)
├─ 히어로 (패럴랙스 + 접속자 뱃지 + 카운트업 통계)
├─ 홈: 통합 피드 → AD 배너 → 오늘의 쇼케이스 → 방금 올라온 매물
├─ 게시판: 말머리 서브탭 + 검색 + 텍스트 리스트 (쇼케이스 탭 = 갤러리 전환)
├─ 쇼케이스: 카드 갤러리 (홀로포일 호버)
├─ 장터: AD 슬롯 + 필터 + 카드 그리드 + 안전거래 안내
├─ 시세: 지수 3종 + 실거래 랭킹 테이블 (Phase 2 제안)
├─ 글 상세: 거래 패널(가격·상태·방식·오픈채팅·더치트) + 댓글/대댓글
├─ 글쓰기 모달: 이중 말머리 + 구조화 거래폼 + AI 카드 인식 + 스팸 제한
└─ 사이드바: 실시간 인기글 · 시세 위젯 · AD 슬롯 · 광고 문의

admin.html
├─ 대시보드: 통계 4종(카운트업) + 주간 활동 차트 + 미처리 신고
├─ 신고 관리: 처리(삭제/기각) + 자동 감지 규칙
├─ 회원 관리: 신뢰등급·스팸 플래그·강제 탈퇴
└─ 광고 슬롯: 6개 존 현황 + 수동 등록/종료 (Phase 1)
```

## 5. 실서비스 제안 스택

- **Next.js (SSR/ISR)** — 우대사항인 SEO·서버사이드 렌더링 직접 충족. 게시글·정보글이 검색 유입 엔진이 되는 구조
- **NestJS + PostgreSQL** — 장터 거래 테이블을 관계형 구조화(카드 마스터 ↔ 매물 ↔ 체결가)로 설계해 2차 시세 DB로 무손실 확장
- **소셜 OAuth** (카카오/네이버/구글) + reCAPTCHA v3 + rate limit (요구사항 2-1)
- **클라우드 비전 API 또는 멀티모달 LLM** — AI 카드 인식 (지원자격 요건 대응, 협의 기능)
- 인프라: 웹호스팅 + 일 단위 자동 백업 + CDN 이미지 리사이징 (다중 이미지 업로드 대응)
