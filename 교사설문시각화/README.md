## 체험 시나리오 (데모 포인트)

**응답 화면**

1. **참여 확인** — 학교 코드 + 1회용 토큰. 같은 토큰으로 두 번 응답할 수 없습니다.
2. **문항 진행** — 한 화면에 한 문항, 키보드 `1~5`로 선택. 상단에 "저장됨"이 계속 깜빡입니다.
3. **중도 이탈 회수** — 문항 3~4개쯤 답하고 **새로고침해 보세요.** 그 지점부터 이어서 진행됩니다.
4. **직위 안내** — 응답자 정보에서 직위를 '교장' 또는 '교감'으로 고르면 익명 보호 안내가 뜹니다.

**관리자 대시보드**

5. **발산형 누적 막대** — 중립을 가운데 축에 정렬해 문항 간 긍·부정 균형이 한눈에 비교됩니다. 업무 부담(Q4)만 막대가 왼쪽으로 길게 뻗습니다.
6. **소규모 셀 자동 마스킹 (핵심)** — 필터에서 **직위를 '교장'으로 두고 교차분석을 '지역' 기준**으로 보세요. 5개 지역 중 4개가 `비공개`로 자동 처리됩니다. 여기서 지역까지 '서울'로 좁히면(n=1) 모든 수치·차트·CSV 반출이 전면 차단됩니다.
7. **사후층화 가중 토글** — 켜면 수치가 실제로 달라집니다. 응답 그대로의 단순 평균과 모집단 비율로 보정한 값의 차이를 볼 수 있습니다.
8. **연도 추이** — Q5(교권 보호)는 2023년 신설이라 **2023년부터만 선이 그려집니다.** 이전 연도와 억지로 잇지 않습니다.
9. **CSV / 인쇄** — CSV는 실제 파일이 받아지며(UTF-8 BOM, 엑셀 한글 정상), 소규모 집단은 `비공개(표본부족)`로 반출됩니다. 인쇄 버튼은 전용 레이아웃으로 출력됩니다.

## ⚠️ 착수 전 반드시 확인이 필요한 항목

공고의 **"응답자 개인이 식별되지 않도록"** 한 줄이 이 프로젝트에서 가장 무거운 요구입니다.

- **학교·직위로 쪼개면 개인이 특정됩니다** — 교장·교감은 학교당 1명이라, 요구사항인 "지역별 집계"와 정면으로 충돌합니다. → **최소 응답 수 5명 미만 자동 비공개**(보완 억제 포함)를 시스템에 강제했습니다.
- **자발적 응답의 단순 평균은 전국 대표값이 아닙니다** — 자기선택 편향으로 지역·학교급 비율이 모집단과 어긋납니다. → **교육통계 기준 사후층화 가중**을 토글로 넣었습니다.
- **문항이 바뀌면 연도 추이가 깨집니다** — 문항별 코드·도입 연도를 관리하고 신설 문항은 추이선을 끊습니다.
- 그 외 리커트 시각화 방식, 중복 응답과 익명성의 딜레마, 중도 이탈 회수를 함께 반영했습니다.

자세한 근거와 대안은 [분석/기획_설계.md](분석/기획_설계.md) 2장을 참고하세요.

## 기술 구성 (데모)

- 순수 HTML/CSS/JS 정적 사이트 — 빌드 불필요, 반응형, `@media print` 인쇄 레이아웃
- **응답 1,284건을 결정론적 시드로 생성**해 필터·집계·가중·마스킹이 실제로 계산됩니다 (하드코딩된 수치가 아닙니다)
- 차트는 외부 라이브러리 없이 canvas/CSS로 직접 구현 (dpr 대응)
- CSV는 Blob으로 실제 파일 생성 (쉼표 이스케이프, UTF-8 BOM, 가중 적용 여부 기록)
- 모든 응답·학교·수치는 **가상 데이터**입니다

실서비스 제안 스택: Next.js + PostgreSQL, 마스킹은 애플리케이션이 아니라 **집계 뷰에서 강제** (기획_설계.md 5장 참조)
