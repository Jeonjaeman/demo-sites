# BOOTHPIN 부스핀 — 플리마켓·행사 셀러 매칭 플랫폼 (데모)

## 체험 시나리오 (데모 포인트)

1. **참여 신청 (⑬)** — 품목·한줄소개·사진 중 하나라도 빠지면 등록이 막힙니다. 사진은 **최대 5장**에서 더 안 늘어나고, 추가 옵션을 고르면 **결제 금액이 실시간 합산**됩니다(참가비 30,000 + 전기 10,000 + 테이블 5,000 = 45,000원).
2. **출석 체크 (⑤)** — 출석 버튼을 **한 번 더 누르면 취소**됩니다(명세서 그대로). 우측 상단에서 QR 발급과 **엑셀 다운로드(실제 CSV 파일)** 가 됩니다.
3. **승인/거절 (⑥)** — 거절을 누르면 바텀시트가 열리고 **사유 40자 제한**이 걸립니다. 사유 없이는 거절되지 않습니다.
4. **지도 (⑩)** — 핀을 누르면 하단 시트에 행사 요약이 뜹니다. 👣 발자국은 참여했던 행사 지점입니다(상호작용 없음).
5. **등급 규칙 진단 (⑰) — 핵심** — 명세서의 등급 정의를 **실제 회원 분포 50명에 대입해 계산**한 결과입니다. 하단 토글로 기획서 규칙과 개선안을 비교할 수 있고, **바꾸면 앱 전체의 등급 배지가 실제로 달라집니다**(예: 12회 참여 셀러가 기획서 규칙에선 실버, 개선안에선 골드).

## ⚠️ 착수 전 확인이 필요한 항목

명세서는 화면 단위로 매우 상세하지만, **법적·운영 측면에서 확인이 필요한 부분**이 있습니다.

- **참가비를 플랫폼이 받으면 PG 등록 대상**이 될 수 있습니다 → 결제를 **주최자 명의로 직접 수취**(PG 서브몰)하는 구조로 설계했습니다.
- **지도 기반 서비스는 위치기반서비스사업 신고 대상**입니다(미신고 시 3년 이하 징역 또는 3천만원 이하 벌금) → 오픈 전 신고를 일정에 넣고, 위치는 **단말에서만 일시 처리**하도록 했습니다.
- **등급 규칙이 그대로는 계산되지 않습니다** — 절대 기준(횟수)과 상대 기준(백분위)이 섞여 있고, 회원 50명 기준 **TOP10이 상위 20%**라 다이아(5%)보다 넓어져 **1위 회원이 다이아가 아닌 TOP10**이 됩니다. 상대평가라 **가만히 있어도 강등**되고 0회 등급은 정의가 없습니다.
- 그 외 QR 출석의 오프라인 대응, 노쇼 대응 수단 부재, 실명·연락처의 제3자 제공 동의를 함께 반영했습니다.

자세한 근거와 대안은 [분석/기획_설계.md](분석/기획_설계.md) 2장을 참고하세요.

## 기술 구성 (데모)

- 순수 HTML/CSS/JS 정적 사이트 — 빌드 불필요
- 데스크톱은 **폰 프레임 + 화면 설명 패널**, 모바일에서는 **폰 프레임 없이 전체화면 앱**으로 전환
- 등급은 회원 50명 분포에 대해 **실제로 계산**합니다 (하드코딩 아님)
- QR은 결정론적 SVG로 형태만 시연(실제 인코딩 아님), 엑셀은 Blob으로 **실제 CSV 파일** 생성
- 모든 행사·셀러·수치는 **가상 데이터**입니다

실서비스 제안 스택: React Native + NestJS + PostgreSQL + 카카오맵 SDK + PG 서브몰 ([기획_설계.md](분석/기획_설계.md) 5장)
