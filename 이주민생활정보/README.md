# MOST 모스트

러시아어권 이주민이 한국의 매물과 생활·법률·비자 정보를 신뢰 근거와 함께 확인하는 반응형 제안 데모입니다. 모든 매물·회원·콘텐츠는 가상 데이터입니다.

## 화면

| 경로 | 내용 |
|---|---|
| `index.html` | 매물 탐색, 한/러 전환, 상세, 용어 사전, 생활정보, 공급자 등록 |
| `admin.html` | 매물 승인/반려, 신고, 콘텐츠 최신성, 광고, CSV 반출 |

## 체험 시나리오

1. 언어를 `Русский`로 바꾸고 지역·가격·등록자 필터를 조합합니다.
2. `확인 완료`와 `광고`가 서로 다른 의미로 표시되는지 확인합니다.
3. 매물 상세에서 계약용어와 광고정보 점검표를 엽니다.
4. 공급자 등록에서 중개사 등록번호를 비워 제출해 차단을 확인합니다.
5. 관리자에서 승인대기 매물을 반려하고 사유가 남는지 확인합니다.
6. CSV를 내려받아 UTF-8 BOM과 한·러 텍스트를 확인합니다.

## 착수 전 확인

- 등록번호 확인을 API로 자동화할지 서류 검수할지
- 임대인 소유권 확인 문서와 보관기간
- PG 결제·환불·세금계산서의 1차 범위
- 지도·GPS 사용과 위치기반서비스 신고 범위
- 자동번역과 전문가 감수 책임
- 광고 상품·기간·노출 규칙

## 디자인 실측

서울외국인포털의 공공정보 IA, Rightmove의 48px 검색 액션, Daft.ie의 1040px 매물 레일을 측정해 MOST의 포레스트 기반 디자인 시스템으로 재조합했습니다. 상세 토큰은 `DESIGN.md`에 있습니다.

## 기술 구성

- HTML5, CSS Grid/Flex, Vanilla JavaScript
- 외부 런타임 라이브러리 없음
- 실제 배열 필터·집계, 현재 화면 내 메모리 상태
- 개인정보 입력은 서버 전송·브라우저 저장 없이 동작하는 정적 시뮬레이션
- Blob + UTF-8 BOM CSV 다운로드
- IntersectionObserver, requestAnimationFrame
- Playwright 기능·반응형 테스트

로컬 실행:

```bash
python -m http.server 8091 --directory 이주민생활정보
```
