# MOST 모스트 시나리오 기반 사용자 여정

## 1. 등장인물

| 역할 | 원하는 것 | 불안 |
|---|---|---|
| 러시아어권 이주민 | 이해 가능한 주거 조건과 최신 생활정보 | 허위매물, 보증금, 한국어 계약용어 |
| 공인중개사 | 검증된 공급자로 매물·광고 노출 | 등록번호/필수정보 누락 반려 |
| 임대인 | 직접 매물을 합법적 범위에서 홍보 | 중개사로 오인되는 표현 |
| 콘텐츠 운영자 | 한·러 정보를 최신 상태로 게시 | 법률·비자 정보의 구버전 노출 |
| 관리자 | 매물·회원·콘텐츠·광고를 빠르게 검수 | 누락, 허위광고, 개인정보 과수집 |

## 2. 전체 타임라인

| 단계 | 상황 | 화면 | 없으면 벌어지는 일 |
|---|---|---|---|
| 발견 | 러시아어 검색으로 접속 | 홈·한/러 전환 | 첫 화면에서 이탈 |
| 판단 | 지역·가격·유형 비교 | 실제 계산 필터·매물 카드 | 광고와 일반매물 혼동 |
| 신뢰 확인 | 등록자·검증 범위 확인 | 승인/등록자/광고 배지 | 허위매물을 공인된 것으로 오해 |
| 행동 | 상세·문의·신고 | 상세 모달·안전 점검 | 계약 전 위험 신호를 놓침 |
| 공급 | 매물 등록 | 역할별 등록 폼 | 필수 광고정보가 빠진 채 노출 |
| 대기 | 검수 결과 대기 | 승인대기/반려 사유 | 공급자가 진행상태를 모름 |
| 운영 | 승인·반려·최신성 관리 | 관리자 | 오래된 정보와 위험 매물 누적 |
| 사후 | 자료 반출·감사 | BOM CSV·상태 기록 | 정부사업 보고와 운영 인수인계 곤란 |

## 3. 역할별 시야

- 비회원: 공개 승인 매물과 공개 생활정보만 열람.
- 이주민 회원: 찜·문의·신고 결과까지 확인.
- 공인중개사: 본인 등록번호, 매물 승인상태, 반려사유, 광고 집행상태 확인.
- 임대인: 본인 소유 확인 항목과 직접등록 상태 확인. 중개사 배지 없음.
- 관리자: 연락처 전체값 대신 운영에 필요한 마스킹 값부터 보고 상세 권한에서만 확인.

## 4. 기능별 존재 이유

- 등록자 유형 분리: 비중개인의 표시·광고를 공인중개사 광고와 동일하게 보이지 않게 한다.
- 중개사 등록번호·필수 광고정보 검증: 공인중개사법 시행령의 인터넷 광고 항목 누락을 등록 단계에서 차단한다.
- 광고 배지: 유료 노출을 승인 신뢰와 혼동하지 않게 한다.
- 출처·최종 검토일: 번역 품질과 정보 최신성을 분리해 판단하게 한다.
- 계약용어 사전: `보증금·월세·관리비·전세`를 러시아어로 즉시 설명한다.
- 신고 흐름: 의심 매물을 운영자가 우선순위로 검수하게 한다.
- BOM CSV: 한글·러시아어가 엑셀에서 깨지지 않게 한다.

## 5. 비는 구멍(미팅 확인 필요)

1. 중개사 등록번호를 외부 API로 실시간 검증할지, 서류 수동 검수할지.
2. 임대인 소유권 확인 서류의 종류·보관기간·열람권한.
3. 비회원 연락처 공개 범위.
4. PG 결제, 세금계산서, 환불을 1차 범위에 포함할지.
5. 자동번역과 전문가 감수의 책임 경계.
6. 지도 검색과 개인위치정보 사용 여부.
7. 법률·비자 게시판 댓글 허용 여부.
8. 만료 매물의 자동 숨김 주기.
