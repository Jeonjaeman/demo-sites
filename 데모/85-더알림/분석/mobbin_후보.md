# Mobbin 레퍼런스 후보 — 더알림 리뉴얼 (2026-10-20 수집)

> Mobbin은 **갤러리(구성 참고)** 이지 실측 소스가 아니다. 색·px·이징은 여기서 뽑지 않는다.
> 채택한 후보는 해당 서비스 라이브 웹을 브라우저로 열어 `getComputedStyle`로 실측한다(3단계).
> 이미지는 `mobbin/` 폴더에 내려받아 두었다 (Mobbin image_url은 30일 뒤 만료).

검색 조건: platform `web`, output `code`, 섹션 8종 + 화면 2종 + 플로우 1종 = 11회 호출.
더알림의 성격(B2B 교육 위탁 + 자격증 + 강사 네트워크)에 맞춰 **"기업용(for Business/Teams) 교육 서비스"** 를 주축으로 골랐다.
