# 더알림 리뉴얼 — 페이지 기획 (멀티페이지 · 초안 2026-10-20, 리서치·실측 반영 후 확정)

브랜드: **THE ALRIM 더알림** (기존 상호 유지) · 별칭 `/thealrim`
구조 원칙: 공개 사이트는 브랜드형(①~⑤ 단락 구성), 프로그램 카탈로그·강사 디렉토리·문의 플로우는 기능형, 강사전용·관리자는 대시보드형. 표면별로 톤을 나눈다.

## 사이트맵 (데모 범위 ●  / 실제 구축 범위 ○)

```
●  index.html               홈 (허브) — 각 페이지로 보내는 역할, 전부 담지 않음
●  outreach.html?c=youth|corp|medical|public   교육출강 센터 페이지 (쿼리로 4센터, 공통 템플릿)
●  programs.html            프로그램 카탈로그 — 센터×대상×시간×형태 필터, 결과 수, "제안서에 담기"
●  program.html?id=         프로그램 상세 — 목표·대상·차시 아코디언·기대효과·추천 강사·스티키 메타 카드
●  lecturers.html           강사 디렉토리 — 분야·권역·대상 필터, 카드(사진·분야·대표 강의·출강 수)
●  lecturer.html?id=        강사 프로필 — 약력·강의 가능 주제·출강 이력·후기·"이 강사로 제안서 요청"
●  certificates.html        민간자격증 — 4분야 32종, 상세 패널(발급기관·등록번호·검정기준·비용·일정·'국가공인 아님' 고지)
●  consulting.html          개인컨설팅 — 7개 과정, 신청
●  academy.html             아카데미 — 명사초청강연·전문가 특강 + 일정
○  contents.html            교재·VOD 제작 (프로세스) — 데모는 index 요약 + 링크
●  cases.html               현장 사례(강의후기) — 업종 필터 칩 + 사진 카드 + 성과형 제목
●  news.html                언론보도·수상 — 연도별 리스트 + 수상 배지
○  notice.html / schedule   공지·일정 — 관리자에서 등록 (데모는 admin에서 시연)
●  partners.html            함께한 곳 — 카테고리별 단색 로고 전체
●  about.html               회사소개 — 인사말·가치/비전·협회 2곳·오시는길 (한 페이지 앵커)
●  request.html             맞춤 제안서 요청 — 4단계 위저드(기관유형→대상·인원→주제·프로그램→일정·예산) → 자동 추천 → 제출 → 접수증
●  contact.html             빠른 상담(15초) · 광고/콘텐츠 제휴 · 강사 지원 3탭
```

## 페이지별 기획

### index — 허브
목적: 30초 안에 "무엇을 하는 회사인지 + 신뢰 근거 + 다음 행동" 전달. 방문자가 할 일: 센터 고르기 또는 제안서 요청.
섹션: ① 히어로(강사 얼굴 스트립 + 대형 카피 + 2트랙 CTA) ② 로고 1줄 ③ 숫자 3(세리프·카운트업) ④ 4대 센터 스택 카드(핀 스크럽) ⑤ 풀블리드 이미지 단락(현장 사진·텍스트 리빌) ⑥ 대표 강사 캐러셀(풀블리드) ⑦ 진행 프로세스 타임라인 ⑧ 사례 4(필터 없이 최신) ⑨ 언론·수상 카드 캐러셀 ⑩ CTA. 길이 목표 데스크톱 7,000px 이하.

### outreach?c= — 센터 페이지 (4종 공통 템플릿)
목적: 담당자 유형별 랜딩. 할 일: 내 기관에 맞는 프로그램 찾기. 섹션: 히어로(센터 사진 풀블리드) → 이 센터가 푸는 문제 3 → 대표 프로그램 6(카탈로그 링크) → 이 센터 강사 → 사례 → CTA. 병원은 "환자경험평가 대응"처럼 평가 일정 연동 안내.

### programs — 카탈로그 (기능형)
필터: 센터(4) · 대상(신입/실무/팀장/임원/의료진/학생/교사) · 시간(2h/4h/8h/다회차) · 형태(집체/온라인/혼합) · 법정의무 여부. 결과 수 표기·정렬·빈 상태("조건을 넓혀 보세요" + 추천). 카드 메타: 차시·시간·대상·권역. **제안서에 담기**(장바구니식, 상단 바에 담긴 수 표시 → request로 이어짐). 프리필: 첫 진입 시 "병원 · 4h" 샘플 필터 적용 버튼.

### program?id= — 상세
좌: 교육 목표·대상·차시 아코디언(번호)·기대효과·준비물. 우 스티키: 총 시간·차시·권장 인원·형태·환급 가능 여부(조건부 표기)·추천 강사 2 · 「제안서에 담기」「샘플 강의계획서 PDF」(Blob 생성).

### lecturers / lecturer — 강사 디렉토리·프로필 ★ 신규
필터: 분야(마케팅·리더십·CS·IT·법정의무·진로·병원 등)·권역(수도권/충청/영남/호남/강원/제주)·대상·경력. 카드: 사진(생성 이미지, 실존 인물 금지)·분야 태그·대표 강의 1줄·출강 N회·평점. 프로필: 약력·강의 주제·출강 이력(기관 유형만)·담당자 피드백 요약·영상 자리. **공개 범위 토글**(강사가 비공개 설정하면 목록에서 실제로 빠짐 — 2,000명 전원 공개가 아님을 설계로 보여줌).

### certificates — 민간자격증
4분야 32종 텍스트 리스트(밀도형) → 클릭 시 상세 패널: 자격명·등급·발급기관(협회)·**민간자격 등록번호**·**"국가공인 민간자격이 아닙니다" 고지**·검정 기준·교육 시간·비용·일정·신청. 리서치 결과(자격기본법 표시 의무)를 **필수 필드 + 미입력 시 공개 차단**으로 구현.

### request — 제안서 요청 위저드 (핵심 기능)
1 기관 유형(학교/기업/공공/병원) → 2 대상·인원·지역 → 3 주제 선택(카탈로그에서 담은 것 자동 반영) → 4 일정·예산·형태 → **자동 추천**(조건으로 실제 필터링된 프로그램 3 + 가용 강사 수 계산) → 담당자 정보 → 제출 → 접수증(접수번호·예상 회신 1~2일·담당 매니저). 전부 프리필 샘플 버튼 「예시로 채우기」. 개인정보 동의 미체크 시 실제 차단.

### contact — 빠른 상담·제휴·강사 지원
탭 3. 빠른 상담은 셀렉트 1 + 연락처 → 인라인 완료. 강사 지원은 분야·지역·경력·강의 영상 링크 → "검토 후 초대코드 발송" 안내(강사전용 가입 경로와 연결).

### lecturer-portal — 강사전용
로그인 화면(샘플 강사 원클릭) → 대시보드: 새 출강 요청(지원/거절, 마감·지역·시간·단가) · 내 일정 캘린더 · 완료 건 피드백(기관 담당자 평가 열람) · 프로필 편집(공개 범위) · 자료실 · 공지. 상태 흐름: 요청→지원→배정→확정→진행→완료→정산.

### admin — 관리자
대시보드(신규 문의·진행 교육·이번 주 출강·평균 만족도·센터별 매출) · 접수함(상태 7단계 칸반/표, 경과일 색, 매니저 배정) · 교육 건 상세(기관·프로그램·일정·강사 매칭 — 조건 필터로 후보 강사 실제 산출·배정·알림 로그) · 피드백 수집(교육 종료 후 설문 발송·결과 → 강사 평점 반영 = 검증 3단계 실구현) · 강사 관리(승인 대기·분야 태그·블랙리스트) · 콘텐츠(프로그램/자격증 저장 즉시 공개 반영·자격 등록번호 미입력 차단) · **검토 항목**(리서치 발견 전수 체크리스트).
