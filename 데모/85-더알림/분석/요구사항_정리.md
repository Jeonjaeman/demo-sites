# 더알림 리뉴얼 요구사항 정리 (공고문 없음 · 현행 2사이트 분석으로 역산 · 2026-10-20)

사용자 결정: **구 사이트 기능 포함** — 현행 아임웹 사이트 + 구 그누보드 사이트를 **하나의 사이트로 통합 리뉴얼**한다.

## 1. 통합 사이트맵 (초안 · 페이지 기획에서 확정)

### 공개 사이트 (브랜드형)
| 메뉴 | 페이지 | 출처 |
|---|---|---|
| 홈 | index | 현행 |
| 교육출강 | 청소년교육 / 기업교육 / 병원특화 / 공공기관 (센터별 독립 페이지) | 현행 + 구(교육출강>프로그램) |
| 프로그램 | 프로그램 카탈로그(필터) · 프로그램 상세(목표·대상·차시·강사·기대효과) | 현행 탭 23+16+3 → 개별 페이지 |
| **강사진** ★신규 | 강사 디렉토리(분야·권역·대상 필터) · 강사 프로필 | 구(교육출강>강사진) — 현행엔 없음 |
| 자격증 | 민간자격증 안내(4분야 32종) · 자격 상세(발급기관·등록번호·검정기준·비용·일정) | 현행 + 구(자격증발급교육) |
| 교재·VOD | 도서출판 / VOD 제작 프로세스 | 현행 + 구 |
| **개인컨설팅** | 진로취업 / 창업 / PT·스피치 / 온라인마케팅 등 1:1 컨설팅 | 구에만 있음 |
| **아카데미** | 명사초청강연 / 전문가 특강 | 구에만 있음 |
| 협회 | 한국인재양성협회 / 한국기업경영협회 | 현행 |
| 소식 | 언론보도 · 강의후기(사례) · 공지사항 · **일정** | 현행 + 구(공지>일정) |
| 회사소개 | 인사말 · 가치/비전/미션 · 함께한 곳 · 오시는길 | 현행 + 구 |
| 문의 | 맞춤 제안서 요청(3~5분) · 빠른 상담(15초) · 광고/콘텐츠 제휴 · 강사 지원 | 현행 + 구(교육문의·광고제휴·강사지원) |

## 2. 현행에서 확인된 데이터 자산 (데모 목데이터 소스)

## 3. 확정 전제
- 예산·기간 공고 없음 → 기능 범위로 시장가 역산 (견적 규칙)
- 플랫폼: 현행 아임웹 의존을 벗어나는 자체 구축 제안 (강사전용·관리자는 아임웹으로 불가)
- 데모 범위: 공개 사이트 주요 페이지 + 강사전용 + 관리자 핵심 화면 (멀티페이지)
