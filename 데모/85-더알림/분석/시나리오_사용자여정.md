### B. 소속 강사 — CS·소통 분야
합류(초대코드) → 프로필(공개 범위 3단계·최소 강사료·가능 요일·인정자격·경력조회 동의서) → 제안 수신(조건 밖 제안은 안 옴) → 수락/거절(사유 불요) → 준비(교안 템플릿·명단 열람 전용) → 당일 체크인 → 피드백 요약(원문 비공개) → 정산(익월 10일·3.3%). 데모: lecturer-portal 7뷰.

### C. 매니저 — 매칭 운영
통합 접수함(출처 배지) → 분류·배정 → 구조화 상담 → 조건 매칭(요건 미충족 비활성+사유, 자기 배정 시 사유 기록) → 기관용/내부용 견적 분리 → 확정·리마인드 → 당일 모니터링 → 피드백 수집 → 정산·재출강. 데모: admin 12뷰.
