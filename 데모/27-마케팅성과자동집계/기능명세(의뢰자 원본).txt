[프로젝트 개요]
- 현재 수동으로 진행 중인 스마트스토어, 메타, 카카오, 구글 광고 성과 리포트
  취합 업무를 자동화하기 위한 사내용 웹 대시보드 구축 프로젝트입니다.

[프로젝트 배경 및 목표]
- 운영 중인 광고 채널과 소재 수가 증가함에 따라 엑셀을 활용한 수작업 데이터
  트래킹이 한계에 도달했습니다. 이에 각 광고 매체의 API를 연동하여 성과 데이터를
  일별로 자동 수집하고, 이를 주간 및 월간 단위로 분석할 수 있는 통합 대시보드를
  구축하고자 합니다. 궁극적으로는 수집된 데이터를 바탕으로 베스트 및 워스트 소재를
  추출하고, 다음 광고 기획에 활용할 수 있는 인사이트를 자동으로 얻는 것을 목표로
  합니다. 사내 사용 목적이므로 화려한 디자인보다는 정확한 데이터 집계와 직관적인
  정보 구조가 최우선입니다.

[과업 범위]

1. 수행 범위
- 상세 기획: 요구사항 정의서 기반 화면 설계 및 API 연동 데이터 매핑 문서 작성
- UI/UX 디자인: 사내 사용 목적에 맞춘 직관적이고 깔끔한 템플릿 기반 디자인 적용
- 프런트엔드 개발: PC 및 모바일 환경에서 확인 가능한 반응형 웹 대시보드 구현
- 백엔드 개발: 4개 매체 API 연동, 데이터 수집 배치 프로그램 개발
- 서버/DB/인프라 구성: 클라우드 환경 기반 데이터베이스 설계 및 호스팅 세팅

2. 상세 기능 요구 사항

2-1. 광고 성과 데이터 자동 수집
- 메타, 구글, 카카오모먼트, 네이버 4개 채널 API 연동
- 광고 성과 데이터 자동 수집 (일별 배치)

2-2. 자동 집계 대시보드
- 일별, 주간, 월간 단위 자동 집계 대시보드 구현
- 광고비, 매출, ROAS, CTR 등 핵심 지표 표기
- 채널별 및 전체 성과 비교가 가능한 웹 대시보드 구성
- 대시보드 내 소재 리스트 클릭 시 이미지 바로보기(URL 연동) 기능 지원

2-3. 소재별 목표 CPA 트래킹
- 소재별 목표 CPA 값을 직접 설정할 수 있는 기능
- 목표 CPA를 초과하는 소재를 매일 자동으로 트래킹해서 보여주는 기능
- 자동 온/오프 제어는 불필요하며, 확인 후 조치는 직접 수행할 수 있도록 구현

2-4. 베스트/워스트 소재 추출 및 인사이트 생성
- 주간 및 월간 단위 베스트/워스트 소재 자동 추출 (ROAS 기준)
- 다음 기획에 참고할 인사이트 자동 생성 (성과 데이터 및 소재 디자인 요소 분석 포함)
- Mcp, 클로드 등 기존 기술에서 활용할 수 있는 건 최대한 활용하여 구현

2-5. 관리자 기능
- 사내 인원 접속을 위한 로그인 및 권한 관리
- 각 채널별 API 연동을 위한 설정 페이지

[기술/제조 스택]
- 데이터 수집 및 웹 대시보드 구축에 적합한 최신 스택을 자유롭게 제안해 주시기 바랍니다.

  일정 조율이 가능한 업체 우대
