# 위시켓 지원서 — 마케팅 성과 자동 집계 및 인사이트 도출 대시보드 개발

---

안녕하세요. 공고를 읽고 **먼저 만들어 본 뒤** 지원합니다.

- 대시보드: https://jeonjaeman.github.io/demo-sites/adsum/
- 관리자: https://jeonjaeman.github.io/demo-sites/adsum/admin/

목데이터지만 **모든 수치가 화면에서 실제로 계산됩니다.** 기준을 바꾸면 값이 바뀝니다.

**1. 요구사항 2-2의 "매출"을 줄 수 있는 API가 4개 중 어디에도 없습니다**

광고 API가 반환하는 매출은 각 매체가 **자체 추적한 전환매출**이지 회계상의 매출이 아닙니다.
그런데 판매 채널이 스마트스토어입니다. **스마트스토어는 외부 스크립트 설치가 자유롭지 않아 메타 픽셀을 직접 심을 수 없습니다.** 별도 솔루션을 경유하지 않으면 메타·카카오가 신고하는 전환매출이 0이거나 심하게 과소로 나옵니다. 4개 광고 API만 붙이면 **대시보드의 매출·ROAS 열이 비거나 거짓이 됩니다.**

→ **네이버 커머스API(스마트스토어 주문)를 5번째 소스로 추가**했습니다. 데모 상단 [매출 기준]을 세 번 눌러 보세요.

| 기준 | ROAS |
|---|---|
| 채널 합산 (각 매체 신고값) | **360%** |
| 광고 기여 (중복 제거) | **248%** |
| 전체 실매출 (MER) | **303%** |

같은 광고비인데 셋 다 다릅니다. 광고 API만 붙이면 **첫 번째 숫자만 보입니다.**

**2. 채널 ROAS를 더하면 실매출을 넘습니다**

메타는 클릭 7일, 구글은 기본 30일, 네이버는 간접전환 추적 7~20일 — 기여 인정 기간이 전부 다릅니다. 한 건의 주문을 세 매체가 각각 전액으로 신고하므로 단순 합산은 구조적으로 부풀려집니다.
데모 데이터 기준 중복 신고율은 **45%** 로 계산됩니다.

→ [중복 진단] 카드에서 격차를 금액과 비율로 보여주고, 채널별 표의 합계 행에 **"기간이 달라 합산 불가"** 를 명시한 뒤 MER 행을 따로 두었습니다.

**3. 일 1회 수집이면 어제 숫자가 영원히 틀립니다**

전환은 지연 도착합니다. 구글은 전환 지연으로 과거 리포팅 값이 몇 주간 계속 갱신되고, 메타는 2026년 3월 어트리뷰션 개편으로 **측정법 자체가 바뀌었습니다**(링크 클릭만 인정, 인게이지드 뷰 10초→5초). D+1에 한 번 긁고 다시 조회하지 않으면 그 날짜는 성숙도 62% 수준에서 굳습니다.

→ [수집 방식] 토글로 `일 1회 수집` ↔ `롤링 재수집`을 바꿔 보세요. **과거 60일 수치가 전부 달라집니다(채널 신고 매출 34% 차이).** 최근 구간은 확정/잠정 배지로 구분했고, 관리자에서 재수집 창(3/7/14/30일)에 따른 회수량과 API 호출 수의 트레이드오프를 그래프로 비교할 수 있습니다.

**4. 전환 0건 소재는 "목표 CPA 초과" 목록에서 사라집니다**

CPA는 광고비÷전환수라 전환이 0이면 정의되지 않고, 따라서 초과 비교에 걸리지 않습니다. **정작 가장 위험한 소재(돈만 쓰고 전환 0)가 목록에서 통째로 빠집니다.**

→ 판정을 `정상 / 목표 초과 / 무전환 소진 / 판정 보류` 4단계로 나눴습니다. [비교 보기]를 누르면 요구사항 그대로 구현했을 때 몇 건이 사라지고 그 소재들이 얼마를 썼는지 숫자로 나옵니다(데모: **3건 · 269만원**).

**5. "이미지 바로보기(URL 연동)"는 그대로 만들면 며칠 뒤 깨집니다**

메타의 `image_url`·`thumbnail_url`은 서명이 붙은 임시 URL이며 **영구 링크가 없습니다.**
→ 소재 표의 [이미지] 버튼에서 세 방식을 비교할 수 있습니다. ① 저장된 URL(**실제로 403 만료 오류가 뜹니다**) ② `image_hash` 재해결 ③ 자체 스토리지 사본.

**6. 카카오모먼트 심사는 일정에 넣고 계산할 수 없습니다**

우대사항에 적어 주신 그 항목입니다. 비즈니스 앱 전환 → 본인인증 → 권한 심사가 선행되는데 **심사 기간이 공식적으로 명시돼 있지 않습니다.**
→ 착수 첫날 신청을 걸고 **3채널 자동 수집 선오픈 + 카카오 후결합** 구조로 설계했습니다. 심사 전까지는 CSV 업로드로 메우고, 대시보드에서 해당 채널에 **"수동 수집" 배지**를 붙여 자동과 구분합니다.

**7. LLM 인사이트에 사내 매출이 그대로 실려 나갑니다**

"MCP, 클로드 등을 최대한 활용" 요청을 그대로 따르면 프롬프트에 광고비와 매출이 들어갑니다.
→ **판단은 서버에서 계산하고 모델은 문장만 씁니다.** ROAS는 전체 평균 대비 지수로, 광고비는 규모 버킷(L/M/S)으로 치환합니다. [LLM 전송 페이로드 미리보기]에서 실제 JSON을 열어 보시면 **금액이 한 건도 없습니다.**

※ 공개 문의에 올라온 "인사이트가 텍스트 요약인가 정량 스코어인가" 질문에는 — **데모에 둘 다 넣었습니다.** 5개 축(형식·톤·인물·가격표기·주조색) 정량 스코어카드를 먼저 계산하고, 그 결과를 문장으로 옮깁니다.
※ **"자동 온/오프 제어는 불필요"** 는 정확한 판단이라고 봅니다. 자동 제어는 어트리뷰션이 흔들리는 데이터 위에서 가장 먼저 사고가 나는 기능입니다.

**유사 프로젝트 경험**

수집 파이프라인·집계 대시보드·외부 API 커버리지 진단을 각각 만들어 왔습니다. 모두 직접 만든 것이고 지금 열어 보실 수 있습니다.

- **리드 수집 파이프라인 백오피스** — https://jeonjaeman.github.io/demo-sites/bizseed/
  수집 → 정제 → 적재, 실패 코드·재시도 관리. **외부 API가 원하는 데이터를 안 주는 상황**을 화면으로 다룬 사례입니다.
- **설문 응답 집계·시각화 대시보드** — https://jeonjaeman.github.io/demo-sites/classpulse/
  필터·교차분석·차트가 실제로 계산되는 구조. 소규모 표본에서 통계가 왜곡되는 지점을 화면에서 차단했습니다.
- **기업 산업지도 + 관리자** — https://jeonjaeman.github.io/demo-sites/lumina/
  외부 데이터 API의 **커버리지를 진단하는 화면**(재무 API가 중소기업의 12.3%만 커버) — 이번 건의 [연동 상태]·[중복 진단]과 같은 계열의 문제입니다.

**저희가 잘하는 것**

- **피드백 반영이 빠릅니다.** AI 도구를 반복 작업(표 UI·관리자 목록·테스트 데이터 생성)에 활용해 수정 요청을 대개 **당일 반영**합니다. 실사용자가 마케터 1인이라 "써 보고 고치는" 사이클이 짧을수록 결과가 좋아집니다.
- 웹디자이너 출신입니다. 사내 대시보드에서 디자인이 중요한 이유는 예뻐서가 아니라, **"이 숫자를 믿어도 되는가"가 화면 구조에서 결정되기 때문**입니다. 확정/잠정 배지, 합산 불가 표기, 판정 기준 노출 — 전부 신뢰를 만드는 정보 설계입니다. 안 믿기면 마케터는 결국 엑셀로 돌아갑니다.
- **오픈 후 운영도 함께 봅니다.** 광고 API는 정책이 바뀝니다(메타는 올해 3월에 이미 한 번 바꿨습니다). 이런 프로젝트는 납품으로 끝나지 않습니다.

**견적**

단가 일 100,000원 기준으로 계산했습니다.

| 작업 | 공수 |
|---|---|
| 상세 기획 · 화면 설계서 · API 데이터 매핑 문서 | 6일 |
| UI/UX 디자인 (대시보드 + 관리자 · 반응형) | 7일 |
| 프런트엔드 (KPI·차트·채널·소재·인사이트·반응형) | 14일 |
| 백엔드 — 표준 스키마 및 DB 설계 | 4일 |
| 백엔드 — 채널 어댑터 4종 | 10일 |
| 백엔드 — 배치 · 롤링 재수집 · 재시도 · rate limit | 6일 |
| 커머스API(스마트스토어 주문) 연동 | 3일 |
| 로그인 · 권한 3역할 | 3일 |
| 인사이트 파이프라인 (정량 스코어링 + LLM + 마스킹) | 5일 |
| 인프라 (클라우드·DB·스케줄러·배포·백업) | 5일 |
| QA · 산출물(기획서·화면설계서·DB설계서·소스) | 5일 |
| **합계** | **68일 · 6,800,000원** (VAT 별도) |

**일정에 대한 정직한 견해** — 68공수를 캘린더 30일 안에 1인으로 끝낼 수 없습니다. 2인 병행으로도 빠듯하고, 카카오 심사는 애초에 저희가 통제할 수 없습니다. 그래서 **범위를 두 단계로 나누되 금액은 예산 안에서 그대로** 제안합니다.

| 단계 | 기간 | 범위 | 공수 |
|---|---|---|---|
| **1차** | 착수 후 **30일** (프런트 1 + 백엔드 1 병행) | 3채널 자동 수집 + 커머스API 실매출 + 통합 대시보드 + 목표 CPA + 권한 + 인프라 + 산출물 | 44일 |
| **2차** | 카카오 심사 완료 기준 **약 3주** | 카카오모먼트 결합 · 인사이트 고도화 · 소재 이미지 아카이빙 | 24일 |

**1차 오픈 시점에 엑셀 수작업은 이미 사라집니다.** 카카오는 그때까지 CSV 업로드로 메웁니다.

**의뢰자 부담 영역 (견적 외 실비)**

- 클라우드·DB·오브젝트 스토리지 (월 실비, 초기 규모 기준 **월 5~12만원 수준** — 공개 문의에도 나온 항목입니다)
- 각 매체 **광고 계정 접근 권한** (메타 시스템 사용자, 구글 애즈 MCC, 네이버 검색광고 API 키)
- **카카오모먼트 비즈니스 인증 및 권한 신청** — 사업자 명의로만 가능하며 **명의자 본인인증이 필요**합니다. 절차는 대행해 드립니다
- **네이버 커머스API 애플리케이션 등록** (스마트스토어 판매자 계정)
- Claude API 사용료 (종량 과금 — 주 1회 인사이트 생성 기준 월 1만원 내외)
- 유료 폰트·이미지 라이선스 (데모는 무료 폰트만 사용했습니다)

김포 오프라인 미팅 가능합니다. 미팅에서 **매출의 정의(결제 완료 / 배송 완료 / 취소·반품 차감 시점)** 와 **커머스API 연동 여부** 두 가지만 정하면 바로 착수할 수 있습니다. 데모를 함께 보며 논의드리고 싶습니다. 감사합니다.
