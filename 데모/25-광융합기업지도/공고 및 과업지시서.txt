1. 사업 개요

 1.1 사업명
  지도 기반 기업 정보 제공 플랫폼 구축 사업

 1.2 목적 및 필요성
  - 사용자가 위치 기반으로 기업의 분포를 한눈에 파악할 수 있는 시각적 인터페이스 제공
  - 지도를 매개로 한 직관적인 기업 탐색, 상세 정보 확인, 필터링 및 검색 기능 제공을 통한
    사용자 편의성 극대화
  - 효율적인 데이터 관리를 위한 관리자 도구(Admin) 구축

 1.3 과업 범위
  - 프론트엔드 : 반응형 웹 서비스 개발 (PC, 모바일 최적화)
  - 백엔드 : 데이터 API 서버 및 데이터베이스 설계
  - 관리자 페이지(Admin) : 기업 데이터 CRUD, 지도 마커 매핑용 좌표 변환(Geocoding) 도구, 기본통계
  - 인프라 및 API 연동 : 국내 지도 API 연동(Kakao, Naver 등), 금융공공데이터 API 연동
    (매출액, 영업이익, 당기순이익 등), 국민연금공단 API 연동(종업원 수 등), 호스팅 및 도메인 설정
    * 코스피, 코스닥, 코넥스 등 연동 가능 기업 外 일반 기업 부문은 엑셀 데이터 연동 고려

2. 기술 스택 및 개발 요구사항

  구분        권장 기술 스택                      비고
  Frontend    jsp, css, javascript, react         SEO 및 성능 최적화(SSR 권장)
  Backend     Spring, java                        안정적이고 빠른 API 처리
  Database    MySQL                               공간 데이터 처리(위도, 경도) 최적화
  Map API     카카오맵 API / 네이버 지도 API       국내 주소 및 POI 검색 최적화

3. 상세 기능 요구사항

 3.1 사용자 페이지 (Web Frontend)

  ① 지도 인터페이스 및 마커 표시
  - 지도 연동 : 카카오/네이버 지도 API 기반의 지도 화면 렌더링
  - 클러스터링 : 다수의 마커가 밀집되어 있을 경우, 줌 레벨에 따라 마커를 그룹화(Clustering)하여 표시
  - 커스텀 마커 : 기업의 카테고리/업종별로 직관적인 맞춤형 커스텀 마커 아이콘 표시
  - 즐겨찾기 : 사용자 즐겨 찾는 기업, 목록 및 클릭 시 해당 기업 이동 및 상세 기능

  ② 상세 정보 제공 (사이드바 / 바텀시트)
  - 좌우 2분할 레이아웃 : 좌측(또는 우측)은 검색 및 리스트/상세 영역, 나머지는 지도 영역으로
    배치 (PC 기준)
  - 모바일 최적화 : 모바일 환경에서는 하단 바텀시트(Bottom Sheet) 형태로 슬라이드 업/다운
    인터페이스 적용
  - 상세 페이지 구성 항목
    · 기업 기본 정보 : 사명, 대표자, 업종, 설립일, 주소, 연락처 등
    · 소개 글 및 주요 서비스/제품
    · 길 찾기 연동(협의 사항) : 카카오맵/네이버 지도 외부 링크 연결
    · 시각 자료(협의 사항) : 기업 로고, 전경 이미지, 소개 이미지 등

  ③ 검색 및 필터링 기능
  - 키워드 검색 : 기업명, 업종, 주소, 키워드 검색
  - 위치 기반 검색 : '현재 지도 영역 내 재검색' 기능
  - 다중 필터링 : 지역(시/도, 구/군), 산업 분류(8대, 9대), 매출액 구간, 업종 분류,
    기업 규모(대,중,소) 등에 따른 다중 조건 필터

 3.2 관리자 페이지 (Admin Backend)

  ① 기업 데이터 관리 (CRUD)
  - 기업 정보(주소, 위치, 시각자료, 소개, 주요 서비스/제품 등) 수동 등록, 수정, 삭제 기능
  - 대량 등록(Excel) : 기업 정보를 엑셀 파일(CSV/XLSX)로 일괄 업로드/다운로드 기능
  - 지오코딩(Geocoding) 자동화 : 주소 입력 시 위도/경도 좌표를 자동으로 변환하여 DB에 저장하는
    파이프라인 구축, API 변환 실패 건에 대한 수동 좌표 입력 및 수정 기능
  - 공통 코드 및 분류체계 관리 : 분류, 기업형태, 지역 등 동적 카테고리 관리 기능

  ② 회원 및 권한 관리
  - 시스템 관리자 계정 생성 및 권한 관리

4. 비기능 및 성능 요구사항

  - 보안 및 규정 준수
  - 개인정보 보호 : 사용자 및 기업 담당자의 개인정보 수집 시 암호화 처리(SHA-256 등) 및
    HTTPS 보안 프로토콜 필수 적용
  - 웹 접근성 및 표준 : 웹 표준 및 크로스 브라우징(Chrome, Safari, Edge 등) 준수
  - 성능 최적화 : 지도 위 수백~수천 개의 마커를 렌더링할 때 끊김 없도록 데이터 페이징 및
    가상 스크롤(Virtual Scroll) 기법 적용
  - 보안 : OWASP Top 10 기준의 취약점 방어 조치 (XSS, SQL Injection 등 예방)
  - 데이터 동기화(협의 사항) : 금융 공공데이터 및 국민연금공단 API의 응답 지연을 대비하여,
    실시간 API 호출이 아닌 스케줄러를 통한 주기적(분기/반기/연 단위) 자체 DB 동기화 로직 구현

 5.1 납품 산출물 목록
