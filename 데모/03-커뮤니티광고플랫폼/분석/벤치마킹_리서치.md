# 벤치마킹 리서치
**커뮤니티 게시판 + 자체 광고 시스템(광고주 셀프서브 + 어드민) 통합 구축 프로젝트**
리서치 기준일: 2026-07 / 방법: 웹 검색 기반 사실 확인(확인 불가 항목은 "추정" 표기)

---

## 1. 국내 (5)

### 1.1 당근(당근마켓) — 하이퍼로컬 커뮤니티 위에 세운 셀프서브 지역광고의 국내 대표 사례
- **서비스 개요**: 중고거래에서 출발해 '동네생활' 커뮤니티, 비즈프로필(동네 가게 프로필)로 확장한 하이퍼로컬 플랫폼. 광고 사업은 [당근비즈니스](https://business.daangn.com/)로 분리 운영.
- **커뮤니티 UX 특징**: 위치 인증 기반 동네 피드, 동네생활 질문/후기 글, 매너온도(신뢰 지표), 가게 소식 구독. 커뮤니티 콘텐츠와 광고(비즈프로필 소식)가 같은 피드 문법을 공유하는 것이 특징.
- **광고/수익화 모델**: 완전 셀프서브. 앱 내 [광고] 메뉴에서 광고 계정 생성 → 비즈프로필 제작 → "글과 사진만 있으면 3분 만에" 집행. 상품은 피드 광고, 카탈로그 광고, 비즈프로필/소식 광고 등이며 CPC 과금. 반경 타기팅 광고로 지역·성별·연령·관심사 타기팅. 결제는 **광고캐시 선충전** 방식(유상캐시 + 신규 무상캐시, 무상캐시 우선 소진·만료일 존재) — 첫 충전 사용액 일부 환급 같은 프로모션 캐시로 광고주 온보딩을 유도.
- **참고 포인트**: ① 광고주용 "캐시 충전 + 무상캐시(쿠폰)" 지갑 모델 — 데모의 셀프서브 결제 화면에 그대로 이식 가능. ② 광고 클릭 랜딩을 외부 URL이 아닌 앱 내 프로필(비즈프로필)로 받는 구조. ③ 비전문가 광고주를 위한 초간단 캠페인 생성 플로우(3분 완성).

### 1.2 블라인드(Blind) — 익명 직장인 커뮤니티 + B2B 광고(피드/전면/액션태그)의 결합
- **서비스 개요**: 회사 이메일 인증 기반 익명 직장인 커뮤니티. 한국 기준 MAU 200만 내외, 유저당 일 평균 이용 40분 수준으로 알려짐.
- **커뮤니티 UX 특징**: 완전 익명이지만 "회사명 배지"가 붙는 반(半)식별 구조, 라운지/토픽 게시판, 좋아요·댓글 중심. 익명성 유지가 신뢰의 핵심이라 광고도 콘텐츠 침해를 최소화하는 형태.
- **광고/수익화 모델**: [블라인드 광고](https://www.teamblind.com/kr/ad-inquiry)는 영업 접수형(셀프서브 아님, 추정: 대행/직접 영업 중심). 상품: **피드 광고**(게시글 사이 이미지/영상 네이티브), **앱 종료 시 전면 배너**(안드로이드, CTR 5~8%로 소개됨), **액션태그**(게시글에 특정 키워드가 포함되면 해당 단어에 광고 랜딩 링크가 자동 태깅되는 문맥 광고), 채용 채널 고정 노출 + 서베이 결합 상품.
- **참고 포인트**: ① 우리 5종 소재 중 "피드 카드형 + 전면 팝업형"의 국내 실증 사례(전면은 '앱 종료 시점' 등 노출 타이밍 제어가 핵심). ② 키워드 기반 문맥 광고(액션태그) — 커뮤니티 텍스트 자산을 광고 인벤토리로 바꾸는 발상. ③ 익명 커뮤니티에서도 회사/직군 데이터를 활용한 타겟팅이 가능하다는 점.

### 1.3 에브리타임 — 폐쇄형 대학생 커뮤니티의 배너 지면 상품화
- **서비스 개요**: 대학교 인증 기반 시간표+익명 게시판 커뮤니티. MAU 300만 돌파, 월 평균 학생 251만 명 수준.
- **커뮤니티 UX 특징**: 학교별 폐쇄형 게시판, 완전 익명 닉네임, 게시판 세분화(자유/비밀/홍보/동아리 등). 익명성 때문에 신고·제재 정책이 매우 중요하게 다뤄지는 서비스.
- **광고/수익화 모델**: 배너 광고 상품이 **지면 위치별로 7종**(홈 배너, 홈 카드 배너 등이 인기)으로 나뉘어 판매되고, 지면에 따라 대학/지역 타기팅 가능 여부가 다름. 셀프서브 대시보드는 없고 매체사/대행 접수형(추정). 이외 게시판에 직접 글을 올리는 바이럴형 집행이 대행 시장에서 활발.
- **참고 포인트**: ① "광고 소재 유형"이 아니라 **게재 위치(지면) 단위로 광고 상품을 정의·판매**하는 모델 — 우리 5종 소재를 지면 상품 카탈로그로 문서화할 근거. ② 지면별로 타기팅 가능 옵션이 다르다는 설계. ③ 커뮤니티 게시판에 침투하는 비공식 바이럴 광고 문제 → 공식 광고 상품과 신고/필터링 정책이 함께 필요하다는 반면교사.

### 1.4 네이버 밴드 — 그룹 커뮤니티 내 '소셜광고' 셀프 집행 모델
- **서비스 개요**: 모임(그룹) 기반 국민 커뮤니티 앱. 밴드 리더가 자신의 밴드를 키우기 위해 직접 광고를 집행하는 독특한 구조.
- **커뮤니티 UX 특징**: 폐쇄형 밴드 단위(공개/비공개), 게시글+댓글+투표+일정 등 모임 운영 도구 일체형. 투표 기능이 기본 탑재된 점이 우리 요구사항(투표)과 유사.
- **광고/수익화 모델**: **소셜광고** — 새소식/밴드홈 노출 광고, 특정 게시글을 멤버에게 푸시하는 **알림 광고**, 스티커를 보상으로 주고 밴드 가입을 유도하는 **보상형 광고**. 최근 정책 개편으로 밴드(소셜광고) 계정만 있으면 **누구나 셀프 집행 가능**해짐. 별도로 외부 광고주 대상 디스플레이 광고(네이버 성과형 DA)도 병행(추정: GFA 체계 편입).
- **참고 포인트**: ① "커뮤니티 운영자가 곧 광고주"가 되는 내부 순환형 광고 — 우리 플랫폼에서도 게시판 운영자/입점사가 자기 글을 부스팅하는 상품으로 확장 가능. ② 알림(푸시)형 광고 상품이라는 6번째 소재 후보. ③ 보상형 광고(가입 시 리워드)로 커뮤니티 성장과 광고를 결합.

### 1.5 카카오모먼트/비즈보드 — 국내 셀프서브 광고 어드민(심사·미리보기·대시보드)의 표준
- **서비스 개요**: 카카오톡 트래픽 기반 성과형 광고 플랫폼. 우리가 만들 "광고주 셀프서브 대시보드 + 심사 어드민"의 국내 표준 레퍼런스로 선정.
- **커뮤니티/지면 특징**: 카카오톡 채팅탭 상단 비즈보드(배너), 뷰/서비스 지면 네이티브 등 — 초고트래픽 지면에 소형 배너를 표준화한 사례.
- **광고/수익화 모델**: 완전 셀프서브. 캠페인>광고그룹>소재 3계층, 소재 등록 시 **미리보기 영역**에서 노출 형태 확인, 등록 소재는 **영업일 최대 2일 내 심사**, 심사 결과는 메일/SMS/카카오톡 알림 + 대시보드의 소재별 심사 상태(승인/보류/보류사유/재심사요청)로 관리([심사 가이드](https://kakaobusiness.gitbook.io/main/ad/moment/intro/ad-audit)).
- **참고 포인트**: ① **소재 심사 워크플로 UI**(대기→승인/보류→보류사유 표시→재심사 요청)를 그대로 벤치마킹 가능. ② 소재 등록 화면 내 실시간 미리보기. ③ 캠페인/광고그룹/소재 3계층 구조와 지표(노출·클릭·CTR·비용) 대시보드 표준.

## 2. 해외 (5)

### 2.1 Reddit — 커뮤니티 네이티브 광고 + 셀프서브 Ads Manager의 글로벌 원형
- **서비스 개요**: 서브레딧 단위 익명(닉네임) 커뮤니티의 세계 최대 사례. 광고는 Reddit Ads Manager(ads.reddit.com) 셀프서브.
- **커뮤니티 UX 특징**: 업/다운보트, 대댓글 트리, **스포일러/NSFW 태그**, 플레어(태그), 카르마(활동 점수), 서브레딧별 자치 모더레이션 — 우리 요구사항(투표·스포일러·신고)의 원조 격.
- **광고/수익화 모델**: 셀프서브 포맷으로 이미지·비디오·**프리폼(텍스트+이미지 혼합 네이티브)**·캐러셀·AMA 광고·**대화(댓글 스레드 내) 광고**·상품 카탈로그 광고 제공, 일 최소 예산 $5. 오가닉 글을 그대로 부스팅하는 프로모티드 포스트, Reddit Pixel 기반 전환 측정. **광고 심사 프로세스**가 문서화되어 있고(랜딩페이지 품질, 타겟 서브레딧 적합성 등), 민감 업종은 사전 승인 필요. **빈도 제한(frequency cap)** 은 매니지드 계정에만 열려 있어 소액 광고주 불만 요인.
- **참고 포인트**: ① 피드 카드형 광고를 "일반 글과 같은 카드 + Promoted 라벨"로 만드는 네이티브 문법. ② 심사 정책 문서 + 심사 사유 안내를 시스템에 내장. ③ frequency cap을 셀프서브에도 개방하면 차별화 포인트가 된다는 시사점. ④ 댓글 스레드 내 광고 슬롯이라는 인벤토리 발상.

### 2.2 Nextdoor — 로컬 커뮤니티 + AI 보조 셀프서브 Ads Manager
- **서비스 개요**: 이웃(동네) 인증 기반 로컬 커뮤니티. 당근의 미국판 대응물로, 2023~ Nextdoor Ads Manager 셀프서브 플랫폼을 자체 구축.
- **커뮤니티 UX 특징**: 실명+동네 인증, 피드/추천 요청 글 중심, 지역 비즈니스 페이지.
- **광고/수익화 모델**: **Quick Create(수 분 내 캠페인 생성) vs Advanced Create(정밀 타기팅)** 2트랙 캠페인 생성. AI 카피/크리에이티브 어시스턴트, 자동 최적화, 홈오너십·소득 등 로컬 특화 타기팅, Nextdoor Pixel/CAPI 전환 측정, 날씨 조건부 노출까지 제공.
- **참고 포인트**: ① 초보 광고주용 "퀵 생성"과 전문가용 "고급 생성"을 분리한 온보딩 설계. ② AI 소재 생성 보조(카피 제안) — 데모의 차별화 기능 후보. ③ 조건부 노출(시간대/상황 트리거) 개념.

### 2.3 Discord — 보상형(리워드) 광고 'Quests'로 커뮤니티 반발 없이 광고 도입
- **서비스 개요**: 게임 중심 실시간 커뮤니티(서버) 플랫폼. 2024년 광고 도입 후 Quests가 주력 수익원으로 성장.
- **커뮤니티 UX 특징**: 서버-채널 구조, 역할(Role) 기반 **세분화된 권한 체계**(우리 4단계 권한의 확장판), 봇 기반 자동 모더레이션.
- **광고/수익화 모델**: [Quests](https://discord.com/ads/quests) — Video Quests(영상 시청), Play Quests(게임 플레이), Arena Quests(스폰서 게임 플레이 시간 연동) 등 **유저가 과업을 수행하면 보상을 받는 광고**. 유저의 50%+가 "Quests가 경험을 개선한다"고 응답. 셀프서브가 아닌 세일즈 주도형(추정).
- **참고 포인트**: ① "광고=보상"으로 재해석해 커뮤니티 거부감을 낮추는 UX(하단 슬라이드/바텀시트 소재에 리워드 요소 결합 가능). ② 역할 기반 권한 모델의 정교함. ③ 광고 성과의 서드파티 검증(측정 신뢰) 이슈.

### 2.4 Circle.so — 커뮤니티 SaaS의 공간(Space) 설계와 구독형 수익화
- **서비스 개요**: 크리에이터/기업용 화이트라벨 커뮤니티 구축 SaaS. 광고가 아닌 **멤버십 결제**로 수익화하는 대조 사례.
- **커뮤니티 UX 특징**: Space(게시판/채팅/이벤트/코스) 단위 조합형 구조, 공개/멤버 전용/유료 Space 혼합 운영, 리더보드·라이브 이벤트 내장.
- **광고/수익화 모델**: Stripe 연동 페이월 — 구독(월/분기/연), 일회성, 분할 결제, 20+ 통화 지원. 광고 시스템은 없음.
- **참고 포인트**: ① 게시판을 "Space 타입 조합"으로 모듈화하는 정보구조 — 우리 게시판 카테고리 설계에 응용. ② 광고 외 제2 수익모델(유료 멤버십/프리미엄 게시판)을 아키텍처에 열어두기. ③ 리더보드/활동 랭킹으로 커뮤니티 활성도를 견인하는 장치.

### 2.5 Facebook Groups / Meta Ads — 익명 참여 모더레이션과 광고 어드민의 세계 표준
- **서비스 개요**: 세계 최대 그룹 커뮤니티 + Meta Ads Manager(셀프서브 광고의 사실상 표준).
- **커뮤니티 UX 특징**: 그룹 내 **익명 게시 기능은 관리자가 켜야 활성화**되며, 일반 멤버에게는 익명이지만 **관리자/모더레이터와 Meta는 작성자 실명을 확인 가능**, AI가 익명 글을 우선 스캔해 정책 위반을 탐지. 익명 글도 동일한 커뮤니티 규정 적용.
- **광고/수익화 모델**: Meta Ads Manager — 캠페인 3계층, **모든 게재 위치(피드/스토리/릴스)별 실시간 미리보기**, **A/B 테스트(소재·타겟·게재위치 분할 테스트) 기본 제공**. 그룹 피드 내 광고 삽입도 집행됨(추정: 자동 게재위치의 일부).
- **참고 포인트**: ① "유저에겐 익명, 운영자/시스템에는 식별 가능"이라는 익명 커뮤니티 모더레이션의 정석 — 우리 신고/제재 설계의 기준. ② 게재 위치별 소재 미리보기 UI. ③ A/B 소재 테스트를 셀프서브 기본 기능으로.

## 3. 시사점 — 의뢰자가 생각지 못한 니즈 후보

| # | 항목 | 착안 벤치마킹 | 데모 반영 아이디어 |
|---|---|---|---|
| 1 | **광고 소재 심사 워크플로** (대기→승인/보류→보류사유→재심사 요청) | 카카오모먼트, Reddit | 어드민에 심사 큐 화면, 광고주 대시보드에 심사 상태 배지 + 반려 사유 + 재심사 버튼 |
| 2 | **게재 위치별 실시간 프리뷰** | Meta Ads Manager, 카카오 | 5종 소재를 실제 앱 화면 목업으로 즉시 프리뷰(피드/전면/배너/바텀시트/슬라이드 전환) |
| 3 | **빈도 제한(frequency cap) + 노출 타이밍 제어** | Reddit(캡 미개방이 소액 광고주 불만), 블라인드(앱 종료 시점 전면 노출) | 캠페인 설정 "1인당 일 N회 제한", 전면/바텀시트는 세션당 1회·"오늘 하루 보지 않기" |
| 4 | **광고주 지갑: 선충전 캐시 + 무상(프로모션) 캐시** | 당근(유상/무상캐시, 무상 우선 소진·만료, 첫 충전 환급) | 셀프서브에 충전/잔액/소진 내역 화면, 신규 가입 무상캐시 지급 |
| 5 | **A/B 소재 테스트** | Meta(분할 테스트 기본), Nextdoor(AI 자동 최적화) | 한 캠페인에 소재 2개 등록 → 노출 50:50 분배 → CTR 비교 리포트 |
| 6 | **익명이되 운영자는 식별 가능한 모더레이션 + 신고 자동화** | Facebook Groups, 에브리타임 | 신고 N회 누적 자동 블라인드, 어드민에서 익명 글 작성자 추적, 제재 이력 관리 |
| 7 | **캠페인 생성 2트랙: 퀵 생성 vs 고급 생성** | Nextdoor(Quick/Advanced Create), 당근(3분 완성) | 소상공인용 3스텝 마법사 + 전문가용 상세 설정 모드 분리 |
| 8 | **부스팅/알림형 광고 등 내부 순환 광고 상품** | 네이버 밴드(알림 광고), Reddit(오가닉 글 프로모트) | 일반 게시글 "끌어올리기" 상품, 게시글 푸시 알림 상품(6번째 소재 후보) |
| 9 | **보상형 광고 요소** | Discord Quests, 밴드 보상형 | 바텀시트 광고에 "확인하면 포인트 지급" 옵션 — 광고 거부감 완화 |
| 10 | **키워드 문맥 광고 및 지면 카탈로그 문서화** | 블라인드(액션태그), 에브리타임(지면별 7종 상품) | (확장 로드맵) 키워드 자동 태깅, 광고 상품을 "지면 단위 카탈로그" 페이지로 제공 |

**종합**: 국내외 공통 패턴은 (1) 광고를 커뮤니티 콘텐츠와 같은 문법의 네이티브 카드로 만들되 "광고" 라벨을 명확히 하고, (2) 셀프서브의 성패는 소재 등록기(미리보기+심사)와 지갑(충전/과금 투명성)에서 갈리며, (3) 익명 커뮤니티일수록 신고·제재·자동 모더레이션이 광고 신뢰(브랜드 세이프티)와 직결된다는 점입니다. 특히 심사 워크플로(1), 위치별 프리뷰(2), 빈도 제한(3)은 요청서에 없지만 실제 운영 시 반드시 필요해지는 기능이므로 데모 단계에서 가볍게라도 시연합니다.
