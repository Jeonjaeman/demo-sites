## 1. 등장인물

| 인물 | 원하는 것 | 불안한 것 |

| **경험 컬렉터**(소장·투자) | 작가 이력·전시·최근 거래가·에디션 여부 | ①시세 대비 적정성 ②진품보증·프로비넌스 ③위작 책임 ④추급권 부담(2027~) |

## 2. 시간순 여정 — 상황 / 화면 / 없으면 벌어지는 일

| # | 단계 | 상황 | 화면 | 없으면 |
|---|---|---|---|---|
| 1 | 발견 | 인스타 릴스·지인 링크, 80%+ 모바일, **특정 작품 하나를 보러 옴** | 작품 딥링크 `#/w/{slug}` | 원페이지뿐이면 그 작품을 못 찾고 이탈, 공유·재방문 불가 |
| 2 | 감상·몰입 | 미장 벽+액자, 스크롤 지그재그, 스토리 | 갤러리→스토리 2단(큐레이터 노트+추천 이유) | "예쁜 이미지 목록"과 구별 안 됨 — 서사가 구매 트리거 |
| 3 | 가격 판단 | "얼마지?" — 대부분 여기서 끝남 | 가격대 밴드+호당가 계산기+렌탈 월가 | **가격 신호 0이면 문의 버튼까지 못 감**(91% 근거) |
| 4 | 문의 | 이름·연락처·작품 지정 | 문의 폼(배송 견적 자동) | 층수·엘베·설치 정보 없으면 견적 왕복 3~4회 |
| 5 | 상담·실물 | 색감·실측 확인, 방문 | 조명 시뮬·벽에 걸어보기 | 색감 안내 없으면 **3개월 청약철회 사유** |
| 6 | 결제·배송·설치 | 운송 방식 결정 | 배송 안내(3변 합 판정) | 180cm↑ 전문운송 10만~15만 사전 고지 없으면 분쟁 |
| 7 | 사후 | 보증서·SNS 자랑·재판매 | 보증서·소유권/저작권 표 | 구매자 상업 이용→저작권 침해→갤러리로 항의 |

## 3. 역할별 시야 차이

| 데이터 | 구매자 | 운영자 |
|---|---|---|
| 가격 | 정책 모드에 따라 밴드/호당가/확정가/비공개 | 4모드 토글로 정책 결정 + 원가·협상 여지 |
| 작품 상태 | "구매 가능"만 기본 노출 | 5단 상태머신(판매중/예약/SOLD공개/아카이브/비공개) |
| 이미지 | 상한 1600px 감상용 | 원본 보관·파생본 자동 생성·게시 동의 플래그 |
| 문의 | 내 문의 1건 | 전체 접수/응대/성사 파이프라인 |
| 법적 의무 | 고지를 받는 쪽 | 신고 판정기·유통 대장·추급권 필드의 주체 |

## 4. 기능별 존재 이유 (전수)

- **지그재그 갤러리(시작칸 랜덤)** — 지정 레퍼런스의 핵심 미학. 기계적 교대는 템플릿으로 읽힘
- **가격 3단 신호** — A1(91% 가격 투명성)과 문의 관행의 양립
- **작품 딥링크+링크 복사** — 인스타 유입 보존(A2)
- **스토리 2단** — 오픈갤러리 검증 구조, 정서적 소유 서사
- **호당가 계산기(구간 보정)** — C3 실무 관행 반영, "최종가는 문의" 논리 근거
- **조명 시뮬** — B3 고지의무의 인터랙션화
- **벽에 걸어보기** — 의뢰자 미장 벽 은유의 기능 완성(D2)
- **해상도 정책·SOLD 상태머신** — 판례 대응(A3)이자 성능(A4)·도용 방지(C1)
- **배송 견적 자동** — C2 왕복 제거
- **철회 판정·고지 체크** — B4
- **프로비넌스·보증서** — B7 무과실 담보책임 방어
- **신고 판정기·유통 대장·추급권 필드** — B1·B2 (시행 1개월/시행 예정 법)
- **렌탈 CTA** — D1 진입장벽 해소

## 5. 비는 구멍 (미팅 확인 필요 10건)

4. 원화/에디션/프린트 구분
5. 렌탈 도입 여부
6. 보증서 발급 주체·표준 감정서 적용
7. 판매완료작 노출 정책·작가 게시 동의
8. 배송·설치 범위와 비용 부담
9. 해외 배송 (데모는 국내 한정)
10. 사이트 내 결제 여부 (PG·통신판매 신고)
