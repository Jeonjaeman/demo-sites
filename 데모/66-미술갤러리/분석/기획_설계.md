# MURO 무로 — 그림 구매 갤러리 사이트 기획 설계

> 의뢰 브리프: 그림 구매 고객용 반응형 웹(폰+PC), 미술 전문 웹디자이너급 감각,
> 그림 선택 → 스토리 연결, 유럽 미장 벽 + 액자 지그재그 배치, 지정 레퍼런스 immersive-g.com, 구매 문의 필수.
> 분석일 2026-08-16~17. 데이터는 전부 가상. 브랜드명 MURO(무로) = 이탈리아어 '벽'.

## 0. 한 줄 결론

"감각적인 갤러리 화면"만 만들면 실패한다. **① 가격 신호가 0이면 문의가 안 오고(구매자 91%가 가격 투명성 요구) ② 미술서비스업 신고제가 지난달(2026.7.26) 시행되어 운영 주체에 따라 신고 의무가 갈리고 ③ 고해상 이미지·판매 후 게시는 판례가 제한**한다. 이 셋을 화면으로 풀어 넣은 갤러리 사이트가 이 데모다. 지정 레퍼런스(immersive-g.com — Awwwards SOTD)는 "참고"가 아니라 **재현·능가** 대상으로 vw 단위까지 실측해 이식했다.

## 1. 명시 니즈 vs 숨은 니즈

| 의뢰자가 말한 것 | 실제로 뜻하는 것 |
|---|---|
| "구매 문의가 있어야 해" | 즉시 결제가 아닌 문의 기반 = 미술 유통 표준(작가 가격 방어·호당가·고가 거래 부담). **"가격을 못 쓴다"가 아니라 "확정가를 못 박는다"** → 가격대 밴드·호당가 계산기·렌탈 월가의 3단 신호로 양립 |
| "그림 선택 시 스토리 연결" | 장식이 아니라 **전환 장치**. 미술품은 스펙 비교 불가 → 서사가 유일한 차별화. 오픈갤러리의 「큐레이터 노트」+「추천 이유」 2단 구조가 국내 표준 |
| "핸드폰 혹은 컴퓨터" | 인스타 유입 전제 → **작품별 딥링크·OG·모바일 우선**이 실제 요구 |
| "미술 전문 웹디자이너" | 템플릿 쇼핑몰 거부. 작품이 주인공, UI가 물러서는 조판(IG의 2색·weight 400 단일·radius 0) |
| "유럽 미장 + 액자" | 화이트큐브가 아니라 **"내 집 벽" 은유** = view-in-room의 원시 버전 → 벽 프리셋 전환 기능으로 완성 |

**비는 구멍(미팅 확인)**: ① 운영 주체 — 갤러리인가 작가 본인인가(신고 의무 유무가 갈림) ② 가격 노출 4택(비공개/밴드/호당가/확정가) ③ 작품 수·증가 속도 ④ 원화/판화(에디션) 구분 ⑤ 렌탈 여부(하면 신고 업종 추가) ⑥ 보증서 발급 주체 ⑦ 판매완료작 노출 정책 ⑧ 배송·설치 범위 ⑨ 해외 배송(데모는 국내만) ⑩ 사이트 내 결제 여부(PG 심사·통신판매 신고).

### C. 운영 중 터짐
- **C1 우클릭 방지는 방어가 아님**(스크린샷·개발자도구 무력) → 해상도 상한(A3와 동일 수단)+타일 확대+크레딧 오버레이+관리자에 무력화 시연 패널
- **C2 문의 폼이 배송 정보를 안 받으면 견적 왕복 3~4회** — 3변 합 180cm↑/유리액자=전문운송(수도권 10만~15만) → **배송 견적 자동 계산**(작품 실측으로 3변 합 판정+층수/엘베/설치)
- **C3 호당가 단순 곱셈은 실제와 어긋남** — ≤10호 할증·>30호 체감 보정 관행 → 계산기에 **구간 보정 계수** 실반영, "최종가는 문의로 확정" 연결
- **C4 판매완료작 정책 부재** → 5단 상태머신 + 「지나간 작품」 아카이브 분리

### D. 있으면 강해짐
- **D1 렌탈 2번째 CTA** — 오픈갤러리 검증 모델(월 작품가 1~3%·3개월 교체·렌탈료 구매 차감) = "실패하면 어쩌지" 해소, 미술품 대여·판매업(B1)과 연결
- **D2 벽에 걸어보기** — 의뢰자의 미장 벽 아이디어를 실측 스케일 view-in-room으로 완성(공간 프리셋+조명 토글 결합)
- **D3 캡션 규격 고정** — `작가·《제목》·연도·재료·크기(cm/호)·에디션·액자` 미입력 시 저장 차단

### 적용 원칙 (실측에서 도출한 7계명)
1. 1440 기준 vw 토큰 시스템(`--sp-N`) — 고정 px 레이아웃 금지
2. 색 2개(미장 아이보리+잉크)+골드 1포인트(커머스 최소한), weight 세리프 400 축, radius 0, 자간 0
3. 지그재그 = 시작칸 랜덤 굴림(2~7)·반대편 오프셋 — 기계적 좌우 교대 금지
4. 작품 간 27.78vw(400px) — 여백이 급을 만든다
5. 리빌 = opacity 1.9s ease-in-out 단일 + 커스텀 lerp 스크롤(velocity 미세 왜곡) — 튀어오름 금지
6. 미장 벽 = 생성 텍스처를 저채도 블렌드로 절제(두꺼운 금박 액자·드롭섀도 도배 = AI스러움), 액자는 얇은 몰딩+미세 그림자

**공개(index)** — 미장 벽 위 액자 지그재그
1. 홈 스크롤 갤러리: 히어로(브랜드+대표작) → 액자 지그재그 ×10(리빌 1.9s·LQIP 베일·시차) → 아카이브 → 문의
2. 작품 상세 오버레이(`#/w/{slug}`): 대형 이미지(해상도 정책 표기)·표준 캡션·**스토리 2단(큐레이터 노트+추천 이유)**·호당가 계산기(구간 보정)·조명 시뮬·**벽에 걸어보기**(공간 프리셋+실측 스케일)·프로비넌스·보증서·소유권/저작권 표·배송 견적·**CTA 2트랙(구매 문의/3개월 걸어보기)**·링크 복사
3. 구매 문의 폼: 작품 자동 지정·배송 자동 판정(3변 합)·층수/엘베/설치·철회 고지 체크·커미션 동의 단계·프리필+예시 전송
4. 지나간 작품(아카이브): SOLD 저해상·게시 동의 필터
5. 푸터: 사업자정보·통신판매/미술서비스업 신고번호 칸·저작권 고지·가상 데이터 명시

**관리자(admin)** — 대시보드 표면
6. 작품 관리: 캡션 필수 검증·5단 상태머신·게시 동의·가격 정책 4모드
7. 문의 관리: 접수/응대/성사 상태·작품별 집계
8. **리스크 콘솔** ★: 신고 판정기·추급권 판정+요율 시뮬·철회 판정기·유통 내역 대장·계도 카운트다운
9. 성능·보호 패널: 전송량·파생본·워터마크 비교·우클릭 무력화 시연
