# MURO 무로 — 원화 갤러리 데모

> 그림 구매 고객용 반응형 갤러리. 유럽 미장 벽 + 액자 지그재그 + 작품 스토리 연결 + 구매 문의.
> 지정 레퍼런스 immersive-g.com(Awwwards SOTD)을 vw 단위까지 실측 이식. 데이터 전부 가상.

## 화면

| 화면 | 내용 |
|---|---|
| index.html | 미장 벽 갤러리 — 히어로 → 액자 지그재그 스트림(10점) → 지나간 작품 → 구매 문의 → 푸터 |

## 체험 시나리오 (입력 없이 클릭만)

1. 홈 스크롤 — 액자가 1.9초 페이드로 등장, 스크롤 속도에 따라 미세하게 휘어짐, 캡션 패럴랙스
2. 아무 액자 클릭 → 작품 이야기(큐레이터 노트·추천 이유) → 조명 토글·벽에 걸어보기·호당가 슬라이더
3. "구매 문의" → 폼 프리필 + 배송 자동 판정 → 원클릭 예시 전송
4. 관리자 → 가격 표시 4모드 전환 → 리스크 콘솔에서 사업 형태 바꿔 신고 판정 → 성능 패널 실측

## 기술

순수 HTML/CSS/JS(라이브러리 0). 해시 라우터·IntersectionObserver 리빌·velocity 왜곡·캡션 패럴랙스.
작품 10점·미장 질감은 Higgsfield 생성(실존 작가·작품 없음). 이미지 총 1.5MB·긴 변 ≤1600px(정책 겸 성능).
