    반려동물행사 / 키즈행사 / 팝업스토어 / 빈티지마켓 / 핸드메이드마켓

- 모집하는 판매품목·서비스 카테고리 (중복선택 가능 / 드롭다운)
  : 핸드메이드 / 패션,잡화 / 푸드,디저트 / 반려동물용품 / 키즈 체험 /

    친환경,업사이클 / 기타(상세설명)
- 참가비 (추가옵션 기능 있음 / 목록 입력, 금액설정 / 결제시스템)

[개최 행사관리]
────────────────────────────────────────────────

  ■ 참여자목록 버튼
  - 출석자 확인 (각 참여자 우측에 출석버튼{한번 더 누르면 취소} /
    출석용 QR코드 발급, 인쇄)
  - 우측상단에 엑셀다운 버튼
    (프로필/실명/나이/등급/판매품목/제품한줄소개/판매할 서비스,품목의 사진/
     포트폴리오 버튼/추가옵션 여부)
  - 참여자 클릭시 참여자의 정보 표시
    (프로필/실명/나이/등급/판매품목/제품한줄소개/판매할 서비스,품목의 사진/
     포트폴리오 버튼/추가옵션 여부 / 승인,거절버튼{거절시 거절된 이유 40자 이내})
