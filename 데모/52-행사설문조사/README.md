# CONFETTI 콘페티 — 행사 부스 모바일 웹 설문 (제안용 데모)

위시켓 공고(오프라인 행사 부스 전용 모바일 웹 설문조사 페이지 구축, 150만·14일·납품 8/17) 대응.
공고 2-1·2-2를 전부 동작으로 구현했습니다 — X배너 QR 즉시 진입, 문항 전환 애니메이션,
엑셀(.xls) 실생성, 인쇄용 QR PNG까지.

| 표면 | 내용 | URL(별칭) |
|---|---|---|
| 설문 (폰 프레임) | 커버→5문항→완료(콘페티) | `…/confetti/` |
| 관리자 | 실집계·엑셀 다운로드·인쇄용 QR | `…/confetti/admin.html` |

베이스: `https://jeonjaeman.github.io/demo-sites/`

## 핵심 구현
- **즉시 진입**: 로그인·본인인증 없음 — 커버에 명시
- **문항 전환 애니메이션**: 카드 슬라이드 + 진행바(그라디언트) 연동, 선택지 stagger 진입
- **응답별 최적 입력 폼**: 라디오(선택 즉시 자동 다음 — 부스 대기줄 대응)·복수선택·별점(바운스+라벨)·200자 텍스트(카운터)
- **완료**: 콘페티 버스트 + 기념품 교환 코드 + **8초 후 자동 초기화**(부스 공용 기기 대응)
- **서버 전송**: 제출 시 적재(데모 localStorage) — 관리자 집계에 실시간 합산
- **관리자**: 샘플 200건+실제 제출 실집계(문항별 바·주관식 목록) · **엑셀(.xls SpreadsheetML) 실생성**(헤더 스타일·숫자 타입·한글 무손상, CSV BOM 병행) · **실스캔 QR + 인쇄용 PNG 다운로드**

## 체험 시나리오 (클릭만)
1. "설문 시작하기" → Q1 라디오 탭 → **자동으로 다음 문항 슬라이드**
2. Q2 별점 → 라벨 변화 → Q3 복수 선택 → Q4 → Q5는 건너뛰어도 제출 가능
3. 제출 → 콘페티 + 기념품 코드 → 8초 후 자동 초기화
4. 관리자 → 총 응답이 201건(+방금 제출분)으로 합산 → 엑셀 다운로드
5. 관리자 → 인쇄용 QR PNG 다운로드 → 휴대폰으로 QR 찍으면 설문이 실제로 열림

## ⚠️ 착수 전 확인 (미팅)
문항 확정본(수·유형) · 중복 참여 정책(쿠키 1회 제한 권장) · 기념품 교환 방식 · 응답 보관·파기 · 피크 트래픽 규모 · 브랜드 가이드

## 디자인·기술
- 밝은 옐로+코랄 2색 · 바운스 이징 · **자체 제작 SVG 라인 아이콘 15종**(이모지 미사용 — 선택지·커버·완료·기프트 전부) · Pretendard
- 정적 HTML/CSS/JS + qrcodejs · 콘페티/집계 차트 canvas·CSS 자체 구현
- 실구축 제안: Node.js(express)+MongoDB+AWS(공고 기술 태그 그대로) — 프론트 정적 호스팅으로 피크 동시 접속 대응
