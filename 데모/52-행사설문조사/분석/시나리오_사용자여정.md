# CONFETTI 콘페티 — 시나리오·사용자 여정

> 모든 데이터는 가상입니다.

## 1. 등장인물
| 인물 | 원하는 것 | 불안한 것 |
|---|---|---|
| 방문객 | 빨리 끝내고 기념품 | 긴 설문·개인정보 요구·로그인 |
| 부스 스태프 | 대기줄 안 밀리게 | 설문이 느려서 현장 정체 |
| 행사 운영자 (발주자) | 응답 데이터 엑셀로 · 참여율 | 서버 다운·데이터 유실 |
| 인쇄소 | 고해상 QR 파일 | 저해상 캡처본 |

## 2. 방문객 여정 (현장 60초)
| 단계 | 화면 | 이 기능이 없으면 |
|---|---|---|
| X배너 QR 스캔 | 커버 즉시 로드 | 앱 설치·검색 요구 = 참여 포기 |
| 시작 | "로그인 없이 바로" 명시 | 인증 화면 = 이탈 |
| Q1 방문경로 | 라디오 — **선택 즉시 다음** | 다음 버튼 2번 탭 = 줄 밀림 |
| Q2 만족도 | 별점 바운스+라벨 | 밋밋한 폼 = "밝은 톤" 미달 |
| Q3 좋았던 점 | 복수 선택 | — |
| Q4 구매 의향 | 라디오 자동 전환 | — |
| Q5 의견 | 선택 입력(건너뛰기 가능) | 필수 주관식 = 최다 이탈 지점 |
| 완료 | 콘페티 + 기념품 코드 | 참여 보상 확인 불가 — 스태프 혼선 |
| (공용 기기) | 8초 후 자동 초기화 | 앞 사람 화면 잔류 |

## 3. 운영자 여정
| 단계 | 화면 | 데모 동작 |
|---|---|---|
| 행사 전 | 관리자 QR | 실스캔 QR + 인쇄용 PNG 다운로드 → X배너 인쇄소 전달 |
| 행사 중 | 집계 대시보드 | 문항별 실집계(제출 즉시 합산) |
| 행사 후 | 엑셀 다운로드 | .xls(헤더 스타일·숫자 타입) — 자체 분석 |

## 4. 비는 구멍 (착수 미팅 확인)
1. **문항 확정본** — 기획안의 문항 수·유형 (데모는 5문항 예시. 문항 수가 늘면 페이지당 소요 재검토)
2. **중복 참여 정책** — 같은 폰 재참여 허용? (기념품 어뷰징 vs 참여 장벽 — 쿠키 기반 1회 제한 권장)
3. **기념품 교환 방식** — 완료 화면 제시로 충분한지, 코드 발급·소진 관리가 필요한지
4. **응답 보관·파기** — 행사 종료 후 보관 기간 (개인 식별 정보는 미수집 설계라 부담 낮음)
5. **행사 일정·트래픽 규모** — 피크 동시 접속 추정(배너 수·방문객 수)
6. **주최측 브랜드 가이드** — 색·로고 반영 여부
