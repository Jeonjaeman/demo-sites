03기술 스택과 선택 이유

접속 방식 — 반응형 모바일 웹 + PWA (앱 대체)

  • 보호자는 앱을 설치하지 않습니다. 동의서 서명은 1년에 몇 번이라 "링크 → 인증 → 서명"이 전부여야 하고, 알림톡 링크는 설치 없이 바로 열립니다.
  • 학생은 홈 화면에 추가(PWA)하면 앱처럼 쓰고, iOS 16.4+에서 웹푸시가 됩니다(보조 채널 — 주 채널은 알림톡).
  • 네이티브 앱은 스토어 심사·개발자 계정(Apple $99/년·Google $25)·OS별 유지보수가 붙어 1,500만원 안에서 화면 퀄리티를 깎습니다. 사용 데이터를 본 뒤 2차에서 판단합니다.

Next.js(React·TypeScript) + Node API + PostgreSQL

  • 학생·보호자 모바일 화면과 교사 PC 콘솔을 한 코드베이스로. 담임의 "본인 학급만"은 서버에서 행 단위로 강제합니다(URL 변조로 다른 반 열람 불가).
  • 증빙·포트폴리오는 객체 스토리지, 서명 원본은 변경 불가 저장, 열람은 10분 서명 URL + 기록.
  • 표준 스택·DB 설계서·운영 매뉴얼로 다른 업체도 이어받을 수 있습니다(저작권 학교 귀속).

국내 클라우드 우선 (CSAP)

  • 학생·보호자 개인정보를 담으므로 네이버클라우드 공공·NHN Cloud 등 국내 CSP 상위 등급을 우선 제안합니다. AWS·Azure·GCP는 CSAP "하" 등급만 보유(2025).
  • 공립학교의 의무 적용 여부는 착수 1주차에 교육청 정보보안 담당과 함께 확인합니다.

알림톡·SMS · 전자서명 · PDF · 엑셀

  • 카카오 공식 딜러사 API(NHN Cloud 또는 네이버 SENS) — 알림톡 약 13원, LMS 45원. 학교 명의 채널·발신번호 등록을 함께 진행합니다.
  • 전자서명은 1차 자체 구현(OTP + 약정 고지 + 감사추적 + 해시) — 건당 0원. 분쟁 대응 강화가 필요하면 모두싸인 API(건당 약 1,400~2,200원)를 2차에.
  • PDF는 서버 헤드리스 크롬 + Noto Sans CJK 임베딩(한글 깨짐 방지), 교육청 XLSX는 원본 양식의 고정 셀을 채워 서식 유지.
