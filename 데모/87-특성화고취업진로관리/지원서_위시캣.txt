[1] 공고에서 먼저 확인드릴 3가지
────────────────────────────
① 표준협약서는 학부모가 서명하는 문서가 아닙니다
   교육부 고시 표준협약서(2025 매뉴얼 서식2 제22조)는 기업 대표·실습생·학교장 3자가 기명날인해
   3부를 보관합니다. 공고의 "알림톡 → 학부모 터치서명 → 서명 완료 협약서 PDF" 흐름대로 만들면
   기업 서명과 학교장 날인이 빠진 협약서가 생기고, 학생이 미성년자라 보호자 동의가 먼저 와야
   입증이 됩니다(민법 제5조).
   → 데모는 문서를 「보호자 사전동의 → 학생 사전동의 → 기업 대표 서명 → 학교장 날인」 4단으로
     나누고, 앞 단계가 끝나기 전에는 다음 링크 발송 버튼이 잠깁니다. 총괄 관리자가 직인을 일괄
     날인하면 3부 PDF가 확정되고 HIFIVE 등재 체크·등재용 엑셀이 함께 나옵니다.

② 터치 서명 이미지만으로는 "누가 서명했는지"를 학교가 증명하지 못합니다
   2020년 전자서명법 개정으로 추정 효력이 사라져, 다툼이 생기면 서명자 식별과 문서 무결성은
   수집한 쪽이 보여줘야 합니다. 링크만 열면 서명되는 구조면 학생이 보호자 폰으로 대신 서명해도
   반증할 근거가 없습니다.
   → 데모는 학교에 등록된 번호로 OTP 6자리를 거쳐야 열리고(5회 실패 잠금), "이 전자서명을
     자필 서명과 같은 효력으로 사용"에 따로 체크하며, 서명 시각·본인 확인 시각·접속 정보·문서
     확인번호를 PDF 마지막 장 감사추적에 자동으로 붙입니다. 링크는 72시간 1회용이고 서명 직후
     사본 알림톡이 가서 이의 제기 창구가 됩니다.

③ 알림톡은 정보성만 되고, "맞춤 채용 공고 일괄 안내"는 반려될 수 있습니다
   카카오 알림톡은 템플릿마다 심사(영업일 1~3일)를 받고, 수신자가 요청하지 않은 정보는
   정보성으로 인정되지 않습니다. 발신번호를 먼저 등록하지 않으면 SMS 대체 발송도 나가지 않고,
   카톡 72시간 미사용자는 알림톡이 실패합니다.
   → 데모는 템플릿마다 승인/심사/반려 상태를 두어 미승인이면 발송 버튼이 잠기고, 채용 공고는
     학생이 "채용 알림 신청"을 한 경우에만 정보성으로 보내는 템플릿으로 바꿨습니다. 발송 준비
     체크리스트(채널·인증·발신번호·템플릿·잔액)와 실패 사유별 SMS 전환·비용 계산이 붙어 있습니다.

그 외 — 공고 항목을 표준협약서 법정 항목(1일 7시간·주 35시간·시간당 최저 수당·산재보험·기업 승인
·1:1 현장교사·60일)과 1:1로 맞춰 기준 초과 공고는 배정이 잠기는 것, 학생 정보를 기업에 보여주려면
학생+보호자 동의가 먼저인 것(교육기본법 §23의3), 취업률 분모를 교육부 기준(진학·입대 제외)과 3학년
전체로 토글하면 수치가 두 배 가까이 달라지는 것, 진로 갭의 "권장 스펙 정답표"가 공식적으로 없어
학교가 직접 고치는 편집기로 만든 것, 엑셀 업로드에서 전화번호 앞 0이 사라지는 것, 졸업 시 5일 내
파기 의무와 사후관리 18개월의 충돌, 안전사고 서식7 보고 흐름, 변경 합의서 재서명, 만 18세 미만
취업전환 친권자 동의서까지 15건을 데모에 기능으로 넣었습니다. 전체는 제안 노트에 있습니다.

[2] 접속 방식 제안 — 반응형 모바일 웹 + PWA (앱 대체)
────────────────────────────
보호자는 앱을 설치하지 않습니다. 동의서 서명은 1년에 몇 번이라 "알림톡 링크 → 본인 확인 →
서명"이 전부여야 하고, 링크는 설치 없이 바로 열립니다. 학생은 홈 화면에 추가(PWA)하면 앱처럼
쓰고 iOS 16.4+에서 웹푸시도 됩니다(주 채널은 알림톡). 네이티브 앱은 스토어 심사·개발자 계정
(Apple $99/년·Google $25)·OS별 유지보수가 붙어 1,500만원 안에서 화면 퀄리티를 깎기 때문에,
사용 데이터를 본 뒤 2차에서 판단하는 것을 권합니다. 데모 학생 앱에 PWA 매니페스트가 들어 있습니다.

[3] 기술 스택과 선택 이유
────────────────────────────
Next.js + TypeScript    학생·보호자 모바일 화면과 교사 PC 콘솔을 한 코드로. 담임의 "본인 학급만"은
                        서버가 행 단위로 강제 (URL을 바꿔도 다른 반 열람 불가)
Node API + PostgreSQL   권한·학급 범위·문서 체인 상태를 DB 제약으로. 증빙·포트폴리오는 객체
                        스토리지, 서명 원본은 변경 불가 저장
국내 클라우드 우선      학생·보호자 개인정보를 담으므로 네이버클라우드 공공·NHN 등 CSAP 상위 등급.
                        공립 의무 여부는 착수 1주차에 교육청과 확인
알림톡·SMS              카카오 공식 딜러사 API(알림톡 약 13원·LMS 45원). 학교 명의 채널·발신번호
                        등록을 함께 진행
전자서명                1차 자체 구현(OTP + 약정 고지 + 감사추적 + 해시) — 건당 0원. 분쟁 대응을
                        더 강화하려면 2차에 모두싸인 API(건당 약 1,400~2,200원)
PDF · 엑셀              서버 헤드리스 크롬 + Noto Sans CJK(한글 깨짐 방지) · 교육청 원본 양식의
                        고정 셀을 채워 서식 유지
