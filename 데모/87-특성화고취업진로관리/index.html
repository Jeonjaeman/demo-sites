5분 체험 순서 — 세 화면이 실제로 연결됩니다

  1. 교사 콘솔에서 「취업지원부로 체험」 → 대시보드 「미완료 전원 독려 알림톡 발송」
  2. 전자동의에서 아무 행의 「학부모 링크 열기」 → 휴대폰 화면 그대로 서명
  3. 서명 후 돌아오면 상태가 「서명 완료」로 바뀌고 PDF 버튼이 활성화
  4. 학생 앱에서 자격증을 올리면 교사 콘솔 학생 상세에 「확인 대기」로 등장 → 확인하면 준비도 숫자가 바뀜
  5. 맞춤 알림에서 「필수 자격증 미보유」 칩 → 대상 수가 줄고, 야간엔 광고성 템플릿 발송이 막힘

요구사항대로만 만들면 걸리는 지점 — 설명이 아니라 기능으로 넣었습니다

전체 발견과 근거는 제안 노트와 분석/기획_설계.md에 있습니다.
