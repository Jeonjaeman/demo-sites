## 체험 시나리오 (입력 없음)
1. 교사 콘솔 → 「취업지원부」 → 대시보드 분모 토글 → 「미완료 전원 독려 알림톡 발송」
2. 전자동의 → 진행 중 건 「학부모 화면 열기」 → OTP 프리필 → 전문 스크롤·체크 → 서명 → 완료 → 돌아오면 학생 단계 열림
3. 총괄 관리자로 전환 → 날인 대기 → 직인 일괄 날인 → 3부 PDF → 「실습 조건 변경」 → v2 체인
4. 기업 공고 → 「예시 공고 불러오기」 → 기준 경고 → 잠긴 공고 배정 시도
5. 학생 목록 → 엑셀 업로드 샘플 → 오류 4행 → 반영
6. 맞춤 알림 → 조건 칩 → 수 감소 → 반려 템플릿 비활성 → 발송 → 이력·비용
7. 학생 앱 → 자격증 등록 → 교사 상세 확인 → 준비도 변화 → 진로 가이드 직무 전환
8. 담임으로 전환 → 목록 18명 · 발송·배정 버튼 잠김 · 타 학급 URL 차단

## 검증에서 고친 버그
- 사이드바 스크림이 보이지 않을 때도 포인터를 가로채 데스크톱 콘솔의 모든 클릭이 막히던 문제(`pointer-events`) — 실측 테스트에서 발견
- 세그먼트 토글이 라벨 하나에 라디오 둘을 넣어 두 번째 옵션이 선택되지 않던 문제
- 통계 캔버스에서 값 0 막대의 음수 반경으로 `arcTo` 예외 · 최대값이 축 상단에 붙던 스케일
- 375px에서 대시보드·통계 표가 가로 스크롤을 만들던 문제 · 로그인 안내 목록이 인라인 노드마다 그리드 칸으로 쪼개지던 문제
