역할을 고르면
그 선생님의 화면으로 들어갑니다

같은 데이터를 역할마다 다르게 봅니다. 담임은 본인 학급만, 취업지원부는 전체를 보고 배정·발송하며, 총괄 관리자는 권한과 연동까지 관리합니다. 비밀번호 없이 클릭 한 번으로 체험됩니다.

실제 서비스의 로그인 방식

교직원은 학교 계정(ID·비밀번호) + 외부망 접속 시 휴대폰 인증번호 2단계, 학생은 학번 + 초기 비밀번호 변경 강제, 학부모는 로그인 없이 알림톡 1회용 링크 + 휴대폰 뒤 4자리 확인으로 설계합니다. 개인정보처리시스템 접속기록은 1년 이상 보관합니다.

입력 없이 5분 체험

  1. 취업지원부로 들어가 대시보드에서 「미완료 전원 독려 알림톡 발송」을 눌러 보세요.
  2. 전자동의 화면에서 진행 중인 건의 「학부모 화면 열기」 → 휴대폰에서 서명하는 화면이 그대로 나옵니다 (OTP는 미리 채워져 있어요).
  3. 서명을 마치고 돌아오면 상태가 「서명 완료」로 바뀌고 다음 차례(학생) 링크가 열립니다.
  4. 맞춤 알림에서 조건 칩을 누르면 발송 대상 수가 실제로 바뀝니다. 대시보드의 「교육부 기준 / 3학년 전체」 토글도 눌러 보세요.
  5. 역할을 담임으로 바꾸면 목록이 한 학급으로 줄고 발송·배정 버튼이 잠깁니다.

모든 인물·기업·수치는 가상입니다. 바꾼 상태는 이 브라우저에만 저장됩니다.
