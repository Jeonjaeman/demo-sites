**한 사람이 두 역할을 겸하는 지점 (권한 설계 필수)**
1. 담임 + 취업지원부: 같은 학생을 "우리 반"과 "전체"로 동시에 본다 → 상단에 **역할 전환 스위치**, 기본은 좁은 범위.
2. 보호자 1명 + 학생 여러 명: 링크는 학생 단위로 따로 발송, 보호자 화면에서 "다른 자녀 서류 1건 더 있음" 안내.
3. 기업 대표(서명) ≠ 현장교사(출결·평가): 기업 측도 **서명자와 운영자를 분리**해 링크를 따로 보낸다.
4. 학생 본인이 보호자 번호를 대신 등록하는 경우(F3 대리 서명 위험) → 보호자 번호는 **학교 기초자료(NEIS 엑셀)에서만** 들어오고 학생이 수정할 수 없게.

## 3. 시간순 여정 — 단계별 상황 / 쓰는 화면 / 이 기능이 없으면

### ① 학년 초 기초자료 업로드
- **상황**: 취업지원부 교사가 NEIS에서 내려받은 학생·보호자 명단을 정리해 올린다. 학생 192명, 보호자 번호 192개.
- **화면**: 관리자 › 학생 › 엑셀 일괄 업로드 → 미리보기 검증(행별 정상/경고/오류) → "010 누락 3건 자동 보정" → 오류 행만 다시 받기 → 반영.
- **없으면**: 보호자 번호 앞 0이 사라진 채 저장 → 10월 동의서 발송 때 **알림톡·OTP가 무더기로 실패**하고, 그제야 원인을 찾는다(F11). 학번 중복이면 두 학생 이력이 섞인다.

### ② 이력 누적 (연중)
- **상황**: 학생이 전기기능사 필기 합격증을 폰으로 찍어 올린다. 자소서 v2를 올린다.
- **화면**: 학생 › 내 이력 › 자격증 추가(사진 업로드) → 상태 "교사 확인 대기" → 담임 확인 → "확인됨(확인자·일시)". 자소서 버전 목록 v1·v2, 교사 코멘트.
- **없으면**: 지금처럼 수기 취합 → 상담 때마다 "그거 언제 땄지?"를 다시 묻는다. 확인 절차가 없으면 기업 추천 시 허위 이력을 걸러내지 못한다.

### ③ 진로 갭 확인
- **상황**: 학생이 희망 직무를 "전기설비 유지보수"로 정하고 리포트를 연다.
- **화면**: 학생 › 진로 가이드 → 충족률 게이지 · 필수/권장 항목 체크리스트 · 미취득 자격 "다음 시험 일정"·추천 교육과정 · 담임 상담 메모(학생에게는 공개 범위 설정) · 인쇄/PDF.
- **없으면**: 학생은 무엇을 먼저 따야 할지 모른 채 3학년 2학기를 맞는다. 단, **권장 스펙 기준표가 없으면 이 화면 자체가 공허하다**(F10) → 관리자 편집기가 선행.

### ④ 기업 공고 등록
- **상황**: 취업지원부 교사가 참여기업 승인을 받은 기업의 공고를 올린다(또는 기업 담당자가 링크로 입력).
- **화면**: 관리자 › 기업 › 공고 등록 — 표준협약서 필드 1:1(기간·장소·1일 실습시간·휴게·수당 시급·지급일·현장교사·안전조치·유해위험 여부). 실시간 경고: 수당 4,900원 미만, 7시간 초과, 야간·휴일, 미승인 기업.
- **없으면**: 공고에 실습시간·수당 지급일이 없어 협약서 작성 때 다시 기업에 묻는다. **최저 수당 미달·시간 초과 공고가 그대로 매칭**되면 학교가 과태료·형사처벌 사안에 연루된다(F7).

### ⑤ 매칭·배정
- **상황**: 학생 참여 의사 확인 → 조건 맞는 학생 추천 → 기업이 학생 프로필 열람 → 배정.
- **화면**: 관리자 › 매칭 보드(공고 열 × 후보 학생 카드, 드래그 배정) · 기업 열람용 프로필(이름 마스킹) · "정보 제공 동의 미완료" 블러 카드.
- **없으면**: 학생 정보를 엑셀로 기업에 메일 발송 → **동의 없는 제3자 제공**(F8). 배정 결과가 흩어져 "누가 어디 가는지" 표가 매번 새로 만들어진다.

### ⑥ 동의서 발송 (알림톡)
- **상황**: 배정된 32명에게 보호자 사전동의서를 보낸다.
- **화면**: 관리자 › 전자동의 › 문서 묶음 생성(학생 사전동의서 + 보호자 사전동의서 + 표준협약서) → 서명자 매트릭스 확인 → 발송 준비 체크리스트 통과 확인 → 승인된 템플릿 선택 → 개인화 변수 미리보기(#{학생명} #{기업명} #{마감일}) → 발송.
- **없으면**: 템플릿 미승인·발신번호 미등록 상태에서 발송 버튼을 눌러 **조용히 실패**한다(F4·F5). 표준협약서를 보호자에게 보내는 잘못된 흐름이 생긴다(F1).

### ⑦ 보호자 서명
- **상황**: 보호자가 퇴근길에 알림톡 버튼을 누른다.
- **화면(5단계, 8장 벤치마크 근거)**: ⑴ 랜딩 — 학교명·담당 교사 실명·문서 요약(기업·기간·1일 시간·수당·장소), "학교에서 보낸 공식 요청" 확인 문구, 마감 시각 ⑵ 본인 확인 — 등록 번호 끝 4자리 표시 + 6자리 OTP(3분, 재요청) ⑶ 문서 열람 — 핵심 조건 카드 + 전문 펼치기 + 필수 동의 체크(전자서명 약정 포함) ⑷ 서명 — 관계 선택 + 서명 패드(지우기, 가로 회전 권장 안내) ⑸ 완료 — 문서번호, "사본을 알림톡으로 보냈습니다", 거부·문의 버튼.
- **없으면**: 종이 가정통신문 회수 → 미회수 학생 추적에 담임 시간이 녹는다. 링크만으로 서명되면 **대리 서명을 반증 못 함**(F3).

### ⑧ 학생 서명 → 기업 서명 → 학교장 날인 → PDF 생성
- **상황**: 보호자 동의 완료와 동시에 학생 서명 링크가 자동으로 열린다. 이어 기업 대표 링크, 마지막으로 총괄 관리자가 학교장 직인 일괄 날인.
- **화면**: 문서 카드 진행 바(보호자 ● 학생 ● 기업 ○ 학교장 ○) · 학교장 날인 대기 목록에서 "선택 12건 일괄 날인" · 완료 시 3부 PDF(감사추적 페이지 포함) 자동 생성·다운로드 · "HIFIVE 등재" 체크.
- **없으면**: "서명 완료 표준협약서"가 기업 서명 없이 만들어져 **법적 효력이 없는 협약서**가 보관된다(F1). 순서가 섞이면 법정대리인 동의 입증이 흔들린다(F2).

### ⑨ 파견
- **상황**: 실습 첫날. 기업은 입문교육(전체 시간의 30% 이상, 의무교육 12시간 이상)을 해야 한다.
- **화면**: 학생 › 실습 정보(기업·현장교사 연락처·출근 시간·안전수칙) · "부당한 대우 상담"은 HIFIVE 딥링크 · 보호자에게 "실습 시작" 정보 알림톡.
- **없으면**: 학생이 사고·부당대우 시 어디로 연락할지 모른다. 공식 상담 창구(HIFIVE)를 두고 학교 앱에 별도 게시판을 만들면 교육청·노무사가 못 본다(F6).

### ⑩ 현장 점검 일지 (순회지도)
- **상황**: 취업지원부 교사가 월 1회 이상 기업을 방문·전화 점검한다. 기업은 매월 초 출결일지를 회신한다.
- **화면**: 관리자 › 현장 점검 › 학생×월 매트릭스(점검 완료/미완료) · 일지 작성(실습 내용 일치·시간 준수·입문교육 이수·안전장비·학생 면담) · **"사안 발생" 토글 → 서식7 사안보고서 모드**(F15) · 출결 회신 미제출 기업 독려.
- **없으면**: 점검 기록이 개인 수첩에 남아 감사·사고 때 증빙이 없다. 사고 시 보호자 통보·교육청 보고가 늦는다.

### ⑪ 변경·중단 (수시)
- **상황**: 학생이 실습 3주차에 직무가 협약과 다르다고 호소. 다른 기업으로 재배정.
- **화면**: 매칭 상태 "변경 합의" → 기존 협약 잠금 → 변경 합의서(서식4) 재서명 플로우 → 위원회 심의 체크 → HIFIVE 등재 체크. 중단 시 수당 일할 계산 표시.
- **없으면**: 원래 협약서가 그대로 "유효"로 남아 서류와 실제가 어긋난다(F16).

### ⑫ 취업 확정
- **상황**: 실습 종료 후 기업이 채용 의사. 학생은 만 17세.
- **화면**: 취업(전환) 동의서(서식3: 학생 + 보호자) 같은 흐름으로 발송 → 18세 미만이면 "기업 비치용 친권자 동의서" 안내 → 취업전환 가능일 자동 계산(참여기업: 겨울방학/1월 1일 · 선도기업: 수업일수 2/3 이후) → 학생 상태 "취업 확정".
- **없으면**: 취업전환 시기 규정을 어긴 조기 취업이 생기고, 기업은 연소자 증명서 미비치로 과태료 위험(F17).

### ⑬ 교육청 보고·통계
- **상황**: 교육청 요청으로 학과·학급별 실습·취업 현황을 제출.
- **화면**: 관리자 › 통계 · 분모 토글(교육부 기준/전체 기준) · 학과 비교 차트 · "교육청 양식 XLSX 내보내기"(양식 고정 셀 채우기).
- **없으면**: 담당 교사가 매번 엑셀을 손으로 만들고, 학교 수치와 교육청 통계가 달라 해명해야 한다(F9).

### ⑭ 졸업·사후
- **상황**: 2월 졸업. 일부 학생은 사후관리 연락에 동의.
- **화면**: 관리자 › 개인정보 › 졸업생 보존·파기 스케줄 · 파기 실행 → 파기 관리대장 XLSX.
- **없으면**: 졸업생 정보가 무기한 쌓여 개인정보 위반 소지(5일 이내 파기)(F12), 반대로 다 지우면 유지취업률 상담을 못 한다.

## 4. 역할별 시야 차이 (= 권한 설계의 핵심)

| 데이터 \ 역할 | 학생 본인 | 보호자(링크) | 담임 | 취업지원부 | 총괄 관리자 | 기업 담당자(링크) | 교육청 |
|---|---|---|---|---|---|---|---|
| 기본 인적사항 | 본인 열람 · 일부 수정(희망 직무) | 해당 자녀 이름·학과만 | **본인 학급만** 열람·수정 | 전체 열람·수정 | 전체 | **마스킹**(김○○, 학번 비노출) | ✗ (집계만) |

| 자소서·포트폴리오 | 버전 등록 | ✗ | 열람·코멘트 | 열람 | 열람 | 동의 시 최신본만 | ✗ |
| 상담 메모 | 공개 설정된 것만 | ✗ | 작성(본인 학급) | 열람 | 열람 | ✗ | ✗ |
| 진로 갭 리포트 | 본인 | 선택적 공유 | 본인 학급 | 전체 | 전체 | ✗ | ✗ |
| 기업 공고 | 지원 가능 공고 | 배정 기업 정보만 | 열람 | 등록·관리·배정 | 승인 | 자기 공고만 | ✗ |
| 동의서·협약 상태 | 본인 문서 | 자녀 문서 서명 | 본인 학급 현황·독려 발송 | 전체 발송·관리 | **학교장 날인**·전체 | 자기 회사 협약 서명 | ✗ |
| 서명 PDF·감사추적 | 본인 사본 | 본인 서명 사본 | 본인 학급 다운로드 | 전체 | 전체 | 자기 회사 사본 | ✗ |
| 현장 점검 일지 | ✗ | 사안 발생 시 통보만 | 본인 학급 열람 | 작성 | 열람·결재 | 출결 회신만 | 사안보고서(서식7) |
| 발송 이력 | 받은 것 | 받은 것 | 본인 학급 | 전체 | 전체 | 받은 것 | ✗ |
| 취업 통계 | ✗ | ✗ | 본인 학급 | 전체 | 전체·학과 비교 | ✗ | **보고 양식(집계)** |

**권한 규칙 요약**
- 교사 3단계는 **역할(Role) × 범위(Scope)** 두 축 — 담임은 Role=담임, Scope=본인 학급. 취업지원부는 Scope=전체 + 배정 권한. 총괄은 + 결재·날인·설정.
- 서버에서 **행 단위로 범위 강제**(URL만 바꿔 다른 반 학생을 보는 일이 없게). 데모에서는 역할 전환 스위치로 "같은 학생이 담임/취업지원부/총괄 화면에서 어떻게 달리 보이는지"를 시연.
- **보호자·기업은 계정이 없다 → 토큰 링크 설계**
  - 링크는 **문서 1건 × 서명자 1명**에 묶인 1회용 토큰, **72시간 만료**(재발송 시 이전 토큰 즉시 폐기).
  - 링크를 열면 바로 서명이 아니라 **등록 번호 OTP**를 거친다(학생이 보호자 폰 링크를 받아도 OTP는 보호자 폰으로 감).
  - **보호자 번호가 바뀐 경우**: 보호자가 링크에서 번호를 바꿀 수 없다(바꿀 수 있으면 대리 서명 통로). "번호가 바뀌었어요" 버튼 → 담임에게 변경 요청 → 담임이 확인 후 수정 → 새 링크.
  - 서명 거부도 선택지로 둔다(거부 사유 입력 → 담임 알림 → 상담 일정).
  - 링크 화면에 **학교명·담당 교사 실명·학교 대표번호**를 노출해 스미싱 의심을 줄인다.

## 7. 비는 구멍 → 미팅에서 확인할 것

| 구멍 | 왜 문제인가 | 데모에서의 처리 | 미팅 질문 |
|---|---|---|---|
| **보호자가 서명을 거부하면?** | 학생 참여 의사와 보호자 의사가 충돌 | 거부 사유 입력 → 담임 알림 → 상태 "거부·상담 필요" | 거부 시 학교 내부 절차(상담·교내 실습 전환)는? |

**결론 — 보호자 서명은 5단계로 설계한다**
1. 랜딩(문서 요약·학교 신원·마감) — DocuSign 상세 화면의 "보낸 사람·수신 시각" 구성
2. 본인 확인(등록 번호 OTP 6자리·타이머·재요청·"문자가 안 와요") — iM뱅크 4화면을 1화면으로
3. 문서 열람 + 필수 동의 2개([필수] 현장실습 참여 동의 · [필수] 전자서명 사용 동의) — 카카오페이 체크리스트
4. 관계 선택 + 서명 패드 + 법적 고지문 — DocuSign 패드 하단 고지
5. 완료(문서번호·사본 발송·거부/문의) — Envelope ID 대응

외부 본인확인(통신사 PASS 등)을 붙이면 마이현대처럼 약관 6개가 추가돼 7단계 이상이 된다 → 1차는 **학교 등록 번호 OTP**, 2차 옵션으로 외부 본인확인.

## 9. 데모 원클릭 체험 시나리오 제안 (입력 없이 버튼만으로)

1. **"취업지원부 선생님으로 보기"** → 대시보드: 동의서 미완료 7건 카드 클릭 → 필터된 목록 → "미완료 7명에게 독려" → 발송 결과(알림톡 5 성공 · 72시간 미사용 1 → LMS 대체 · 번호 오류 1) → 비용 합계.
2. **분모 토글** → 취업 확정률 약 26% ↔ 약 52%로 실제 재계산, 학과 막대 재정렬.
3. **역할 전환** → 담임(2반) → 같은 학생 목록이 24명으로 줄고 다른 반 학생 URL 접근 시 "열람 권한 없음".
4. **"보호자 화면 체험"** (데모 QR/버튼) → 5단계 서명(OTP는 데모 코드 자동 입력) → 완료 → 관리자 화면 진행 바가 보호자 ● 로 바뀌고 학생 서명 링크 잠금 해제.
5. **학교장 일괄 날인** → 3부 PDF 생성 → 마지막 장 감사추적(해시·시각·IP).
6. **공고 등록 "예시 불러오기"** → 수당 4,800원 경고 · 7.5시간 차단 · 미승인 기업 매칭 잠금.
7. **엑셀 업로드 "샘플 파일로 시험"** → 오류 6건 표시 → 자동 보정 → 오류 행 다운로드.
8. **진로 리포트 "예시 학생"** → 충족률 62% → 관리자가 직무 스펙 편집기에서 "전기기능사"를 필수로 바꾸면 48%로 재계산.
9. **템플릿 관리** → 「맞춤 채용 공고」 반려 상태 → 발송 버튼 비활성 사유 툴팁.
10. **현장 점검 "사안 발생" 토글** → 서식7 자동 채움 → 보호자 즉시 알림 미리보기.
11. **졸업생 파기 스케줄** → 파기 실행 → 파기 관리대장 XLSX 다운로드(BOM 포함).
