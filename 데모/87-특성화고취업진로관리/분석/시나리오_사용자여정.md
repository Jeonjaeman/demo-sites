## 2. 한 학년도 타임라인
3월 기초자료 업로드(F11) → 3~7월 이력·갭·상담 → 6~9월 기업 발굴·실사·심의(F7 승인 상태) → 9~10월 공고·참여 의사·매칭·정보 제공 동의(F8) → 10~11월 보호자→학생→기업→학교장 체결(F1·F2·F3) → 11월~ 파견·월 점검·출결·HIFIVE(F6) → 수시 변경·중단·사안(F16·F15) → 12~1월 종료·취업전환 동의(F17) → 2월 졸업 파기 스케줄(F12) → 4.1 교육부 통계(F9) → 6·12·18개월 유지취업(동의자만).

## 7. 원클릭 체험 경로 (입력 없음)
1. 허브 → 취업지원부 → 대시보드 분모 토글 → 「미완료 전원 독려」 → 결과 토스트(알림톡/SMS 대체 수)
2. 전자동의 → 진행 중 건 「학부모 화면 열기」 → OTP(프리필) → 전문 스크롤·체크 → 관계·서명 → 완료·PDF → 돌아오면 학생 단계 열림
3. 날인 대기 → 총괄 관리자로 전환 → 직인 일괄 날인 → 3부 PDF · HIFIVE 체크 → 「실습 조건 변경」 → v2
4. 기업 공고 → 「예시 공고 불러오기」(4,800원·7.5h·미승인) → 기준 경고 → 잠긴 공고 「배정 잠김」 모달

6. 맞춤 알림 → 「필수 자격증 미보유」 칩 → 수 감소 → T04 반려 비활성 → T07 신청자 → 발송 → 이력·비용

8. 운영 → 기준표 필수/권장 토글 → 평균 준비도 재계산 → 파기 실행(총괄) → 관리대장 XLSX
