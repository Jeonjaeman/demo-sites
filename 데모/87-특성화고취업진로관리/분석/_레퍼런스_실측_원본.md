  - **갤러리** = Mobbin·유아이볼 스크린샷. 구성·위계·단계 수만 기록하고 **수치는 적지 않는다.**
  - 자간은 `letter-spacing ÷ font-size`로 **em 환산**. 폰트명은 기록만 하고 **가져오는 것은 메트릭**이다(유료·커스텀 폰트 사용 불가 → Pretendard에 em 비율로 이식).

- **골격** — 레퍼런스 라이브러리 shopify-admin 프레임을 그대로: 상단 바 56(검정 계열) + 사이드바 240 + 본문 판(좌상단 r12). 사이드바 IA는 1단 아이콘 메뉴 + 우측 카운트 배지(예: "동의서 12" = 미완료 건수, Shopify Orders [4] 문법).
- **홈(대시보드)** — Heron 목업 문법: 페이지 머리 아래 **"김OO 선생님, 오늘 확인할 서명 12건 · 마감 D-3 4건" 주의 우선 인사** → KPI 4타일(재학생·파견율·취업확정률·동의서 미완료). 타일 = 라벨 13/600 + **우상단 8px 색 사각** + 숫자 32/700 tabular-nums ls −0.02em(매쓰플랫 숫자 강조 = 같은 크기 색 변경, 모두싸인 통계 56/500 ls −0.025em의 축소 이식) → 학과별 비교 막대 → **"서명 대기 큐"**(Heron Pending approval: 행마다 진행 바 2/3 + "독려 보내기 →" 버튼).
