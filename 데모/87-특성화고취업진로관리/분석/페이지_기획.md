# 페이지 기획 — 특성화고 취업·진로 이력 관리 + 현장실습 전자동의 데모 (CAREERPASS 커리어패스)

> 공고 159208(1,500만 · 60일 · 지원 151명)의 5개 모듈을 **세 표면(교사 콘솔 PC / 학생 모바일 웹 / 학부모 서명 페이지)** 으로 나눠 독립 HTML 페이지로 기획.
> 성격 판정: **기능형(대시보드 + 모바일 플랫폼 + 서명 폼)**. 브랜드 단락 구성(풀블리드 히어로·캐러셀)은 넣지 않는다. 모션 강도: 교사 콘솔 = 약(차트 성장·카운트업·토글), 학생 앱 = 중(리스트 진입·탭 전환·토스트), 서명 = 최소(진행바·단계 전환·저장 표시).
> 의뢰자가 가진 「7개 핵심 화면 PDF」는 비공개 → 공고 2-1~2-5의 문장을 화면으로 1:1 전개하고, 7개로 압축한 "의뢰자 기준 화면 지도"를 함께 둔다.

## 0. 의뢰자 7개 화면(추정) ↔ 데모 페이지 지도

공고 2-1~2-5를 "눈으로 보고 클릭해 볼 수 있는" 단위로 자르면 7개가 된다. 미팅에서 PDF를 받으면 이 표의 좌측만 바꿔 끼운다.

| # | 의뢰자 기준 화면(추정) | 공고 조항 | 데모 페이지 |
|---|---|---|---|
| 1 | 통합 대시보드 | 2-1 전부 | `admin/dashboard.html` |
| 2 | 학생 프로필·이력 | 2-2 ①②③ | `admin/students.html` → `admin/student.html?id=` · 학생 측 `app/me.html` |
| 3 | 엑셀 일괄 업로드 | 2-2 ④ | `admin/students.html` 「엑셀 업로드」 모달(검증 단계 포함) |
| 4 | 기업 공고·매칭 | 2-3 ① | `admin/jobs.html` · 학생 측 `app/jobs.html` |
| 5 | 전자동의(학부모 서명) | 2-3 ②③④ | `admin/consents.html` · 학부모 `sign.html?t=` |
| 6 | 진로 가이드 리포트 | 2-4 전부 | `admin/report.html?id=` · 학생 측 `app/path.html` |
| 7 | 알림 발송·취업 통계 | 2-5 전부 | `admin/messages.html` · `admin/stats.html` · 권한 `admin/settings.html` |

## 1. 사이트맵

```
/ (허브)
├─ index.html                 데모 입구 — 세 표면으로 보내는 허브(역할 카드 3 + 공고 요약 + 체험 순서)
├─ proposal.html              제안 노트 — 발견·구성도·기술 스택·일정·완료 기준(지원서 링크용)
│
├─ admin/  교사 콘솔 (PC 1280 기준 · 1024~375 반응형)
│  ├─ index.html              로그인 — 역할 원클릭 체험(담임 / 취업지원부 / 총괄 관리자)
│  ├─ dashboard.html          통합 대시보드 — KPI 4 · 학과별 파견·취업 비교 차트 · 서명 상태 필터 목록 · 독려 알림톡 즉시 발송
│  ├─ students.html           학생 목록 — 학과/반/희망직무/증빙상태 필터 · 검색 · 엑셀 일괄 업로드(매핑→검증→반영)
│  ├─ student.html?id=        학생 상세 — 인적사항·진로 목표 · 이력 타임라인(자격증·수상·어학, 증빙 확인/반려) · 포트폴리오 버전(v1·v2…) · 진로 갭 요약 · 상담 메모
│  ├─ jobs.html               기업 공고·매칭 — 공고 등록(업종·직무·수당·기간·인원 + 법정 항목 검증) · 매칭 보드(모집중→배정→협약→파견→종료)
│  ├─ consents.html           전자동의 현황 — 표준협약서·학생 동의서·학부모 동의서 3종 상태 · 발송·재발송·만료 · 서명 PDF 다운로드
│  ├─ messages.html           맞춤 알림 — 대상 추출(조건 칩) → 템플릿(승인 상태) → 개인화 변수 미리보기 → 발송 · 이력 · 실패 SMS 대체 · 미확인 재발송
│  ├─ stats.html              취업 통계·보고 — 학과·학급별 통계 · 현장 점검 일지 · 교육청 보고 양식 XLSX
│  ├─ report.html?id=         진로 가이드 리포트 — 인쇄용(A4) · PDF 저장 · 상담 메모 포함
│  └─ settings.html           운영 — 3단계 권한 매트릭스 · 알림톡 채널/템플릿 상태 · 검토 항목(리스크 점검)
│
├─ app/  학생 모바일 웹 (375 기준 · PC에서는 폰 프레임)
│  ├─ index.html              학생 홈 — 내 진로 목표 · 갭 요약 · 해야 할 일(증빙 보완·동의서) · 새 공고
│  ├─ me.html                 내 이력 — 자격증·어학·수상 등록(증빙 업로드·확인 상태) · 자소서/포트폴리오 버전
│  ├─ path.html               진로 가이드 — 희망 직무 권장 스펙 vs 보유 (충족·미취득) · 보완 가이드
│  ├─ jobs.html               실습 공고 — 열람·지원 · 내 지원 상태
│  └─ inbox.html              알림함 — 받은 알림톡/문자 · 동의서 링크
│
└─ sign.html?t=               학부모 서명 (로그인 없음 · 알림톡 링크 진입)
                              본인확인 → 문서 열람(끝까지 스크롤) → 터치 서명 → 완료 · PDF · 만료/이미 서명 상태
```

페이지 수: 허브 2 + 교사 10 + 학생 5 + 서명 1 = **18 페이지**. 견적·지원서는 이 수 기준.

## 2. 페이지별 기획

### 허브 · 제안
| 페이지 | 목적 | 방문자가 할 일 | 섹션 | 다음 유도 |
|---|---|---|---|---|
| `index.html` | 세 표면으로 분기 | 역할 카드 하나 클릭 | 역할 카드 3(교사·학생·학부모) · 체험 순서 4단계 · 공고 요약 · 가상 데이터 고지 | 교사 로그인 / 학생 홈 / 서명 링크 |
| `proposal.html` | 지원서 보조 | 발견·일정 읽기 | 치명적 발견 · 구성도 · 스택 · 60일 일정 · 완료 기준 · 의뢰자 부담 | 데모 링크 |

### 교사 콘솔
| 페이지 | 목적 | 교사가 할 일 | 핵심 상호작용(실제 계산) |
|---|---|---|---|
| 로그인 | 역할 체험 | 역할 클릭 | 역할 → 학급 스코프가 모든 목록에 실제 적용 |
| 대시보드 | 오늘 할 일 파악 | 미완료 동의서 독려 | KPI 카운트업 · 학과별 막대(canvas) · 상태 필터 즉시 반영 · 독려 발송 → 이력 생성 |
| 학생 목록 | 찾기·일괄 등록 | 필터·검색·엑셀 업로드 | 업로드 3단계(열 매핑 → 오류 행 표시(전화 앞 0·학번 중복·학과명 불일치) → 반영) |
| 학생 상세 | 한 학생 전체 파악 | 증빙 확인/반려 · 메모 | 확인 상태 변경이 갭 계산에 즉시 반영 · 버전 누적 |
| 기업 공고 | 공고 등록·배정 | 등록 · 학생 배정 | 법정 항목 검증(실습시간·수당·기간) · 배정 시 동의서 3종 자동 생성 |
| 전자동의 | 서명 수합 | 발송·재발송·PDF | 상태 머신(미발송→발송→열람→서명→완료/만료) · 링크 만료 · PDF 생성(Blob) |
| 맞춤 알림 | 대상별 발송 | 조건 → 템플릿 → 발송 | 조건 칩이 대상 수를 실제로 줄임 · 변수 치환 미리보기 · 실패 시 SMS 대체 · 재발송 |
| 통계·보고 | 보고서 만들기 | XLSX 추출 · 점검 일지 | 학과·학급 집계 실제 연산 · XLSX(SheetJS 없이 xlsx zip 생성 또는 CSV+BOM 병행) |
| 리포트 | 상담 자료 | 인쇄·PDF | A4 인쇄 CSS · 갭 표 · 메모 |
| 운영 | 권한·연동 상태 | 매트릭스 확인 | 3단계 권한 × 기능 표 · 템플릿 승인 상태 · 검토 항목 |

### 학생 앱
| 페이지 | 목적 | 학생이 할 일 | 핵심 상호작용 |
|---|---|---|---|
| 홈 | 다음 할 일 | 카드 탭 | 갭 링(진행률) · 할 일 체크 |
| 내 이력 | 스스로 누적 | 항목 추가·증빙 | 추가 즉시 "교사 확인 대기" 상태 · 버전 v1→v2 |
| 진로 가이드 | 방향 확인 | 직무 바꿔보기 | 희망 직무 변경 시 갭 재계산 |
| 실습 공고 | 지원 | 지원 버튼 | 지원 → 교사 콘솔 매칭 보드에 반영 |
| 알림함 | 수신 확인 | 링크 열기 | 열람 시 교사 측 "확인" 상태 변경 |

### 학부모 서명
| 단계 | 화면 | 편의 설계 |
|---|---|---|
| 0 | 링크 진입(`?t=`) | 만료·이미 서명·없는 링크 3상태 분기 |
| 1 | 본인확인 | 생년월일 또는 전화 뒤 4자리 1필드(프리필) |
| 2 | 문서 열람 | 요약 카드 먼저(기업·기간·시간·수당) → 전문 · 끝까지 스크롤해야 다음 |
| 3 | 서명 | 큰 서명 패드(canvas) · 다시 쓰기 · 손가락 굵기 보정 |
| 4 | 완료 | 서명 시각·식별 정보 표시 · PDF 받기 · 학교 연락처 |

## 3. 공통 구조
- `assets/css/tokens.css`(실측 토큰) · `base.css` · `admin.css` · `app.css` · `sign.css`
- `assets/js/data.js`(시드 생성 + localStorage 상태) · `calc.js`(갭·통계·상태 머신) · `ui.js`(토스트·모달·리빌·카운트업·차트) · `xlsx.js`(파일 생성) · `pdf.js`(인쇄/PDF)
- 모든 페이지 공통 헤더(현재 페이지 `aria-current`) · 역할 배지 · 가상 데이터 고지
- 상태는 localStorage에 저장해 페이지를 넘나들어도 유지(「초기화」 버튼 제공)

## 4. 입력 없이 체험되는 경로 (★)
1. 허브 → 「취업지원부로 체험」 → 대시보드에서 「미완료 12명 독려 발송」 → 이력 토스트
2. 전자동의 → 임의 행 「학부모 링크 열기」 → 서명 페이지(프리필 본인확인) → 서명 → 완료 → 돌아오면 상태 「완료」·PDF 버튼 활성
3. 학생 목록 → 「샘플 엑셀로 업로드」 → 오류 2행 표시 → 「오류 제외 반영」
4. 맞춤 알림 → 조건 칩 「자격증 미보유」 → 대상 수 변화 → 템플릿 → 「발송」 → 실패 1건 SMS 대체 표시
5. 학생 앱 → 「희망 직무 바꿔보기」 → 갭 재계산
