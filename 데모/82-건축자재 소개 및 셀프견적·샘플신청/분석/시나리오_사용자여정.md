# 82 ARGILO 아르길로 — 시나리오 · 사용자 여정

> 공고: 바이브 코딩 기반 건축자재 소개 및 셀프견적·샘플신청 홈페이지 구축 (위시켓 · 300만원 · 30일)
> 원자료: `_리서치_원자료.md` 1~5장. 이 문서는 그 요약과 기능 매핑이다. 데모 명칭은 가상(포미스톤 → 아르길로).

## 1. 등장인물

| 인물 | 원하는 것 | 불안한 것 | 겸직 |
|---|---|---|---|
| **건축주** (개인 리모델링·상가) | 대략 몇 박스·얼마인지, 실물 샘플, 비슷한 사례 | 계산이 틀려 모자라거나 남음, "외벽에 붙여도 되나" | 셀프 시공이면 시공자 겸직 |
| **인테리어·시공업체 실무자** | 현장 실측값으로 수량 산출 → 발주, 고객에게 보여줄 샘플 | 단종·로트 색차, 감리의 성적서 요구 | 견적 의뢰자 + 시공사례 사진 제공자 + 재주문 고객 |
| **설계사무소** (스펙인) | 국내 시험성적서(외부용·유효기간)·시방서·판형·색상 코드 | 성적서 없거나 만료 → 인허가 반려, 다운로드 가입 강요 | — |
| **내부 운영 담당자** (비개발자 1~2인) | 엑셀 쓰듯 쉬운 등록, 접수 누락 없음 | 사이트가 깨짐, 매번 개발자 호출, 개인정보 사고 | 응대 + 발송 + 콘텐츠 혼자 |
| **대표** | 문의가 느는가, 월 비용 | 월 유지비, 업체 의존 | 운영 담당 겸직 가능 |
| 시공 파트너·건축주(피사체)·제조사·택배사·감리 | 사진 권리 · 게시 동의 · 이미지 사용권 · 배송 필드만 · 품질관리서 | | |

## 2. 시간순 여정 (방문자)

| 단계 | 상황 | 데모 화면 | 이 기능이 없으면 |
|---|---|---|---|
| 발견 | 검색·소개로 유입, "이 소재가 뭔지" | `index` 히어로 → `about` 소재 비교(점토계 MCM vs 금속복합패널) | 설계자가 "복합패널 품질인정 대상?"으로 오해해 스펙인에서 탈락 |
| 판단 | 질감·사례 탐색 | `products` 필터(용도·시리즈·성적서) · `cases` 벤토 + 필터 2축 · `case` 사용 자재 칩 → `product` | 사례와 제품이 끊겨 "이 사진 자재가 뭐예요" 상담만 늘어남 |
| 계산 | 벽 치수로 수량 | `estimate` 4단계 → 장·박스·남는 장수·접착제 · 외벽이면 층수·높이 질문 | 면적÷장당 면적 공식 하나 → 줄눈 무시 21% 과다, 개구부 무시 1박스 과다, 외벽 법규 안내 없음 |
| 행동 | 견적 의뢰·샘플·카톡 | `quote`(계산 내역 자동 첨부·전달 범위 고지) · `sample`(한도·배송지·마케팅 분리) · 퀵메뉴 카톡 | 계산 결과를 폼에 다시 타이핑, 샘플 남용, 동의 없는 마케팅 |
| 대기 | 접수 후 불안 | `done` 접수번호·다음 단계 4칸·알림 발송 현황 | "접수됐나?" 전화 |
| 실행 | 샘플 수령·시공 | 접수함 상태 흐름(접수→확인→발송→완료→후속) | 발송 누락, 재신청 중복 발송 |
| 사후 | 시공사례 등록 | 관리자 사례 등록(사진 출처·동의·자재 체크) → 제품 상세 자동 연계 | 개발자 호출, 동의 없는 사진 게시 |

### 설계사무소 트랙 (B2B)
자료실 `resources` 성적서 탭 — 로그인 없이 바로 다운로드, 유효기간 칼럼, 외부용 표기, 만료 자동 숨김 → 제품 상세 Downloads 묶음 → 상담 신청(설계 스펙인 타일). **없으면**: 성적서 유효성을 전화로 확인, 만료 성적서로 품질관리서 제출.

### 운영 담당자 트랙 (오픈 후)
대시보드 "오늘 할 일"(응대 초과·성적서 만료·파기 대상·비공개 사례·계정 갱신·샘플 후속) → 접수함(경과 색 칩·같은 연락처 이력·송장·알림 재발송) → 제품(판형 N·정합성 경고·계산 미리보기·주의 표현 검사) → 사례(자재 체크·동의 게이트) → 자료실(공개 방식·대용량 경로) → 설정(카톡 ID·한도·수탁자→처리방침·계정 소유표·운영비·파기).

## 4. 명시 니즈 vs 숨은 니즈 (요약)

| 공고 문구 | 숨은 니즈 | 데모 응답 |
|---|---|---|
| "오픈 후 저희가 콘텐츠를 업데이트하는 과정이 번거롭지 않을지 우려" | **성공 기준 = 비개발자 혼자 갱신** | 공개 화면 하드코딩 0, 관리자 7화면, 저장 즉시 공개 반영(기능 테스트 38건 통과) |
| "소요되는 자재의 개수를 자동으로 계산" | "개수"가 장인지 박스인지 → 실제 주문 단위 | 장·박스·㎡·남는 장수 동시 표기 |
| "계산된 수량 내역을 바탕으로 최종 견적 의뢰" | 다시 입력하지 않게 | 스냅샷 자동 첨부 + 전달 범위 고지 |
| "원하는 샘플을 선택하고 배송 정보를 입력" | 남용·비용 통제 | 개인 5·사업자 10 한도, 30일 재신청 배지 |
| "카카오톡 채널 링크 연동, 신청 내역 접수 알림" | 놓치지 않기, 업무시간 외 | 접수함 + 발송 로그·재발송, 채널 ID → 링크 자동, 알림톡은 2차 |
| "포미스톤 등 건축 내외장재" | 외장 = 법적 성능 근거 | 외벽 선택 → 층수·높이 질문 → 방화 검토 플래그, 성적서 배지 분리 표기 |
| "포미 디스플레이, 포미쏠라" | 전기·발전 제품 → 다른 규제 | 국내 인증 상태 필드 → "제조사 발표 기준" 꼬리표, CTA 도입 상담 |
| "[1순위] 금액" + "월 단위 유지보수" | 월 운영비도 낮게, 의존은 싫음 | 운영비 계산기(무료 한도 사용률), 계정 소유표(의뢰자 명의) |

## 5. 비는 구멍 — 미팅 확인 질문 (전체 25문항은 원자료 5장)

1. 셀프견적 대상은 포미스톤 전 제품인가, 기타자재(롤·포대·개)도 포함인가?
2. 제품별 판 크기·두께·박스당 장수 자료가 있나? 같은 색상에 길이가 여러 개(Z·A·B·C)인가? **폭 1200mm가 맞나?**
3. 실제 로스율 — 일자·엇갈림·헤링본·곡면별로 쓰는 값이 있나? (데모 기본 10·15·20·15%)
4. 줄눈 폭 — 외부 2mm·실내 0mm·벽돌형 10mm 가정이 맞나? 개구부 공제 기준은?
5. 계산 결과에 가격을 보여줄 것인가(참고가/범위/비노출)? 단가는 누가 결정하나?
6. 샘플 — 무료/유료, 개수·배송비·사업자 우대, 유료 샘플 온라인 결제 여부(통신판매업 신고 검토)
7. 접수 알림 받을 사람·채널·근무시간·응대 목표 시간
8. 카카오톡 채널 보유·비즈니스 전환 여부, 운영시간·자동응답 설정 (알림톡은 2차)
9. **국내 시험성적서 보유 현황** — 제품별·외부용 여부·유효기간·시험기관
10. 포미 디스플레이·쏠라의 국내 판매 여부와 KC·KS 인증 상태
11. 제조사와의 관계(공식 수입·총판·대리점), 이미지·카탈로그 사용 허락 범위, "포미스톤" 명칭 사용권(국내 복수 유통사 확인)
12. 시공사례 사진 촬영 주체·건축주 게시 동의·주소 공개 범위
13. 자료실 — 바로 다운로드 vs 연락처 게이트, 카탈로그 PDF 용량(25MiB 초과 여부)
