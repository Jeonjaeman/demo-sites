# ARGILO 아르길로 — 건축자재 소개 · 셀프견적 · 샘플신청 홈페이지 데모

> 위시켓 공고 「바이브 코딩 기반 건축자재 소개 및 셀프견적·샘플신청 홈페이지 구축」(300만원 · 30일) 제안용 데모.
> 공개 사이트 19페이지 + 비개발자 관리자 7화면. **모든 제품·사례·접수 데이터는 가상**이며, 공고의 "포미스톤"은 실존 브랜드라 데모에서는 **아르길로(ARGILO)** 라는 가상 명칭을 씁니다(메뉴 구조는 1:1).

- 공개: https://jeonjaeman.github.io/demo-sites/argilo/
- 관리자: https://jeonjaeman.github.io/demo-sites/argilo/admin/
- 로컬: `python -m http.server 8039` (launch.json `argilo`)

## 체험 시나리오 (입력 없이 클릭만)

1. 홈 → 「셀프견적 시작」 → 상단 **「예시 · 주택 외벽 덧방」** → 결과 3박스·14장·개구부 공제 7.29㎡·**방화 검토 안내** → 층수를 3으로 바꾸면 사유 추가 → 「이 내역으로 견적 의뢰」 → 폼 프리필 → 접수 → 완료 화면
2. 제품보기 → 카드 「샘플 담기」 ×3 → 퀵메뉴 샘플 배지 → 샘플 신청 → 6개 담으면 제출 비활성 → 「시공·설계 사업자」로 전환 → 접수
3. 관리자 → 접수함 → 방금 접수 건 열기(방화 검토·스냅샷·알림 로그) → 「확인」 → 「발송」(송장 입력)
4. 관리자 → 제품 → 트라베르 S-1260 → **로스 · 일자 10 → 15** → 계산 미리보기 2박스 → 3박스 → 저장 → 공개 셀프견적 「예시 · 거실 아트월」이 3박스로 바뀜
5. 관리자 → 시공사례 → + 새 사례 → 사용 자재에 트라베르 체크 → 허락·동의 체크 → 게시 → 제품 상세 「이 자재를 쓴 시공사례」에 자동 연결
6. 관리자 → 제품 편집 → 한 줄 소개에 "불연 친환경" 입력 + 성적서 삭제 → 저장 버튼이 **「검토 요청」**으로
7. 관리자 → 역할 「대표」 → 설정 → 파기 대상 2건 「지금 파기」 → 기록만 남음
8. 자료실 → 성적서 3건 체크 → 일괄 다운로드 · 카탈로그 탭 → 「링크 받기」 게이트

## 기술 구성

- 의존성 0 — HTML/CSS/JS, 폰트만 CDN(Pretendard·Libre Baskerville)
- `assets/js/data.js` 시드 → `store.js`(localStorage `argilo.db.v1`, 공개·관리자 공유, `argilo:change` 이벤트) → `calc.js`(계산 엔진, 공개·관리자 동일 함수) → `ui.js`(헤더·푸터·퀵메뉴·리빌·틸트·캐러셀·패럴랙스·토스트) → `pages.js`(페이지 렌더) / `admin.js`(해시 라우팅 7화면)
- 공개 페이지는 `_build_pages.py`로 공통 셸에서 생성(빌드 보조)
- 이미지: Higgsfield 생성 20장 → WebP(히어로 1600 · 사례 1200 · 질감 900 · 카드 720)
- 다운로드: Blob 실제 생성(CSV UTF-8 BOM), 사진 업로드는 canvas 리사이즈 미리보기
- 모션: IntersectionObserver 리빌 · 라인 마스크 · 단어 스크럽 · rAF 틸트(데스크톱만) · 캐러셀 스냅·드래그·자동 · `prefers-reduced-motion` 존중
