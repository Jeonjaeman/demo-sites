# 탑로더 TOPLOADER — 스포츠카드·TCG 통합 커뮤니티 (데모)

국내 스포츠카드·원피스·포켓몬 콜렉터가 네이버 카페·오픈채팅에 흩어져 있는 문제를 해결하는
**게시판 중심 통합 커뮤니티 + 직거래 장터**의 제안용 데모사이트입니다.

## 체험 시나리오 (데모 포인트)

1. **전역 관심사 필터** — 상단 칩에서 "포켓몬" 선택 → 홈 피드·게시판·장터가 전부 포켓몬 글만 노출 → 새로고침해도 유지 (localStorage, 요구사항 2-1).
2. **2클릭 글쓰기 + 이중 말머리** — 우하단 ✏️ FAB → 말머리 "팝니다" 선택 시 가격·상태·거래방식 구조화 입력폼 자동 노출 → 말머리/주제 미선택 시 등록 차단.
3. **AI 카드 인식 (협의 기능)** — 글쓰기에서 사진 업로드 클릭 → AI가 카드명 인식 + 시세 제안 + 제목·카테고리 자동 입력 시뮬레이션.
4. **스팸 방지** — 글 등록 직후 재등록 시도 → 60초 도배 방지 차단 토스트.
5. **장터 → 오픈채팅** — 매물 카드 클릭 → 판매가/상태/거래방식 패널 + 노란 오픈채팅 버튼 + 더치트 조회·거래후기 안전장치.
6. **소셜 온리 로그인** — 카카오/네이버/구글 3버튼, 이메일 가입 없음 (원클릭 데모).
7. **관리자 운영** — [admin.html](admin.html)에서 신고 삭제/기각, 스팸 회원 강제 탈퇴, 광고 슬롯 수동 등록·종료.
8. **시세 탭** — 장터 구조화 데이터가 Phase 2 시세 서비스로 확장되는 그림 (지수 + 실거래 랭킹 + 차트).

## 기술 구성 (데모)

- 순수 HTML/CSS/JS 정적 사이트 — 빌드 불필요, 모바일 우선 반응형 (하단 탭바)
- 상태: 관심사 필터·로그인·도배 타이머는 **localStorage 지속**, 글/매물/신고는 세션 인메모리
- 이미지: Higgsfield 생성 (가상의 카드 디자인 — 실존 IP 미사용)
- 모든 게시글·매물·시세·인물은 가상 데이터입니다

실서비스 제안 스택: Next.js(SSR/SEO) + NestJS + PostgreSQL(시세 확장 대비 관계형 스키마) + 소셜 OAuth + 클라우드 비전 API (기획_설계.md 5장 참조)
