[청년-지역 매칭 플랫폼 웹사이트 신규 개발 — 지원서]

■ 지원서 대신, 동작하는 프로토타입을 먼저 만들었습니다
데모 → https://jeonjaeman.github.io/demo-sites/청년지역매칭/

공고문을 읽고 화면 흐름 전체를 미리 구현해 봤습니다. 화면만 그린 목업이 아니라,
청년 화면과 관리자 화면이 실제로 연결되어 돌아갑니다.

· 3분 체험 코스 :
  ① [청년으로 둘러보기] → 로그인 화면의 "테스트 계정으로 바로 시작" 클릭
  ② 공고 상세에서 매칭 적합도 % 확인 → 지원서 제출 (프로필이 자동으로 채워집니다)
  ③ [관리자 데모 보기] → 지원자 관리 → 방금 낸 지원서가 목록에 나타납니다 ("내 지원" 배지)
  ④ 합격 처리 → 청년 마이페이지로 돌아가면 상태가 "합격"으로 바뀌어 있습니다
· 관리자 성과 대시보드의 모든 숫자는 하드코딩이 아니라 지원 데이터에서 실시간 집계됩니다
  (선발률·참여완료율·후속연결 퍼널 — 정부지원사업 성과보고에 그대로 쓰는 지표 구조)


■ 요구사항 대응 (공고 항목 그대로)

1) 사용자단 (청년)
   - 인증 : 이메일 + 카카오/구글 OAuth, 비밀번호 재설정, 가입 시 부가정보 입력·약관 동의(필수/선택 분리)
   - 공고 탐색 : 상태 배지(모집중/마감임박/마감)·D-day·지역/분야 필터·검색 — 데모에 구현되어 있습니다
   - 지원 시스템 : 프로필 자동 연동 지원서(한 번 쓴 정보는 다시 안 씁니다), 파일 업로드(S3), 접수번호 발급
   - 마이페이지 : 지원 내역·합격 상태 실시간 확인, 참여 여정 타임라인, 프로필/역량 수정, 계정 관리
   - 콘텐츠 : 서비스 소개, 인터뷰·지역탐방 목록/상세 열람

2) 관리자단 (비커넥트랩 / B2B 파트너)
   - 인증 : 사용자 서비스와 URL 분리, 이메일 가입 후 기존 관리자 승인으로 활성화되는 계정 구조
   - 프로그램/공고 : 프로그램(상위)-공고(하위) 2단계, 생성·수정·복제·삭제, 게시/모집 상태 토글
   - 지원자 관리 : 상태·공고별 필터, 상세 조회, 합격/불합격 처리(청년 화면 즉시 반영),
     평가 데이터(점수·역할·코멘트) 입력 — 전부 데모에서 눌러보실 수 있습니다
   - 청년 인재 관리 : 활동상태·이력·리스크 필터, 활성/비활성, 운영 메모
   - 콘텐츠 관리 : 자체 에디터 작성·발행 → 사용자 화면에 즉시 노출 (외부 링크 아닌 자체 아카이빙)
   - 성과측정/통계 : 조회수·지원자수·선발률·참여완료율 대시보드, 만족도 조사 축적,
     취업·창업·재참여 후속연결 상태 관리, GA4 이벤트 트래킹(페이지뷰·지원 전환·가입)
   - 데이터 활용 : 지원자·청년 인재 목록 CSV 추출 (데모에서 실제로 다운로드됩니다)

3) 확장 대비 (공고에 적어주신 부분)
   - 결제/PG·구독형 자동결제 : 파트너-요금제-청구 테이블과 권한 구조를 처음부터 분리 설계해
     Phase 2에서 스키마 변경 없이 얹을 수 있게 합니다
   - 파트너별 통계·리포트 자동화 : 데모의 "파트너 리포트" 화면이 그 원형입니다


■ 기술 스택 — Next.js + PostgreSQL + AWS 제안
확장성과 유지보수를 선호하신다고 하여, 국내 채용 시장에서 개발자 수급이 가장 쉬운 조합을 제안합니다.
  - 프런트/백엔드 : Next.js (사용자단 SSR로 검색 노출 대응 + 관리자 콘솔 동일 스택)
  - DB : PostgreSQL(AWS RDS) — 프로그램/공고/지원/평가/후속연결 관계형 구조에 적합
  - 파일 : S3 + CloudFront (개인정보 서류는 비공개 버킷 + 만료 링크)
  - 개인정보 : 연락처·서류 암호화 저장, 역할 기반 접근 통제, 열람 로그 — 관련 법령 준수 설계
계약 시 인프라 구성서(월 예상 비용 포함)를 먼저 드리고 합의 후 구축합니다.

■ 일정 (50일 · 9월 착수 → 10월 초 오픈 역산)
  1주    설계 확정 : Figma 핸드오프 수령, IA·기능정의서 대조, DB 스키마·API 명세 합의
  2~3주  사용자단 : 인증 → 공고 탐색 → 지원 → 마이페이지 (핵심 여정 우선)
  4~5주 ★ 관리자단 : 공고/지원자 관리 → 통계 대시보드 → 콘텐츠/인재 관리
  6주   ★ 통합 QA : 반응형 전수 점검, 개인정보 처리 점검, 실데이터 리허설
  7주    오픈 : AWS 배포, GA4 연동 확인, 운영자 교육, 안정화
  ★ = 주차 종료 시 중간 시연. 데모를 이미 만들어 봤기 때문에 설계 단계에서 헤매는 시간이 없습니다.
