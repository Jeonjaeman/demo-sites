# 마음터 MAUMTEO — 정신과 상담 특화 비대면 진료 (제안용 데모)

정신과 상담에 특화된 비대면 진료 서비스의 1차 버전 데모입니다.
위시켓 「정신과 상담 특화 비대면 진료 서비스 1차 개발」 공고(예상 5,000만·150일·대구)에 대응해 제작했습니다.

> ⚠️ 서비스명(마음터)·의사·환자·진료·처방 등 **모든 데이터는 가상**이며 실제 의료행위가 아닙니다.
> 법령 해석은 공개 자료 기반 참고용이며, 최종 판단은 의료법 전문 변호사 자문이 필요합니다.

## 3표면 구성

| 표면 | 파일 | 핵심 |
|---|---|---|
| 사용자 앱 (폰 프레임) | `index.html` | 홈·의사찾기·**사전 문진(자살 위기 즉시 분기·109 연계)**·의사 상세·**예약 유형 분기(상담 중심 Z코드=진단 기록 없음)**·수가 자동 산출 결제·상담 연결(잔여시간·끊김 유예)·처방전(열람권·만료 카운트다운)·약국(거리순만·유인 금지)·마이페이지 |
| 의사 전용 웹 | `doctor.html` | 예약 대기열(가명 처리·위기 플래그)·**월 30% 상한 게이지**·상담 진행·**처방 작성(향정신성 성분 자동 차단→대면 안내)**·Z코드 청구 |
| 관리자 백오피스 | `admin.html` | **규제 준수 대시보드(규제 적용 시점 전환 스위치 — 개정 의료법 2026.12.24)**·의사 승인·**30% 상한 모니터링(초과 시 슬롯 잠금·대면 연계)**·정산(급여 공단 직지급/플랫폼 월정액 분리)·후기 심의(치료효과 표현 필터)·사업자 준수 체크 |

## 체험 시나리오 (입력 없이 클릭만으로)
1. **위기 분기**: 앱 → 셀프 체크 → 마지막 문항에서 "구체적으로 생각함" 선택 → 즉시 위기 화면(109·응급·최속 슬롯)
2. **Z코드 상담**: 의사 찾기 → 김서연 원장 → 예약 → 「상담 중심」 선택(처방 단계가 사라지고 Z71.9 표시) → 결제(수가 자동 산출 8,100원)
3. **향정 차단**: doctor.html → 박○우(재진) 선택 → 알프라졸람 클릭 → 차단·대면 안내 / 에스시탈로프람 → 발행 가능
4. **규제 스위치**: admin.html → 「현행 시범사업」↔「개정법 기준」 전환 → 기준별 차이표 변경, 30% 모니터링 → 초과 기관 강조·대면 연계 시뮬

## 핵심 발견 → 기능 (상세: 분석/_리서치_초안.md)
개정 의료법이 개발 기간 중(2026.12.24) 시행 / 향정신성 비대면 처방 금지(정신과 주력 약물) / 평점·후기·건당 수수료의 각 조문 위반 / 시간 단위 임의 과금=임의비급여 / 월 30% 상한·초진 지역 제한 / Z·F코드 분기 / 자살 위기 대응 공백 / 관리자 상담 내용 열람 차단.
