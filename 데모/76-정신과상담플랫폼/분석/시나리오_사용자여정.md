# 데모76 · 마음터 — 시나리오 & 사용자 여정 (확정본)

> 전문(여정 17단계·시야 매트릭스·비는 구멍 12항목·근거 URL)은 `_리서치_초안.md` §1이 원본.

## 1. 등장인물 요약
- **이용자**: 우울·불안·불면의 20~40대. 낙인·기록(F코드→보험)·5분 진료·앱의 열람을 불안해함.
- **의사**: 상담 중심 진료를 원하나 면허 리스크(비대면 처방 규정·30% 상한·유인 공범·평점 방어 불가)를 두려워함. **의사 확보가 사업의 병목 → 의사가 안심하는 설계가 곧 사업성.**
- **간호사**: 하위 계정. 진료기록 접근 시 본인이 위반 주체.
- **관리자(대표 1인)**: 재하청·유지보수 미확정 우려 + (본인이 모르는) 중개매체 신고 의무.
- **약국(잠재)**: 추천·배지 = 유인 위반(닥터나우 사례).

## 2. 여정 핵심 분기 (없으면 벌어지는 일)
증상 인지→셀프 체크(최대 이탈 지점) → 익명 탐색(가입 강요 시 이탈/후기 전면 공개 시 §56 위반) → 의사 선택(평점순 = 유인 소지 → 공정 노출 병기) → **진료 유형 선택(누락 시 전원 F코드)** → 사전 문진(30분 중 15분 절약) → **위기 분기(공고에 없음 — 3일 뒤 예약은 최악)** → 예약(30% 상한 슬롯) → 본인확인 → **수가 결제(임의 금액 = 부당청구)** → 상담(끊김 유예) → **시간 초과(자동 과금 = 임의비급여 → 과금하지 않음)** → **처방(향정 UI = 위법 유도 화면)** → 처방전(열람권) → 약국(거리순만) → 재진(핵심 지표) → 후기(치료효과 = 불법 광고).

## 3. 역할별 시야 (권한 매트릭스 — 공고 2-4 전개)
상담 내용: 이용자·진료 의사만 / 다른 의사·간호사·**관리자 차단**(존재·상태만).
문진: 진료 의사만(간호사 차단). 실명: 관리자는 가명처리본. 위기 플래그: 간호사는 알림만(내용 없이).
→ 데모: 의사 웹 가명 대기열·관리자 가명 통계·"관리자는 내용에 접근할 수 없습니다" 명시.

## 4. 비는 구멍 — 미팅 확인 (요약)
위기 신고·기록 보존 / 30% 상한 시 슬롯 잠금 규칙 / 노쇼·의사 취소 배상 / 통화 끊김 정의 / 미성년(법정대리인·부모 열람권) / 후기 삭제 이의 / 의사 정산 주기(급여 직지급 구조) / 약 배송 대상 / 광고심의 임계 / 진료기록 보관 주체 / **초진 지역 제한 vs "지역 무관" 컨셉**(→ 대면 초진 연계+재진 중심으로 재설계).
