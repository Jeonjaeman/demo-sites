# 데모76 · 마음터 — 기획·설계 (확정본)

> 공고: 「정신과 상담 특화 비대면 진료 서비스 1차 개발」 (위시켓 · 5,000만 · 150일 · 대구 중구)
> 분업: 0~2단계 리서치 = Opus 에이전트 / 4~8단계 구축·검증 = Fable 메인 세션
> ★ 상세 근거(발견 전문·근거 URL·수가·조문)는 `_리서치_초안.md`(757줄)가 원본이며 이 문서는 요약 확정본.

## 1. 이 건의 본질
공고 기능 중 최소 6개가 그대로 만들면 위법이고, 근거법(개정 의료법)이 **개발 기간 한복판(2026.12.24) 시행**된다.
의뢰자가 "확인 중"이라 쓴 처방 범위는 이미 답이 나와 있다(§34-3 ④ 향정신성 금지).
따라서 데모의 승부처 = **오픈 시점의 법으로 이미 만들어 놓은 화면**.

## 2. 표면 구성 (하이브리드)
사용자 앱(폰 프레임·안심 sage 톤) + 의사 전용 웹(대시보드) + 관리자 백오피스(규제 준수 대시보드).
공개 랜딩은 서비스 소개 + 앱 체험 인덱스.

## 4. 요구사항 커버리지
공고 2-1(사용자 앱 9기능)·2-2(의사 웹 6기능)·2-3(관리자 5기능)·2-4(권한) 전부 화면 구현 ✅.
미확정 3항목 권고: ① 시간 초과 = 과금하지 않음(임의비급여) ② 처방 범위 = 향정 차단·SSRI 등 허용(답 확정) ③ 약국 = 1차는 위치 조회까지(전송은 전달시스템 규제 확정 후) — 지원서에 반영.

## 5. 견적 — 5,000만 / 100 man-day (일 50만 역산)
공수표·범위 밖·유지보수(무상 3개월+월 정액·개정법 대응 포함·재하청 없음)·1차 검증 성공 기준(닫힌 루프 5항목)은 `_리서치_초안.md` §5와 `지원서_위시캣.txt`에 확정.

## 6. 디자인
차분한 sage green(#3f7d6e) + warm neutral — 낙인·불안을 줄이는 안심 톤. 폰 프레임 앱 + 대시보드 콘솔. 모션 절제(대시보드 약·앱 중). ※ 이 건은 기능·규제 증명이 본체라 어워드 실측 대신 헬스케어 도메인 톤 기반(74·75와 달리 별도 실측 생략을 명시).
