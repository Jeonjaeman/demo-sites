# MEDIQ 메디크 — AI 의료 서비스 메인 페이지 디자인 시안 데모
위시켓 「AI 의료 서비스 웹사이트 메인 페이지 디자인 시안 제작」 (80만·3일·마감 8/18·지원 30명) 대응.
- 시안(동작): https://jeonjaeman.github.io/demo-sites/mediq/

## 체험 (클릭만으로)
1. 히어로 규제 3모드 스위치 — 의료기기(SaMD)/의료기관/웰니스로 카피셋이 통째로 전환 (적법 문구 규칙 각주 포함)
2. 신뢰 스트립 2모드 — 지표 보유(카운트업+출처 각주 강제) ↔ 지표 없는 초기(인증·검증 절차)
3. 기능 카드 상태 뱃지 4종 — 허가 완료/심사 중/연구용/비의료
4. 풀블리드 판독실 단락(패럴랙스) + 임상 근거 텍스트 스크럽
5. 파트너 3단(동의 컬러/협의 중/숫자 대안) + 명도대비 실측표(검수 기준)
6. 우하단 「디자인 근거 보기」 — 각 섹션의 설계 근거·규제 출처 주석 오버레이
7. 푸터 — 사사표기 슬롯·사업자 전문(VUNO 문법)·AI 인물 미사용 고지
