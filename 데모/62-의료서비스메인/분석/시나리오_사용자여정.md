# MEDIQ — 방문자 여정 (요약)
## 등장인물
A 의료기관 도입 결정자(허가·도입처 확인) / B 일반 이용자 / C 정부 과제 평가위원(사사·성과 실물) / D 투자자(트랙션·규제 단계) / F 발주자 본인(검수 경험 없음 — 실질 심사자)
## 3초/30초/3분
0~3초: 한 문장 정의+제품 실체(50ms 첫인상 연구) → 히어로 제품 UI / 3~30초: 기능을 동작 흐름으로+인증·숫자 → 신뢰 스트립·기능 카드 / 30초~3분: 경쟁 대비·도입처·근거·문의 → 풀블리드·논문·파트너
