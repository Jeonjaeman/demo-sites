# LUMIÈRE · 한·일 프리미엄 성형·치과 정보 플랫폼 (제안용 데모)

> 한국과 일본 시장을 동시 타겟으로 하는 **성형외과·치과 병원 정보 제공 + 상담 예약 플랫폼 MVP** 데모.
> 의뢰자 요구사항의 **"UI/UX 디자인 최우선 · 하이엔드 · 다국어(한/일)"** 에 맞춰 제작되었습니다.

**디자인 무드:** K/J 뷰티 그라디언트 — 로즈→라일락, 글래스모피즘, 라운드 프리미엄, 시네마틱 모션.

## 핵심 기능

- 🌐 **한국어 ⇄ 일본어 실시간 전환** — 헤더 토글 한 번으로 전 화면(콘텐츠·병원정보·후기 포함) 전환. `localStorage`로 언어 유지.
- 🏥 **병원 탐색·비교** — 카테고리/지역/평점/검색 필터, 글래스 병원 카드.
- 📅 **간편 예약 플로우** — 캘린더 날짜 선택(과거·일요일 자동 비활성) → 시간 슬롯 → 예약자 정보 → 완료. 2단계 모달.
- 🔀 **전후(Before/After) 사례 갤러리** — 카테고리 필터 + 다중 드래그 슬라이더(랜딩 8종·상세 3종), 성형·치과에 특화된 결과 비교 UX.
- 🎬 **브랜드 필름 + 영상 슬롯** — 커스텀 플레이어(재생·일시정지·진행바·음소거)의 브랜드 필름 섹션. 히어로/필름은 애니메이션 캔버스 "영상"으로 재생되며, `assets/hero.mp4`·`assets/film.mp4`를 넣으면 실제 촬영본이 자동 반영됩니다.
- ✨ **인터랙션 강화** — 마그네틱 버튼, 3D 틸트, 버튼 샤인 스윕, 마우스 반응 그라디언트.
- 🎞️ **itddaa급 스크롤 연출**(랜딩 전면) — 인트로 프리로더(세션 1회)·스플릿 글자/줄 rise(ease back)·스크램블 타자기·핀 스크럽 히어로·**글자 좌우 쪼개짐 카테고리**·**가로 스크롤 병원 쇼케이스(핀)**·**마그네틱 채움 텍스트**·스포트라이트·이중 마퀴. (`assets/motion.js` 엔진)
- 🎬 **시네마틱 모션** — 애니메이션 그라디언트 히어로(Canvas), 카운트업, 커서 글로우. (GSAP + ScrollTrigger + Lenis)
- 🛠 **관리자 대리입력·승인 구조** — 입점 병원은 직접 수정 불가, 관리자에게 요청 → 관리자 검토·발행(요구사항 그대로).

## 기술 구성

- **정적 프런트엔드**: HTML + CSS + Vanilla JS (프레임워크·빌드 없음) — 데모 특성상 경량·즉시 배포.
- **공유 에셋**
  - `assets/style.css` — 디자인 시스템(토큰·글래스·컴포넌트·모션 유틸)
  - `assets/i18n.js` — 한/일 전환 엔진(`data-ko`/`data-ja`, `I18N.t()`, `langchange` 이벤트)
  - `assets/data.js` — 병원·시술·후기·전후사례 이중언어 데이터(`window.LUMIERE_DATA`)
  - `assets/motion.js` — 스크롤 연출 엔진(스플릿·스크램블·마그네틱·스포트라이트·Lenis 스무스)
- **모션 라이브러리(CDN)**: GSAP, ScrollTrigger, Lenis(스무스 스크롤) — 랜딩에만 적용.
- **폰트**: Pretendard(국문) · Noto Sans JP(일문) · Poppins(영문 디스플레이).

> 실제 구축 시에는 요구사항대로 **완전 독립형 자체 서버/DB/API**(예: Node/NestJS + PostgreSQL, 한·일 리전 CDN)로 확장하며, 본 데모의 화면·플로우·다국어 구조를 그대로 이식할 수 있습니다.
