# MIYO — 글로벌 의료 뷰티 플랫폼 데모 (v2)

`요청업데이트.txt` (위치 기반 병원 검색 및 다국어 뷰티/의료 독립몰 MVP) 요구사항을 반영한 제안용 정적 데모입니다.
레이아웃·무드는 프리미엄 스킨케어 브랜드 사이트의 에디토리얼 구조(풀블리드 히어로 영상, 아웃라인 마키, 필러 카드, 컬렉션 캐러셀, 저널)를 참고해 **오리지널 콘텐츠**로 구성했으며, RFP 우대사항에 맞춰 **주황 계열 팔레트 + Pretendard 폰트**를 적용했습니다.

## 페이지

| 파일 | 내용 |
| --- | --- |
| `index.html` | 메인 — 히어로 영상, 브랜드 필러, 성형/치과 컬렉션, 승인제 입점 철학, 지도 티저, 프로모션, 저널, QR 로그인 |
| `clinics.html` | 병원 찾기 — 카테고리/지역/정렬/검색 필터, 서울·도쿄 지도(핀), 내 주변(위치 기반) 데모 |
| `clinic.html?id=…` | 병원 상세 — 갤러리, 소개/시술·가격/실후기/위치 탭, 스케줄 달력 예약, 전화·카카오톡·LINE 상담, 리뷰 신고 |
| `admin.html` | 관리자 콘솔 — 총관리자/중간관리자/파트너 3단계 권한, 실시간 알림(벨·토스트), 예약/상담 이력, 승인 워크플로, 리뷰·신고·차단·환불, 회원 관리, 정산 자동계산 |

## 요구사항 매핑 (요청업데이트.txt)

- **2-1 권한 분리**: `admin.html` 권한 전환 셀렉터 — 메뉴 노출, 승인 권한, 정산 열람/확정 권한이 역할별로 분리 (중간관리자는 정산 확정 불가, 파트너는 자사 데이터만)
- **2-2 로그인·다국어**: QR 로그인 + 구글/네이버/카카오/LINE 소셜 로그인 모달(데모), KO/JA/EN 3개 국어 — 최초 접속 시 브라우저 언어 자동 감지 + 헤더 토글 수동 전환
- **2-3 예약·상담**: 병원별 스케줄 달력(휴무/마감/시간 슬롯), 예약 시 병원·운영팀 실시간 알림(토스트+벨 카운트), 상담 내역 localStorage 저장 → 관리자 '상담 내역' 타임라인에서 병원·운영 공동 열람, 보존 기간 5년 표기
- **2-4 위치 검색·정보 관리**: 서울/도쿄 지도 핀 + 내 주변 정렬(데모, 실서비스 Google Maps SDK 안내), 파트너 수정 요청 → 운영 승인 후 반영 워크플로
- **2-5 리뷰·신고**: 병원 제공/이용자 인증 2종 리뷰 라벨, 별점, 신고 → 관리자 신고 큐에서 차단/환불 처리
- **2-6 정산**: 실연동 없는 계산식 기반 대시보드 (완료건수 × 평균시술가, 수수료 10%, 광고비, PG 1.5% 자동 계산)

## 미디어

`assets/media/` 의 이미지 12장과 히어로 영상 1편은 전부 **Higgsfield AI**(Soul v2 이미지 + Kling 3.0 Turbo 영상)로 생성한 오리지널 에셋입니다.

## 실행

정적 사이트입니다. 레포 루트에서 `npx serve .` 후 `/v2/index.html` 접속.
모든 병원·리뷰·수치·연락처는 가상의 데모 데이터입니다.
