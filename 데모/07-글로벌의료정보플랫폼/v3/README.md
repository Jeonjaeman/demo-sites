# LUMIÈRE v3 — 위치 기반 다국어 뷰티/의료 독립몰 데모

루트(원본) 데모의 뼈대·인터랙션(시네마틱 히어로 필름, GSAP 스크롤 리빌, 커버플로우 캐러셀, 마키, 커서 글로우)을 **그대로 유지**하면서, `요청업데이트.txt`(위치 기반 병원 검색 및 다국어 뷰티/의료 독립몰 MVP)의 변경 요구를 반영한 버전입니다.

## 루트 대비 변경 사항

### 1) 프라이머리 색상 — 로즈→주황 계열 (RFP 우대사항)
- 디자인 토큰 전면 교체: `#E85D9E`(로즈) → `#F4581C`(주황), 라일락 보조색 → 앰버(`#F7B267`/`#E88A1A`)
- 그라디언트·글로우·오로라 배경·병원 카드 그라디언트·뱃지까지 전 팔레트 일괄 전환 (Pretendard 유지)

### 2) 모드(권한)별 구조 변경 — RFP 2-1
| 모드 | 화면 | 변경 내용 |
| --- | --- | --- |
| 사용자 | index / clinics / clinic | QR·소셜 로그인, 위치 검색, 실후기 신고, 상담 채널 |
| 파트너(병원) | hospital.html | 예약 **확정/거절/방문완료 처리** 추가, **정산 열람**(확정 권한 없음), 실시간 신규 예약 알림 |
| 중간관리자 | admin.html | 로그인 시 권한 선택 — 회원 관리 메뉴 숨김, 정산 **열람만**(확정 잠금 🔒) |
| 총관리자 | admin.html | 전체 메뉴 + 정산 확정 + 회원 차단 + 신고/환불 처리 |

### 3) 기능 추가 (RFP 2-2 ~ 2-6)
- **2-2 로그인·다국어**: QR 로그인 + 구글/네이버/카카오/LINE 소셜 로그인 모달 · KO/JA/**EN** 3개 국어(브라우저 언어 자동 감지 + 수동 토글, EN 미번역 데이터는 KO 폴백)
- **2-3 예약·상담**: 상담 채널(전화·카카오톡·LINE) — 홈 플로팅 버튼 + 상세 페이지 버튼 · 예약 완료 시 "병원·운영 대시보드 실시간 알림 + 이력 5년 보존" 안내 · 관리자/파트너 콘솔에 벨·토스트 실시간 알림 시뮬레이션
- **2-4 위치 검색**: 홈 `#map` 섹션 + 병원찾기 지도 패널(핀·현재위치·가까운순 정렬·거리 표시, 실서비스 Google Maps SDK 안내)
- **2-5 리뷰·신고**: 홈 `#reviews` 섹션 신설 + 상세 페이지 리뷰에 **병원 제공/이용자 인증 2종 라벨** · 신고 → 숨김 처리 → 관리자 신고·차단·환불 콘솔에서 처리
- **2-6 정산**: 관리자 정산 대시보드(완료건수 × 평균시술가, 수수료 10%·광고비·PG 1.5% 자동 계산 — 실연동 아님) + 파트너 자사 정산 열람

## 파일
`index.html` · `clinics.html` · `clinic.html` · `hospital.html`(파트너) · `admin.html`(총/중간관리자) · `assets/`(i18n 3개 국어 엔진, data.js v3 패치 포함)

## 실행
정적 사이트 — 레포 루트에서 `npx serve .` 후 `/v3/index.html` 접속. 모든 병원·리뷰·수치는 가상 데이터입니다.
