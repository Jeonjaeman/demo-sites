예약조회

예약번호로 상태를 확인하세요.

공개 데모는 실제 개인정보를 받지 않습니다. 예약번호와 고정 샘플 확인코드 0000으로 조회합니다.

이용안내

예약 요청부터 확정까지, 보이는 흐름으로.

1. 날짜로 검색

날짜·지역·인원을 고르면 사이트별 가능 상태가 계산됩니다. 데모에서는 결정적 목 데이터를 사용합니다.

2. 요청과 결제 시뮬레이션

옵션과 예약자 정보를 확인하고 결제 시뮬레이션을 완료합니다. 실제 청구는 0원입니다.

3. 담당자 확인

접수된 요청은 담당자가 캠핑장에 연락해 확인합니다. 이 단계에서 상태가 '캠핑장 확인 중'으로 바뀝니다.

4. 확정 · 대체 · 취소

확정, 대체 사이트 제안, 취소 중 하나로 안내드립니다. 운영 데모 패널에서 상태 전환을 직접 체험할 수 있습니다.

결제는 실제로 일어나나요?

아니요. 이 데모의 모든 결제는 시뮬레이션이며 실제 청구는 0원입니다. 실제 PG 연동은 사업자 정보·통신판매업 신고·환불 정책·PG 심사가 끝난 뒤 별도 범위로 진행합니다.

예약은 언제 확정되나요?

결제 시뮬레이션 완료는 '예약 요청 접수'이며 확정이 아닙니다. 담당자가 캠핑장에 확인한 뒤 확정·대체·취소가 결정됩니다.

취소·환불은 어떻게 되나요?

숙박비는 체크인 D-7 이상 전액, D-3 70%, D-1 50%, 당일 0%로 계산하고, 옵션은 전일까지 전액 환불로 분리 계산합니다. 실제 정책은 확정 전 데모 값입니다.

개인정보는 저장되나요?

실제 개인정보는 저장하지 않습니다. 예약 샘플은 이 브라우저의 localStorage에만 남는 가상 데이터이며, 언제든 브라우저 데이터 삭제로 지울 수 있습니다.
