[프로젝트 개요]
- 반응형 웹 기반 아웃도어(캠핑장) 예약 플랫폼 1차 MVP를 만듭니다. 인스타그램처럼 스크롤하며 볼 수 있는 매거진형 큐레이션 콘텐츠로 캠핑장 정보를 먼저 보여주고, 필터링 검색과 날짜별 예약, PG 카드결제로 이어지는 흐름이 핵심입니다. 예약 시 인근 옵션 상품 등을 추가로 예약할 수 있는 옵션도 포함합니다. 네이버로 앱은 만들지 않으며, 캠핑장(업체)이 직접 로그인해 정보를 등록하는 화면도 만들지 않습니다. 이번 범위는 정부 지원사업 일정에 맞춰 실제 사용자가 이 방식으로 캠핑장을 예약하는지 확인할 수 있는 최소 기능까지만입니다.

[클라이언트 소개]
- 정부 지원사업(9월~11월 사업비 확보)의 일환으로 아웃도어 캠핑장 예약·정보 큐레이션 서비스를 준비 중입니다. 운영 중인 서비스는 없고 일반 소비자가 직접 이용하는 고객용 서비스입니다.
- 프로젝트 의사결정 구조: 요구사항 확정부터 검수, 최종 승인까지 직접 진행합니다.
- 개발 지식: 서버 개발이나 전산 담당이 없습니다. 기술 선택 이유를 비개발자가 이해할 수 있는 수준으로 설명해 주셔야 합니다.
- 세금계산서 발행: 정부 지원사업 예산으로 진행되어 세금계산서 발행이 가능한 사업자만 지원 가능합니다.

[왜 이 프로젝트를 하는가]
- 지금 사람들은 이렇게 하고 있습니다: 캠핑장을 찾는 사람들은 블로그나 지도 서비스, 개별 캠핑장 홈페이지 등에 흩어진 정보를 일일이 찾아보고 전화나 개별 사이트로 예약합니다. 정보가 한곳에 큐레이션되어 있지 않고, 숙소 예약 서비스처럼 날짜·필터로 바로 예약까지 이어지는 곳이 없습니다.
- 끝나면 이렇게 되기를 바랍니다: 사용자가 매거진을 보듯 큐레이션된 캠핑장 정보를 보다가 바로 날짜를 골라 예약하고 결제까지 마칠 수 있게 됩니다. 9월 중 티켓을 오픈해 실제 결제가 발생하는 것이 이번 사업 성과의 핵심입니다.
- 다만 이런 점이 우려됩니다: 완료 후 연락이 끊기고 피드백이나 대응이 없어지는 상황을 가장 우려하고 있습니다.

[필수 작업 범위와 결과물]
1. 수행 범위
- 기획 및 디자인: 직접 만든 프론트엔드 프로토타입과 기능 명세가 있으나 참고용이며, 정확한 화면 설계, UI·UX 디자인은 새로 진행합니다.
- SW 개발: PC·모바일 반응형 웹, 관리자 화면, API, DB 신규 구축, 네이티브 앱은 이번 범위에서 제외합니다.
- 인프라 구축: 배포, 클라우드 신규 구성과 배포, PG사 연동.

2. 필수 작업
- 매거진형 큐레이션 콘텐츠: 캠핑장 정보를 SNS 피드처럼 스크롤하며 볼 수 있게 노출합니다. 아웃도어 매거진형 콘텐츠를 다뤄 본 경험이 있으면 좋습니다.
- 캠핑장 검색·필터링: 날짜별 예약 가능 여부 조회, 조건별 필터링
- 예약과 PG 카드결제: 예약과 동시에 결제까지 완료되어야 하며, 이 결제가 실제 매출로 이어지는 핵심 기능입니다.
- 부가 예약 옵션: 예약 시 인근 옵션상품 등을 추가로 예약할 수 있는 옵션
- 관리자 등록 화면: 캠핑장 등 업체 정보는 담당자가 관리자 화면에서 직접 등록합니다. 업체용 로그인 화면은 만들지 않습니다.
- 예약 확정 흐름: 예약이 들어오면 담당자에게 연락이 가고, 담당자가 업체에 연락해 예약을 확정하는 구조입니다.

3. 결과물
- 요구사항 정의서
- 화면 설계서
- 전체 소스코드(발주사 소유 저장소)
- DB 스키마
- 배포·운영 매뉴얼

[클라이언트 준비 사항]
- 준비된 것: 직접 만든 프론트엔드 프로토타입과 기능 명세(참고용), 정부 지원사업 사업비(9월~11월)
- 준비 중인 것: 캠핑장 등록 대상 업체 목록과 큐레이션할 콘텐츠
- 이 프로젝트 담당: 담당자 1인이 요구사항 확정과 검수를 모두 맡습니다.

[오픈 시점과 예산]
- 목표 시점: 9월 둘째~셋째 주 티켓 오픈, 지원사업 일정에 맞춰 이 시점에 반드시 오픈해야 합니다.
- 희망 착수: 계약 후 즉시 개발 기간 약 2주
- 예산: 500만~1,000만원 (부가세 별도)

[제안 포함 필수 사항]
지원 내용은 아래 기준으로 검토합니다.
1. 적합한 기술 스택과 그 선택 이유를 제안에 포함해 주세요. 저희 쪽에 개발 인력이 없으므로 비개발자가 이해할 수 있는 수준으로 적어 주시면 도움이 됩니다.
2. 파트너님께서 판단하시기에 어떤 부분이 완료되어야 이 서비스의 1차 검증이 성공적으로 마무리되었다고 보시는지 제안에 포함해 주세요. 전문가로서 이 프로젝트의 결과물에 대한 의견 부탁드립니다.
3. 9월 2~3째 주까지 MVP 구축이 완료되어야 합니다. 해당 일정에 맞춰 어떻게 진행하실 계획인가요?
4. 완료 이후 피드백이나 대응이 끊기지 않도록 어떻게 지원하실지 제안에 포함해 주세요.

안녕하세요, 15일 내 MVP 구축 및 정시 오픈을 책임질 스마트 개발 파트너입니다.

정부지원사업 일정(9월 2~3째 주 티켓 오픈)에 맞춰 실제 결제 검증이 가능한 아웃도어 캠핑장 큐레이션 웹 플랫폼 구축 제안을 드립니다. 서버 개발 인력이 없으신 점과 일정 상의 긴급함을 충분히 이해하고 있으며, 최신 AI 기반 초고속 개발 공정(AI-Assisted Workflow)을 통해 품질과 일정을 완벽히 충족시켜 드리겠습니다.

1. 추천 기술 스택 및 선택 이유(비개발자 맞춤 설명)

화면(Front-end): Next.js / React (반응형 웹)
선정 이유: 모바일과 PC 모두에서 인스타그램과 같은 ‘매거진형 피드 스크롤’을 끊김 없이 부드럽게 구현하는 데 가장 최적화되어 있습니다.

데이터 및 서버(Back-end & DB): Supabase / Node.js
선정 이유: 단 2주라는 짧은 기간 동안 회원/캠핑장 데이터 및 날짜별 예약 로직을 오류 없이 가장 신속하고 안정적으로 구축할 수 있는 현대적인 개발 스택입니다.

결제 시스템(PG): 포트원(Portone) API 연동
선정 이유: 토스페이먼츠, KCP 등 주요 결제 모듈을 신속하게 붙일 수 있어, 9월 둘째 주 빠른 실결제 검증이라는 목적에 완벽히 부합합니다.

2. 1차 서비스 검증(MVP 성공) 판단 기준
전문가로서 이번 사업의 성공적인 1차 검증 기준은 “실제 사용자가 매거진 피드를 탐색하고, 날짜 선택 후 카드 결제(PG)까지 완료되어 DB에 정상 저장되는 순간”으로 정의합니다.

매거진 피드 스크롤 및 필터링 검색 정상 동작
관리자 화면에서 캠핑장 정보 및 부가 예약 옵션(인근 음식점 등) 직접 등록/수정 가능
예약 발생 시 담당자에게 즉시 전달되는 통지 로직 및 카드 결제/취소 데이터 연동 확인

3. 9월 2~3째 주 오픈을 위한 15일 타이트 일정 관리 플랜

1~3일차 (기획 확정 및 DB/UI 설계): 제공해주시는 프로토타입/명세를 바탕으로 데이터베이스 구조 및 화면 설계를 즉시 확정합니다.

4~9일차 (핵심 기능 집중 개발): 반응형 매거진 피드, 필터 검색, PG 카드결제 연동, 부가 예약 옵션 로직을 우선 개발합니다.

10~12일차 (관리자 페이지 구축): 담당자가 직접 캠핑장 데이터와 부가 옵션을 등록할 수 있는 대시보드를 구축합니다.

13~14일차 (통합 테스트 & 결제 검증): 실제 결제 테스트 및 예약 확정 흐름을 검증하고 클라우드(Vercel/Supabase)에 배포합니다.

15일차 (최종 검수 및 오픈): 클라이언트 검수 완료 후 9월 둘째/셋째 주 정상 티켓 오픈을 마칩니다.

4. 완료 후 지속 지원 및 A/S 방안(연락두절 우려 해소)
무상 A/S 보장: 완료 후 연락이 끊기는 우려가 없도록, 오픈 후 발생할 수 있는 주요 오류 및 버그에 대해 1개월간 무상 A/S를 보장합니다.

쉬운 운영 매뉴얼 제공: 개발 지식이 없으셔도 직접 운영하실 수 있도록 관리자 화면 사용법 및 클라우드 운영 매뉴얼을 문서화하여 전달합니다.

정부지원사업 결과물 일체 이관: 발주사 소유 GitHub 저장소로 전체 소스코드 이관, 요구사항 정의서, DB 스키마 완비 및 세금계산서 발행을 완벽히 지원합니다.

일정이 엄수되어야 하는 중요한 프로젝트인 만큼, 속도와 품질을 모두 잡는 최선의 결과를 만들어 드리겠습니다. 감사합니다.
