## 5. 기술 선택 (비개발자 설명용)

- **이번 데모**: 바닐라 HTML/CSS/JS. 서버 없이 브라우저만으로 예약→운영 상태까지 체험 가능. 빌드 도구가 없어 어디서나 열리고 검증이 빠르다.
- **실제 서비스 제안 스택**: Next.js(반응형 웹) + Supabase(DB·인증 대비) + 포트원(PG).
  - Next.js: 매거진 피드·반응형을 한 코드로 만들기에 유지보수가 단순.
  - Supabase: 2주 일정에서 예약·재고 테이블과 관리자 화면을 가장 빠르게 안정 구축.
  - 포트원: 토스페이먼츠·KCP 등 주요 PG를 하나의 연동으로 붙여 9월 실결제 오픈에 유리.
  - 실제 PG는 사업자 정보·통신판매업 신고·환불 정책 확정·PG 심사(외부 의존) 후 별도 범위.

## 6. 일정·견적 근거 (제안안)

결정 기록: 73번 공고의 카드 예상금액은 500만원, 본문 범위는 500만~1,000만원이다. 루트 `CLAUDE.md` 최신 견적 규칙(공고 예상금액 우선, 기간은 공고 명시 기간 우선, 일당은 총액/총일수로 역산)을 적용해 **총액 500만원(VAT 별도)·15일**을 기준으로 산정한다. 기존 24일×30만원 또는 구 5만원 고정 산식은 이 건에 적용하지 않는다.

범위 원칙: 15일 안에서 실제 전체 서비스의 1차 오픈 범위만 포함한다. 데모에 없는 하위 화면을 억지로 늘리지 않고, 예약 탐색·상세·예약/결제 요청·담당자 운영·배포/인수에 필요한 최소 산출물로 맞춘다. PG 심사 통과 자체는 사업자 서류와 PG사 심사 일정에 좌우되는 외부 의존성이며, 본 견적에는 연동 준비·신청 지원·샌드박스/승인 후 실결제 전환 대응만 포함한다.

역산 단가: 500만원 ÷ 15일 = **일 33.333만원(약 33.3만원)**. 아래 금액은 소수 반올림 때문에 항목별 표기는 참고이며, 계약 기준 총액은 500만원이다.

## 8. 미확정 (needs_confirmation)

1. 결제 시점(선결제/확정 후 결제/가승인) — 공고 문구 기준 가정, 미팅 확정 필요.
2. 취소 수수료·환불 규칙 실제 값 — 데모는 D-7 100/D-3 70/D-1 50 가정치.
3. 예약조회 인증 방식 — 데모는 예약번호+연락처 뒤 4자리, 실서비스는 보안 검토 필요.
4. 서비스명 `CAMP FLOW`는 문서용 가칭.
