- category: documentation / reproducibility
- environment: 설치 Chrome 151.0.7922.172, 1440×900, 로컬 정적 서버
- reproduction:
  1. README 36~44행의 입력 없는 체험 순서대로 홈 기본 검색을 실행한다.
  2. 검색 결과에서 반려견, 제주, 전기 조건만 적용한다.
  3. empty 상태와 조건 초기화 버튼을 확인한다.
- expected: README 설명대로 0건 empty 상태와 조건 초기화가 표시된다.
- actual: empty가 아니며 결과 3건이 남는다. `readme_filter_empty=false`.
- acceptance: README 체험 조건을 현재 데이터에서 실제 0건이 되는 조합으로 고치거나, 해당 조합이 0건이 되도록 샘플 데이터를 의도적으로 조정한다.
- evidence: `qa/argos-v02/readme-experience-v02.txt:1`
- impact: 보안·예약 흐름에는 영향이 없지만 검토자가 문서대로 empty 복구를 재현할 수 없다.
- owner: hephaestus
- retest: 수정된 README의 절차를 설치 Chrome에서 그대로 실행해 empty=true 확인.
