| 확인한 근거 | 적용 조건 | MVP 반영 |

- 기상 악화, 캠핑장 폐쇄, 예약 확정 실패 시 전액 환불 기준.
- 통신판매업 신고번호와 하단 사업자 정보 노출 책임 주체: 플랫폼 사업자, 개별 캠핑장, 양자 병기 여부.

## 5. 치명적 리스크와 MVP 기능 매핑

## 6. 정적 데모 범위 제안

포함할 화면:
1. 탐색: 매거진형 피드 + 날짜 칩 + 지역/유형/반려견/카라반/전기/화로 필터
2. 상세: 사진/시설/규정/취소환불/가용 사이트/업체 확인 상태
3. 예약: 예약자 정보 목입력, 부가옵션 선택, 총액·환불액 계산
4. 완료: 목 결제 접수, 업체 확인 대기, 담당자 연락 예정, PG/사업자 체크리스트
5. 최소 운영 패널 1개: 캠핑장 목데이터 등록, 예약 요청 큐, 확정/대체/취소 상태 전환

제외할 것:
- 실제 서버, DB, PG, API, 로그인, 업체 관리자 CRUD
- 실제 개인정보 저장
- 실존 캠핑장/업체/고객 데이터 사용
- 복잡한 관리자 멀티페이지

## 7. 미확정 질문

3. 캠핑장 재고는 플랫폼 담당자가 수기로 관리합니까, 업체가 외부 채널과 병행 관리합니까?
4. 캠핑장별 취소·환불 규정은 동일 정책입니까, 업체별 정책입니까?
5. 부가옵션 제공자와 정산 책임자는 누구입니까?
6. 사업자 정보, 통신판매업 신고, PG 심사 자료는 누가 언제 준비합니까?
