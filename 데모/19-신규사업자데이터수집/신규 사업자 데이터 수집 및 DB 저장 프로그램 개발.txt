업무 내용
[프로젝트 개요]
- 신규 개업한 사업자 데이터를 공공 API 및 다양한 정보 소스를 통해 수집하고, 웹 사이트 검색을 통해 해당
  사업장의 연락처를 확보하여 내부 영업용으로 활용할 수 있는 리스트를 데이터베이스에 저장하는 프로그램 개발

[프로젝트 배경 및 목표]
- 신규 개업한 소상공인 및 신규 사업자를 대상으로 아웃바운드 영업을 진행하기 위해 영업 대상 사업자 정보가
  필요합니다. 공공데이터 API만으로는 사업장 연락처 확보가 불가능하여 실제 사이트 검색이 필요한 상황입니다.
  현재 수동으로 진행하고 있는 데이터 수집·정리 업무를 자동화하여 영업 담당자가 즉시 활용 가능한 형태로
  데이터베이스에 축적하는 것이 목표입니다.

[과업 범위]
1. 수행 범위
- 상세 기획: 데이터 수집 주기, 크롤링 대상 URL, 데이터베이스 스키마 설계
- 프로그램(스크립트) 개발: 공공데이터 API 연동 및 크롤링 개발
- 백엔드 개발: 크롤러·데이터 API 연동, 검색 데이터 크롤링 개발, 수집 자동화 스케줄러 개발
- 데이터베이스 구성: 수집 데이터 적재용 데이터베이스 설계 및 클라우드 서버 구축

2. 상세 기능 요구 사항
2-1. 공공데이터 연동 및 1차 수집 기능
- 국세청 사업자등록 상태 및 사업자등록 공공데이터 API 연동
- 상호명, 사업장 주소, 등록 정보, 업종 정보를 스케줄러로 내부 DB에 적재
- 매일 1회 지정된 시간에 신규 등록 사업장 목록을 조회하여 신규 건만 축적

2-2. 연락처 정보 수집 기능
- 1차 수집된 상호명과 사업장 주소를 조합하여 검색 포털 및 지도 서비스 검색 자동 실행
- 검색 결과 페이지에서 사업장 연락처를 텍스트로 추출하여 해당 사업자 정보에 연결
- 크롤링 차단 방지를 위한 IP 우회 또는 요청 간격 조절 적용
- 검색 결과가 없거나 수집이 실패한 경우 실패 사유 코드를 DB에 기록

2-3. 관리자 화면 기능
- 수집된 사업자 리스트 조회 화면 구현
- 상호명, 등록일자, 지역, 연락처 유무를 기준으로 리스트 필터링 및 검색 기능 구현
- 조회된 데이터 리스트를 엑셀 파일(.xlsx)로 다운로드하는 기능 구현
- 스케줄러 작동 상태 및 일자별 데이터 수집 성공 건수를 확인할 수 있는 화면 구현

[기술/제조 스택]
- 제안 요청

[지원 자격 및 우대 사항]
1. 지원 자격
- 서버 사이드 및 검색 사이트 데이터 크롤링 실무 수행 경험
- 공공데이터포털 API 연동 경험
2. 우대 사항
- 캡차 및 크롤링 차단 등 데이터 수집 방해 요소에 대한 기술적 대안을 제시할 수 있는 역량
- 스케줄러 기반 배치 운영 경험

[산출물]
- 데이터베이스 테이블 정의서
- 관리자 매뉴얼 및 화면 설계서
- 원본 소스 코드

[개인정보 관련 유의 사항]
- 수집한 데이터는 재판매 목적이 아닌 내부 영업 활동으로만 활용할 예정이며, 개인정보 활용에 대한 법적
  리스크는 클라이언트가 부담합니다.
