GUIDE

이용 안내

서식을 찾습니다

상단 검색창에 서식명, 사건유형(예: 대여금), 근거 법령(예: 민사집행법) 어느 것으로든 검색할 수 있습니다. 서식명이 기억나지 않으면 분야별 색인이나 사건 진행 단계별 색인에서 좁혀 들어가는 편이 빠릅니다.

미리보기로 구성을 확인합니다

서식 상세 화면에서 문서의 짜임과 기재 항목을 먼저 확인합니다. 작성 요령 탭에는 항목별 주의사항이, 첨부 서류 탭에는 제출 시 함께 내야 하는 서류 목록이 정리되어 있습니다.

한글 파일로 내려받습니다

한글 파일로 열기를 누르면 HWP 파일이 내려받아지고 PC에 설치된 한글에서 바로 열립니다. 전자소송 제출용은 HWPX, 인쇄용은 PDF를 선택하면 됩니다. 하루 내려받기 한도는 이용등급에 따라 다릅니다.

자주 쓰는 서식은 서식함에 담아 둡니다

사건별로 폴더를 만들어 담아 두면 해당 서식이 개정될 때 알림을 받고 최신본만 다시 받을 수 있습니다. 정회원은 300건, 프리미엄은 제한 없이 보관됩니다.

HWP SETUP

한글 연동 설정

내려받은 파일이 한글에서 바로 열리지 않는 경우, 대부분 파일 연결 설정 문제입니다. 아래 순서로 확인해 주세요.

파일 연결 확인 (Windows)

내려받은 .hwp 파일에서 마우스 오른쪽 버튼 → 연결 프로그램 → 한글을 선택하고 "항상 이 앱 사용"에 체크합니다.

브라우저 내려받기 설정

Chrome·Edge에서 매번 저장 위치를 묻도록 되어 있으면 확인 단계가 하나 늘어납니다. 브라우저 설정 → 다운로드에서 저장 폴더를 고정해 두면 클릭 한 번으로 열립니다.

HWPX가 열리지 않는 경우

HWPX는 한글 2014 이상에서 열립니다. 이전 버전을 쓰고 계시면 HWP 형식으로 내려받으시면 됩니다. 모든 서식은 HWP를 기본으로 제공합니다.

REQUEST

찾으시는 서식이 없으면 요청을 남겨 주세요. 법원 공식 서식은 보통 2영업일 안에, 실무 변형 서식은 검토 후 등록해 드립니다. 등록되면 알림으로 알려드립니다.
