[프로젝트 개요]
지도 기반으로 부동산 정보를 탐색하고 확인하는 웹 서비스의 프론트엔드 구축
프로젝트입니다.

[프로젝트 배경 및 목표]
현재 기획(화면정의서)과 백엔드 API 개발이 완료되었으며, 일부 기능이 구현된
데모 사이트가 존재합니다. 기존 데모 코드를 이어받아 화면을 퍼블리싱하고,
다음(카카오) 지도 API, 공공 API, PG 결제 등의 핵심 기능을 백엔드와 연동하여
서비스를 완성해 주실 프론트엔드 파트너를 찾습니다.

[과업 범위]

1. 수행 범위
- 기획 및 디자인: 제공된 화면정의서 및 데모 사이트를 기반으로 한 화면 퍼블리싱
  (디자인 공수 최소화)
- SW 개발: React 또는 Next.js 기반 프론트엔드 개발, 기 구축된 백엔드 REST API 연동,
  외부 SDK(지도, 공공API, PG) 연동

2. 상세 기능 요구 사항

2-1. UI/UX 및 공통 퍼블리싱
- 기존 데모 사이트 기반 PC/모바일 반응형 퍼블리싱
- 화면 간 라우팅 및 전역 상태 관리(Zustand 등) 구현
- 로딩 스피너, 에러 페이지 등 기본적인 예외 처리 UI 적용

2-2. 지도 및 부동산 탐색 시스템
- 다음(카카오) 지도 API 연동 및 초기화
- 백엔드 API 데이터를 활용한 지도 내 부동산 위치 핀(마커) 표시
- 마커 클릭 시 부동산 요약 정보 오버레이 노출

2-3. 공공 API 및 외부 연동
- 부동산 관련 공공데이터 API 연동 및 프론트엔드 데이터 바인딩 로직 구현
- 소셜 로그인(OAuth) 연동 및 JWT 토큰 기반 인증 처리

2-4. 결제 및 기타
- PG사 결제 모듈 프론트엔드 연동 및 결제 성공/실패/취소 라우팅 처리
- 기타 게시판 및 부가 기능 프론트엔드 구현

3. 비기능적 요구사항
3-1. 성능/규격: API 호출 최적화 및 지도 렌더링 지연 최소화
3-2. 보안/인증: 결제 및 공공 API 호출 시 안전한 토큰 관리 및 예외 처리

- React 또는 Next.js
- Daum(Kakao) Map API
- 공공데이터 API 및 PG 결제 모듈
- 상태 관리 라이브러리 (Zustand, Redux 등)

  사이트 소스코드, 공공 API 및 PG사 계약 정보
- 투입 인력 및 조직: 프로젝트 매니저, 백엔드 개발자
