## 체험 시나리오 — 이 순서로 보시면 3분입니다

### 지도 탐색

1. **좌하단 [렌더 성능] 패널에서 클러스터링을 꺼 보세요** ★
   프레임 시간이 **1.0ms → 33.4ms**로 뜁니다. 지어낸 수치가 아니라 지금 그린 프레임을 잰 값입니다.
   공고 3-1 "지도 렌더링 지연 최소화"가 왜 필요한지가 숫자로 나옵니다.

2. **필터를 걸어 보세요** — 거래유형·평형·가격·세대수·입주년차(호갱노노 축).
   2,467건이 실제로 걸러지고 지도와 목록이 함께 바뀝니다.

3. **목록에서 ⚠ 경고가 붙은 매물을 눌러 보세요** ★
   "좌표 매칭 실패 — 지도에 표시되지 않습니다"가 뜹니다.
   실거래가 API에 좌표가 없어서 생기는 문제를 화면으로 드러낸 것입니다(96건 · 3.9%).

4. 클러스터 클릭 → 자동 확대, 마커 클릭 → 요약 오버레이, 900px 이하에서 바텀시트 전환.

### 착수 전 검토

5. **[프론트 경계선] → "공공데이터 API 실제 호출" 버튼** ★ 핵심
   이 페이지에서 진짜로 호출합니다. **CORS는 통과합니다.** 대신 `serviceKey`가 URL에 그대로 남는 걸
   보여줍니다 — 공공데이터포털 키에는 도메인 제한이 없어 복사해 가면 누구나 씁니다.
   "커스텀 헤더로 호출" 버튼을 누르면 프리플라이트에서 막히는 것도 재현됩니다.

6. **[지오코딩 파이프라인]** — 캐시 히트 71.5% / 신규 지오코딩 24.6% / 매칭 실패 3.9%.
   실거래가 API 응답 샘플에 `lat/lng`이 없는 것도 함께 보여줍니다.

7. **[지도 렌더 성능] → 측정 실행** — 개별 마커 vs 클러스터링을 각 12회 측정한 중앙값.

8. **[결제 검증] → "0원으로 바꾸기"** ★
   서버 검증이 없으면 49,000원이 사라지고, 있으면 PG 원장 재조회로 차단됩니다.

9. **[일정]** — 계약 종료(9/2)와 오픈 희망일(9/15) 사이 **13일이 계약 기간 밖**입니다.

## ⚠️ 착수 전 확인이 필요한 항목

### 1. "프론트엔드 프로젝트"인데 프론트에서 못 하는 항목이 둘 있습니다 ★

공고 **2-3(공공 API 연동)** 과 **3-2(안전한 토큰 관리)** 는 브라우저 단독으로 성립하지 않습니다.
직접 호출해 확인한 결과입니다.

| 케이스 | 결과 |
|---|---|
| 단순 GET | **통과** (`ACAO: *`) |
| 프리플라이트(OPTIONS) | 실패 — ACAO 헤더 없음 |
| 커스텀 헤더 GET | 실패 |
| **서비스키** | **URL 쿼리에 그대로 노출 · 도메인 제한 없음** |

흔히 "공공데이터는 CORS가 막힌다"고 하지만 실제로는 단순 GET이면 통과합니다.
**진짜 문제는 키입니다.** 브라우저에 내려간 값은 전부 보이므로 "안전한 토큰 관리"는 원리적으로 불가능합니다.
→ **백엔드에 공공 API 프록시 엔드포인트가 있는지**가 1순위 확인 항목입니다.

### 2. 실거래가 API 응답에는 좌표가 없습니다

법정동코드 5자리 + 계약년월로 조회하고, 응답에는 지번·법정동명만 옵니다.
지오코딩이 필요하고 카카오 로컬 API 쿼터(일 10만)를 씁니다.
→ **서버에서 1회 지오코딩 후 캐시**를 제안합니다. 매칭 실패분은 지도에서 실제로 빠집니다.

### 3. 마커 1,000개부터 지도가 버벅입니다

카카오맵 데브톡에 마커 1,000개 이상 렌더링 지연, 2만 개 클러스터링 10초 보고가 있습니다.
→ 클러스터링 + 뷰포트 컬링을 기본값으로 두고, **프레임 시간을 화면에서 측정**합니다.

### 4. PG 결제는 프론트 콜백만 믿으면 금액이 바뀝니다

→ 결제 승인·금액 대조는 서버가 PG API로 재조회해야 합니다. **검증 엔드포인트 확인 필요.**

그 밖에 — **계약 30일과 오픈 희망일 사이 13일 공백**, **일부 공공 API의 국내 IP 제한**(해외 리전 배포 시 차단),
**"디자인 공수 최소화"인데 카테고리는 퍼블리싱**인 점도 정리했습니다.

자세한 근거는 [분석/기획_설계.md](분석/기획_설계.md) 2장을 참고하세요.

## 기술 구성 (데모)

- 순수 HTML/CSS/JS — 빌드 불필요, 외부 SDK 키 없이 동작
- **지도는 canvas 직접 렌더** — 카카오 SDK 키 없이 데모가 돌고, 프레임 시간을 우리가 직접 잴 수 있습니다
  (실서비스는 카카오 지도 JS SDK + 클러스터러를 씁니다)
- **모든 수치가 실제로 계산됩니다** — 매물 2,467건을 시드 기반으로 생성하고,
  좌표는 원본 레코드가 아니라 **별도 지오코딩 테이블에서 매칭**합니다(실거래가 API 구조를 그대로 반영)
- 가격은 ㎡당 단가 모델 — 강남 84㎡ 매매 중앙값 **23.8억**, 관악 84㎡ **8.9억**으로 실제 시세대에 맞췄습니다
- 클러스터링은 그리드 버킷 방식, 뷰포트 밖은 그리지 않음(컬링)
- 375px 가로 스크롤 0 · 900px 이하 바텀시트 전환
- **단지명·지번·가격·세대수는 전부 가상**입니다. 실존 단지와 무관합니다

실서비스 제안 스택: Next.js(App Router) + Zustand + 카카오 지도 SDK + TanStack Query,
공공 API는 **Route Handler 프록시 경유**, 배포는 **국내 리전 고정**
([기획_설계.md](분석/기획_설계.md) 5장)
