문의 주신 내용 먼저 말씀드리면 — 홈페이지부터 데이터 연동, 노션 DB, 리포트 자동 발송까지
정말 폭넓게 구상해 오셨더라고요. 이 정도로 흐름을 구체적으로 그려서 문의 주시는 분이
흔치 않아 인상 깊었습니다. 필요한 기능은 이미 다 짚으셨어요.

말씀만 드리기보다, 생각하신 흐름을 눌러 보실 수 있는 데모로 만들어 두었습니다.

  MOLIP 데모 — 공개 홈 + 통합 관리자 (입력 없이 버튼만으로 체험)
  https://jeonjaeman.github.io/demo-sites/molip/
  (공개 홈 우측 상단 “관리자 데모 →”로 실장용 화면까지 보실 수 있어요)

────────────────────────────────────────
[1] 만드는 사람 입장에서 솔직하게 하나

말씀하신 도구들(아임웹 + 구글시트 + 노션 + Make/Zapier)을 각각 붙여 연결하는 방식은
구현은 되지만 소모되는 자원이 꽤 큽니다.

· 일부 도구는 매달 구독료가 따로 나가고 (스택 합쳐 월 10만 원 안팎)
· 연결 지점이 많아질수록 그중 하나만 끊겨도 신청·리포트 흐름 전체가 멈추며
· 그때마다 손봐야 해 유지관리 부담도 커집니다.

그래서 이 흐름을 맞춤형 홈페이지 + 통합 관리자 시스템 하나로 깔끔하게 묶어 제안드립니다.
데모의 [왜 통합인가]에서 두 방식의 월 비용을 숫자로 비교해 두었어요(연 약 113만 원 절감).

[2] 제안 구성

① 맞춤형 홈페이지 — 메인·시설/요금·가입폼을 외부 플랫폼 없이 자체 제작(반응형·SEO·
   네이버/구글 검색등록). 웹디자인 전공이라 브랜드에 맞춰 완전 맞춤으로.
② 통합 관리자 — 보내주신 엑셀 출석표 양식 3개 시트를 그대로 화면으로 옮겼습니다.
   개인별 출석 체크(학생이 낸 계획 O표시 위에 실장님이 출석 체크), 전체 좌석 출석부
   (좌석×시간 한 화면, 시간대 일괄 체크), 월 60시간 규칙·운영시간(평일 15~24시/주말
   10~22시)도 자동 반영. 요금·공지·이벤트는 사장님이 직접 수정하는 편집기로, 데이터는
   구글시트로 자동 백업. 기존 양식 그대로 엑셀(CSV) 내보내기도 됩니다.
③ 리포트 자동 발송 — 계획(O표시) 대비 실제 출석을 주/월/연 리포트로 자동 생성해 학부모
   이메일로. 학부모가 가장 궁금한 "계획대로 하고 있는가"를 숫자로 보여줍니다. 데모 관리자
   [학습 리포트]에서 발송되는 이메일을 그대로 미리볼 수 있어요.

이렇게 하면 아임웹·자동화툴 같은 월 이용료가 0원이고, 연결이 끊길 지점도 없어 훨씬 안정적입니다.

[3] 짚어둔 것 세 가지 (데모 [리스크]에 대응까지 넣었어요)

· 학생 출석·학습은 미성년 개인정보 → 학부모(법정대리인) 동의 기반, 최소수집으로.
· 리포트 이메일은 “도달”이 생명 → SPF/DKIM 인증 트랜잭셔널 발송(대량 머지·스팸행 방지).
· “관리형”을 과하게 내세우면 학원법 등록 경계에 닿을 수 있어, 문구는 공간·자기주도 관리 중심으로.

────────────────────────────────────────
[4] 1차 견적 — 2,500,000원 (VAT 별도, 세금계산서 발행)

  · 맞춤형 홈페이지(메인·시설/시스템·요금·가입폼) · 반응형·SEO·검색등록
  · 통합 관리자(회원 + 출석·학습 입력/조회) · 요금/공지 편집기
  · 가입 신청 → 자체 DB 적재 + 구글시트 자동 백업
  · 주/월/연 학습 리포트 자동 생성·학부모 이메일 발송
  · 오픈 후 1개월 무상 유지보수

  예상 기간 — 3~4주 / 유지보수 — 이후 요청 건별 협의, 기본 0원

아래 세 가지 확인해 주시면 최종 금액으로 확정해 드릴게요.
  1) 출석·학습 데이터로 어떤 항목을 기록하실 계획인가요? (출석시간 / 과목·진도 / 자습시간 등)
  2) 리포트 받을 학부모 인원 규모와, 리포트에 넣고 싶은 내용은요?
  3) 사장님이 직접 수정하고 싶은 콘텐츠 범위는 어디까지일까요? (요금·공지·이벤트·사진 등)

의뢰자 부담 — 서버·도메인(소액) · 이메일 발송 도메인/인증 · (앱 확장 시) 스토어 등록.
