# MOLIP 몰입 스터디카페 — 기획·설계

> 관리형 스터디카페 신규 오픈 홈페이지 + 데이터 자동화 (크몽 견적 요청) · 제안용 데모
> ★ 혼합(하이브리드) 프로젝트 — 공개 홈(브랜드) + 통합 관리자(대시보드)를 표면별로 설계
> 모든 브랜드·회원·수치는 시연용 가상값

---

## 0. 의뢰 요약

- 업종: 프리미엄 관리형 스터디카페 · 타깃: 학생·학부모
- 핵심: **가입 신청 자동화 + 학부모 대상 출석/학습 리포트 자동 발송**
- 개발 범위:
  - 공개 홈(아임웹): 메인·시설/시스템·요금·가입 신청 폼 → 데이터 외부 연동
  - 데이터 연동/관리자: 아임웹 폼 → 구글시트 & 노션 동시 적재 · 실장용 일별/시간별 출석 슬롯(엑셀 양식 기반)
  - 리포트: 출석·누적 학습시간 → 주/월/연 학부모 이메일 자동 대량 발송(템플릿 시각화)
- 선호: 노코드 툴(Make/Zapier) 비용효율 연동 · 세금계산서 · 유지보수/API 비용 범위

### 별첨 분석
- **요구 txt**: 위 사양 + 이미 상세히 그린 흐름
- **출석표 xlsx**(3시트): 출석계획표 / 개인별 일일계획표 / 일별 전체출석표 — **좌석번호 × 시간(09:00~23:50, 50분 슬롯) × 날짜**. 월 최소 60시간 권장. → 관리자 출석 슬롯 UI의 정확한 근거

## 1. 핵심 제안 (발견 → 대안)

의뢰자는 필요한 기능을 이미 다 짚었습니다. 다만 **아임웹 + 구글시트 + 노션 + Make/Zapier를 각각
붙이는 방식**은 구현은 되지만:
- 도구마다 **월 구독료**가 쌓이고(월 10만 원 안팎),
- 연결 지점이 많아 **하나만 끊겨도 신청·리포트 전체가 멈추며**,
- 그때마다 사람이 손봐야 해 **유지관리 부담**이 큽니다.

→ **맞춤형 홈페이지 + 통합 관리자 + 리포트 자동 발송을 하나로 묶어** 제안합니다.
월 소프트웨어 구독료 **0원**, 끊길 연결 지점 없음, 데이터는 구글시트로 **백업만**.

## 4. 화면 구성 (★ 혼합 — 표면별)

### 공개 홈 (브랜드 표면, index.html) — ①②⑤ 적용
- 히어로(브랜드) · ② 풀블리드 statement · ① 마우스 카드(시설/시스템) · 요금 · 가입 신청 폼(→ 적재+구글시트 백업) · 비용 비교 진단 · 리스크 · 견적(2.5M + 3확인질문)

### 통합 관리자 (대시보드 표면, admin.html) — 대시보드 UI
- KPI · 회원 관리(신청 접수) · **출석 슬롯 그리드**(좌석×시간, 엑셀 양식 기반, 클릭 O→누적시간 실계산) · 주/월/연 **리포트 이메일 preview + 발송 시뮬** · 요금/공지 **편집기**(사장 직접 수정) · 구글시트 백업 표기

> 지침대로 한 저장소 안에서 화면 성격에 맞춰 혼합: 공개 홈은 브랜드 단락, 관리자는 대시보드.

## 5. 제안 스택·일정

- 자체 제작(정적/경량 SPA + 폼 백엔드) · 리포트 자동 생성·발송(SPF/DKIM 트랜잭셔널) · 구글시트 백업
- 일정: **3~4주** · 유지보수 오픈 후 1개월 무상, 이후 건별 협의(기본 0원)

## 6. 레드팀 검수(AI스러움 제거)

- 공개 홈은 프리미엄 학습 톤(웜 앰버·집중), 관리자는 데이터 가독 우선 — **표면이 섞이지 않게**
- 출석 그리드·리포트·비용비교는 실제 계산으로 근거 제시, 장식으로 늘리지 않음
