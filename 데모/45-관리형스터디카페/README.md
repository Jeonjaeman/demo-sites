# MOLIP 몰입 스터디카페 — 관리형 스터디카페 홈 + 통합 관리자 (제안용 데모)

관리형 스터디카페 신규 오픈 홈페이지 + 데이터 자동화. 아임웹·구글시트·노션·자동화툴을
각각 붙이는 대신 **맞춤형 홈 + 통합 관리자 + 리포트 자동 발송을 하나로** 묶어 월 구독료 0원으로.

## 체험 시나리오 (입력 없이 클릭만으로)

1. 공개 홈 **가입 신청**: `🪄 예시로 채우기` → `가입 신청하기` → 자체 적재 + 구글시트 백업 표시(체험).
2. **비용 비교**: 노코드 스택 월 10.5만 vs 통합 월 1.1만, 연 약 113만 절감을 숫자로.
3. **관리자 → 출석·학습**: 좌석을 고르면 출석 슬롯이 채워져 있고, 칸을 클릭하면 누적 학습시간이 실시간 계산됩니다.
4. **관리자 → 리포트**: 주/월/연을 바꾸면 학부모에게 가는 이메일 미리보기가 바뀌고, 발송 시뮬로 도달까지.
