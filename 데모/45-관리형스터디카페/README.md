# MOLIP 몰입 스터디카페 — 관리형 스터디카페 홈 + 통합 관리자 (제안용 데모)

관리형 스터디카페 신규 오픈 홈페이지 + 데이터 자동화. 아임웹·구글시트·노션·자동화툴을
각각 붙이는 대신 **맞춤형 홈 + 통합 관리자 + 리포트 자동 발송을 하나로** 묶어 월 구독료 0원으로.

> ★ 혼합(하이브리드) 프로젝트 — 지침대로 표면별로 설계했습니다.
> **공개 홈(브랜드)** = `index.html` · **통합 관리자(대시보드)** = `admin.html`
>
> ★ 관리자는 **의뢰자가 보내온 엑셀 출석표 양식(3개 시트)을 그대로 기능화**했습니다.
> ① 출석계획표(작성 규칙) ② 개인별 출석 계획표(시간×요일 O표시) ③ 일별 전체 출석표(좌석×시간)

공개 URL(별칭): `https://jeonjaeman.github.io/demo-sites/molip/`

| 요금 · 가입 신청 폼 | 신청 → 자체 적재 + 구글시트 자동 백업(체험) |

### 통합 관리자 (대시보드) — admin.html · 사이드바 6개 뷰
| 뷰 | 내용 |
|---|---|
| **대시보드** | KPI(활동·오늘 출석·현재 재실·평균 계획 이행률·신규 대기) · 시간대별 재실 캔버스 차트 · **관리 필요 학생**(월 60h 규칙 미달·이행률 저조 자동 감지) · 신청 접수 |
| **회원 관리** | 검색·상태 필터 · 월 목표/최근 4주 학습/지난주 이행률(실계산) · CSV 내보내기 |
| **개인별 출석** | 엑셀 「개인별 출석 계획표」 그대로 — 계획(O·빗금) 위에 출석 체크. 출석/계획 편집 2모드 · 주 이동 · 계획 미이행 표시 · **월 60h 규칙 자동 판정** |
| **전체 좌석 출석** | 엑셀 「일별 전체 출석표」 그대로 — 20석×시간 그리드, **시간 헤더 클릭 = 일괄 체크**, 날짜 이동, 가동률·재실 차트, **엑셀 양식 CSV 내보내기** |
| **학습 리포트** | 학생·주/월/연 선택 → **계획(O) 대비 실제 출석** 이메일 미리보기(출석일·학습시간·이행률·페어 바)·발송 시뮬(SPF/DKIM) |
| **요금·공지 편집** | 요금·공지·이벤트·운영시간을 사장 직접 수정 → 홈 즉시 반영 |

**엑셀 규칙 반영** — 학기중 운영시간(평일 15:00–24:00·주말/공휴일 10:00–22:00)을 그리드에서
운영시간 외로 잠그고, 상단 **학기중/방학 전환**으로 바뀝니다. 「한 달 최소 60시간」 규칙은
계획 월 환산으로 자동 판정해 미달 학생을 대시보드에 띄웁니다.

**뷰 간 동기화** — 전체 좌석에서 일괄 체크하면 개인별 출석·리포트 수치에 즉시 반영됩니다
(같은 데이터를 한 곳에서 관리 — 구글시트+노션 이중 적재의 대안이라는 제안 요지 그대로).

## 체험 시나리오 (입력 없이 클릭만으로)

1. **관리자 → 대시보드**: 오늘 재실 차트와 “관리 필요 학생”(60h 규칙 미달·이행률 저조)이 이미 떠 있음 → [리포트] 버튼으로 해당 학생 리포트 바로 미리보기.
2. **개인별 출석**: 학생을 고르면 계획(빗금 O)과 출석이 채워져 있고, 칸 클릭·주 이동·계획 편집 모드 전부 동작. 우측 요약에 이행률·월 목표 페이스·60h 규칙 판정.
3. **전체 좌석 출석**: 시간 헤더를 클릭하면 그 시간대 전좌석 일괄 체크 → 개인별 출석에도 반영. 「엑셀 양식 CSV」로 기존 출석표 포맷 그대로 다운로드.
4. **학습 리포트**: 주/월/연·학생을 바꾸면 계획 대비 실제 페어 바가 실계산으로 바뀌고, 발송 시뮬로 도달까지.
5. 공개 홈 **가입 신청**: `🪄 예시로 채우기` → `가입 신청하기` → 자체 적재 + 구글시트 백업 표시(체험).

## 디자인·기술

- 도메인: 스터디카페 브랜드 랜딩 · 아임웹/노션/Make(대안 비용 근거) / 디자인: Linear·Vercel 메트릭
- 관리자: 다크 사이드바(딥 차콜) + 웜 크림 컨텐츠 · SVG 라인 아이콘 · 이모지 미사용 · 절제 모션
- 웜 크림/차콜 + 앰버(스탠드 조명) · 정적 HTML/CSS/JS(빌드 없음) · Pretendard · 외부 라이브러리 미사용
- 출석·이행률·가동률·리포트 전부 **그리드에서 실계산**(하드코딩 없음) · 캔버스 차트 dpr 대응
- CSV는 Blob + UTF-8 BOM(엑셀 한글 호환) · 100vw 풀블리드 · `overflow-x:clip` · `prefers-reduced-motion`
