# 오브젠 통합 기업 홈페이지 기획·설계

## 1. 프로젝트 정의

오브젠과 잘레시아의 합병 이후 새로운 기업 정체성을 대외적으로 설명하는 공식 통합 홈페이지 구축 제안이다. 단순한 회사 소개가 아니라 고객, 투자자, 언론, 파트너, 운영자가 각자 필요한 정보와 행동으로 빠르게 이동하는 정보 허브를 목표로 한다.

원본 요구사항:

- 반응형 웹, 약 25페이지
- 회사소개, 합병 스토리, 제품·서비스, 뉴스·공지, IR, 문의
- 통합검색, 관리자, 다국어 선택 옵션
- 로그인 없는 공개 기업·IR 사이트
- 기획·디자인·퍼블리싱·개발·QA·오픈 지원

## 2. 핵심 문제

1. 합병의 의미가 첫 화면에서 이해되어야 한다.
2. 기존 제품 나열을 “수집 → 통합 → 분석 → 실행” 흐름으로 재구성해야 한다.
3. 고객용 제품 정보와 투자자용 공식 정보가 서로 방해하지 않아야 한다.
4. 공지·IR·보도자료가 검색, 필터, 다운로드까지 자연스럽게 이어져야 한다.
5. 운영자가 콘텐츠를 수정할 때 페이지 전체가 다시 로드되는 인상을 주지 않아야 한다.

## 3. 제안 콘셉트

### Signal Loom

오브젠의 고객 데이터·마케팅 실행 역량과 잘레시아의 데이터 엔지니어링·BI 역량을 서로 다른 두 흐름으로 시각화한다. 두 흐름은 통합 AI 제어 레이어에서 만나 하나의 의사결정 신호가 된다.

핵심 메시지:

> 고객 데이터와 경영 데이터를 연결해, 다음 행동이 보이는 기업을 만듭니다.

## 4. 정보 구조

실 구축 기준 약 25개 상세 페이지를 다음 7개 상위 메뉴로 묶는다.

1. 회사소개
   - 통합 법인 소개, CEO 메시지, 조직, 연혁, 합병 스토리, 성장 전략, 오시는 길
2. 통합 플랫폼
   - 플랫폼 개요, CDXP+, Analytics, onCMS, Sales Cloud, 생성형 AI, Smart AI/MLOps, Data Intelligence, Survey
3. 산업별 적용
   - 금융, 유통, 제조, 공공
4. 서비스
   - 컨설팅, 데이터 구축, AI 모델링, 운영 지원
5. 신뢰와 거버넌스
   - 접근 통제, 데이터 품질, 감사 이력, 배포 방식
6. 홍보·IR
   - 공지, 보도자료, 공시, IR 자료, 홍보 영상
7. 문의
   - 사업·제품, 파트너십, IR, 연락처

데모는 25개의 얇은 화면을 만드는 대신, 핵심 사용자 판단을 검증할 수 있는 공개 사이트·통합검색·문의·관리자 기능을 깊게 구현했다.

## 5. 화면별 기능

### 공개 홈페이지

- 합병 후 통합 역량을 보여주는 시스템 맵
- 플랫폼 단계 탭: 선택 영역만 즉시 갱신
- 산업별 시나리오 탭
- 거버넌스 상세 펼침
- 뉴스·IR 유형 필터
- 가상 문서 Blob 다운로드
- 통합검색 다이얼로그와 결과 개수 안내
- 한국어/영어 핵심 메시지 전환
- 문의 폼 검증과 개인정보 안내

### 관리자 데모

- 공지·IR·보도자료 목록
- 제목 검색, 유형 필터
- 콘텐츠 등록·수정
- 게시/임시 상태
- `localStorage` 저장 및 초기화
- 패널 기반 편집으로 화면 전체 재렌더링 방지

## 6. 데이터와 사실성 원칙

- 공식 사이트와 공개 자료로 확인한 회사명, 제품명, 합병 맥락만 실제 사실로 다룬다.
- 고객명, 실적, 재무 수치, 일정, 연락처, IR 문서는 임의 생성하지 않는다.
- 데모용 날짜·문서·시나리오는 화면에 “제안용 가상 데이터”로 표시한다.
- 실제 구축 단계에서 공시·IR·개인정보·보안 문구는 법무·IR 책임자 검수를 거친다.

## 7. 기술 구조

- 순수 HTML/CSS/JavaScript
- 빌드 과정 없이 정적 서버에서 즉시 실행
- SVG·CSS 기반 시그니처 그래픽
- `dialog`, `IntersectionObserver`, `Blob`, `localStorage` 등 브라우저 표준 기능 사용
- 탭, 필터, 편집은 해당 DOM만 갱신
- `prefers-reduced-motion`, 키보드 초점, `aria-live`, 의미 있는 HTML 랜드마크 적용

## 8. 실제 구축 권장 단계

1. 이해관계자 워크숍과 콘텐츠 감사
2. 합병 후 브랜드 메시지·명칭 체계 확정
3. 25페이지 IA와 URL·SEO 매핑
4. 디자인 시스템과 핵심 템플릿 승인
5. CMS, 검색, 문의, IR 배포 파이프라인 개발
6. 데이터 이관과 국·영문 콘텐츠 작성
7. 접근성·보안·성능·크로스브라우저 QA
8. 운영 교육, 모니터링, 오픈 후 안정화
