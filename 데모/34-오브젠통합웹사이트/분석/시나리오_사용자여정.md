# 오브젠 통합 기업 홈페이지 사용자 여정

## 1. 잠재 고객

목표: 합병 후 무엇이 달라졌는지 이해하고 자신의 업무 문제와 맞는 역량을 찾는다.

1. 검색 또는 소개 링크로 홈페이지 진입
2. 첫 화면에서 고객 데이터와 경영 데이터의 결합 메시지 확인
3. 통합 플랫폼 단계에서 현재 문제 지점 선택
4. 산업별 적용에서 데이터 → 분석 → 행동 구조 확인
5. 신뢰·거버넌스와 배포 선택권 검토
6. 사업·제품 문의 작성

성공 조건:

- 10초 안에 통합 회사의 가치가 읽힌다.
- 제품명보다 업무 흐름을 먼저 이해한다.
- 문의 폼까지 재탐색 없이 도달한다.

## 2. 투자자·애널리스트

목표: 합병 맥락, 사업 구조, 최신 IR 정보를 빠르게 검토한다.

1. 검색 또는 IR 링크로 진입
2. 합병 스토리와 통합 포트폴리오 확인
3. 홍보·IR 섹션에서 자료 유형 필터
4. 문서 다운로드
5. 통합검색으로 특정 제품·합병 정보 재확인
6. IR 문의로 이동

성공 조건:

- IR 자료가 마케팅 콘텐츠와 시각적으로 구분된다.
- 날짜, 유형, 제목, 다운로드가 한 행에서 읽힌다.
- 가상 데이터와 공식 정보가 혼동되지 않는다.

## 3. 언론·미디어

목표: 최신 발표와 회사의 공식 메시지를 확인한다.

1. 통합검색 열기
2. 회사명, 합병, 제품명 검색
3. 보도자료 필터 적용
4. 관련 회사·플랫폼 정보 교차 확인
5. 문의 유형에서 담당 경로 선택

성공 조건:

- 검색 결과 수가 즉시 안내된다.
- 검색과 필터는 페이지 전체를 다시 로드하지 않는다.

## 4. 파트너·채용 관심자

목표: 회사가 강한 영역과 협업 가능성을 판단한다.

1. 합병 후 역량 구조 확인
2. 산업별 시나리오 탐색
3. 서비스 범위와 운영 원칙 확인
4. 파트너십 문의

성공 조건:

- 실제 고객 실적으로 오해할 만한 가상 수치를 사용하지 않는다.
- 협업 문의 유형이 일반 제품 문의와 구분된다.

## 5. 콘텐츠 운영자

목표: 공지·IR·보도자료를 빠르고 안전하게 관리한다.

1. 관리자 데모 진입
2. 유형 필터 또는 제목 검색
3. 기존 콘텐츠 편집 패널 열기
4. 제목·요약·게시 상태 수정
5. 저장 후 해당 행과 통계만 갱신
6. 새로고침해도 브라우저 저장 상태 확인
7. 초기화로 제안용 시드 데이터 복원

성공 조건:

- 버튼 클릭 때 애플리케이션 루트가 교체되지 않는다.
- 편집 중인 맥락과 스크롤 위치가 유지된다.
- 저장 결과가 토스트와 표에서 즉시 확인된다.

## 6. 예외·오류 여정

- 검색 결과 없음: 0건 안내와 추천 검색어 유지
- 문의 필수값 누락: 오류 요약에 초점을 이동하고 브라우저 기본 오류도 제공
- 잘못된 이메일: 제출하지 않고 해당 필드 형식 안내
- 관리자 저장 데이터 손상: 시드 데이터로 안전 복원
- 모션 축소 설정: 애니메이션 없이 동일 정보 제공
- 작은 화면: 표를 읽을 수 있는 핵심 열로 축소하고 편집기는 전체 폭 패널로 전환
