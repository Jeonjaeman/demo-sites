## 핵심 발견 (근거 URL은 리서치 원문 기준)
- **A-2 ceil 부동소수 = 배치 1개 과청구**: Math.ceil(0.1*60)=7 실사고. → 엔진 전체 정수 최소단위 연산 + 배치 경계 불변식 (bugs.ruby-lang.org/issues/13599)
- **A-4 목표 용량 ≠ 실용량**: 초회효율 NMC 85~88%·흑연 90~92% → 설계/실용량 2단 표시 (medium.com/batterybits FCE)
- **A-5 N/P 1.10·음극 오버행**: "전극 소요량" 단수 정의를 양·음극 분리로 교정 (batterydesign.net)
- **A-6 권취 나선**: L=π(D²out−D²in)/4t, 18650 내경 17.5·권심 2mm — 미확정 #5 가정 채움 (batterydesign.net/cylindrical-cell-electrode-estimation)
- **B-1 소급 금지 = 불변 버전 행+스냅샷**: Stripe "create a new price... immutable record" (docs.stripe.com) + Fowler Snapshot/AuditLog
- **B-4 검증 4단**: 골든(엑셀 원 단위 일치 인수 기준) → property(배치 경계·단조·멱등·비음수) → metamorphic → 프론트/서버 대조 CI. V&V 분리(ASME V&V 10) — 미확정 5건 확정 전 Validation 불가
- **C-2 슬롯 키 = calendar_id**: EXCLUDE USING GIST(공유 캘린더 예외) + tstzrange '[)' (postgresql.org/docs/rangetypes)
- **C-3 수기 입금 = 홀드+TTL**: Shopify 예약·확정 동일 트랜잭션 사례
- **C-5 환불 기준 시각 = 요청 접수 서버 시각**: WMU 코터 공개 티어(D-21/15/8/0, 100% 몰취 없음) 벤치마크
- **E-1/2 전자상거래법**: B2B 원칙 비적용이나 소비자 간주 예외 → "청약철회" 용어 금지·개별생산 별도 동의 모달
- **E-3 세금계산서 공급시기 특례**: 발행 후 7일 경고 대시보드
- **F-1 국가핵심기술**: Ni 80% 초과 양극재 지정 확인 → 사전 진단·해외 계정 차단·국내 리전 (law.go.kr 고시 2023-60)
- **F-6 Draft 명세 = CR 절차 선제시**: 무상 허용량 게이지
