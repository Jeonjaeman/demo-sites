# CELLFAB 셀팹 — 이차전지 파일럿 제조 주문 플랫폼 데모

위시켓 「이차전지 파일럿 제조 서비스 고객 주문 플랫폼 구축」 (3,000만 원 · 90일 · 마감 8/17) 대응.

- 고객 포털: https://jeonjaeman.github.io/demo-sites/cellfab/
- 관리자: https://jeonjaeman.github.io/demo-sites/cellfab/admin/

## 체험 시나리오 (타이핑 없이 — 전부 프리필)

1. **전극 케이스**: 3단계 스텝레일 → 실시간 축척 도면 → 2단계에서 레인을 2로 → **폭 초과 경고 + 해법**(레인 축소/폭 상한) → 3단계 수율 슬라이더(50~95%)로 배치 수·가격 실시간 변동 → **계산 체인 9단계 전부 공개** → 배치 경계 안내("여유 N L — 추가 비용 없이 증량 가능")
2. **셀 케이스**: 파우치/원통 → 설계 용량 vs **예상 실용량(초회효율 반영)** 2단 표시 → 양극·음극 소요 분리(N/P 1.10) → 권취 나선 시각화 → N/P를 1.08로 낮추면 석출 마진 경고
3. **제출**: 개별생산 **별도 동의 모달**(약관과 분리 — 전자상거래법 시행령 요건) → 심사 큐 적재
4. **슬롯**: 라인 1·2가 캘린더 공유 — 자재 조달 구간 비활성, 홀드 카운트다운, **동시 예약 시뮬레이션**
5. **내 케이스**: 견적마다 상수 v·엔진 v·입력 해시 동결 배지 → **환불 시뮬레이터**(오늘/7일 뒤/착수 후, 불가분 산정 근거 명시) → **열람 이력**(내 설계를 누가 봤나)
6. **관리자**: 심사 큐(SLA·조성 마스킹) → 입금·홀드 TTL(+세금계산서 7일 경고) → **소급 방지 검증**(단가 변경 → 기존 케이스 불변) → **계산 엔진 검증 탭**(골든 14건 + 불변식 4종×500회가 브라우저에서 실제 실행) → 12상태 전이(불법 전이 차단) → CR 관리 → 기술보호(Ni80% 플래그·해외 차단)

## 핵심 발견 → 기능 (상세: 분석/기획_설계.md)

| 발견 | 데모 기능 |
|---|---|
| ceil 부동소수 = 배치 1개 과청구 (실사고 사례) | 엔진 전체 **정수 최소단위 연산** + 배치 경계 불변식 자동 검출 |
| 목표 용량 ≠ 실용량 (초회효율 NMC 85~88%) | 설계/실용량 2단 표시 |
| 소급 금지는 UPDATE 구조로 불가 (Stripe 원칙) | 불변 버전 행 + 케이스 스냅샷 — 관리자 검증 화면 |
| 슬롯 잠금 키 = 캘린더(공유 예외) | 공유 캘린더 UI + 동시 예약 시뮬 |
| 수기 입금 공백 | 홀드+TTL 큐, 만료 임박 정렬 |
| 검증 접근(공고 제안 요청) | 골든·불변식 **실행 버튼** — V&V 분리 프레임 |
| 국가핵심기술(Ni>80%) | 자동 플래그·해외 계정 차단·국내 리전 |

## 데모 범위 명시
로그인·비밀번호 재설정·다국어(영문)·이메일 통지·파일 업로드는 데모에서 생략(로그인 후 상태 가정) — 실구축 포함. 상수는 전부 가정값(미확정 5건은 화면 배지).
