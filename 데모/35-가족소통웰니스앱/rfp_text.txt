모바일 앱 개발 제안요청서 (RFP) 
React Native 앱 개발 (백엔드 API는 발주처 기 구축·제공) · 견적 제안 요청 
1. 사업 개요 
항목 내용 
사업명 모바일 앱(iOS/Android) 개발 — 백엔드 API는 발주처가 기 구축·제공 
발주처 식품·헬스케어 분야 기업 (제안사 선정 후 개별 안내) 
사업 기간 계약 체결 후 착수 ~ 2026년 10월 정식 출시 목표 
발주 범위 React Native 기반 iOS/Android 앱 개발 및 발주처 제공 API 연동 (백엔드·관
리자 페이지는 발주처 기 보유, UI 디자인은 별도 업체 수행) 
계약 방식 총액 도급 계약 · 제안 견적 기반 협상 
 
1.1 사업 배경 및 목적 
본 서비스는 성인 자녀와 부모 세대를 하루 한 번의 공동 미션으로 연결하는 가족 소통·웰니스 모바일 
앱입니다. 현재 서비스 기획과 화면 설계(IA·와이어프레임)가 확정되어 있으며, UI 디자인은 별도 지정 
업체가 수행합니다. 
백엔드 서버와 API는 발주처가 이미 구축하여 운영 중이며, 본 사업은 이를 연동하는 React Native 기
반 iOS/Android 앱을 개발할 수행사를 선정하는 것을 목적으로 합니다. 2026년 10월 정식 출시를 목
표로 합니다. 
2. 사업 범위 
상세 요건은 (제안사 선정 후 제공되는) 과업지시서 및 IA(화면구조도)·와이어프레임을 따르며, 본 장
은 범위의 개요입니다. 
구분 범위 
모바일 앱 React Native 기반 iOS/Android 동시 개발 · 총 24개 화면 (온보딩 5, 홈·미션 6, 레
시피 3, 피드 1, 건강 2, 랭킹 2, 설정 5). 화면 UI 구현, 상태관리, 앱 내 API 연동, 네
이티브 연동 및 빌드 일체를 포함한다.

3. 계약 조건 
● 무상 하자보수: 검수 완료(출시) 후 3 개월. 개발 범위 내 기능 결함(버그)은 개발사 책임으로 
무상 수정합니다. 
● 유상 유지보수: 신규 기능 추가, OS 버전 업데이트 대응, 외부 API·SDK 변경 대응, 서버 이전 
등은 무상 하자보수 범위에 포함되지 않으며 별도 유상 계약으로 처리합니다. 연간 유지보수 
요율(개발비 대비 %) 및 등급별 M/M 단가를 제안 시 함께 제시합니다. (유상 유지보수가 
가능한 경우에 한하며, 필수 계약 조건은 아닙니다) 
● 지식재산권: 본 과업으로 산출된 소스코드 및 산출물 일체의 권리는 발주처에 귀속됩니다. 
● 보안: 계약 시 비밀유지협약(NDA) 체결, 개인정보 처리 관련 발주처 법무 검토 사항 준수. 
● 디자인 협업: 발주처가 제공한 디자인 산출물(Figma)을 기준으로 개발하며, 디자인 업체에 
협조합니다. 
● 대금 지급 조건: 선금·중도금·잔금 비율 및 지급 시점은 제안 후 협의하여 확정합니다. (잔금은 
검수 합격 후 지급을 원칙으로 함)

5. 유의사항 및 문의 
● 본 RFP 및 첨부 자료는 제안 목적 외 사용·외부 공개를 금하며, 제안 시 비밀유지에 동의한 
것으로 간주합니다. 
● 상세 과업지시서, 화면구조도(IA), 와이어프레임 등 세부 자료는 제안 의사를 밝힌 업체에 
한하여 비밀유지 동의 후 개별 제공합니다. 
● 문의 및 제안 접수는 본 플랫폼의 메시지 기능을 통해 진행합니다.
