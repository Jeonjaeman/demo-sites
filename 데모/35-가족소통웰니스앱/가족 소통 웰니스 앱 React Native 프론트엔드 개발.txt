[프로젝트 소개]
- React Native 기반 iOS/Android 앱을 개발하는 프로젝트입니다. 가족 소통·웰니스 분야 모바일 앱으로, 성인 자녀와 부모 세대를 하루 한 번의 공동 미션으로 연결하는 서비스입니다. 서비스 기획과 화면 설계(IA·와이어프레임)가 확정되어 있으며, UI 디자인은 별도 지정 업체가 수행 후 Figma로 전달 예정입니다. MVP를 웹으로 구현해 둔 상황이라 백엔드 서버와 API는 발주처가 구축·운영 중이며, 본 프로젝트는 이를 연동하는 앱 프론트엔드 개발에 한정됩니다. 추가적으로 모바일 앱에 필요한 백엔드 개발이 이루어져야 하는 경우 발주처에서 수행합니다.

[프로젝트 진행 상황]
- 기획 완료, 화면 설계(IA·와이어프레임) 완료
- UI 디자인 별도 업체 진행 중 (~7월 말)
- 백엔드·API 발주처 자체 구축·운영 중

[과업 범위]
1. 수행 범위
- 프런트엔드/Client 개발 (iOS, Android 크로스플랫폼)
- 외부 서드파티 SDK 및 네이티브 모듈 연동
- 앱 스토어 심사 대응 및 정식 배포
- 백엔드 개발 및 관리자 페이지 구축은 과업 범위에서 제외 (당사 수행)

2. 상세 기능 요구 사항
2-1. 화면 및 공통 기능 구현
- 30개 내외의 화면 UI 구현 (온보딩, 홈, 미션, 레시피, 피드, 건강, 랭킹, 설정 화면)
- 앱 내 상태 관리 및 재사용 가능한 공통 컴포넌트 설계
- 당사에서 제공하는 RESTful API 연동 및 데이터 바인딩

2-2. 인증 및 가족 그룹 기능
- 카카오 소셜 로그인, 회원가입, PASS 본인인증 데이터를 수집하여 처리
- 가족 그룹 생성, 초대 코드 발급, 카카오톡 초대 공유, 코드 입력 합류 기능 구현

2-3. 건강 데이터 및 SDK 연동
- Apple HealthKit 및 삼성헬스(Health Connect) 걸음 수 데이터를 수집하여 API로 동기화
- 에이슬립(A-sleep) 수면 데이터 SDK를 연동하여 수면 시간, 수면 단계, 주간 데이터 정보를 수신하여 화면에 출력
- 디바이스 카메라 및 앨범 접근 권한을 획득하여 미션 인증용 이미지 등록 기능 구현

2-4. 미션 및 리워드 로직 처리
- API 데이터를 기반으로 가족 전원 달성 판정, 재료 획득 로직 화면 처리
- 특정 조건 달성 시 레시피 잠금 및 해제 상태 UI 반영

2-5. 푸시 알림 및 앱 딥링크
- 핑거푸시(Finger Push) SaaS 솔루션을 연동하여 디바이스 토큰 발급 및 기기 등록
- 푸시 수신, 푸시 탭 이벤트, 딥링크를 통한 특정 화면 라우팅 처리

2-6. 마켓 출시 및 심사
- Android APK/AAB 및 iOS IPA 패키징
- Google Play Store 및 Apple App Store 심사 등록 및 반려(Reject) 시 수정 대응

3. 비기능적 요구사항
3-1. 성능 및 규격
- React Native 프레임워크를 사용하여 단일 코드베이스로 iOS와 Android를 동시 지원해야 함
- 외부 SDK(수면, 푸시, 본인인증) 연동 시 공식 React Native 플러그인이 없을 경우, 네이티브(Swift, Kotlin) 브릿지 코드를 직접 작성하여 호환성을 확보해야 함
- 백그라운드/포그라운드 상태 전환 시 헬스 데이터 동기화 누락 방지 처리
3-2. 보안 및 인증
- PASS 본인인증 및 카카오 로그인 시 발급되는 토큰 및 개인정보의 안전한 클라이언트 측 보관(보안 스토리지 활용)
- 사용자 건강 데이터 접근 시 OS 표준 가이드에 따른 명시적 권한 획득 프롬프트 구현
