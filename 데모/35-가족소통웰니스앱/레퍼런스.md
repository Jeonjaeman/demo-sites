# 레퍼런스 분석 — 가족 소통·웰니스 앱

서비스의 핵심 루프(하루 1회 공동 미션 → 가족 전원 달성 → 재료 획득 → 레시피 해제)를 구성 요소별로 분해해, 각 요소의 대표 레퍼런스를 정리했다.

## 1. 관계 기반 데일리 리추얼 — 썸원(SumOne)
- [sumone.co](https://www.sumone.co/) · [Google Play](https://play.google.com/store/apps/details?id=com.sumone&hl=en_US)
- **하루 1개 질문에 둘 다 답해야 완성**되는 구조 = 본 서비스의 "가족 전원 달성 판정"과 동일한 상호 의존 루프. 누적 1,000만 사용자로 검증된 모델
- 답변 완료 시 캐릭터(에그몬)가 성장하고 재화(pebble)를 모아 꾸미기 → **미션 보상 = 재료 수집 = 레시피 해제**로 치환 가능
- **콕 찌르기(nudge) 리마인드**: 상대가 미답 시 알림 재촉 기능 — "가족 전원 달성" 모델의 이탈 방어 장치로 그대로 차용할 것 (데모의 "콕 찌르기" 버튼)
- 교훈(리뷰 불만): 재화 적립 속도·콘텐츠 다양성 부족 불만 다수 → 미션 풀·레시피 풀의 주기적 갱신이 운영 핵심

## 2. 미션 인증 UX — 챌린저스
- [나무위키 분석](https://namu.wiki/w/%EC%B1%8C%EB%A6%B0%EC%A0%80%EC%8A%A4) · [사용성 분석 글](https://brunch.co.kr/@bydot/9)
- **사진 인증샷 중심의 미션 수행 UX** 국내 표준: 카메라 즉시 촬영 → 인증 가이드(예시 사진) → 제출 → 피드 노출
- 달성률 85% 이상 환급이라는 명확한 판정 규칙 → 본 서비스도 "오늘 가족 3명 중 2명 완료" 같은 **판정 상태의 실시간 가시화**가 중요 (데모 홈의 가족 달성 현황 링)
- 인증 방식 다양화(사진·좋아요·리뷰 등) 사례 → 걷기 미션은 사진 없이 **걸음 수 자동 판정**으로 마찰 제거

## 3. 걸음 수 리워드 — 캐시워크
- [cashwalk.com](https://cashwalk.com/) · [나무위키](https://namu.wiki/w/%EC%BA%90%EC%8B%9C%EC%9B%8C%ED%81%AC)
- 100걸음=1캐시의 **즉각적·시각적 적립 피드백**, 잠금화면 상시 노출로 습관화 — 시니어 포함 전 연령 검증된 만보기 UX
- 브랜드 협업 챌린지(삼성화재 '착!한걷기' 등) 운영 사례 → 식품·헬스케어 발주처의 브랜드 미션 확장성 근거
- 데모 반영: 홈·건강 탭의 걸음 수 링 게이지 + 목표 대비 % + 가족별 걸음 비교

## 4. 수면 데이터 — 에이슬립(A-sleep)
- [asleep.ai](https://www.asleep.ai/) · [기술 문서](https://docs.asleep.ai/docs/system-overview) · [에이닷 슬립 사례](https://medigatenews.com/news/1572864264)
- 별도 기기 없이 **스마트폰 마이크 호흡음으로 수면 단계 분석**하는 SDK. 측정 시작/종료 함수 호출로 연동, 30초 간격 서버 업로드
- 리포트 구성이 사실상 표준: **총 수면 시간 · 수면 점수 · 단계별 비율(깸/렘/얕은/깊은) · 수면 효율 · 주간 추이** → 데모 건강 탭의 수면 리포트를 이 스키마 그대로 구성
- SKT 에이닷 탑재로 대중 검증 완료 — 발주처가 이 SDK를 지정한 배경
- 주의: 마이크 상시 사용 → iOS 심사·배터리·권한 UX 리스크는 니즈분석 §2-A-2, §2-B-8 참고

## 5. 가족 공유 피드 — FamilyAlbum(패밀리앨범)·카카오톡
- FamilyAlbum: 가족 전용 폐쇄형 사진 공유(월 1억 장 업로드) — **"가족만 보는 안전한 피드"** 톤앤매너, 조부모 세대도 쓰는 단순한 타임라인
- 카카오톡: 초대 공유·리마인드 채널로서의 역할(RFP 명시). 초대 코드 복사 + 카톡 공유 버튼의 이중 제공이 국내 표준
- 데모 반영: 피드 1화면 = 미션 인증 사진 타임라인 + 가족 리액션(이모지)

## 6. 시니어 UX 원칙 (부모 세대 대응)
- 국내 시니어 대상 서비스(시니어 모드 뱅킹앱, 큰글씨 카톡)의 공통 원칙:
  - 본문 16px+ / 핵심 수치 24px+, OS 폰트 크기 설정 존중
  - 터치 타깃 48dp 이상, 한 화면 한 가지 행동
  - 전문용어 대신 구어체 카피("오늘 미션을 완료했어요!")
- 온보딩은 **자녀 주도**(자녀가 그룹 만들고 부모는 초대 링크 탭 → 카카오 로그인 → 끝)로 설계하는 것이 이탈 최소화의 핵심
