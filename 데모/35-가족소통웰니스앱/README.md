성인 자녀와 부모 세대를 **하루 한 번의 공동 미션**으로 연결하는 서비스.
가상의 브랜드 「한상(HANSANG) — 하루 한 번, 우리 가족 한 상」으로 RFP의 **24개 화면 전부**를 인터랙티브 폰 프레임 데모로 구현했다.

## 실행

빌드/서버 불필요. `index.html`(소개·분석) → `app.html`(앱 데모).

| 화면 | 파일 | 내용 |
|---|---|---|
| 데모 소개 | `index.html` | 니즈 요약 · 갭 분석 6가지 · 코어 루프 · 24화면 구성 · 레퍼런스 표 |
| 앱 데모 | `app.html` | 폰 프레임 SPA — RFP 24개 화면 전체 (좌측 패널 "24개 화면 인덱스"로 즉시 이동) |

## RFP 24화면 ↔ 데모 매핑

- **온보딩 5**: 스플래시 → 카카오·**Apple 로그인**(심사 4.8 선반영) → PASS 본인인증 → 가족 그룹 생성/합류(초대코드 6자리·카톡 공유) → 권한 안내(HealthKit·마이크·카메라·알림)
- **홈·미션 6**: 홈(미션 카드·가족 달성 링·걸음/수면 미니카드·스트릭) → 미션 상세 → 사진 인증(셔터 인터랙션) → 가족 달성 현황(**콕 찌르기 넛지**) → 재료 획득 연출(컨페티) → 미션 기록 캘린더
- **레시피 3**: 도감(잠금/해제 그리드·재료 진행바) → 해제 상세(장보기 담기 = 커머스 연결 지점) → 잠금 상세(재료 5개 수집)
- **피드 1**: 가족 전용 인증샷 타임라인 + 이모지 리액션(토글 동작)
- **건강 2**: 걸음(링 게이지·가족 비교·HealthKit/삼성헬스 배지) ↔ 수면(에이슬립 스타일 점수 82·단계 바·주간 차트) — 세그먼트 전환
- **랭킹 2**: 우리 가족 주간 MVP ↔ 전체 가족 스트릭 랭킹(익명 별명)
- **설정 5**: 설정 홈 → 가족 관리(초대코드·카톡 초대) → 알림(푸시 토큰·토글 동작) → 연동 관리(토글 동작) → 계정·약관(**계정 삭제** = App Store 5.1.1(v) 대응)

## 핵심 시연 시나리오 (미션 → 레시피 해제)

1. 홈에서 **"미션 인증하러 가기"** → 미션 상세 → 사진 인증(셔터 탭 → 제출)
2. 가족 전원 달성 판정 → **재료 획득 연출** (찹쌀 🍚, 5/5 완성)
3. 레시피 해제 화면 → **"엄마의 여름 삼계탕"** 오픈 → 장보기 담기
4. 홈/피드/도감이 모두 완료 상태로 갱신됨 (localStorage 저장 · 사이드 패널 "데모 초기화"로 리셋)

## 구현 메모

- 순수 HTML/CSS/JS 단일 SPA(빌드 없음) · 상태는 `localStorage(hs_demo)` 저장
- 폰 프레임 390×812, 모바일 접속 시 풀스크린 전환
- **비주얼 에셋 7종은 힉스필드(Higgsfield) AI 생성** (`assets/img/*.webp`, 총 ~575KB): 히어로(가족 요리)·미션 인증 2종(산책/식사)·레시피 2종(된장찌개/삼계탕)·온보딩 일러스트·수면 씬

## 납품(실제 개발) 버전에서 달라지는 것

- 웹 SPA → **React Native (TypeScript)** iOS/Android 단일 코드베이스
- 데모 상태 → 발주처 Django RESTful API 연동
- 예시 사진 → 실제 카메라/앨범 권한 + HealthKit/Health Connect + 에이슬립 SDK + 핑거푸시(어댑터 추상화) 네이티브 연동
- 스토어 심사 대응: Apple 로그인 병행, 계정 삭제, 권한 목적 문구, 심사용 데모 계정 체크리스트
