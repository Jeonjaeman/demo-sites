# 헤리가드공제조합 HERIGUARD — 대외용 대표 홈페이지 (제안용 데모)

국가유산 수리업체 대상 **보증서·공제(보험)·신용평가 발급** 공제조합의 대외용 대표 홈페이지 데모입니다.
위시켓 「협회 대외용 대표 홈페이지 신규 구축」 공고(예상 800만·75일·서초)에 대응해 제작했습니다.

> ⚠️ 기관명(헤리가드공제조합)·수치·인물·증서 데이터는 전부 **가상**입니다. 실존 조합·업체와 무관합니다.

### 관리자 콘솔 (admin.html) — 8개 탭
1. **대시보드** — 오픈 준비 체크리스트(실시간 %)·만료 임박 배너/팝업·오늘 조회 KPI
2. **콘텐츠·블록 편집** — 공지·자료실 + **메인 문구·업무 설명·연락처·조직도 블록** · 미리보기→발행→버전이력→되돌리기
3. **배너·팝업** — **게시 종료일 필수** · 만료 자동 종료 · 날짜 시뮬레이션
4. **접근성 검사** — 등록 전 자동 검사, 오류 시 **발행 버튼 실제 비활성**
5. **콘텐츠 수집 진행판** — 원고·이미지 담당/마감/상태 (대시보드 연동)
6. **조회 로그** — 발급 조회 감사 로그·이상 징후 감지·CSV 다운로드
7. **보안 설정** — 권한 2단 분리·IP 허용목록·접속기록·OTP
8. **연계 진단** — 인증 연계 3안 조건 채점·권고

## 체험 시나리오 (입력 없이 클릭만으로)

1. **발급 사실 조회** → verify.html → 「예시로 조회 · 유효한 계약보증」 클릭 → 조회하기 → 「조회 확인서 만들기」 → 인쇄
2. **열거 공격 시연** → verify.html → 입력 방식 「증권번호 단독」 → 「번호 30개 연속 조회 실행」 → 23건 노출 확인 → 「다중 대조」로 바꿔 재실행 → 0건 차단
3. **로그인 연계** → login.html → 인증서 「전자세금용」 선택 → 거부 확인 → 「범용」 선택 → 「공동인증서로 로그인」 → 인계 브리지 3스텝
4. **관리자** → admin.html → 권한 「콘텐츠 담당」 전환(보안 메뉴 사라짐) → 「접근성 검사」 탭 → 검사(오류→발행 차단) → 「배너·팝업」 탭 종료일 없이 등록(거부)

- 서버 환경 스펙(OS·웹서버·WAS·DB·언어) — 스택 제안의 전제
- 기존 영업점 벤더의 협조 조건(신규 API 안의 실현 가능성)
- "11월 초 필요 기능"의 구체 범위(75일=11/20이라 부분 오픈 설계 필요)
- 웹 접근성 인증마크 취득 여부(심사비·1개월 별도)
- 콘텐츠 원고·이미지 제공 일정, 개인정보처리방침·약관 작성 주체

## 기술 구성 (데모)

- 순수 HTML + CSS + 바닐라 JS (외부 프레임워크 없음). 폰트: Pretendard(본문)·Archivo(영문 수치)
- 상태: `localStorage`로 관리자 편집·조회 로그·팝업 게시 상태 유지
- 파일 다운로드: Blob(자료실·확인서) · CSV UTF-8 BOM(조회 로그)
- 차트·게이지: CSS(프로그레스) · canvas 미사용(가벼움 우선)
- 접근성: skip nav · 4.5:1 대비 · 포커스 링 · 팝업 포커스 트랩+ESC · `prefers-reduced-motion`

### 실 구축 제안 스택
기존 인터넷 영업점과 **동일 서버 환경**에 종속되므로 서버 스펙 확인 후 확정.
서버 사이드 렌더 CMS(기존 환경에 맞춘 PHP/Java 또는 Node) + RDB.
설치형 보안 플러그인 회피(전자서명법 개정 이후 웹표준 인증). 인증 연계는 **②안(기존 인증 + 1회용 토큰 교환)** 권고.

### DB 스키마 개요 (실 구축)
```
member(id, biz_no, name, cert_type, status, ...)          -- 조합원
certificate(no, type, member_id, amount, issued, expires, status, holder)  -- 증서
verify_log(id, cert_no, matched, link_mode, input_mode, ip, at)  -- 조회 감사 로그
notice(id, cat, title, body, file, pinned, published_at)  -- 공지
library(id, cat, name, ext, size, file_url, uploaded_at)  -- 자료실
block(key, value, version, updated_by, updated_at)        -- 페이지 블록(CMS)
banner_popup(id, title, from, to, active, kind)           -- 배너/팝업(게시기간 필수)
admin_user(id, role, ip_allow[], otp, last_login)         -- 관리자(권한 2단)
admin_log(id, who, what, ip, at)                          -- 관리 감사 로그
```
