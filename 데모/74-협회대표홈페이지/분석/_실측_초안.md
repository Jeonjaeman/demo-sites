「보증거래사실확인」 실제 폼(cyberbiz.cgbest.co.kr) — **조회 모드 3종 라디오**:

| 모드 | 입력 구성 |
|---|---|
| ① 보증서확인번호로 조회 | 5자리 × 4칸 = **20자리 확인번호** (`GUAS_CNFM_NO 1~4`, 각 maxlength=5) |
| ② **기타조건으로 조회** | 보증종류 `select` + 보증서번호 `발급년도(4)-일련번호(8)` + **보증금액** + **발급일자(YYYYMMDD)** |
| ③ 보증서인증번호로 조회 | 인증번호 10자리 + **변경차수 1자리** (`CHNG_SRNO`) |

**③ SGI서울보증** — 「보험가입사실 확인 조회 > 증권 발급내용 조회」(`CCPINQ020101F01`). 비회원 조회 진입점을 **메인 히어로 직하단 3개 버튼 중 하나(「증권 발급 확인」)로 승격**해 노출. 폼 본체는 세션 없이는 렌더되지 않아 필드 미실측(안내 텍스트만 확인).

**→ 이 데모가 반드시 반영해야 할 3가지**

| 관찰 | 데모 구현 방향 |
|---|---|
| 번호 하나로는 조회 안 됨. **3~4개 항목 동시 일치**가 업계 표준 (무작위 대입 방지) | 발급사실조회를 `증서번호 + 금액 + 발급일` 3중 대조로 구현하고, 하나만 틀려도 "일치하는 증서가 없습니다"로 차단. 어느 항목이 틀렸는지 알려주지 않는 것이 정답(대입 힌트 제공 금지) |
| **변경차수(CHNG_SRNO)** · 공기연장·기재변경·감액 보증서 예외 | 증서에 `변경차수` 개념을 넣고, 최초 발급본과 변경본을 구분해 표시. 감액·변경건은 "원본 발급일 기준" 안내를 화면에 |
| 증서 **종류별로 폼이 다름**(보증서 / 공제증권 / 제증명 / 확인서) | 게이트 → 종류 선택 → 종류별 필드로 분기. 단일 폼으로 뭉개지 않는다 |

## 4. 이 데모에 적용할 디자인 방향

> **전제**: 공고 요건은 "신뢰감·전문성이 전달되는 정돈된 화면 / 주요 정보가 한눈에 / 직관적 메뉴 / **과도한 스크롤 애니메이션·화려한 모션 지양**"이다.
> 이 조건에서 "급"은 **모션이 아니라 여백·타이포 대비·정밀 정렬**로만 만들 수 있다. 아래는 그 세 가지를 수치로 고정한 것이다.

### 4-3. "급"을 만드는 3가지 — 모션 없이

**① 여백으로.** 3사 도메인 레퍼런스의 섹션 여백은 40~100px인데 GDWEB 수상작 KMAC은 **140~190px**이다. 같은 콘텐츠를 넣어도 여백이 1.5~3배다. **공개 사이트 섹션 상하 140px**을 지키는 것만으로 국내 공제조합 평균을 넘는다. (기능 화면은 56px로 낮춰 정보 밀도를 지킨다.)

**② 타이포 대비로.** 도메인 레퍼런스 3사의 최대/최소 비는 K-FINCO 48/16 = 3.0×, 건설공제조합 55/17 = 3.2×, SGI 40/16 = 2.5×다. 수상작은 KMAC 64/16 = 4.0×, SharpLink 68/13 = **5.2×**. **디스플레이 64px + 라벨 13px(+0.08em 대문자)** 조합으로 4.9×를 만든다. 중간 크기(20~28px)를 남발하지 않는 것이 핵심이다.

**③ 정밀 정렬로.** SharpLink는 12칼럼·28px 거터·**8px 로우갭**을 토큰으로 못 박았다. 본 건도 **8pt 그리드**를 강제하고, 폼 라벨·입력·버튼의 베이스라인을 맞춘다. 입력 52px·버튼 54px처럼 2px 어긋나는 K-FINCO의 실수는 따라하지 않는다 — **입력·버튼 모두 52px로 통일**한다.

### 4-4. 절제의 구체적 규칙 (레드팀 ①이 잡을 AI스러움 사전 차단)

- **weight를 남발하지 않는다.** SharpLink는 68px 디스플레이를 **400(regular)**으로 쓴다. 한글은 400이 약하므로 700~800을 쓰되, **한 화면에 weight는 3개(400·600·800)까지만**.
- **그림자 1종.** `0 2px 12px rgba(0,0,0,.08)` 외 금지. 경계가 필요하면 KMAC처럼 **1px 라인**으로.
- **radius를 섞지 않는다.** 폼 4px / 카드 14px / 칩 50px / 미디어 0px — 이 4개 값만.
- **그라디언트·글로우·글래스모피즘 전면 금지.** SharpLink는 583개 토큰 중 그라디언트가 없다.
- **아이콘은 면(fill) 우선, stroke 시 2px butt/miter.** 라운드 캡은 친근함을 주지만 **공적 기관의 정밀함을 깎는다.**
- **중앙정렬은 히어로에서 끝.** 본문 전 섹션 좌측정렬 + 우측 액션(KMAC 패턴).
- **모션은 `fade-up` 하나로 통일.** KMAC 수상작도 33개소 전부 `fade-up` 단일 패턴이다. 섹션마다 다른 연출을 넣는 것이 오히려 AI스러움이다.
