# BONCHO 본초 — 페이지 기획 (사이트맵 · 페이지별 기획)

> 공고: 회원제 한의학 커뮤니티 및 강의 콘텐츠 플랫폼 신규 구축 (프리모아 · 1,000~2,000만원 · 60일)
> 디자인: 레퍼런스 라이브러리 **poscoflow 도메인 전체 적용** (디자인시스템·레이아웃·인터렉션 3축 문서 기준)
> 성격: **혼합(하이브리드)** — 공개 표면(index·join·login)은 브랜드 문법, 회원 표면(커뮤니티·강의)은 기능형 UI, 관리자는 대시보드 UI.

## 브랜드

- **BONCHO 본초** — 본초학(本草學)에서 따온 이름. 한의학 지식이 모이는 곳.
- 별칭(공개 URL): `/boncho` · 관리자 `/boncho/admin`
- 로컬 포트: **8049**

## 핵심 설계 축 — 「권한이 곧 화면」

이 공고의 본질은 게시판이 아니라 **권한 구조(비회원 → 승인 대기 → 일반회원 → 한의사회원 → 관리자)**다.
데모 전 페이지 상단에 **역할 전환 컨트롤(데모 전용)**을 두어, 같은 화면이 권한에 따라
실제로 다르게 렌더되는 것을 클릭만으로 확인하게 한다. 이것이 이 데모의 1번 차별점.

## 사이트맵

```
/ (index.html)          공개 랜딩 — 허브. 승인제 구조·커뮤니티/강의 티저·가입 유도
├─ join.html            회원가입 — 일반/한의사 분기, 면허 증빙 업로드, 승인 대기 화면
├─ login.html           로그인 — 카카오/네이버 소셜 버튼, 승인 대기 계정 처리
├─ community.html       커뮤니티 — 게시판 6종 탭·목록·검색·권한 잠금 표시
├─ post.html?id=        게시글 상세 — 본문·첨부(PDF/HWP/XLSX)·댓글·북마크·신고
├─ write.html           글쓰기 — 게시판 선택(권한별 필터)·첨부·등록
├─ lectures.html        강의 — 강의 영상 게시판 목록 (권한별 잠금)
├─ lecture.html?id=     강의 재생 — 유튜브 연동 재생 + 회원번호 워터마크 + 열람 이력
├─ gallery.html         갤러리 — 이미지 그리드·상세 라이트박스·권한별 접근
├─ mypage.html          마이페이지 — 내 정보·북마크·열람 이력·승인 상태
└─ admin/
   ├─ index.html        대시보드 — KPI·가입 승인 대기·신고 현황
   ├─ members.html      회원 관리 — 목록·승인/반려·권한 변경
   ├─ boards.html       게시판 관리 — 게시글/댓글·신고 접수·블라인드 처리
   ├─ logs.html         열람 로그 — 회원/일시/콘텐츠/IP·마스킹·CSV
   └─ cms.html          공지 CMS — 공지 작성·노출 관리
```

## 페이지별 기획

| 페이지 | 목적 | 방문자가 할 일 | 섹션 구성 | 다음 유도 |
|---|---|---|---|---|
| index | 승인제 플랫폼의 신뢰 형성 | 서비스 이해 → 가입 결심 | 히어로(2행 디스플레이+통계) → 권한 구조 안내(다크 밴드·글래스 카드) → 커뮤니티 티저(잠금 카드) → 강의 티저 → 가입 절차 3단계 → CTA | join |
| join | 가입 + 승인제 체험 | 유형 선택→정보 입력→증빙→대기 화면 | 유형 분기 → 폼 → 면허 증빙 → 소셜 가입 → 승인 대기 상태 | login/mypage |
| login | 재방문 진입 | 로그인·소셜 로그인 | 폼 + 카카오/네이버 + 승인 대기 안내 | community |
| community | 활동 허브 | 게시판 골라 읽기·검색 | 게시판 6종 탭 → 필터/검색 → 목록(표형) → 페이지네이션 | post/write |
| post | 정보 소비·상호작용 | 읽기·댓글·북마크·신고 | 본문 → 첨부 → 반응 → 댓글 → 관련글 | community |
| lectures | 강의 발견 | 카테고리 탐색 | 필터 → 강의 카드 그리드(3열) → 잠금 표시 | lecture |
| lecture | 수강 | 재생·이어보기 | 플레이어(워터마크 오버레이) → 커리큘럼 → 열람 이력 | lectures |
| gallery | 자료 열람 | 이미지 탐색 | 그리드 → 라이트박스 | — |
| mypage | 자기 관리 | 상태·이력 확인 | 프로필/등급 → 북마크 → 열람 이력 | — |
| admin/* | 운영 (비IT 관리자 2~3명) | 승인·제재·모니터링 | KPI → 승인 큐 → 신고 큐 → 로그 → CMS | — |
