2-2. 데이터 처리 및 저장 기능

- 응답 저장 및 대화 턴 수 기록 로직
- 참가자별 진입 시점 및 응답 메시지별 정보 기록
- 로우 데이터를 CSV 형식으로 저장

2-3. 연구자용 관리자 기능
- 관리자 로그인
- 4개 실험 집단별 시스템 프롬프트 텍스트 설정 및 수정

3. 데이터/보안 요구사항
3-1. 참가자 응답 데이터 누락 방지 및 기본 안정성 확보
3-2. 수집한 데이터 파일 유출 방지 관리
