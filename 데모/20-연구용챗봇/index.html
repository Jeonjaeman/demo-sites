연구 참여 동의

본 연구는 대화형 AI의 응답 방식이 조언 수용도에 미치는 영향을 살펴봅니다.
아래 내용을 읽고 동의해 주시면 참여를 시작합니다.

1. 연구 목적

대화형 AI가 서로 다른 방식으로 응답할 때, 이용자가 조언을 어떻게 받아들이는지 비교합니다. 참가자는 수면 습관을 주제로 챗봇과 대화하게 됩니다.

2. 참여 방법 및 소요 시간

챗봇과 최소 6턴 이상 대화한 뒤 종료합니다. 약 10~15분이 소요됩니다.

3. 수집하는 정보

  • 참가자 고유 ID (연구용 익명 코드, 실명·연락처 수집하지 않음)
  • 챗봇과 주고받은 대화 내용 전문
  • 대화 시작·종료 시각, 턴 수, 응답 소요 시간

대화 중 전화번호·이메일 등이 입력될 경우 저장 단계에서 자동으로 마스킹됩니다.

4. 보관 및 파기

수집된 자료는 연구 목적으로만 사용하며, 연구 종료 후 3년간 보관 후 파기합니다. 접근 권한은 연구책임자에게만 부여됩니다.

5. 참여 철회

참여는 자발적이며, 언제든 중단할 수 있고 불이익은 없습니다. 종료 후에도 참가자 ID를 알려 주시면 자료를 삭제해 드립니다.

6. 문의
