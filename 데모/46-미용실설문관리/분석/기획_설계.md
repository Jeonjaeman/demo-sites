# QUILL 퀼 — 기획·설계

> 미용실 고객 설문지 디지털화 및 데이터 관리 시스템 (크몽 공고) · 제안용 데모
> 모든 고객·디자이너·매장·응답 데이터는 시연용 가상값

---

## 0. 공고 요약

- 아이디헤어(지점 약 100개) **종이 설문지 → 디지털 설문 시스템** 전환
- 예산 **1,000만원** · 착수 후 2~3개월(2026-08-10 ~ 10-16) · 세금계산서 필요
- 주요 기능: 태블릿(메인)·모바일·PC 반응형 설문 / **설문 항목 커스터마이즈(필드 추가·삭제·순서변경)** /
  **권한 3단계(슈퍼관리자=본사 → 원장=매장 → 디자이너=본인 고객)** / 신규 고객 DB 별도 구축(기존 CRM 연동 없음) /
  대시보드(목록·합계·기간·항목 필터·ChartJS) / 엑셀(xlsx) / 백업·복구 / **개인정보 수집 동의 절차**
- 제안 시 명시 요망: 무상 하자보수 기간 · 오픈 후 월 서버 유지/관리 비용
- 스택: HTML · PHP · MySQL · JavaScript · PostgreSQL · ChartJS
- 첨부: 실제 종이 설문지 사진(idHAIR) · 참고용 설문 빌더 예시(마음노트) 3장

### 사용자 추가 요구 (의뢰 방향)
- "어떤 설문이든 생성" — 미용실 전용 폼이 아니라 **범용 설문 폼 생성기**
- 설문 생성 시 **필요한 모든 항목을 자유롭게 커스텀** 생성
- 권한을 주고 **역할별로 실제로 작동**하게
- 레드팀 관점의 우려를 언급하고 개선하며 진행

## 1. 명시된 니즈 vs 숨은 니즈

| 구분 | 내용 |
|---|---|
| 명시 | 반응형 설문 · 필드 에디팅 · 권한 3단계 · 대시보드 · 엑셀 · 백업 · 동의 절차 |
| 숨은 ① | 종이 설문지의 동의란이 **마케팅 목적을 필수 동의에 묶고 있음** → 그대로 디지털화하면 위법 소지 |
| 숨은 ② | 매장 **공용 태블릿** = 제출 후 화면·입력값이 남으면 다음 손님에게 개인정보 노출 |
| 숨은 ③ | 권한 3단계의 실제 목적 = **퇴사 디자이너의 고객 명단 유출 차단** (열람 범위 + 유출 경로) |
| 숨은 ④ | 지점 100개가 가맹(별도 사업자)이면 지점→본사 데이터 흐름의 법적 성격(위탁 vs 제3자 제공) 규정 필요 |
| 숨은 ⑤ | "커스터마이즈"의 진짜 수요 = 신규 설문(재방문·직원·이벤트)을 **개발자 없이** 계속 만드는 것 |

## 5. 제안 스택·일정

- 운영: PHP(Laravel 또는 순수 PHP) + MySQL — 공고 명시 스택. 설문 구조는 JSON 컬럼(스키마리스)로 저장해 필드 커스터마이즈가 DB 마이그레이션 없이 동작
- 프론트: 반응형(태블릿 우선) · ChartJS
- **알림톡 고도화**: 카카오 비즈니스 채널 → 발신프로필 → 발송 대행 API 연동 설정 → 템플릿 검수(알림톡=정보성만, 광고성은 친구톡/LMS+동의자) → 발송 → 실패분 문자 대체. 데모 admin에 전 흐름 구현
- 100개 지점: 지점·계정 CSV 일괄 등록 도구 포함
- 일정 60일: 설계7 · 빌더11 · 응답7 · 대시보드9 · DB/엑셀5 · 알림톡7 · 백업/감사5 · 지점세팅3 · QA/배포6
- 총 8,800,000원 (VAT 별도 · 항목당 비용은 지원서 견적표) · 무상 하자보수 3개월 · 서버비 월 3~5만원 수준 · 유지관리 월 계약 별도
- 예산 잔여분은 월 서버·유지관리비 또는 예비비(운영 중 추가 개발)로 활용 제안

## 6. 레드팀 검수 (AI스러움 제거)

- "AI 스타트업 보라 그라디언트" 배제 → 페이퍼 화이트 + 단일 vermillion, 잉크 블랙 버튼
- 카드 3열 반복 최소화 — 랜딩은 진입 3장 + 유형 카탈로그(기능 목록이라 정당)만, 나머지는 표·데모 실화면
- 빌더/대시보드는 툴 성격에 맞게 모션 절제(리빌·카운트업·바 성장·드로어만)
- 검증에서 잡은 버그: ① survey.js 리스너 중복 등록(렌더마다 bind) → 1회 바인드 가드 ② 브라우저 첫 페인트 지연으로 리빌 미부착 → 재시도 로직 ③ 375px 빌더 26px 가로 오버플로(q-top 미줄바꿈·상단바) → 모바일 CSS 보정
