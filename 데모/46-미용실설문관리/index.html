HOW IT WORKS

세 화면이 하나의 흐름으로

빌더에서 만든 설문이 그대로 태블릿에 뜨고, 제출된 응답이 권한별 대시보드에 쌓입니다. 이 데모에서도 세 화면이 실제로 연결되어 있습니다.

STEP 1

본사가 설문을 만든다

빌더에서 질문 유형 12종으로 자유 구성. 템플릿(신규 고객·재방문·직원·이벤트)으로 시작하거나 빈 설문부터. 저장하면 전 매장 태블릿에 즉시 반영됩니다.

STEP 2

고객이 태블릿에서 답한다

담당 디자이너 선택 → 약 2분 응답 → 필수/선택 동의 → 제출. 제출 순간 화면이 초기화되어 공용 태블릿에서도 개인정보가 남지 않습니다.

STEP 3

권한만큼 데이터를 본다

디자이너는 내 고객만, 원장은 매장 전체, 본사는 전 지점. 기간·매장·항목 필터와 차트로 보고 엑셀로 내보냅니다. 마케팅 발송은 동의자에게만.

FIELD TYPES

질문 유형 12종 — 전부 커스텀

참고 주신 설문 빌더 예시의 유형(객관식·중복선택·단답·장문·별점·점수선택·개인정보 동의)을 전부 포함하고, 미용실 현장에 필요한 유형(연락처 자동 하이픈·사진 첨부·구역 제목)을 더했습니다.

RED TEAM REVIEW

만들기 전에 먼저 본 것들

화면을 그리기 전에, 이대로 운영하면 터지는 지점부터 확인했습니다. 전부 이 데모에서 동작하는 기능으로 구현되어 있습니다.

R1종이 설문지의 동의란, 그대로 옮기면 위법 소지

현재 종이 설문지는 「매장이벤트 및 할인 안내」를 개인정보 수집 목적에 묶어 동의/비동의 하나로 받습니다. 마케팅 수신 동의는 서비스 필수 동의와 분리해 선택으로 받아야 하며, 위반 시 1천만원 이하 과태료입니다.

데모 반영 ✓ 동의 블록이 필수/선택로 분리되어 있고, 빌더에서 마케팅 문구를 필수에 넣으면 즉시 경고가 뜹니다.

R2공용 태블릿은 "앞 손님 정보"가 남는 기기

매장 태블릿은 여러 손님이 이어서 씁니다. 제출 후 화면·입력값이 남으면 다음 손님에게 이름·연락처가 노출됩니다. 개인정보 안전성 확보조치(접근통제·세션 관리) 관점에서 반드시 막아야 할 지점입니다.

데모 반영 ✓ 제출 즉시 입력값 파기 + 7초 카운트다운 자동 초기화. 미조작 방치 타임아웃도 운영 버전에 포함합니다.

R3퇴사 디자이너의 고객 명단 유출 — 업계 최다 분쟁

디자이너가 전 고객 연락처를 보고 내보낼 수 있으면, 퇴사·이직 시 고객 DB가 통째로 따라갑니다. 권한 3단계는 "열람 범위"만이 아니라 "유출 경로 차단"까지 설계해야 의미가 있습니다.

데모 반영 ✓ 디자이너 역할은 본인 고객만 + 연락처·생년월일 마스킹 + 엑셀 내보내기 차단. 대시보드에서 역할을 바꿔 직접 확인하세요.

R4지점 100개 — 본사 집중이 「위탁」인지 「제3자 제공」인지

지점이 별도 사업자(가맹)라면 지점에서 수집한 고객 정보를 본사가 모으는 구조는 계약 형태에 따라 처리위탁 또는 제3자 제공으로 갈리고, 후자는 동의 문구에 명시해야 합니다.

미팅 확인 가맹 계약 구조 확인 후 동의 문구 확정. 데모의 동의 블록은 항목 추가(제3자 제공 동의)까지 지원합니다.
