# QUILL 퀼 — 미용실 설문 디지털화 · 범용 설문 폼 빌더 (제안용 데모)

아이디헤어(지점 ~100개) 종이 설문지 디지털화 공고(크몽) 대응.
종이 설문지 15문항을 그대로 옮기는 데서 멈추지 않고, **어떤 설문이든 만드는 범용 폼 빌더 +
권한 3단계가 실제로 작동하는 데이터 관리**로 구현했습니다.

| 화면 | 내용 | URL(별칭) |
|---|---|---|
| 허브 | 3화면 진입 · 레드팀 4건 · 견적 | `…/quill/` |
| 빌더 | 질문 12종 자유 커스텀 + 실시간 법 점검 | `…/quill/builder.html` |
| 태블릿 응답 | 동의 분리 · 필수 차단 · 자동 초기화 | `…/quill/survey.html` |
| 대시보드 | 권한 3단계 · 차트 · 엑셀 · 백업 | `…/quill/admin.html` |

베이스: `https://jeonjaeman.github.io/demo-sites/`

## 핵심 기능

### ✎ 빌더 (builder.html)
- **질문 유형 12종**: 객관식 · 중복선택 · 단답 · 장문 · 별점 · 점수선택 · 드롭다운 · 날짜 · 연락처(자동 하이픈) · 사진 첨부 · 구역 제목 · **개인정보 동의 블록**
- 추가·삭제·순서변경(↑↓)·복제·필수 토글·옵션 편집·테마·미리보기 전부 동작
- 템플릿 5종(신규 고객=종이 설문지 재현 · 재방문 · 직원 · 이벤트 · 빈 설문) — **범용성 증명**
- **실시간 법 점검**: 식별정보 수집인데 동의 블록 없음 → 경고 / 마케팅 문구를 필수 동의에 넣음 → 과태료 경고 (직접 재현 가능: 동의 블록의 「선택 ↔ 필수」 클릭)

### 📱 태블릿 응답 (survey.html)
- 필수/선택 동의 분리 렌더 · 필수 미응답 7건 개별 차단 · 필수 동의 거부 시 저장 차단+대안 안내
- 제출 즉시 입력값 파기 + 7초 자동 초기화(공용 태블릿 잔류 차단)
- **「예시로 채우기」** — 입력 없이 클릭만으로 제출까지 체험

### 📊 대시보드 (admin.html)
- **역할 전환(슈퍼관리자/원장/디자이너)** 시 실제로 바뀌는 것: 데이터 범위(전체 184건→강남점→이유진 담당만) · 연락처/생년월일 마스킹 · 엑셀 버튼(디자이너=차단) · 백업 메뉴(슈퍼 전용)
- 샘플 응답 184건 실집계: KPI 카운트업 · 일별 추이 라인차트 · 방문동기 도넛 · 메뉴/고민 바(canvas dpr 대응)
- 기간·매장·디자이너·메뉴 필터 → 차트·표 실변경
- **응답 상세 = 종이 설문지 뷰**: 행을 누르면 원본 idHAIR 설문지 양식 그대로 렌더 — 로고·담당 디자이너·기본정보·동의란, 문항마다 전체 선택지를 ☐로 깔고 응답만 ☑ 표시, 별점·밑줄 메모까지. 현장 직원이 종이 보던 방식 그대로 읽습니다 (디자이너 역할이면 이 뷰에서도 연락처·생년월일 마스킹)
- 마케팅 대상: **선택 동의자(76명)만 자동 추출**, 미동의 108명 자동 제외
- CSV(UTF-8 BOM) · 백업 JSON 다운로드 · 복구 시뮬 · 권한 매트릭스 표

### 💬 알림톡 (admin.html — 연동에서 발송까지)
- **① 연동 설정**(슈퍼관리자 전용): 카카오 비즈니스 채널 → 발신프로필 키 등록 → 발송 대행 API 연동 테스트 — 단계형 UI, 완료 시 발송 활성화
- **② 템플릿 검수 시뮬레이션**: 알림톡은 **정보성만 허용** — 광고성 문구(할인·이벤트·% 등)를 넣고 검수 요청하면 자동 반려 + 친구톡/LMS 대안 안내. 승인 템플릿은 즉시 발송에 사용
- **③ 발송**: 템플릿 유형에 따라 대상 자동 전환 — 정보성=전체 응답자 / 광고성=마케팅 동의자만. 카톡 스타일 미리보기(변수 치환) · 발송 결과(성공/실패/문자 대체) 리포트
- 권한 반영: 연동 설정=슈퍼 전용 · 발송=원장 매장분만 · 디자이너=전체 차단

## 체험 시나리오 (입력 없이 클릭만)
1. 빌더 → 동의 블록의 「선택 ↔ 필수」 클릭 → **과태료 경고** 등장 → 다시 클릭해 복구
2. 빌더 → 템플릿 → 「직원 근무환경 설문」 적용 → 미용실과 무관한 설문이 즉시 생성됨
3. 응답 → 「예시로 채우기」 → 제출 → **7초 자동 초기화** 확인
4. 응답 → 필수 동의 「동의하지 않습니다」 → 제출 → 저장 차단 확인
5. 대시보드 → 역할을 디자이너로 → 연락처 마스킹·내보내기 차단 확인 → 슈퍼관리자로 → 엑셀 다운로드
6. 알림톡 → 발신프로필 등록·API 연동 → 새 템플릿에 "20% 할인" 넣고 검수 요청 → **자동 반려** → 정보성 문구로 승인 → 발송 시뮬
