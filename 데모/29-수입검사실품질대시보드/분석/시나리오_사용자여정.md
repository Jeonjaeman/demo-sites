# 시나리오 · 사용자 여정 — QWALL 수입검사 품질 대시보드

> 기능을 **시간순 사용 흐름**으로 재구성해 각 기능의 존재 이유와 정의가 비는 지점을 드러냅니다.

---

## 1. 등장인물

| 역할 | 누가 | 무엇을 원하나 | 무엇을 불안해하나 |
|---|---|---|---|
| **품질관리 담당자** | 수입검사실 실무자 | 검사·부적합 현황을 매번 취합 없이 한 화면에서 | 숫자가 3개 시스템과 안 맞으면 신뢰가 깨짐 |
| **품질보증팀 관리자** | 팀장 | TOP 부적합 업체·실패비용·전년 대비 개선을 근거로 의사결정 | 낡은 데이터로 회의하다 오판 |
| **시스템 운영 담당자** | 전산/운영 | 매일 자동 갱신, 지정 인원만 열람, 무인 안정 동작 | 게이트웨이 새로고침이 조용히 실패 |

**역할 겸임 주의**: 담당자↔관리자는 같은 대시보드를 보되 **관리자만 실패비용·TOP 업체 집중도로 판단**한다(열람 범위 동일, 해석 목적 상이). 운영 담당자는 **데이터가 아니라 파이프라인·권한**을 본다 → 운영 콘솔 분리.

---

## 2. 시간순 여정

| 단계 | 상황 | 쓰는 화면 | 이 기능이 없으면 |
|---|---|---|---|
| 수집 | 밤사이 3소스에서 데이터 유입 | (운영) 자동 새로고침 | 매일 아침 수작업 취합 30분 |
| 통합 | 코드 통일·중복 제거·매핑 | (운영) ETL 규칙 | 부적합이 이중 계상돼 KPI 거짓 |
| 확인 | 아침 회의 전 현황 | 메인 대시보드 14 KPI | 시스템 3개 열어 대조 |
| 분석 | 유형·원인·TOP 업체·장치 | 필터 + 분포/랭킹 | 원인 추적·재발 방지 불가 |
| 비교 | 작년 대비 나아졌나 | 전년 비교·추이 | 개선 추세 근거 없음 |
| 판단 | 품질 투자 결정 | 실패비용 KPI | 금액 근거 없이 설득 불가 |
| 상시 | 현장 대형 모니터 24h | 풀스크린 현황판 | 팀 전체 실시간 공유 안 됨 |
| 사고 | 새로고침 실패 | stale 경고 배너 | 낡은 데이터로 오판 |

---

## 3. 역할별 시야 차이

| 데이터 | 담당자/관리자(대시보드) | 운영 담당자(운영 콘솔) |
|---|---|---|
| KPI | 통합된 최종 수치 | 통합 **규칙**(중복 제거·코드 통일)이 수치를 만드는 과정 |
| 새로고침 | "최신/이전 데이터" 상태 배너 | 실행·이력·소스 상태·실패 대응 |
| 실패비용 | 금액 결과 | 처분별 **단가 기준 편집** |
| 열람 | 로그인해서 본다 | **누가 볼 수 있나** 권한 관리 |

→ 운영 콘솔에서 규칙 하나(중복 제거) 끄면 대시보드 부적합이 **즉시 88% 부풀려진다**(데모 실측). 통합 규칙이 곧 KPI 신뢰다.

---

## 4. 기능별 존재 이유

- **오더 매핑 중복 제거**: ERP·QMS 이중 계상 제거. 없으면 모든 부적합 KPI가 거짓.
- **코드 통일**: 유형 코드 체계 차이로 같은 유형이 쪼개지는 것 방지.
- **stale 경고**: 무인 상시 표출의 새로고침 실패를 드러내 오판 차단.
- **실패비용 단가표**: "합의된 기준" 없으면 금액이 임의 → 노출·조정.
- **전년 비교(율 기준)**: 검사량 차이 착시 제거.
- **열람 권한**: 품질 데이터는 대외 민감(협력업체 부적합) → 지정 인원만.

---

## 5. 상태 흐름 (구현됨)

- **새로고침**: 대기 → 소스 추출 → 정제·통합 → 완료(반영) / 실패(이전 데이터 유지·알림)
- **부적합(QMS 참조)**: 등록 → 발생구분 분류 → NCR 발행 여부 → 접수 확인 → 집계 반영

---

## 6. 비는 구멍 (착수 전 미팅 확인 필요)

임의로 정하지 않고 착수 시 협의(공고도 동일 입장).

1. **14개 KPI 정의서 확정** — 데모는 실무 표준 가정치. 발주처 정의·산식과 대사 필요.
2. **직접 DB 접근 세부** — 대상 DB·읽기 권한·스키마(전산팀 협의).
3. **실패비용 산정·배부 규칙** — 처분별 단가, 공수 원가 반영 여부.
4. **새로고침 주기** — 엑셀 ITP 일간 기준, 실시간성 요구 수준.
5. **게시 환경·상시표출 라이선스** — Power BI 유지 시 Service/온프렘, 계정 종속 대응.
6. **오더 매핑 규칙** — S오더-F오더 연결 키·예외(1:N) 처리.
7. **부적합 유형·원인 코드 마스터** — 통일 기준표.
8. **열람 권한 그룹·감사 로그** 범위.

> 8가지는 데모에 합리적 기본값으로 구현했고, 계약 시 확정할 항목으로 분리했습니다.
