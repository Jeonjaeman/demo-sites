# QWALL 큐월 — 수입검사실 품질 대시보드 (데모)

ERP(수입/완성검사)·QMS(부적합)·오프라인 엑셀(ITP) **3개 소스를 ETL로 통합**해 **14개 KPI·실패비용·전년 비교**를 제공하고, **대형 모니터에 상시 표출(풀스크린)**하는 무인 품질 대시보드입니다. 대시보드와 운영 콘솔이 실시간 연동됩니다.

- 공개 URL(별칭): `https://jeonjaeman.github.io/demo-sites/qwall/`
- 운영 콘솔: `https://jeonjaeman.github.io/demo-sites/qwall/admin/`
- 로컬: `python -m http.server 8086 --directory 데모/29-수입검사실품질대시보드`
- ⚠️ 데이터·업체·설비·금액은 모두 **가상**입니다. (시드 RNG로 결정적 생성)

## 화면

| 구분 | 화면 |
|---|---|
| 대시보드 (`index.html`) | 로그인(권한) · 메인(14 KPI·필터·유형/원인 분포·TOP5 업체·장치별·추이) · 전년 비교·추이 · 데이터 통합(ETL) · **대형 모니터 상시표출(풀스크린)** |
| 운영 콘솔 (`admin.html`) | 새로고침·소스(수동 실행·실패 시뮬·이력) · 통합 규칙(중복 제거·코드 통일) · 실패비용 기준 · 열람 권한 |

## 체험 시나리오 (2분)

1. **대시보드** → 로그인에서 `kim.qc` 선택(또는 `guest.x`로 **차단** 확인).
2. 14 KPI·전년 비교 화살표 확인 → 필터(업체·기간) 바꾸면 **모든 KPI 재계산**.
3. `🖥 대형 모니터 표출` → 다크 풀스크린 현황판(시계·자동 새로고침 카운트다운).
4. **운영 콘솔**(우측 하단) → `통합 규칙`에서 **중복 제거 OFF** → 대시보드 부적합이 **+90% 부풀려지고** 경고 배너.
5. `새로고침·소스` → **⚠ 실패 시뮬레이션** → 대시보드·현황판에 **stale 경고**("이전 데이터, 최신 아님").
6. `실패비용 기준`에서 처분 단가 변경 → 실패비용 KPI **즉시 재계산**.

## ⚠️ 착수 전 확인 항목

14 KPI 정의서 확정 / 직접 DB 접근(대상·권한·스키마) / 실패비용 산정·배부 규칙 / 새로고침 주기 / 게시 환경·상시표출 라이선스 / 오더 매핑 키·예외 / 유형·원인 코드 마스터 / 열람 권한·감사 로그. (자세히는 `분석/시나리오_사용자여정.md` 6장)

## 핵심 설계 (리서치 함정 → 기능)

- **ERP·QMS 이중 계상** → 오더 매핑 중복 제거 토글이 KPI를 실제로 바꿈(원시 94건 vs 순 50건)
- **무인 새로고침 실패 오판** → stale 경고 배너 + 마지막 성공 시각(현황판까지 전파)
- **Power BI 상시표출 라이선스 종속** → 라이선스 비종속 웹 대안 제시(공고 허용)
- **실패비용 기준 임의** → 처분별 단가표 편집 → KPI 반영

## 기술 구성

- 정적 HTML/CSS/**바닐라 JS**, 빌드 없음. Pretendard(CDN). 외부 차트 라이브러리 없이 canvas(도넛·라인·바, dpr 대응).
- 데이터: **시드 RNG(mulberry32)로 결정적 생성** → 새로고침해도 수치 불변, 검증 가능.
- 상태: `localStorage` 공유(대시보드↔운영 콘솔). 운영 콘솔 `↺ 초기화`로 리셋.
- 파일: `assets/js/data.js`(엔진·KPI·ETL) · `app.js`(대시보드) · `admin.js`(운영 콘솔) · `assets/css/style.css`
