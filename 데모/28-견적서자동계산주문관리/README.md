# GREENDESK 그린데스크 — 교사 전용 견적·주문 B2B (데모)

친환경 업사이클 교구 회사의 **교사 전용 B2B**. 고유번호증 제출 → 관리자 승인 → 인원 구간별 강사비·교구 견적 자동 계산 → **직인·문서번호 찍힌 견적서 PDF 실발행(회차 보존)** → 주문·예약 → 진행·청구·결제 기록까지, 교사 화면과 관리자 백오피스가 실시간 연동됩니다.

- 공개 URL(별칭): `https://jeonjaeman.github.io/demo-sites/greendesk/`
- 관리자: `https://jeonjaeman.github.io/demo-sites/greendesk/admin/`
- 로컬: `python -m http.server 8087 --directory 데모/28-견적서자동계산주문관리`
- ⚠️ 모든 데이터·직인·연락처는 **가상**입니다. 실제 거래·법적 효력이 없습니다.

## 화면

| 구분 | 화면 |
|---|---|
| 교사 (`index.html`) | 안내 · 회원가입(고유번호증) · 승인대기 · 로그인 · **견적 계산**(교구/수업) · 견적서 상세(PDF·수정요청·주문) · 주문 신청 · 내 주문 · 마이페이지(발급 이력 회차별 재다운로드) · 다운로드 센터 |
| 관리자 (`admin.html`) | 대시보드(KPI·주문 도넛·월별 발급 바) · 회원 관리(승인/반려/서류/편집/삭제) · 발급 내역(재발행·재발송) · **주문 관리**(진행/청구/결제 조건 조회) · 단가 기준 |

## 체험 시나리오 (2분)

1. **교사 화면** → `로그인`에서 "김민서 · 햇살유치원" 선택.
2. `견적 계산` → **수업 예약** 탭 → 인원 28명 입력 → 강사 2인·480,000원 자동 → `견적서 발행`.
3. 견적서에서 **PDF 다운로드**(직인·문서번호 포함 실제 .pdf 생성) · **수정 요청** · **이 견적으로 주문**.
4. **관리자 화면**(우측 하단 링크) → `회원 관리`에서 승인대기 교사 **승인**(→ "문자 발송됨").
5. `발급 내역`에서 **재발행** → 2차 생성, 1차 보존 확인. `주문 관리`에서 상태·청구·결제 기록 → 조건별 조회.
6. `단가 기준`에서 교구 단가 변경·저장 → 교사 견적 금액이 **즉시** 바뀌는지 확인.

## ⚠️ 착수 전 확인 항목

강사비 구간·교구 단가 확정값 / 견적 유효기간 경과 규칙 / 반려 후 재신청 동선 / 주문 취소 처리 / 수업+교구 혼합 주문 / 세금계산서 발행 시점 / 명단 파일 파기 주기 / 직인·발신번호 제공 시점. (자세히는 `분석/시나리오_사용자여정.md` 7장)

## 계산 규칙 (데모 기본값)

- **교구 주문**: Σ(단가×수량) + 배송비 30,000(공급가 30만↑ 무료), 수량 50개↑ 5% · 100개↑ 10% 할인
- **수업 예약**: 인원 구간별 강사비(1~15명 25만 / 16~30명 48만 / 31~45명 69만 / 46~60명 88만, 61명↑ 별도협의) + 재료비(인원×교구단가) + 지역 교통비
- 협약기관 5% 할인 · 부가세 10% · 견적 유효기간 발행+14일

## 디자인 실측 명세

- 색: 그린 단일 액센트 `#1f8a4c` + 뉴트럴 배경 `#f4f7f3`, 상태 5색 토큰(대기 amber·완료 green·정보 blue·위험 red·중립 gray)
- 도메인 레퍼런스: Toss 비즈 · Stripe Invoicing · 정부지원 교구 발주서 / 디자인: Linear(백오피스 밀도) · WWiT(폼·승인 패턴)
- 인터랙션: 카운트업(easeOutCubic 620ms) · 바 성장(700ms) · 리빌 stagger · 토스트 · canvas 도넛/바(dpr 대응)

## 기술 구성

- 정적 HTML/CSS/**바닐라 JS**, 빌드 없음. Pretendard(CDN).
- **PDF**: html2canvas → jsPDF (CDN). 한글·직인 SVG를 래스터화해 A4로 출력, 실패 시 인쇄(브라우저 PDF) 폴백.
- 상태: `localStorage` 공유(교사↔관리자 실시간 연동). 관리자 화면 우측 상단 `↺ 초기화`로 샘플 리셋.
- 파일: `assets/js/data.js`(엔진·시드) · `app.js`(교사) · `admin.js`(관리자) · `assets/css/style.css`
