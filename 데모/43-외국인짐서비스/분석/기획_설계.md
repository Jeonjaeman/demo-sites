## 0. RFQ 요약

- 부산/김해 외국인 관광객 대상 **짐배송·짐보관** 예약~운영관리 시스템 신규 구축
- 현재: 정적 홈페이지(4개 언어) + Google Sheets 수기, 누적 30건. **화면 15개**로 상세 명세(별첨)
- 예산 **2,000만원 / 60일 / 지원자 55명** · 계약 8월 중순 · 1차 오픈 10월 초 · 정식 런칭·정산 11월
- **한국관광공사 제17회 초기관광벤처 연계 → 11월 정산 완료 확정 일정**(일정 준수 매우 중요)
- 대금 선금30/중도금40/잔금30 · 잔금 완납 시 소스 일체 귀속 · **특수 빌드환경·난독화 불가**
- 견적: **화면 단위(A~M) 분리 필수**, 총액만 적으면 검토 안 함

## 1. 명시된 니즈 vs 숨은 니즈

| 구분 | 내용 |
|---|---|
| 명시 | 15개 화면·4통화 PayPal·번호 조회·4개 언어·주소 자동완성·이메일 3종·모바일 우선 |
| 숨은 ① | **번호만으로 조회**하면 남의 예약(이름·주소·항공편)이 IDOR로 샌다 |
| 숨은 ② | **통화별 정액 + 환율환산 없음** → 원화 실수취가 통화마다 벌어져 마진 역전 |
| 숨은 ③ | 별첨1 코드의 **tier 할인**이 남아 프로모 종료 시 RFQ 균일가와 어긋남 |
| 숨은 ④ | 남의 **짐·개인정보·결제**를 책임짐 → 배상한도·통지·국외이전 동의 필요 |
| 숨은 ⑤ | 짐 개수는 예약 때 확정 안 됨(당일 실측) → 폼이 강제하면 이탈 |

## 2. 웹 리서치 — 치명적 발견 (근거)

| 우선순위 | 발견 | 근거 |

| **마진 역전** | PayPal 해외거래 수수료 + 통화별 고정수수료 + 환전 스프레드 → 통화별 원화 실수취 상이 | [PayPal 한국 비즈니스 수수료](https://www.paypal.com/kr/business/paypal-business-fees) |
| **배상 분쟁** | 택배 표준약관 — 가액 미기재 시 한도 50만원, 14일 내 통지 안 하면 책임 소멸, 공제합의 불허 | [택배 손해배상 (easylaw)](https://www.easylaw.go.kr/CSP/CnpClsMainBtr.laf?popMenu=ov&csmSeq=663&ccfNo=3&cciNo=1&cnpClsNo=2) |
| 개인정보 국외이전 | 대만·일본·중국 손님·LINE 로그인 → 국외이전 고지·동의 | 개인정보보호법 국외이전 |
| 요금 불일치 | 별첨1 booking.js의 tier가 RFQ 균일가와 충돌(프로모가 가림) | 별첨1 필드명세 tier() |

## 3. 화면 구성 (재개발 — RFQ 15개 화면 전부 구현)

검수 기준이 “화면 15개 전부 실기기 정상 작동”이므로 데모 자체를 15개 화면으로 재구축.

| 표면 | 화면 | 핵심 구현 |
|---|---|---|
| 고객 앱(폰 프레임) `index.html` | S-01~06 | 배송/보관 분기 · 프런트→할증→거점(1km·적재<80%·지도 핀 패널) 분기 흐름도 그대로 · 사이즈 S/M/L 검증 · 원거리 +15,000 · 부산 외→문의 · PayPal 4통화 정액 · PF-MMDD-XXXX 비순차 · 조회=번호+전화 뒷자리(IDOR 차단)·사진→입고·연장 결제 · LINE/구글+게스트 |
| 관리자 `admin.html` | S-07~14 | 로그인 게이트 · 오늘 할 일(목록/지도·새벽/실측 태그) · 세로 아코디언 현황 · 상세 드로어(다음 단계 버튼·되돌리기·취소 사유·이력 실기록) · 수기 등록(미확정 허용) · 거점(적재율 지도·80% 제외·전용링크/QR) · 통계(이탈 퍼널·CSV) · 설정(통화 정액표+원화 실수취 실시간 진단) |
| 거점 `partner.html` | S-15 | 전용 링크·로그인 없음·모바일 전용 · 유일 버튼+되돌리기 · 개인정보 최소화 |

발견→기능 매핑: IDOR→S-03 이중 인증 · 마진 역전→S-14 실수취 진단 · tier 충돌→요금의 유일
원천을 설정 데이터로(데모 전체가 실제로 그렇게 계산) · 당일 실측→S-11 미확정 허용 ·
수거사진→S-10 사진 3종+이력. 허브(index)에 요금/통화 진단·리스크 6·견적 A~M 유지.
