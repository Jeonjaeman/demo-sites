# Pack&Fly 팩앤플라이 — 외국인 짐배송·짐보관 예약·운영관리 (제안용 데모)

부산·김해 외국인 관광객이 숙소↔공항으로 짐을 배송·보관하는 서비스의 예약~운영관리.
RFQ의 15개 화면 중 **핵심 흐름과 치명적 발견**을 동작하는 화면으로 구현했습니다.

공개 URL(별칭): `https://jeonjaeman.github.io/demo-sites/packnfly/`

| **요금·통화 진단** | tier vs 균일(RFQ) 비교 · PayPal 4통화 → 원화 실수취(마진 역전) |

## 체험 시나리오

1. 상단 **언어(EN/KO/JA/ZH)** 를 바꾸면 히어로·위저드가 그 언어로.
2. **예약 위저드**: 배송/보관 → 방향 → 짐 개수(가격 실시간) → 장소 → 연락처(약관 동의) → 결제(통화) → **예약번호** 발급.
3. **요금·통화 진단**: tier(프로모 종료 시)와 RFQ 균일가가 어긋나는 표 / 통화별 원화 실수취가 최대 10%p 벌어지는 계산(JPY 최저·TWD 최고).
4. **예약 조회**: 왼쪽(번호만)은 남의 예약이 노출, 오른쪽(번호+연락처 뒷자리)만 본인 확인.

## ⚠️ 착수 전 확인 (미팅)

- PayPal 통화별 정액가를 원화 기준 얼마로 재설정할지 · 국내 PG 병행 여부(옵션)
- 분실·파손 배상한도·귀중품 제외 약관 · 수거사진 보관 · 개인정보 국외이전 동의
- AWS/Vercel 재활용 범위(Google Sheets 이관은 발주자 직접) · 제휴 거점 데이터 · 당일 실측 청구 규칙

## 디자인 실측

- 도메인: **Bounce**(흰 배경·InstrumentSans·인디고 #454ced·pill·30,000 거점·QR·정액), **Radical Storage**(정액)
- 디자인: **Linear**(64px/−0.022em·pill), **Vercel**(radius4·−0.06em·모노) — 메트릭 이식
- 시스템: 웜화이트 + 코랄 액센트 + 네이비 잉크 · 모바일 우선 · 가격/수치 모노

## 기술 구성
