## 화면 15개

### 고객 (S-01~06) — index.html 폰 프레임
- **S-01 예약 폼**: 0단계 배송/보관 분기 → (배송) 방향+개수 → 출발지(주소 자동완성 데모) →
  **프런트 유무(+1층) → 할증>0? → 거점 1km·적재<80%? → 지도 핀+슬라이드 패널(목록 없음)** →
  사이즈 S/M/L(합계=총개수 검증) → 도착지+항공편 → 연락처·메신저 채널 → 요금·약관.
  (보관) **지도 먼저** → 날짜(최대 7일 검증) → 사이즈별 요금 → 연락처 → 약관.
  **원거리(송정·기장·정관) +₩15,000 자동 · 부산 외 주소 → “문의해 주세요” 전환.**
- **S-04 결제**: PayPal 임베드(시뮬) · **통화별 정액(KRW·TWD·JPY·USD) 그대로 청구** — 모든 요금이 S-14 설정 데이터에서 계산
- **S-02 완료**: **PF-MMDD-XXXX 비순차 발급** · 선택 채널 연결 · 확인 메일(1/3종)
- **S-03 조회**: **번호+전화 뒷 3자리**(IDOR 차단 — 틀리면 차단·rate limit) · 거점 이용 시 **사진 업로드→“짐을 맡겼어요”=입고 접수** · 상태 타임라인 · 미결제 재결제 · **보관 초과 시 연장(일수×동일 요율→결제→날짜 갱신)**
- **S-05 로그인**: LINE·Google(시뮬) · **게스트 경로 유지(로그인 강제 금지)** / **S-06 내 예약**: 진행/완료 · 탭→조회 · 재예약 프리필

### 관리자 (S-07~14) — admin.html
- **S-07** 로그인 게이트 → **S-08 오늘 할 일**: 수거/인도/환불 섹션 · 새벽·프런트無·당일실측 태그 · **목록/지도 탭**(오늘 방문지 위치만)
- **S-09 현황**: 세로 아코디언 5상태 · 날짜/검색 필터 · **드래그 없음, 상태 변경은 상세에서**(와이어프레임 규칙)
- **S-10 상세(드로어)**: **다음 단계명이 버튼 라벨**(확정→수거완료→전달완료) · 되돌리기 · 취소(사유) · 결제 변경 · 거점 변경/대신 입고 · 사진 3종 · **변경 이력(감사 로그) 실기록**
- **S-11 수기 등록**: S-01 동일 필드 · **개수·시간·금액 미확정 허용**(별첨2 “당일 실측” 패턴) · 번호 자동발급 → 현황/오늘 할 일에 즉시 반영
- **S-12 거점**: 지도 기본 탭(적재율 핀 · **80%↑ 고객 지도 제외**) · 수용량 S/M/L · 현재 짐 목록 · 지급액 정액 · **전용링크 복사·접수 QR PNG 다운로드**
- **S-13 통계**: 건수·완료율·외국인 비율(실계산) · **예약 폼 이탈 퍼널**(RFQ 이탈 추적) · 거점 정산 **CSV(BOM)**
- **S-14 설정**: **통화별 정액표에 원화 실수취 실시간 표시 — 수정하면 마진 역전 경고** · 프로모/할증 스위치(끄면 고객 폼 분기·가격이 실제로 바뀜) · 원거리 목록 · 이메일 3종 미리보기

### 거점 (S-15) — partner.html
로그인 없는 전용 링크 · 가져갈 것/찾아갈 것/입고 예정 · **유일한 버튼 “손님이 찾아갔습니다”+상시 되돌리기** · 이름·개수·사진만(개인정보 최소화) · 교육 30초

## 체험 시나리오 (입력 없이 클릭만)
1. 폰에서 **짐배송 → 방향 → 광안리 선택 → 프런트 없음** → 지도 핀 탭 → 거점 선택 → 사이즈 → 결제 → **PF번호 발급**
2. 출발지에 **송정** 입력 → +₩15,000 자동 / **서울** 입력 → 문의 화면 전환
3. **조회**: 예시 칩 2개(배송 건 / 보관 기간 초과 건) — 사진→입고, 연장→결제→날짜 갱신. 뒷자리 틀리면 차단
4. **관리자**: 오늘 할 일 건 클릭 → 상태 전환·이력 / 수기 등록(미정 그대로) / 설정에서 JPY 정액을 내려 보면 **역전 경고**
5. **거점 현황판**: “손님이 찾아갔습니다” → 되돌리기

## ⚠️ 착수 전 확인 (미팅)
- 통화별 정액가 재설정 기준(원화 실수취) · 국내 PG 병행 여부(옵션)
- 배상한도·통지기한·귀중품 제외 약관 · 수거사진 보관 · 개인정보 국외이전 동의 문안
- AWS/Vercel 재활용 범위 · 거점 계약 조건(지급 정액) · 당일 실측 청구 규칙

## 디자인·기술
- 도메인: **Bounce·Radical Storage**(정액·거점·모바일 우선) / 디자인: **Linear·Vercel** 메트릭 이식
- 웜화이트+네이비+코랄 · 수치 모노 · 폰 프레임 375 · 관리자 네이비 사이드바 · 이모지 최소
- 정적 HTML/CSS/JS(빌드 없음) · 외부 라이브러리 미사용 · 지도는 캔버스 자체 구현(dpr 대응)
- 요금·통화·적재율·퍼널·정산 **전부 실계산**(요금은 S-14 설정 데이터가 유일 원천 — tier 하드코딩 제거 제안과 일치)
- 4개 언어 i18n(기기 언어 자동 감지 · 언어→통화 연동) · CSV/QR은 Blob 실파일 · `prefers-reduced-motion`
