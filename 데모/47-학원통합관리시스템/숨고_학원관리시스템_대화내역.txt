1. 대화 타임라인 (턴별 결론)
────────────────────────────────────────────────────────────

[1] 최초 견적 요청
→ 3티어 제시: BASIC 178만 / STANDARD 328만 / PREMIUM 468만
→ Zapier·Make 대신 앱스스크립트 권고 (월 유지비 0원 논리)
→ 리드 등급 A (요건서 구체적, 진성 리드)

[2] "노션 학생정보 공유 보안문제는?"
→ 노션 공개 링크 리스크 3가지: 링크 유출 무방비 / 검색엔진
   노출 / 퇴원생 회수 불가
→ 대안 C안: 학부모 전용 조회 페이지 별도 구축 (+45만)
→ 미성년자 개인정보 = 법정대리인 동의 필수, 국외이전 고지

[3] "모든 걸 자체 DB로 구현한다면?"
→ 기술적으로 전부 가능. 진짜 단점은 "원장이 직접 못 고침"
→ 절충안: 코어(저장·인증·권한)=자체DB / 메모=노션 유지 /
   월간 백업=구글시트 자동 내보내기
→ FULL CUSTOM 598만 안 제시 (앵커 역할)

[4] "130만 부가세 제외로"
→ 1단계 분할 프레임: 출결+성적+학부모조회+알림톡2종 (95h)
→ 손익분기 95만, 배수 1.37 — 마진 얇음 경고
→ 2단계 업셀 6항목 225만을 진짜 수익원으로 설계

[5] "AI 개발 반영해서 손익분기 재산정"
→ 95h → 낙관65h/현실80h/비관110h
→ AI가 못 줄이는 35%: 요건 커뮤니케이션, 카카오 심사 대응,
   데이터 이관, 인수인계, 영상 매뉴얼
→ 진짜 병목은 원가가 아니라 달력(주당 가용 18h)
→ 손절 라인 125만으로 상향

[6] "220만 부가세 포함 확정"
→ 공급가 200만 / 현실 배수 2.27 — 기준 충족
→ 수납 모듈 포함 권고 (200만 방어 논리) → 92h, 배수 2.0
→ 납기 4주 → 5주 수정

[7] "미포함까지 전부 해서 330만이면?"
→ 개별 합산 402만 → 묶음 330만 (18% 절감 프레임)
→ 현실 138h, 손익분기 138만, 배수 2.17
→ 납기 8주 (실질 9~10주 각오), 4주차 중간 오픈 + 중도금 30%
→ 결제: 착수 40 / 중도 30 / 잔금 30
→ 손절 라인 270만

[8] "매뉴얼 제거하고 PDF로"
→ 원 요청서에 매뉴얼 명시됨 → 완전 삭제 대신
   "인수인계 화상 세션 1회"로 대체, 매뉴얼은 옵션 +25만
→ 공수 8h → 3.5h, 배수 2.28로 개선
→ (PDF 작업은 이후 작업 시나리오 논의로 전환됨)

[9] "시스템 구조 수정이 뭘 의미?"
→ 원장의 멘탈모델 = 노코드 ("내가 직접 고친다")
→ 수정 요구 5단계 분해: 1~3단계(데이터/설정값/항목추가)는
   설정 화면으로 해결 가능, 4~5단계(화면/구조)는 개발 필요
→ 설정 화면 6~8h 투자 = A/S 방어 + 원 요청 충족
→ 계약서에 "직접 변경 가능 / 개발 필요" 구분선 명시

[10] "작업 시나리오 + 내 병목 파악" (노션·알림톡 미경험)
→ 8주 이중 트랙: 개발 트랙(통제 가능) vs 행정 트랙(통제 불가)
→ 핵심 체인: 도메인 확정 → 카카오 채널 → 발신프로필 →
   템플릿 등록 → 검수(3~5영업일) → 발송 테스트 가능
→ 알림톡: 코딩은 쉽고 행정이 병목. 템플릿 3주차 제출 필수
→ 학부모 인증: 인증번호 대신 "알림톡 24시간 만료 링크" 권고
   (12h → 5h, 보안 오히려 우수)
→ 노션 3대 벽: Integration 페이지 연결 404 / 초당 3회 제한 /
   이미지 외부 URL 필요
→ 숨은 함정 5: CP949 인코딩 / 동명이인 매칭 / 타임존 KST /
   cron UTC / 부분납부·환불
→ 착수 전 사전학습 4개: 노션 연동 1~2h, 솔라피 SMS 1h,
   RLS 테스트 2h, CP949 읽기 30m

[11] "노션 목적이 학생프로필이면 자체DB가 맞지 않나?"
→ 맞음. 보안은 두 저장소 중 약한 쪽으로 수렴 → 노션 연동
   제거가 논리적 귀결
→ 대체: 학생 프로필 페이지 신설 (상담이력 + 내부메모,
   학부모 비공개 권한 분리)
→ 공수 -9h +7h = 순 -2h, 금액 330만 유지
→ 원장 반발 대비: 읽기 전용 요약 동기화 옵션 +20만

[12] "원장은 Zapier가 왜 필요하다고 생각한 거야?"
→ DB 동기화 아님. "손으로 옮기는 일을 없애는 접착제" 개념
→ 요청서 문구 분석: 열거만 하고 선택 안 함 = 애착 없음 /
   "유지비" 명시 = 구독료 부담 인지 / "제안해주세요" = 위임
→ 진짜 기대 = "내가 화면 보고 조건을 바꾼다" (통제권)
→ 견적서에 가격 논리 + 통제권 논리(설정 화면) 병기

[13~14] 데모사이트 구축
→ 단일 HTML 40KB, 시드 데이터 12명·2개 반, localStorage
→ 시그니처: 출석 도장 모션 (인주 레드 #C2402E)
→ 구현: 키오스크(지각 자동판정) / 수납 CSV 시뮬(동명이인

2. 최종 확정 사항
────────────────────────────────────────────────────────────

금액        : 3,300,000원 (부가세 포함 / 공급가 300만)
납기        : 요건 확정·자료 수령일 기준 8주 (알림톡 심사 제외)
결제        : 착수 40% / 중도 30%(4주차 중간오픈 시) / 잔금 30%
공수        : 현실 138h → 노션 제거 반영 136h
손익분기    : 136만 / 배수 2.21 (비관 175h에도 1.7배 방어)
손절 라인   : 270만 이하 패스, 300만 이하는 범위 축소 대응
A/S         : 오픈 후 3개월 오류 수정 무상 (기능 추가 별도)

■ 포함 범위 (최종)
1. 출결: 키오스크(번호/QR)·실시간 반영·지각 자동판정
2. 수납: 결제선생 CSV 매칭·미납 분류 (동명이인 수동확인 가드)
3. 성적: 문항유형별 입력·추이 그래프·유형별 정답률
4. 과제 성취도: 수행률·취약유형·총평 누적
5. 오답 클리닉: 기준 미달 유형 해설영상 자동 매칭
6. 학생 프로필: 상담이력·내부메모 (노션 연동 대체, 학부모 비공개)
7. 학부모 조회: 알림톡 24h 만료 링크 (무로그인)·열람 로그
8. 알림톡 3종: 성적표/미제출·미응시/미등원 + SMS 대체발송
9. 대시보드 + 반별·기간별 통계 리포트 / 권한 3단계
10. 설정 화면: 지각기준·클리닉 기준점수·발송시각·문구 직접 수정
11. 구글시트 월간 자동 백업 / 소유권 100% 이전
12. 인수인계 화상 세션 1회 (문서·영상 매뉴얼은 옵션 +25만)

■ 원장 부담 (별도)
- 카카오 비즈니스 채널 + 템플릿 심사 (사업자 명의, 3~5영업일)
- 솔라피 발송비 13원/건, 인증 SMS 약 20원/건
- Supabase Pro 권장 월 3.5만 (무료 시작 가능) / 도메인 연 2만
- 개인정보 동의서 확보 (만14세 미만 법정대리인 필수, 국외이전 고지)
- 학생 명단·결제선생 CSV 샘플·유형분류 기준·해설영상 링크
- 출결 태블릿 기기

■ 계약서 필수 방어 문구
- 개인정보 동의 확보·관리 주체 = 발주자, 개발자는 기술 구현만
- 납기 기산 = 요건 확정 및 자료 수령일 / 알림톡 심사기간 제외
- A/S = 버그 수정 한정, 기능 추가·화면 변경·시나리오 추가 별도
- 제3자 서비스(Supabase·Cloudflare·솔라피·카카오) 정책 변경·
  장애·요금 인상은 책임 범위 외
- 학부모 조회 인증은 간이 인증임을 명시
- "직접 변경 가능 항목 / 개발 필요 항목" 구분 명시
- 데이터를 발주자가 외부 도구에 복사 시 보안 책임은 발주자

3. 기술 스택·아키텍처 (확정안)
────────────────────────────────────────────────────────────
- DB/인증/권한: Supabase (RLS로 학부모=자기 자녀만 강제)
- 프론트/배포: Next.js + Cloudflare Pages (무료)
- 알림톡: 솔라피 API + Edge Functions/Workers Cron (UTC 주의)
- 학부모 열람: 알림톡 내 24시간 만료 토큰 링크
- 백업: 구글시트 월간 자동 내보내기
- 노션: 연동 제거 (학생 프로필 페이지로 대체)
- 월 운영비: 알림톡 발송비 외 0원 구조

■ AI 생성 코드 직접 검증 필수 4지점
1. 결제선생 CSV 파싱 (CP949, 부분납부·환불·중복결제)
2. 출결 중복 체크인
3. 알림톡 발송 실패 재시도
4. 통계 집계 쿼리 (반 이동·중도 퇴원 처리)

■ 착수 전 사전학습 (저녁 시간)
