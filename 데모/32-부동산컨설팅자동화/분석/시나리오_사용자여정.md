# AUTOCAST 오토캐스트 — 시나리오·사용자 여정

> 기능 목록을 **시간순 사용 흐름**으로 다시 배치한 문서입니다.
> 이 건은 "매일 콘텐츠를 찍어내야 하는 사람"과 "그 비용·법적 책임을 지는 사람"이
> 서로 다르다는 점이 핵심입니다.

---

## 1장. 등장인물

| 인물 | 누구인가 | 원하는 것 | 불안한 것 |
|---|---|---|---|
| **박대표 · 부동산 중개·컨설팅 대표** | 발주자. IT를 모릅니다. 마케팅을 자동화하고 싶습니다. | 매일 콘텐츠가 알아서 나오는 것. **예산 안에서.** | AI 툴이라는데 자꾸 돈이 나가는 것. 법적으로 문제 생기는 것. |
| **김실장 · 콘텐츠 운영 담당** | 매일 카드뉴스·숏폼을 만들어야 하는 실사용자. | AI가 초안을 주고, 자기는 **검수만** 하는 것. | AI 초안이 엉망이면 결국 자기가 다 고치는 것. |
| **개업공인중개사(법적 주체)** | 발행되는 광고의 법적 책임자. | 규제 위반 없이 나가는 것. | 자동 발행된 콘텐츠에 등록번호가 빠지거나 과장이 섞여 **과태료**를 맞는 것. |
| **파트너(우리)** | 자동화 시스템 구축자. | 경계가 명확한 상태로 착수. | 노코드로 안 되는 지점(비용·법)을 착수 후 알게 되는 것. |

**한 사람이 두 역할을 겸하는가?**
소규모 중개사무소에서는 **박대표 = 개업공인중개사 = 검수자**가 한 명입니다. 그러면 이 사람이
비용도 걱정하고 법적 책임도 지므로, **"이게 왜 돈이 나가고 왜 위험한지"를 화면으로 보여주는 것**이
곧 신뢰입니다. 공고가 "한계점을 말해 달라"고 한 이유입니다.

## 2장. 전체 타임라인 — 하루와 한 주

### 매일 (자동 파이프라인)

```
06:00  수집    뉴스·청약·단지 API/RSS → DB 적재
06:10  초안    오늘 요일 주제로 AI가 카드뉴스·대본 초안 생성
06:15  대기    ┌─ 김실장 검수 대기 (승인 전 정지) ★
       ...     │  여기서 멈추지 않으면 틀린 대본이 그대로 영상이 됩니다
09:00  검수    └─ 김실장 열람·수정 → 컴플라이언스 통과 → 승인
09:05  영상    승인분만 HeyGen 렌더 (초당 과금 — 승인분에만 돈이 나감)
09:20  발행    스토리지 저장 + 텔레그램 알림
```

**요일별 주제 (공고 2-2)**
월 청약 브리핑 · 화 실거래 급등락 · 수 정책·세금 · 목 단지 스포트라이트 · 금 주말 임장 추천

**여기서 이미 드러나는 문제**
- 검수를 건너뛰면 HeyGen이 틀린 대본을 렌더 → 다시 만들며 **과금이 두 번**
- AI 초안에 등록번호가 없고 "확실히 오른다"가 섞이면 **자동 발행 시 과태료**

### 한 주 (파이프라인 보드)

대시보드의 파이프라인 보드가 이 흐름을 그대로 보여줍니다. 지난 주는 발행까지 완료,
이번 주는 수집·초안·검수에 걸쳐 있습니다. **검수 대기 열이 비어 있어야 하루가 끝납니다.**

## 3장. 역할별 시나리오

### 시나리오 A — 김실장의 아침 검수

| 단계 | 상황 | 쓰는 화면 | **이 기능이 없으면** |
|---|---|---|---|
| A-1 | 파이프라인을 연다 | 주간 보드 | 오늘 뭘 검수해야 하는지 흩어져 있습니다 |
| A-2 | 검수 대기 티켓을 연다 | 에디터 모달 | AI 초안이 어디 있는지 매번 찾습니다 |
| A-3 | 초안을 읽는다 | 텍스트 에디터 | — |
| A-4 | **"강력 추천" 같은 과장이 잡힌다** | 컴플라이언스 체크 | 그냥 승인하면 부당광고(최대 500만원)로 나갑니다 |
| A-5 | 등록번호 등 명시사항 누락이 뜬다 | 명시사항 5종 체크 | 누락 발행(최대 100만원) |

| B-2 | 영상 개수·길이를 넣는다 | 슬라이더 | 감으로 추측합니다 |

## 5장. 기능별 존재 이유 — 전수 매핑

| 기능 | 어떤 장면에서 나왔나 | 없으면 벌어지는 일 |
|---|---|---|
| 데이터 수집 파이프라인 | 매일 06:00 | 매일 사람이 자료를 모읍니다 |
| AI 초안 생성 | A-3 | 매일 백지에서 씁니다 |
| 요일별 주제 분기 | 한 주 | 뭘 만들지 매일 고민합니다 |
| 에디터 UI | A-2 | 초안이 어디 있는지 찾습니다 |
| **검수 게이트** ★공고 "중요" | A-7, B-3 | 틀린 대본이 영상이 되어 과금 두 번 |
| **컴플라이언스 체크** ★공고 밖 | A-4·5, C-1 | 위반 콘텐츠가 자동 발행돼 과태료 |
| **HeyGen 비용 계산기** ★공고 밖 | B-1~5 | 청구서를 보고 놀랍니다 |
| **재렌더율 반영** ★공고 밖 | B-3 | 왜 비싼지 이해 못 합니다 |
| **아바타 등급 비교** ★공고 밖 | B-4 | 최고 등급으로 4배 비싸게 씁니다 |
| HeyGen 렌더·저장·알림 | A-8 | 영상을 손으로 내려받아 올립니다 |
| 고객 폼 → DB → 리포트 | (2-5) | 상담 신청이 흩어집니다 |
| **기술 경계선 표** ★공고 밖 | D-1 | 견적을 잘못 냅니다 |
| **운영 방식 비교** ★공고 밖 | D-2 | 셀프호스팅으로 1차가 늦어집니다 |

## 6장. 예외 상황 — 시나리오를 그리면 드러나는 구멍

| 상황 | 지금 정의가 없는 것 | 데모에서의 처리 |
|---|---|---|
| **HeyGen 렌더 실패** | 재시도·비용 처리 | 미구현 — **미팅 확인 항목** |
| **AI 초안이 매번 나쁨** | 프롬프트 재조정 책임 | 프롬프트 엔지니어링 공수에 포함 |
| **외부 API 스키마 변경** | 누가 고치나 | 실패 알림 + 유지보수 매뉴얼 |
| **명시사항 정보 출처** | 등록번호 등 어디서 주입 | **미팅 확인 항목** |
| **리포트가 투자 권유가 됨** | 정보/권유 경계 | 금지어 + 사실 정보 중심 |
| **검수자가 자리를 비움** | 승인 지연 시 발행 밀림 | 미구현 — 알림으로 대체 |
| **월 물량이 급증** | 클라우드 비용 폭증 | 셀프호스팅 전환 시점 논의 |
| **2차 범위** | DB 구조화 수준 | 1차 설계에 대비, 2차 견적 별도 |

## 7장. 미팅에서 확인이 필요한 항목

1. **HeyGen 등급·월 물량** — 비용 상한
2. **수집 대상 API/RSS 목록**
3. **에디터 툴** (Retool/Airtable/노션)
4. **운영 방식** (클라우드 vs 셀프호스팅)
5. **명시사항 정보 출처** — 중개사무소 정보 주입 경로
6. **리포트 성격** — 정보 제공 vs 투자 권유
7. **1차 범위** — 요일 몇 종
8. **인수·유지보수** — 매뉴얼 수준, 지원 범위
9. **HeyGen 렌더 실패 시 재시도·비용 처리 정책**
