[프로젝트 개요]
- 부동산 업무 자동화 1차 MVP 구축

[프로젝트 배경 및 목표]
- 부동산 중개업무 및 마케팅 효율성을 극대화하기 위해 기성 AI 툴과 자동화 솔루션을
  결합한 시스템을 구축하고자 합니다. 방대한 올인원 개발이 아닌, 예산 범위 내에서
  당장 실무에 적용 가능한 1차 MVP(최소 기능 제품) 구현이 목표입니다. n8n과
  헤르메스(Hermes) 에이전트를 기반으로 부동산 핵심 데이터를 수집하고, 이를 바탕으로
  카드뉴스 및 숏폼 영상 대본을 생성하며, HeyGen API를 통해 아바타 영상을 자동으로
  제작하는 파이프라인을 구축해야 합니다. 또한, 구글 폼 등 설문 조사로 유입된 고객
  정보를 데이터베이스화하여 맞춤형 부동산 리포트를 생성하는 기능이 필수적입니다.
  향후 2차 고도화를 위한 확장성을 고려하여 시스템을 설계해야 합니다.

[과업 범위]

1. 수행 범위
- 자동화 파이프라인 기획 및 아키텍처 설계
- n8n, Hermes Agent 초기 세팅 및 워크플로우 구성
- 부동산 데이터 수집용 외부 API 연동
- HeyGen API 연동 및 아바타 영상 생성 자동화
- 뉴스/대본 수정을 위한 관리자용 노코드 웹 UI 또는 노션/데이터베이스 연동 세팅
- 프롬프트 엔지니어링 및 AI 요약/생성 로직 구현

2. 상세 기능 요구 사항

2-1. 부동산 데이터 자동 수집 파이프라인
- 부동산 뉴스, 청약 정보, 아파트 단지 정보를 지정된 API 및 RSS 피드를 통해 정기 수집
- 수집된 원시 데이터를 데이터베이스(구글 시트 또는 노션)에 자동으로 적재

2-2. AI 기반 콘텐츠 초안 및 대본 생성
- 수집된 데이터를 바탕으로 헤르메스 또는 연동된 AI 모델을 활용하여 카드뉴스 텍스트
  초안 생성
- 유튜브 쇼츠, 인스타그램 릴스 제작을 위한 영상용 음성 대본(스크립트) 자동 작성
- 월요일부터 금요일까지 요일별로 지정된 주제에 맞는 콘텐츠 기획안 초안 자동 산출

2-3. 에디터 UI 및 수정 기능 (중요)
- AI가 생성한 카드뉴스 텍스트 및 영상 대본을 최종 발행 및 영상 제작 전 관리자가
  직접 열람하고 수정할 수 있는 관리자 화면 제공
- 순수 커스텀 개발 대신 Retool, Softr, Airtable, 노션 중 협의된 툴을 사용하여
  비용 효율적으로 에디터 환경 구축
- 수정 완료 버튼 클릭 시 다음 워크플로우(영상 생성 단계 등)로 데이터가 전달되는
  트리거 로직 구현

2-4. HeyGen 아바타 영상 자동 제작
- 에디터 UI에서 최종 승인 및 수정된 대본 텍스트를 HeyGen API로 전송
- 지정된 아바타 모델과 음성(정해진 프리셋 활용)을 적용하여 숏폼 해상도 영상 자동
  렌더링 요청
- 렌더링이 완료된 영상 파일을 다운로드하여 지정된 클라우드 스토리지(구글 드라이브 등)에
  자동 저장 및 텔레그램 알림 발송

2-5. 고객 데이터베이스 및 맞춤 리포트 생성 기능
- 구글 폼, 타입폼, 노션 폼을 통해 유입된 고객 상담 신청 정보를 데이터베이스에 자동 저장
- 저장된 고객의 요구 조건(예산, 희망 지역, 면적)을 분석하여 사전에 하드코딩된 로직과
  AI 요약을 결합한 맞춤형 리포트 문서 자동 생성

2-6. 2차 고도화(추후 별도 진행)를 위한 대비 사항
- 본 과업 범위에 포함되지 않으나, 추후 시스템 연동을 위해 데이터베이스 구조화 필수
- 2차 고도화 예정 기능: 협력 부동산 배정 및 진행 상태 추적, 고도화된 세금 분석 리포트,
  생성 완료 콘텐츠의 다채널(인스타, 유튜브, 네이버 블로그 등) 완전 자동 발행 시스템
