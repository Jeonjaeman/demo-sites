## 체험 시나리오 — 이 순서로 보시면 3분입니다

### 파이프라인

1. **검수 대기 티켓을 열어 승인해 보세요** ★
   AI 초안에 "강력 추천" 같은 과장이 섞여 있으면 **컴플라이언스가 잡아 승인을 막습니다.**
   [자동 교정 시연]을 누르면 금지어 제거 + 명시사항 삽입 후 통과합니다. 그때만 영상 단계로 넘어갑니다.

2. **승인 안 된 티켓은 영상 단계로 못 넘어갑니다** ★
   검수 없이 자동 렌더하면 틀린 대본에 HeyGen 초당 과금이 나가기 때문입니다.
   공고가 2-3 에디터 검수를 "중요"로 표시한 이유가 이겁니다.

3. **HeyGen 비용 계산기를 만져 보세요** ★
   영상 개수·길이·**재렌더율**·아바타 등급을 넣으면 월/연 비용이 실제로 계산됩니다.
   등급을 Avatar III로 낮추면 비용이 4배 가까이 줄어드는 것을 수치로 보여줍니다.

### 착수 전 검토

4. **[HeyGen 비용 현실]** — 2026-02부터 무료 크레딧 폐지, 초당 과금. 등급별 단가표.

5. **[표시광고 컴플라이언스]** ★
   콘텐츠 20건을 실제로 검사해 **11건 위반**, 그대로 발행했다면 누적 과태료 위험 **3,500만원**을 계산합니다.

6. **[기술 경계선]** — 요구사항별로 노코드로 되는 것과 개발 공수가 드는 것을 나눴습니다.

7. **[2차 고도화 견적]** — 공고가 요구한 2차 제안(45일 · 225만원).

## ⚠️ 착수 전 확인이 필요한 항목

### 1. HeyGen 무료 크레딧이 폐지됐습니다 — 영상이 곧 비용입니다 ★

2026년 2월부터 무료 API 크레딧이 없어지고 초당 과금($0.0167~$0.0667/초)입니다.
요일별로 매일 숏폼을 만들면 재렌더까지 감안해 비용이 빠르게 쌓입니다.
→ 비용 계산기로 실측하고, 아바타 등급 선택을 발주사가 정하게 했습니다.

### 2. 검수 없이 자동 영상화하면 틀린 대본에 돈이 나갑니다 ★

공고가 2-3을 "중요"로 표시한 이유입니다. `draft → 승인 → video` 게이트를 강제해
승인 전에는 영상이 만들어지지 않습니다.

### 3. AI가 만든 부동산 콘텐츠는 표시·광고 규제 대상입니다 ★

공인중개사법 §18의2 — 명시사항 누락 최대 100만원, 부당광고 최대 500만원.
→ 발행 전 컴플라이언스 검사로 명시사항·금지어를 잡고, 통과분만 발행합니다.

그 밖에 — **n8n이 외부 API 변경에 멈추는 문제**(실패 알림·매뉴얼), **"올인원 아닌 1차 MVP"**(한 줄기 먼저),
**리포트가 투자 권유가 되는 경계**도 정리했습니다.

자세한 근거는 [분석/기획_설계.md](분석/기획_설계.md) 2장을 참고하세요.

## 기술 구성 (데모)

- 순수 HTML/CSS/JS — 빌드 불필요
- **파이프라인은 실제 상태를 가집니다** — 티켓이 수집→초안→검수→영상→발행 단계를 이동하고,
  승인 없이는 영상 단계로 넘어가지 않습니다(검수 게이트)
- **HeyGen 비용은 실측 단가로 계산** — 초당 $0.0167~$0.0667(2026-07 G2/eesel 기준), 재렌더율 반영
- **컴플라이언스는 텍스트를 실제로 검사** — 명시사항 5종 누락 + 금지어 사전으로 과태료 위험 산출
- 콘텐츠 20건(4주×5요일) 시드 생성, 일부에 과장 표현을 심어 검사가 잡게 함
- 375px 가로 스크롤 0 · 표는 자체 컨테이너 내부 스크롤 · 900px 이하 보드 세로 스택
- **단지명·주제·수치·중개사무소 정보는 전부 가상**입니다. 실존 단지·중개사무소와 무관합니다

실서비스 제안 스택: n8n Cloud(1차) + OpenAI/Claude API + Retool/Airtable + HeyGen API,
발행 트리거 앞단에 컴플라이언스 미들웨어 ([기획_설계.md](분석/기획_설계.md) 5장)
