[1] HeyGen 무료 크레딧이 폐지됐습니다 — 영상이 곧 비용입니다

  "AI 툴로 저렴하게"라는 기대와 달리, HeyGen 은 2026년 2월부터 무료 API 크레딧을
  없애고 초당 과금(pay-as-you-go)으로 바꿨습니다. 아바타 등급별로 초당
  $0.0167 ~ $0.0667 입니다. 요일별로 매일 숏폼을 만들면 월 20~40개, 재렌더까지
  감안하면 비용이 빠르게 쌓입니다. 그런데 이 비용은 공고에 없습니다.

  → 데모 [비용 계산기]에서 영상 개수·길이·재렌더율·아바타 등급을 넣으면 월/연
    비용이 실제로 계산됩니다. 등급을 Avatar III 로 낮추면 비용이 4배 가까이 줄어드는
    것을 수치로 보여드립니다. 어느 플랜을 감당하실지 착수 전에 정하는 게 안전합니다.


[2] 검수 없이 자동 영상화하면 틀린 대본에 돈이 나갑니다

  공고가 2-3 에디터 검수를 "중요"로 표시하신 이유가 이겁니다. AI 초안은 사실 오류·
  과장이 섞입니다. 검수 게이트 없이 초안을 바로 HeyGen 에 넘기면, 틀린 대본을 렌더한
  뒤 다시 만들면서 초당 과금이 두 번 나갑니다.

  → 파이프라인을 초안 → 승인 → 영상 순으로 강제했습니다. 승인 전에는 영상 단계로
    넘어가지 않습니다. 데모에서 승인 안 된 티켓을 영상화하려 하면 막힙니다.
    검수 게이트가 곧 비용 방어선입니다.


[3] AI가 만든 부동산 콘텐츠는 표시·광고 규제 대상입니다

  공인중개사법 제18조의2 — 중개대상물을 광고할 때 중개사무소 명칭·소재지·연락처·
  등록번호·개업공인중개사 성명을 반드시 명시해야 합니다. AI 초안에는 이 명시사항이
  없고, "확실히 오른다" 같은 과장 표현이 섞이기 쉽습니다. 명시사항 누락은 최대
  100만원, 부당(과장)광고는 최대 500만원 과태료입니다. 자동 발행이면 사람 눈을
  안 거치므로 위반이 그대로 나갑니다.

  → 발행 전 [컴플라이언스 체크]가 텍스트를 실제로 검사합니다. 데모 콘텐츠 20건 중
    11건이 위반으로 잡혔고, 그대로 발행했다면 누적 과태료 위험이 3,500만원입니다.
    이 검사를 통과한 콘텐츠만 발행 단계로 갑니다.

  그 외 - n8n 워크플로우는 외부 API 가 응답 형식을 바꾸면 그 지점부터 조용히 멈춥니다.
  각 단계에 실패 알림(텔레그램)을 넣고 유지보수 매뉴얼을 산출물에 포함합니다(우대사항).
  그리고 공고가 스스로 "올인원 아닌 1차 MVP"라고 하신 만큼, 수집→초안→검수→영상→발행
  한 줄기를 먼저 끝까지 돌리는 것을 1차로 제안합니다. 리포트·다채널은 2차입니다.
