## 체험 시나리오 (타이핑 없이 클릭만으로)

1. 스코어보드 → LIVE 경기 클릭 → 몇 초 안에 득점 bump·토스트
2. 응원방 채팅 관찰 → 도박 스팸(`토0토`·`안전 놀이터` 같은 우회 표기 포함)이 자동 차단되는 순간
3. 메시지에 마우스 오버 → 답장/신고/차단 → 차단 시 해당 이용자 즉시 소멸
4. 응원방 「중계 지연 보정」 15초 → 채팅이 늦춰 도착 (스포일러 차단)
5. 게시판 우측 「시점 전환」 — 팬/작성자/운영자로 임시조치 글이 다르게 보임 → 작성자 시점에서 이의신청
6. 검토 항목 — 리그 체크·폴링 슬라이더·Redis 토글(상류 호출 불변 확인)·Sportradar 탭(리드타임 경고)
7. 검토 항목 — 크롤러 시점 토글 (SSR vs 캔버스), 권리침해 신고 제출 → **관리자 큐에 실제 적재**
8. 관리자 — 처리 큐 SLA, 부하 시뮬 「득점 이벤트」(백프레셔 OFF로 메모리 곡선 폭주 확인), 스토어 체크에서 「차단」 기능 끄면 리젝 사유 표시

## ⚠️ 착수 전 확인 (상세: 분석/기획_설계.md — 발견 17건)

1. **"Redis 캐싱으로 과금 방지"는 성립하지 않음** — 과금 = 경기 수×폴링 주기. 캐시는 무관
2. **종목별 별개 구독 + Sportradar는 예산 밖** — API 확정이 설계보다 먼저
3. **도박 홍보 방치 = 형사 리스크** (국민체육진흥법 49조·판례) — 자동 필터는 오픈 첫날부터
4. **"블라인드"만으론 44조의2 미충족** — 임시조치 30일·통지·이의신청이 한 세트
5. **Apple 1.2 4요소** 미비 시 리젝 — 8주차 스토어 등록 일정 직결
6. **Flutter Web 금지** — 웹은 Next.js SSR (커뮤니티 검색 유입)
