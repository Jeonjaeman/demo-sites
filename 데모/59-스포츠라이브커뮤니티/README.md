## 체험 시나리오 (타이핑 없이 클릭만으로)

1. 스코어보드에서 LIVE 경기 클릭 → 몇 초 안에 득점·스코어 갱신·토스트 확인
2. 응원방에서 채팅 흐름 관찰 → 도박 스팸이 자동 블라인드되는 순간 확인
3. 아무 메시지에 마우스 오버 → 답장/신고/차단 → 차단 시 해당 이용자 메시지 즉시 소멸
4. 「검토 항목」 → 동시접속 슬라이더를 움직여 직접폴링 vs 캐시 구조의 요금제 판정 비교
5. 관리자 → 신고 큐에서 「블라인드+제재」 처리, 스팸 필터에 금칙어 추가 → 사용자 화면 채팅에 즉시 적용
6. 관리자 → API 모니터링 「장애 상황 시뮬레이션」 → 스테일 서빙 배너·폴링 상태 변화

## ⚠️ 착수 전 확인 항목 (요약 — 상세는 분석/기획_설계.md)

1. Sportradar vs API-Football 가격 500배 차 — API 확정이 설계보다 먼저
2. 폴링 주체를 서버 1곳으로 — 클라이언트 직접 호출 구조면 과금 폭발
3. App Store 1.2(필터·신고·차단·24h) — 미비 시 심사 리젝으로 8주 일정 붕괴
4. 도박 스팸 자동 필터 — 오픈 첫날부터 필요 (KISA: 스팸 43%가 도박)
5. Flutter Web 금지 — 웹은 Next.js SSR (커뮤니티 검색 유입)
