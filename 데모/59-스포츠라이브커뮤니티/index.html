리서치로 확인한 지점 — API 과금 구조 오해, 도박 홍보의 형사 리스크, 임시조치 법정 절차, 스토어 심사 요건, 렌더링 스택의 검색 유입 — 을 전부 아래에서 직접 조작 가능한 기능으로 구현했습니다. 관리자 화면에는 처리 큐·부하 시뮬레이션·심사 체크리스트가 있습니다.

API 예산 시뮬레이터 — 과금은 유저 수가 아니라 「경기 수 × 폴링 주기」로 결정됩니다

공고의 "Redis 캐싱으로 과금 방지"는 성립하지 않습니다. 캐시는 유저 수에 대한 방어이고, 상류 API 호출량은 유저가 0명이어도 동일합니다. 리그를 고르고 폴링 주기를 움직여 보세요. 요금(API-Sports 공개 요금 예시, 2026.08)·커버리지·계약 리드타임까지 실계산됩니다.
