## 2. 웹 리서치 — 발견 17건 (검색 15회 + 원문 페치 3회, 근거 URL 전수)

### 【A】 그대로 만들면 작동하지 않음
- **A-1 ★ Redis 캐싱은 API 과금을 막지 못함** — 과금 = `경기 수 × 경기 시간 × (3600/폴링 주기)`, 캐시는 이 식에 없음(유저 0명이어도 동일). API-Football 라이브 15초 갱신 = 경기당 시간당 240요청, Pro $19 = 일 7,500 → **주말 유럽 축구만으로 첫날 오후 한도 소진**.
  https://www.thestatsapi.com/blog/thestatsapi-vs-api-football · https://www.api-football.com/pricing
  → **데모: API 예산 시뮬레이터** — 리그 체크+폴링 슬라이더로 실계산, Redis 토글이 상류 호출에 영향 없음(응답 42ms↔720ms만 변화)을 화면으로 증명
- **A-2 종목별 별개 API·별개 구독** — API-Sports는 12종목이 독립 API, 축구 $19는 축구만. "종목별 목록" = 종목 수만큼 정규화 어댑터 개발. https://api-sports.io/
  → 데모: 시뮬레이터에 종목별 구독료 계단 + 어댑터 카운터
- **A-3 Sportradar는 예산 밖** — 공개 요금 없음·용도 심사 계약, 보고 최소 구간 월 수천 달러~$10,000+. 개발비 2,500만 원과 별개의 연간 고정비. https://www.lsports.eu/blog/sports-data-cost/
  → 데모: 업체 탭 전환 시 리드타임 경고("계약 협상 ~6주 — 착수 후 시작이면 4주차 API 마일스톤 불성립")
- **A-4 Flutter Web은 "PC 웹" 요구를 무너뜨림** — CanvasKit 캔버스 렌더 = 시맨틱 HTML 0, 크롤러가 볼 것 없음 + 번들 1.5~2MB. 커뮤니티는 검색 유입이 생명. https://asoasis.tech/articles/2026-03-14-2053-flutter-web-seo-limitations-and-workarounds/
  → **데모: 렌더링 비교 패널** — 크롤러 시점 토글로 SSR(색인 가능) vs canvas(빈 태그) 대비
- **A-5 "8주 내 스토어 등록"은 리젝 1회면 붕괴** — 신규 앱 첫 제출 대기 2~5일 + 첫 제출 ~40% 리젝, UGC 앱이 최다 리젝 유형. https://www.lowcode.agency/blog/app-store-review-time
  → **데모: 관리자 「스토어 심사 체크리스트」** — 기능 플래그와 연동, 끄면 체크 풀리고 예상 리젝 사유 표시

### 【B】 법 위반 소지
- **B-1 ★ 도박 홍보 방치 = 운영자 형사 리스크** — 국민체육진흥법 26조 유사행위 홍보 = 49조 3년/3천만 원, 배너 게시 유죄 판례 존재. 국내 라이브스코어 커뮤니티가 불법 토토 1순위 유입 통로(이용자 신고 누적 기록 확인).
  https://law.go.kr/LSW/precInfoP.do?mode=0&precSeq=232931 · https://www.lawtalk.co.kr/posts/159613 · https://livescore.co.kr/mobile/bbs/board.php?bo_table=video&wr_id=35337
  → **데모: 정규화 자동 탐지 필터** — 공백·숫자 삽입(`토0토`)·자모 분리(`토ㅌㅗ`) 우회를 복원해 발송 차단 + 관리자 홀드 큐(신뢰도·원클릭 처리·자동/수동 카운터)
- **B-2 "블라인드"만으론 정보통신망법 44조의2 미충족** — 임시조치 30일 이내 + 작성자 통지 + 이의신청 + 약관 명시가 한 세트. 데이터 모델에 상태·조치개시일 필수.
  https://easylaw.go.kr/CSP/CnpClsMainBtr.laf?popMenu=ov&csmSeq=293&ccfNo=2&cciNo=1&cnpClsNo=1
  → **데모: 임시조치 관리** — D-30 카운트다운·만료 자동 이동 + 게시판 **시점 전환(팬/작성자/운영자)** 으로 통지·이의신청 절차 시연
- **B-3 스코어 데이터는 되고 중계 영상은 안 됨 + 크롤링 대체 불가** — 경기 자체는 비저작물이나 중계 영상은 저작물. 대법원 2021도1533: "반복적·체계적 복제로 상당 부분 복제와 같은 결과"면 침해 — 15초 주기 시즌 내내 크롤링이 정확히 해당.
  https://casenote.kr/대법원/2021도1533
  → 데모: 경기 상세 **데이터 출처 배지**(영상 블록 "권리 미확보 — 표시 불가" 잠금) + 관리자 크롤링 토글 시 판례 경고
- **B-4 만 14세 미만 — 소셜 로그인은 나이를 안 줌** — 개인정보 보호법 22조의2 법정대리인 동의. https://casenote.kr/법령/개인정보_보호법/제22조의2
  → 데모: 가입 연령 확인 → 미만 시 보호자 동의 분기 + 관리자 대기 목록
- **B-5 Apple 1.2 4요소 + 4.8** — ①게시 전 필터 ②신고+적시 대응 ③사용자 차단 ④공개 연락처 (원문 직접 확인). 공고에는 신고만 있음. 4.8: 소셜만 제공 불가(이메일 병행). https://developer.apple.com/app-store/review/guidelines/
  → 데모: 차단(즉시 숨김+차단 목록)·신고·필터·푸터 연락처 전부 구현, 체크리스트와 연동

### 【C】 운영 중 반드시 터짐
- **C-1 경기 종료 직후 5분 — 팬아웃·백프레셔** — 비용 = 메시지×접속자. 노드당 동시 연결 5천~3만, 백프레셔 실패로 16GB 노드가 스테일 데이터에 잡아먹힌 실제 보고. https://ably.com/topic/the-challenge-of-scaling-websockets · https://dev.to/speed_engineer/what-broke-when-we-pushed-websockets-from-100k-to-1m-users-2i24
  → **데모: 부하 시뮬레이션** — 동접 슬라이더×득점 버튼 → 팬아웃 카운트·노드 자동 증설·드롭 정책 ON/OFF에 따른 메모리 곡선(canvas)
- **C-2 Apple 24시간 조치 vs 운영자 1인** — 자동화 없이는 물리적으로 불가.
  → **데모: 관리자 홈 = 「오늘 처리할 것」 큐** — SLA 잔여 타이머·자동 N/수동 M 카운터·일괄 처리
- **C-3 선수 실명 비방 — 이미 고소 진행 중인 영역** — 선수협×김앤장 협약, 실제 수사 사례. 비이용자(제3자) 삭제 요청 창구가 공고에 없음. https://isplus.com/article/view/isp202606110118
  → **데모: 권리침해 신고 창구** (비로그인 폼) — 제출하면 관리자 큐에 「제3자 요청」으로 실제 적재(localStorage 연동)
- **C-4 스코어 지연 vs 채팅 실시간 = 스포일러** — API 15초 갱신 + 캐시 TTL vs 채팅 밀리초. "골!!!"이 스코어보드·TV보다 먼저 도착.
  → **데모: 중계 지연 보정** — 0/15/30/60초 선택 시 채팅 지연 재생 + "data N초 전" 상시 표시(실시간인 척하지 않기)
- **C-5 스팸 도배·재가입 우회** — 정지 계정이 새 계정으로 즉시 복귀(소셜 = 생성 비용 0). https://casenote.kr/법령/정보통신망_이용촉진_및_정보보호_등에_관한_법률/제50조
  → **데모: 동일인 의심 그룹** (기기 지문·IP 대역·행동 패턴 묶음 일괄 정지) + 신규 계정 점진 신뢰 정책 토글

### 【D】 있으면 좋음
- **D-1 국내 리그 커버리지를 계약 전에 못 박기** — KBO는 제공사별 상이(Sportradar Global Baseball 포함·스포츠투아이 공식 기록). → 시뮬레이터에서 미커버 리그 잠김 표시
