[프로젝트 개요]
- 스포츠 라이브 스코어 및 커뮤니티 통합 플랫폼 (Web & App) 구축

[프로젝트 배경 및 목표]
- 스포츠 팬들이 실시간 경기 스코어(생중계 데이터)를 확인하고, 유저 간 소통을 할 수 있는
  커뮤니티 플랫폼을 구축하고자 합니다. 기존 모바일 전용 앱들의 한계를 벗어나, 집에서
  PC(웹)로도 편하게 접속하고 외부에서는 모바일 앱(iOS/Android)으로 연동하여 사용할 수
  있는 통합 환경을 제공하는 것이 핵심 목표입니다.

[과업 범위]
1. 수행 범위
- 기획 및 디자인: PC 웹 및 모바일 앱 UI/UX 기획, 관리자 페이지 기획
- SW 개발: 프론트엔드(Web 및 App) 개발, 커뮤니티 기능 구현, 외부 스포츠 API 연동
  백엔드 구축, 관리자 백오피스 개발

2. 상세 기능 요구 사항

2-1. 프론트엔드 (PC Web & Mobile App)
- 회원가입 및 로그인: 이메일 및 소셜 로그인 연동
- 라이브 스코어 보드: 종목별, 날짜별 실시간 경기 목록 및 스코어 제공
- 경기 상세: 특정 경기 클릭 시 라인업, 타임라인 등 상세 정보 시각화
- 크로스 플랫폼: PC 브라우저와 모바일 앱(iOS/Android)에서 모두 최적화된 UI 제공

2-2. 커뮤니티 기능
- 경기별 응원방: 특정 경기 상세 페이지 내 실시간 응원 댓글 및 답글 기능
- 자유게시판: 유저 간 분석글 및 자유로운 의견을 나눌 수 있는 게시판 (추천/신고 기능 포함)
- 마이페이지: 내가 쓴 글/댓글 조회 및 관심 경기 즐겨찾기

2-3. 백엔드 및 데이터 파이프라인
- 외부 API 연동: 실시간 스포츠 데이터 API 연동 (Sportradar, API-Football 등)
- 데이터 캐싱: API 호출 과금 방지 및 응답 속도 최적화를 위한 Redis 인메모리 캐싱
  파이프라인 구축
- 동기화: PC 웹과 모바일 앱 간의 실시간 데이터 및 세션 동기화 처리

2-4. 통합 관리자 백오피스
- 대시보드: 유입자 수, 활성 유저 등 기본 통계
- 회원/게시글 관리: 유저 리스트 조회 및 악성 게시글/댓글 블라인드 처리
- 시스템 관리: 외부 API 연동 상태 모니터링

3. 비기능적 요구사항
3-1. 성능/규격: 실시간 트래픽이 몰리는 스포츠 경기의 특성을 고려하여 병목 현상이 없도록
     서버 아키텍처 설계
3-2. 개발 방식: 예산과 일정을 고려하여 iOS와 Android 앱을 동시에 구축할 수 있는
     크로스 플랫폼(Flutter, React Native 등) 활용 권장

[기술/제조 스택]
- Flutter, React Native, React.js, Node.js, Redis, MySQL

[클라이언트 준비 사항]
- 문서 및 자료: 벤치마킹할 타사 라이브 스코어 서비스 리스트 및 대략적인 요구사항
- 투입 인력 및 조직: 외부 스포츠 API(유료) 계약 및 프로젝트 의사결정을 담당할 내부 인력 1인 배정

[주요 일정]
- 희망 착수일: 계약 완료 후 1주일 이내
- 주요 마일스톤: 착수 후 2주 내 기획/디자인 완료, 4주 내 백엔드 및 외부 API 연동 완료,
  6주 내 프론트엔드(Web/App) 연동 완료, 8주 내 통합 테스트 및 스토어 등록
- 최종 오픈(납품) 희망일: 착수일로부터 2개월 이내

[지원 자격 및 우대 사항]
- 지원 자격: 크로스 플랫폼(Flutter 등) 기반 앱 개발 및 반응형 웹 구축 경험이 있는 개발사(팀)
- 우대 사항: 스포츠 라이브 스코어 데이터 API 연동 경험이 있거나, 실시간 채팅/커뮤니티
  구축 경험이 풍부한 파트너
