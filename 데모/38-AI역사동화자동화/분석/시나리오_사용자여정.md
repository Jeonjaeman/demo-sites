# YEODAM 여담 — 시나리오·사용자 여정

> ⚠ 모든 인물·데이터는 가상입니다.

---

## 1. 등장인물

| 인물 | 누구 | 원하는 것 | 불안한 것 |
|---|---|---|---|
| **아이 방문자** (8세) | 여주로 체험학습 온 아이 | 내 이름이 나오는 나만의 역사동화 | (직접 인식 못 함 — 보호자·기관이 대신 지킴) |
| **보호자/교사** | 아이와 동행 | 안전하고 **역사적으로 맞는** 콘텐츠 | "AI가 이상한 걸 만들면?", "이름 정보는?" |
| **여주시 담당자**(발주처) | 관광 플랫폼 사업 | PoC로 **품질·소요시간** 확인 후 본구축 발주 | "저작권은 누구 것?", "역사 왜곡 나면 책임", "삽화 비용 폭탄" |
| **운영자**(월 유지보수) | 콘텐츠·프롬프트 관리 | 프롬프트·팩트를 직접 손보기 | "모델 바뀌면 결과 달라지나" |
| **개발사(우리)** | PoC 납품 → 본구축 수주 | 완성도로 다음 계약 | 정부지원 산출물·아동·역사 리스크 |

**역할 겸임 주의**: 여주시 담당자는 **발주처**이자, 배포된 동화의 **역사 정확성·저작권 책임 주체**입니다.
그래서 "사실 검증"과 "저작권 이력"이 이 담당자를 위한 핵심 화면입니다.

## 2. 시간순 여정 — 아이 방문자(+보호자)

| 단계 | 상황 | 쓰는 화면 | 이 기능이 없으면 |
|---|---|---|---|
| 발견 | 키오스크/웹에서 시작 | 입력(이름·관광지) | 개인화 없이 밋밋 → 몰입 실패 |
| 판단 | 이름 입력 | 개인정보 안내 | 아동 정보 무단수집 = 법 위반 |
| 대기 | 생성 진행 | 파이프라인 계측 | 얼마나 걸릴지 몰라 이탈(삽화가 느림) |
| 검사 | 승인 전 | 사실검증·가드레일 게이트 | **틀린 역사·부적절 표현이 그대로 배포** |
| 실행 | 동화 감상 | 동화 뷰어 | 결과물이 안 보이면 가치 전달 실패 |
| 사후 | 소장 | PDF 다운로드 | 집에 못 가져감 → 재방문·확산 동력 상실 |

## 2-b. 여주시 담당자(발주처)의 여정

| 단계 | 상황 | 쓰는 화면 | 없으면 |
|---|---|---|---|
| 검증 | PoC 품질 판단 | 파이프라인 계측·비용 | 본구축 원가(삽화 병목)를 모른 채 발주 |
| 안심 | 역사 정확성 | 사실 검증기·팩트 DB | 환각 배포 → 시 신뢰·책임 문제 |
| 방어 | 저작권 | 생성이력·CSV | AI 산출물 저작권·귀속 근거 없음 |
| 운영 | 유지보수 | 프롬프트 콘솔·가드레일 | 개발사 없이는 문구 하나 못 바꿈 |

## 3. 역할별 시야 차이 (= 권한/화면 설계)

| 데이터 | 아이/보호자(사용자) | 담당자/운영자(관리자) |
|---|---|---|
| 동화 | 완성된 이야기·삽화·PDF | 프롬프트·생성 파라미터·검증 결과 |
| 역사 사실 | "안전 통과" 표시만 | 승인 팩트 DB·문장 검사기 |
| 비용/시간 | (숨김) | 단계별 계측·페이지수 시뮬 |
| 저작권 | (숨김) | 생성이력·인간 개입 기록·CSV |
| 이름(개인정보) | 로컬에서만 | 이력에 주인공명(브라우저 로컬) |

## 4. 기능별 존재 이유 (전수 매핑)

| 기능 | 왜 있나 |
|---|---|
| 이름·관광지 입력 | 공고 2-1/2-2 맞춤 생성. 개인화가 재방문 동력 |
| 개인정보 로컬·미저장 | 아동 개인정보보호(§22의2) |
| 파이프라인 단계 계측 | 공고 3-1. **삽화 병목**을 발주처에 실증(본구축 원가 판단) |
| 사실 검증 게이트 | 발견②(환각). 틀린 역사 배포 차단 = 발주처 신뢰 보호 |
| 아동 가드레일 | 공고 3-2. 부적절 표현 차단 |
| 저작권 생성이력 | 발견①. AI 산출물 저작권·정부지원 귀속 대응 |
| 캐릭터 일관성 | 발견④. 페이지마다 주인공이 바뀌는 기술 함정 해결 |
| PDF 오프라인 생성 | 공고 2-3. 한글 폰트 임베딩 문제 회피(캔버스→JPEG) |
| 프롬프트 테스트 환경 | 공고 2-4 + 운영자 자립(월 유지보수) |

## 5. 비는 구멍 (미팅에서 정의 필요)

1. **여주 원천 콘텐츠의 출처·검수** — 팩트 DB를 누가 채우고 누가 사실 확인하나(시/학예사).
2. **저작권 귀속** — 정부지원 산출물의 IP를 시·개발사 중 누가, 2차 이용(출판·판매) 범위는?
3. **삽화 원가 상한** — 페이지 수·해상도·재생성. 사전제작 vs 실시간, 캐싱 정책.
4. **모델 스냅샷·재현성** — 텍스트/이미지 모델 버전 고정, 교체 시 회귀 검증 기준.
5. **아동 연령·동의** — 만 14세 미만 법정대리인 동의 UX(키오스크/웹/현장).
6. **오프라인/현장** — 관광지 현장 네트워크, 인쇄본 제공 여부.
7. **다국어** — 외국인 관광객 대응(현재 국문).
