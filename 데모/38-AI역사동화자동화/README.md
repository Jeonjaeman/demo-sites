# YEODAM 여담 — 여주 AI 역사동화 자동 생성 · PDF 파이프라인 (PoC 데모)

여주 관광 체험 플랫폼 **본구축 전 PoC**. 아이 이름·방문 관광지를 넣으면 맞춤 역사동화와 삽화를 만들고
PDF 전자책으로 묶습니다. 단계별 소요시간·비용, 역사 사실 검증(환각 탐지), 아동 안전 가드레일,
저작권 대응 생성이력이 **실제로 동작**합니다.

> ⚠ 모든 텍스트·삽화·이력은 가상 예시입니다. 삽화는 사전 생성된 AI 에셋(Higgsfield)입니다.

**공개 URL(별칭)**
- 파이프라인 — `/yeodam/`
- 프롬프트·검토 콘솔 — `/yeodam/admin/`

| 관리자 콘솔 | `admin.html` | 프롬프트 테스트 · 팩트 DB/사실검증 · 비용 시뮬 · 가드레일 · 생성이력 |

## 체험 시나리오

1. **동화 만들기** — 아이 이름 입력(기본 "하늘") → 여주 관광지 선택(영릉·신륵사·도자기·명성황후 생가) →
   "역사동화 자동 생성".
2. **파이프라인 계측** — 6단계가 순차 실행되며 각 소요시간·비용이 찍힙니다. **삽화 생성이 병목**임이 강조됩니다.
3. **안전 게이트** — 역사 사실 검증 + 아동 가드레일 결과. 통과해야 다음.
4. **동화 뷰어** — 표지+페이지(삽화+텍스트), 페이지 넘김.
5. **PDF 발행** — 실제 PDF 다운로드(외부 라이브러리 없이 생성).
6. ★ **환각 주입(데모) 토글**을 켜고 다시 생성하면, 일부러 섞인 틀린 역사("세종대왕이 명성황후에게…", 허위 연도)를
   **사실 검증이 잡아내고 PDF 발행이 차단**됩니다.
7. **관리자**(`admin.html`) — 프롬프트를 바꿔 테스트, 문장 검사기로 사실 검증 직접 실행, 페이지 수 슬라이더로
   삽화 병목 확인, 가드레일 단어 편집, 생성이력(저작권) CSV, 캐릭터 일관성 에셋 확인.

## ⚠️ 착수 전 확인 (미팅 안건)

1. 여주 원천 콘텐츠 출처·정확성 검수 주체 (팩트 DB)
2. 정부지원 산출물 **저작권 귀속**·2차 이용 범위
3. 아동 개인정보(법정대리인 동의) 절차
4. 삽화 **원가 상한**(페이지·해상도·재생성·캐싱)
5. 텍스트/이미지 모델 **스냅샷·재현성**

## 디자인 실측 명세

- **도메인**: 리디(전자책·pill·#141414) × 핑크퐁(아동·#191f28·h1 −0.022em) × 뤼튼(AI제품·다크 pill)
  → 흰 배경·near-black 잉크·Pretendard·pill CTA
- **디자인(어워드)**: Partizan(Awwwards SOTD 2026.07.26) — 헤드라인 자간 −0.012em·이징 expo-out
  `cubic-bezier(.23,1,.32,1)` + 놀이감 back-out `cubic-bezier(.175,.885,.32,1.275)`
- **적용**: 아동 동화라 따뜻한 크림 종이 팔레트 + 절제된 전환. 페이지 넘김·버튼 팝에 back-out 이징.
  삽화는 힉스필드로 캐릭터 레퍼런스를 고정해 6종 생성. `prefers-reduced-motion` 존중.

## 기술 구성

- 순수 HTML/CSS/JS(외부 런타임·라이브러리 의존 없음), Pretendard(CDN).
- `assets/js/core.js` — 여주 팩트 DB · 동화 생성(그라운딩) · **사실 검증(환각 탐지)** · 가드레일 ·
  단계별 계측 모델 · 생성이력 · **오프라인 PDF 생성기(캔버스→JPEG 임베드)**.
- `assets/js/pipeline.js` — 파이프라인 실행 · 게이트 · 동화 뷰어 · PDF.
- `assets/js/admin.js` — 프롬프트 테스트 · 팩트/검증기 · 비용 시뮬 · 가드레일 · 생성이력.
- **PDF는 브라우저에서 실제 생성**: 각 페이지를 캔버스로 렌더(한글 안전) → JPEG → 최소 PDF(1.4)에 임베드.
