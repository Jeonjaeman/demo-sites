## 공고 요구 → 데모 매핑 (전부 동작)
- **풀스크린 배경 영상 자동재생**: AI 생성 이미지 기반 image-to-video로 만든 실제 mp4(3.1MB) + 영상 실패 시 포스터 켄번즈 폴백
- **스크롤 페이드인/아웃**: 히어로 텍스트가 스크롤 위치에 따라 실제로 사라지고, 섹션은 리빌로 등장
- **마우스 오버 확대+색상 반전**: 그리드 호버 = 흑백→컬러+확대(기본) / models 페이지의 **「색상 반전 모드」 토글**을 켜면 공고 문구 그대로 invert
- **동적 전환 라우팅**: 내비 클릭 → 레드 커튼 와이프 → 페이지 간 실제 이동
- **썸네일 그리드 + 모달**: 모델 북 모달(신체 스펙) — 폴라 영상 버튼을 누르면 **실제 필름 재생**
- **Campaign Films 파트**: image-to-video로 제작한 **실제 영상 3편** — 카드 호버 시 미리 재생, 클릭 시 풀사이즈 비디오 모달
- **새로고침 없는 필터**: 모델 4탭·뉴스 5탭 — 비동기 재정렬 + stagger 재진입
- **CMS**: 에디터 등록(등록 즉시 사이트 반영) · 노출 토글 · 배경 영상 교체(**150MB 파일을 끌어놓으면 실제로 차단·알림**) · 수정·삭제 — localStorage로 공개 사이트와 실연동

## 체험 시나리오 (클릭만)
1. 메인 — 영상 히어로에서 스크롤 → 텍스트 페이드아웃 → 캠페인 패럴랙스
2. MODELS 클릭 → 커튼 전환 → 서브 페이지 → WOMEN 필터 → 카드 클릭 → 모달
3. models 페이지 우측 「색상 반전」 토글 → 호버 효과가 invert로 변경
4. CMS → 새 기사 작성(프리필) → 등록 → 사이트 News 맨 위 확인
5. CMS → 메인 배경 영상 → 아무 대용량 영상을 끌어놓기 → 용량 차단 알림
