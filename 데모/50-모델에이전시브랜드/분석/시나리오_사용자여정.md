# ELAN 엘랑 — 시나리오·사용자 여정

> 모든 인물·데이터는 가상입니다.

## 1. 등장인물
| 인물 | 원하는 것 | 불안한 것 |
|---|---|---|
| 브랜드·광고주 (방문자) | 모델 풀을 빠르게 훑고 무드 확인 → 컨택 | 로딩 느린 영상 · 촌스러운 화면 |
| 캐스팅 디렉터 | 카테고리로 좁혀 스펙·폴라 확인 | 필터마다 새로고침되는 느린 탐색 |
| 내부 관리자 (비개발자) | 기사·영상을 직접 올리고 내리기 | 개발사에 매번 요청하는 비용·시간 |
| 에이전시 대표 (발주자) | 트렌디한 첫인상 + 관리 자립 | 오픈 후 유지보수 종속 |

## 2. 방문자 여정
| 단계 | 화면 | 이 기능이 없으면 |
|---|---|---|
| 첫인상 | 메인 영상 히어로 | 정지 이미지 = "트렌디하고 시각적인" 목표 미달 |
| 탐색 | 스크롤 페이드·캠페인 패럴랙스 | 밋밋한 스크롤 — 광고 산업 톤 미달 |
| 모델 찾기 | models 서브 — 필터·호버 | 새로고침 필터 = 탐색 끊김 |
| 상세 확인 | 모달 (스펙·영상) | 페이지 왕복 피로 |
| 소식 확인 | news 서브 — 카테고리 탭 | 에이전시 활동 증명 없음 |
| 컨택 | 푸터 CTA | — |

## 3. 관리자 여정 (CMS)
| 단계 | 화면 | 데모 동작 |
|---|---|---|
| 기사 작성 | 에디터 | 등록 → 사이트 News 맨 위 즉시 노출 |
| 노출 제어 | 목록 토글 | 끄면 사이트에서 즉시 사라짐 |
| 영상 교체 | 업로드 | 용량 초과 시 차단+이유 안내, 통과 시 적용 |
| 정리 | 수정·삭제 | 목록에서 바로 |

## 4. 비는 구멍 (착수 미팅 확인)
1. **10페이지의 정확한 목록** — 화면설계서 기준 페이지 맵 확정 (데모는 4페이지 구조 증명)
2. **기존 사진·영상 권리** — 리뉴얼 재사용 범위(작가·모델 계약), 신규 촬영분 인수 방식
3. **색상 반전 연출의 확정** — 흑백→컬러 vs invert (데모에 둘 다 구현, 시안 기준 확정)
4. **CMS 계정 체계** — 관리자 수·권한 분리 필요 여부 (공고는 회원가입 배제 = 방문자 기준)
5. **영상 용량 정책** — 제한값(데모 100MB)·트랜스코딩 프리셋·CDN 여부
6. **기존 도메인·호스팅 이관** — 무중단 전환 순서
7. **다국어 여부** — 해외 클라이언트 대응 영문 페이지 필요 여부
