# ELAN 엘랑 — 기획·설계

> 모델 에이전시 인터랙티브 웹사이트 프론트엔드 및 CMS 구축 (위시켓, 800만·60일·지원 53) · 제안용 데모
> 에이전시·모델·기사 전부 가상 · 인물 이미지는 AI 생성(실존 인물 아님)

## 0. 공고 요약
- 매니지먼트 에이전시 **기존 웹사이트 리뉴얼** — 기획·디자인은 클라이언트 제공, 개발사는 **인터랙티브 프론트 퍼블리싱 + CMS 백엔드**
- 프론트 약 10페이지 · 회원가입 배제 · 서버/DB/인프라 포함
- 2-1 메인: **풀스크린 배경 영상 자동재생** · 스크롤 페이드인/아웃 · **호버 확대+색상 반전** · 동적 전환 라우팅
- 2-2 서브: 포트폴리오 썸네일 그리드 · 클릭 모달(이미지·영상) · **새로고침 없는 카테고리 필터** · 미디어 인더스트리 폰트·자간 최적화
- 2-3 CMS: 에디터 등록 · **노출 토글** · **배경 영상 교체(용량 제한 알림)** · 전체 수정·삭제
- 스택 자유 제안 · 참고: bnbindustry.com/news (영상·움직임) · 산출물: 소스+관리자 매뉴얼+인프라 구성도
- 사전 질문: 포트폴리오 / 워드프레스 아니어도 되는지 / sanity 같은 CMS 문제없는지

## 1. 명시 vs 숨은 니즈
| 구분 | 내용 |
|---|---|
| 명시 | 인터랙티브 프론트 + 쉬운 CMS + 인프라 |
| 숨은 ① | "개발 지식 없이" = CMS의 성패 기준은 기능이 아니라 **관리자 화면의 단순함** — 데모로 미리 보여주는 게 최고의 검증 |
| 숨은 ② | 배경 영상은 **용량 관리가 운영 리스크** — 원본 그대로 올리면 로딩 파탄. 업로드 시 제한+트랜스코딩 설계 필요 |
| 숨은 ③ | 모델 화보의 **인물 권리** — 리뉴얼 시 기존 사진 재사용 범위(작가·모델 계약) 확인 필요 |
| 숨은 ④ | 영상 자동재생은 모바일 데이터·접근성 이슈 — `prefers-reduced-motion`·포스터 폴백 설계 |

## 2. 리서치·레퍼런스 실측
| 축 | 내용 |
|---|---|
| 참고 사이트 실측 | **bnbindustry.com** — 다크 #111 · Albert Sans · 24px/700 대문자 카테고리 탭(ALL/ARTIST/BUSINESS/OPERATIONS) → 뉴스 필터 문법 이식 |
| 도메인 관행 | 모델 에이전시 사이트 — 풀블리드 화보 · 흑백→컬러 호버 · 모델 북 모달(신체 스펙·폴라·워킹 영상) |
| 디자인 | im-fine(경량 190~200 대형 타이포·기존 실측) · Linear 이징 cubic-bezier(.22,.61,.36,1) |
| 에셋 | 가상 모델 6인+캠페인 2컷 AI 생성 · **히어로 영상은 생성 이미지 기반 image-to-video로 실제 mp4 제작**(3.1MB) — 레드팀 검수로 인쇄물 프레임·로고 전량 크롭 제거 |

## 3. 화면 구성 — 요구사항 전부 동작
| 요구 | 데모 구현 |
|---|---|
| 풀스크린 배경 영상 자동재생 | hero.mp4 autoplay·muted·loop + 포스터 폴백(영상 실패 시 켄번즈) |
| 스크롤 페이드인/아웃 | 히어로 텍스트가 스크롤에 따라 실제로 사라짐 + 섹션 리빌 |
| 호버 확대+색상 반전 | 그리드 흑백→컬러 + scale(1.07) (색상 반전 방식은 시안 확정 시 invert로 교체 가능) |
| 동적 전환 라우팅 | 내비 클릭 시 레드 커튼 와이프 후 이동 |
| 썸네일 그리드+모달 | 모델 북 모달(스펙·영상 버튼) |
| 새로고침 없는 필터 | ALL/WOMEN/MEN/CAMPAIGN — 비동기 재정렬 + stagger 재진입 |
| CMS 에디터·토글·영상 교체·수정·삭제 | admin.html 전부 동작 — **localStorage로 공개 사이트 News와 실연동**, 영상 150MB 드롭 시 실제로 차단·알림 |

## 6. 레드팀 ①~③ 검수
- **① 디자인**: 생성 이미지 8장 전수 검수 → 인쇄물 프레임·미러 텍스트·이젤 검출 → 전량 정밀 크롭. 모노크롬+레드 단일 액센트, 대문자 타이포 위계
- **② 인터랙션**: 요구 모션 전부 구현 + 추가 — 내비 밑줄 슬라이드, mix-blend difference 내비, 캠페인 패럴랙스, 카운트업, 필터 stagger 재진입, 커튼 와이프
- **③ 실측 QA**: 애니메이션 정지 후 전 요소 rect 검사 — 오버플로 0 · 모바일 375 오버플로 0·그리드 1열 전환 · CMS 흐름(토글→등록→150MB 차단→42MB 통과) 자동 시나리오 통과
