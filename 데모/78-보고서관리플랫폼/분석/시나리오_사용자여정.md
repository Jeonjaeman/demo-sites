# 시나리오 · 사용자 여정 — ATTEST 어테스트 (데모 78)

> 공고: 보고서 QR 연동 관리 플랫폼 신규 구축 (위시켓 · 1,000만~1,500만 · 60일 · 지원 111명)
> 원문 리서치: [리서치_상세.md](리서치_상세.md) · 실측: [레퍼런스_실측.md](레퍼런스_실측.md) · 화면: [페이지_기획.md](페이지_기획.md)

## 1. 등장인물 — 공고는 3화면이라 썼지만 실제 인물은 7명

| 인물 | 원하는 것 | 불안한 것 | 데모 표면 |
|---|---|---|---|
| 임상기관 담당자(PM 겸임, 1명) | 보고서 올리고 QR 뽑고 끝. "지난번 보고서 다시 보내주세요" 메일 소멸 | 오등록·개발업체 연락 두절·본인 부재 시 정지 | 관리자 |
| 고객사 마케터 | 인쇄 가능한 벡터 QR을 지금 | 인쇄 후 안 찍힘 · 문구가 식약처에 걸림 | 고객사(MKT) |
| 고객사 품질·RA 담당 | 식약처 요청 시 **15일 안에** 원본·기관 요건 증빙 | 원본 못 찾음 · 요건 증빙 없음 | 고객사(RA) |
| 소비자 | 3초 안에 "진짜 시험했구나" | 큐싱 · 폰에서 30MB PDF | 공개 조회 |
| 인쇄·패키지 업체 | 벡터 + 최소 크기·여백 스펙 | PNG 확대 → 수만 개 재인쇄 | 고객사 인쇄 패키지 |
| 다음 개발업체 | README·ERD·runbook·발주사 명의 계정 | 파악 비용 = 재개발 비용 | 관리자 인수인계 |
| 식약처 조사관·해외 바이어 | 실증 여부 · 영문 확인 | — | 공개(EN)·실증 패키지 |

겸임: 담당자 = 최고관리자 = 발주사 PM(SPOF) → 관리자 2인 정책 배너. 마케터와 RA는 같은 고객사의 다른 사람 → 역할 3종.

## 2. 시간순 여정 → 구현

| # | 단계 | 없으면 벌어지는 일 | 데모 구현 |
|---|---|---|---|
| 1 | 보고서 등록 | 드라이브 폴더에 던짐 → 최종본 불명 | 등록 폼 + 실증 요건 게이트 + 버전 v1·해시 |
| 2 | 공개 범위 결정 | 미정의 → 원문 그대로 공개 | 공개 항목 화이트리스트(체크 해제 즉시 공개 화면에서 소거) + 고정 비공개 3종 |
| 3 | 개인정보 점검 | 피험자 사진·연령 노출 | 4항목 점검 모달 — 미완 시 발급 잠김 |
| 4 | 고객사 공개 동의 | 기밀 위반 | 동의 전 발급 불가 · 동의자·시각·범위 기록 |
| 5 | QR 발급 | 어떤 QR이 어느 보고서인지 추적 불가 | 불변 토큰 · 보고서 1:N · 발급 이력 · 감사로그 |
| 6 | 고객사 조회·다운로드 | PNG 한 장 → 인쇄 실패 | 인쇄 패키지 ZIP(SVG·PNG·사양서·승인 문구) + 크기 시뮬레이터 |
| 7 | 인쇄 수만 개 | 스펙 없이 넘김 | 사양서 자동 생성(최소 크기·quiet zone·EC) |
| 8 | 소비자 스캔 | 위조 구별 불가 · 원문 노출 | 발급기관 배지 · 적용 제품 · 요약만 · 진위확인 · 해시 · 신고 |
| 9 | 보고서 개정 | 인쇄된 QR이 옛 자료 | 「v2 게시」 → 같은 QR이 최신본 · 개정 배지 · 고객사 통지 |
| 10 | 실증 요구 | 15일 내 못 맞춤 → 중지명령 | D-15 카운트다운 + 실증자료 ZIP 원클릭 |
| 11 | 계약 종료·미납·오발급 | QR 404 → 브랜드 사고 | 상태 4종 각각 다른 안내 랜딩, 404 없음 |
| 12 | 업체 교체 | 계정·키 위치 모름 → 재구축 | 인수인계 현황(발주사 명의 배지) + 패키지 ZIP + 30분 테스트 |

## 5. 비는 구멍 — 미팅 확인 (요약 10)

1. 보고서 개정 빈도(연 몇 건) → 버전 정책 강도
2. 소비자 공개 범위 — 요약만(기본 제안) / 그래프 / 원문
3. 계약 종료 후 QR 안내 유지 기간 — 종료 후 3년 제안(유통기한+α)
4. 고객사 담당자 수·역할 구성
5. 시험번호 체계(연도 순환·중복) → 내부 ID 분리
6. 보고서 PDF에 피험자 사진·개인정보 실제 포함 여부 → 공개본 분리
7. 구독 과금 단위(고객사/보고서/QR/스캔) → 스키마 반영
8. 참고 자료 1(미팅 파트너 공개분)
9. 기존 드라이브 QR이 인쇄돼 유통 중인 제품 유무 → 레거시 인수 경로
10. 발주사 명의 계정 개설 주체·도메인 문자열

## 6. 검증에서 발견해 고친 버그

1. **QR 인코더 정렬 패턴 누락** — 타이밍 패턴이 먼저 그려져 (6,x) 정렬 패턴을 건너뛰고 그 자리에 데이터가 덮임. v1~6은 오류보정이 복구해 통과했지만 v8·9 디코드 실패로 발견 → 파인더 모서리 3곳만 제외하도록 수정, jsQR 디코드 8/8 통과
2. **공개 화면 미등록 상태에서 렌더 중단** — 진위확인 블록이 없는 화면에서 이벤트 바인딩 null 참조 → 가드 + 미등록 화면에도 진위확인 블록 추가
3. **차트 캔버스 backing 86px** — 숨겨진 팬(뷰포트 0) 상태에서 측정 → ResizeObserver로 크기 확정 시 재그림
4. 국문 라벨이 모노 폰트 폴백 자간으로 벌어짐 → 라벨류 sans 전환, 토큰·해시·번호만 모노
5. 공개 화면 터치 타겟 12개 44px 미만(언어 30·해시 32·데모 독 32) → 44px로 상향
