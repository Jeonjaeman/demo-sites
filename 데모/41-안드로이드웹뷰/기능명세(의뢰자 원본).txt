업무 내용

[프로젝트 개요]
이미 구축·운영 중인 모바일웹을 감싸는 Android 하이브리드(WebView) 앱을 제작하고 Google Play에
배포합니다. 앱은 모바일웹을 화면으로 띄우되, 파일 업로드/다운로드·로그인 유지·뒤로가기 등 앱에서
필요한 동작과 FCM 기반 푸시 알림을 포함합니다. 푸시는 신규 Firebase 프로젝트를 생성해 앱에
연동하고, 서버 측은 기존 PHP 소스를 FCM HTTP v1 방식으로 수정해 발송합니다.

[프로젝트 배경 및 목표]
모바일웹은 이미 완성되어 운영 중이며, 이를 별도 앱으로 개발할 필요 없이 하이브리드(WebView)
방식으로 감싸 Google Play에 배포하려 합니다. 앱 배포로 접근성을 높이고, 웹만으로는 어려운 푸시
알림을 통해 재방문·재참여를 확보하는 것이 목표입니다.

[과업 범위]

3-1. 수행 범위 (요약)
- Android Studio 프로젝트 생성(API 36 기준) 및 WebView 앱 구현
- 파일 업로드/다운로드, 로그인 유지, 뒤로가기 등 네이티브 동작 처리
- 신규 Firebase 프로젝트 생성 및 FCM 푸시 알림 연동(앱 측)
- 기존 PHP 소스 수정 — FCM HTTP v1 방식 푸시 발송 구현
- 앱 서명 및 Google Play 등록·배포

3-2. 상세 기능 요구사항
① 앱 기본 (WebView)
- Android Studio 프로젝트 생성 — compileSdk/targetSdk API 36 기준
- 모바일웹 로딩 및 WebView 설정 — 자바스크립트, DOM 스토리지 등 웹 정상 동작에 필요한 설정
- 파일 업로드/다운로드 처리 — 웹 화면의 파일 첨부(파일 선택) 및 내려받기 동작을 앱에서 지원
- 로그인 유지 — 앱을 종료 후 다시 실행해도 로그인 상태 유지(세션·쿠키 저장)
- 뒤로가기 처리 — 기기 뒤로가기 버튼으로 웹 이전 화면 이동
- 네트워크 오류·로딩 상태 안내 처리
- Android 런타임 권한 처리 — 파일·알림 권한 등(Android 13+ 알림 권한 포함)

② 푸시 알림 (FCM)
- 신규 Firebase 프로젝트 생성 및 앱 연동
- FCM SDK 연동 — 디바이스 토큰 수신, 알림 수신·표시, 알림 탭 시 해당 화면으로 이동
- 기존 PHP 소스 수정 — FCM HTTP v1 방식으로 푸시 발송 구현(서비스 계정 기반 인증 포함)

③ 배포
- 앱 서명(키스토어) 및 릴리스 빌드
- Google Play Console 등록 및 배포
