# MIYABI Seoul — 일본인 대상 K-뷰티 예약 컨시어지 (데모)

방한 일본인 관광객이 클리닉·에스테틱·퍼스널컬러·헤어·메이크업을 일본어로 예약하는
프리미엄 컨시어지 플랫폼 데모. **모든 데이터·시설·요금·인물은 가상입니다.**

- 공개 사이트: https://jeonjaeman.github.io/demo-sites/miyabi/
- 관리자: https://jeonjaeman.github.io/demo-sites/miyabi/admin/

## 체험 시나리오 (입력 없이 클릭만으로)

1. 홈 → 「選ばれているプログラム」 캐러셀에서 아무 카드 → 상세
2. 위저드에서 날짜·시간 클릭 → 다음 (이름·메일 **프리필**) → 다음 → 동의 체크 → 결제 → 예약번호 발급
3. 클리닉 프로그램(医療 배지)을 열면 **결제 단계가 사라지고 무료 상담 신청**으로 바뀜 — 외국인환자 유치업 등록 구조의 기능화
4. 마이페이지 → 「デモアカウントで入る」 원클릭 로그인 → 예약 목록 → キャンセル: D−일수별 수수료·환불액 실계산
5. 이력 탭 → 리뷰 쓰기: 비의료는 본문 입력, 의료는 평점만(의료법 §56 대응)
6. 푸터 ADMIN → 관리자: 필터·상태 변경·프로그램 노출 토글·가격 수정(1만원 미만 거부)·CSV 다운로드
7. 우상단 JA/KO 스위처 — 전 화면 즉시 전환

## 핵심 발견 3건 (리서치 근거는 분석/기획_설계.md)

1. **병원 예약 중개 = 외국인환자 유치업 등록 대상** — 미등록 알선은 형사처벌 소지. 데모는 의료를 "상담 예약"으로 분리, 시술 계약·수납은 제휴 의료기관 직접.
2. **의료 리뷰 = 치료경험담 광고 금지 (의료법 §56)** — 의료는 시설 평점만, 비의료만 본문 게재. 작성 모달도 분기.
3. **해외카드 PG 수수료 ≈ 4.5% (JCB 필수)** — 가격·환불 정책의 전제. 정산 화면에 반영.
