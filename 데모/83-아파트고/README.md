# APTGO 아파트고 — 아파트 평면도 서비스 UI/UX 리뉴얼 시안 (HTML 데모)

위시켓 공고 「아파트고 웹 서비스 UI/UX 리뉴얼 디자인 (퍼블리싱 제외)」 제안용 데모입니다.
공고의 결과물인 Figma 원본에 더해, 이 제안은 **같은 금액에 같은 토큰으로 만든 기초 퍼블리싱 HTML/CSS/상태 JS**를 추가 납품합니다. 이 데모가 그 HTML 납품물의 축소판입니다.

- 공개: https://jeonjaeman.github.io/demo-sites/aptgo/ · 관리자: https://jeonjaeman.github.io/demo-sites/aptgo/admin/
- 로컬: `python -m http.server 8038 --directory 데모/83-아파트고` → http://localhost:8038/
- 모든 단지·도면·회원·주문 데이터는 가상이며 결제는 일어나지 않습니다. 상태는 브라우저 localStorage(`aptgo.v1`)에만 저장됩니다.

## 체험 시나리오 (입력 없이 클릭만으로)
1. 홈 → 「예시로 보기」 → 단지 상세 → 「모든 타입 JPG로 담기」 → 장바구니(묶음 할인) → 주문서(동의 체크 → 결제) → 완료 → 「지금 열기」 확인 모달 → 뷰어
2. 뷰어 우상단 「구현 방식」을 벡터로 → 손 아이콘 → 방 클릭(면적 합산) · 자 아이콘 → 두 점 클릭(mm) · 다운로드 → 실제 파일
3. 마이페이지 → 주문 상세 → 환불 신청(열람한 도면은 비활성) → 관리자(검토 패널 역할 「운영 책임자」) → 주문·환불 → 같은 주문의 증명 자료
4. 검토 패널 「극단값 켬」 → 검색·단지 상세에서 26자 단지명·18타입 처리 확인 / 역할 「비회원」「회원」「CS 담당」으로 권한 없음 3종 확인
5. 디자인 가이드 → Foundations 대비 검사기 · Components 8상태 + 스펙 보기 · States 셀 클릭 · 제안 범위 계산기
