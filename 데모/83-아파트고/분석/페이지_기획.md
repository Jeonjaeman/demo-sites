# 아파트고 리뉴얼 데모 — 페이지 기획 (구축 전 확정)

- 작성 2026-10-17 · 근거: `_agent_리서치.md`(발견 F1~F18 · 화면 인벤토리 23/11/6+4)
- 성격: **플랫폼(기능형) + 관리자(대시보드형)** 혼합. 공개 메인은 허브이되 브랜드 단락은 최소(②풀블리드 1·⑤텍스트 리빌 1)만. 나머지 표면은 그 화면이 실제로 하는 일(검색·미리보기·결제·열람·환불·검수)을 정확히 구현한다.
- 원칙: 메뉴·화면마다 **독립 HTML**(딥링크). 관리자는 `admin.html` 안에서 해시 라우팅(11화면). 공통 헤더·푸터·토큰·데이터는 분리 파일 공유, 내비 `aria-current`.
- 납품 전략: 공고는 Figma 요구이나 **같은 금액에 기초 퍼블리싱(HTML/CSS/상태 JS/반응형)까지** 납품. 데모 = 그 납품물의 축소판. 가이드 페이지의 토큰·상태 값은 전부 실제 CSS 값.

## 2. 페이지별 기획 (목적 · 방문자가 할 일 · 섹션 · 다음 유도)

### index.html — 메인 홈 (C-01)
- 목적: 3초 안에 "단지 검색 → 미리보기 → 구매"가 보이게. 허브.
- 할 일: 검색창에 단지명 입력(프리필 「헬리오」 + 자동완성) 또는 「예시로 보기」 원클릭.
- 섹션: ① 히어로(검색 + 자동완성 + 지역 칩) ② 이용 3단계(검색→미리보기→구매·열람) ③ 최근 등록 도면 카드 ④ 풀블리드 이미지 단락(도면 질감, 텍스트 리빌 — "무료 평면도와 무엇이 다른가" F15) ⑤ 포맷 안내(JPG/PDF/DWG 비교) ⑥ 출처·정확도 정책 요약(F6·F17) ⑦ 사업자 고객 섹션(세금계산서·묶음) ⑧ 푸터(사업자 정보·개인정보처리방침 강조 F8)
- 유도: 검색 결과 / 단지 상세 / 제안 페이지(검토자용 배너 1줄)

### login.html / signup.html / recover.html (C-02~C-06)
- 로그인: 이메일·비밀번호 프리필, 오류 상태(불일치·5회 잠금) 버튼으로 재현, `?next=` 복귀.
- 가입: ①유형(개인/사업자 카드) + **수집 항목 고지 카드**(체크박스 아님 F8) + [선택] 마케팅 미체크 → ②정보(이메일 인증·비밀번호 규칙 실시간·사업자 선택 시 추가 필드) → ③완료(사업자 인증 대기). 단계 수 3 = 탈퇴 2단계보다 길지 않게 표기(F3).
- 복구: 링크 발송·만료 상태.

### search.html (C-07·C-08)
- 목적: 동명이 단지를 틀리지 않고 고른다.
- 할 일: 필터(지역·세대수·준공·면적대·보유 포맷)·정렬 → 결과 카드(주소·준공·세대수 구분줄) → 지도 분할 토글.
- 상태: 0건(유사어 제안 + 도면 등록 요청), 스켈레톤, 지도 영역 내 0건. 현재 위치 버튼 없음(F11, 캡션으로 이유 표기).
- 유도: complex.html

### complex.html (C-09)
- 섹션: 개요 헤더(25자 대응 2줄 말줄임) · 타입 탭(넘침 시 가로 스크롤 + 전체 드롭다운) · 배치도 · 타입별 도면 카드(가격 VAT 포함·구매함 배지) · 출처·기준일 캡션 · (옵션) 실거래 블록 해제 배지(F16)
- 유도: plan.html · cart 담기

### plan.html (C-10·C-11)
- 목적: 무료와의 차이를 증명하고 법적 시험사용(미리보기)을 제공한다.
- 섹션: 미리보기(워터마크·저해상·치수 마스킹 — 모달 확대) · 면적표(전용/공급/계약 ㎡, 평은 토글 F10) · 포맷 옵션 카드(JPG/PDF/DWG 총액) · 무료 vs 구매 비교표 · 도면 메타 배지 + 정확도 고지(F17) · 이용 범위 카드(F6) · 장바구니/바로 구매
- 상태: 구매함(→ 뷰어 열기) · 비공개

### viewer.html / compare.html (C-12·C-13·C-14)
- 뷰어: canvas 기반 줌(+ − 맞춤 100% 25~400%)·회전·**방향 버튼**·키보드·전체화면·타입 레일·면적 레이어·**다이내믹 워터마크(구매자 ID·주문번호·시각)**·다운로드(포맷·남은 기한)·정확도 고지. 구현 방식 토글에 따라 「방 하이라이트·치수 측정」 활성/비활성. 미구매 시 「권한 없음 ②」(미리보기 + 구매). 모바일: 하단 툴바·시트 패널.
- 비교: 두 타입 나란히, 줌 동기화 토글, 면적 차이 요약. 한쪽 미구매면 미리보기.

### cart.html / checkout.html / pending / complete / failed (C-15~C-19)
- 장바구니: 단지별 그룹·포맷 변경·**이미 구매한 도면 경고**·묶음 할인·VAT 포함 총액·빈 상태.
- 주문서: 증빙 선택(카드전표/현금영수증/세금계산서 자동채움) · 결제수단 · **청약철회 제한 고지 + 확인 체크(미체크 시 결제 버튼 비활성)** · 최종 확인(정정) · 버튼 라벨에 최종 금액. 동의 시각 기록(F2·F3).
- 대기: 가상계좌 발급(복사)·기한·열람 불가 안내 / 완료: 주문번호·**첫 열람 확인 모달**(열면 환불 불가 → 열람 시각 기록) / 실패: 사유·재시도·장바구니 보존.

### my.html / orders.html / order.html / refund.html / account.html (C-20~C-23)
- 도면함: 단지별 라이브러리·재다운로드(남은 기한·횟수)·열람 배지. 주문 상세: 도면별 `미열람·환불 가능`/`열람함·환불 불가`. 환불: **미열람만 선택 가능, 예정액 실시간 계산**. 회원정보: 개인↔사업자 증빙 기본값·마케팅 변경·**탈퇴 2단계**(가입 3단계보다 짧음 표기).

### states.html (S-01~S-06)
- 행=화면(검색·상세·뷰어·장바구니·주문서·도면함·관리자 목록), 열=상태(기본·로딩·빈·에러·권한 없음). 셀 클릭 시 그 화면의 미니 프레임이 실제 상태로 전환. 로딩은 대기 시간에 따라 스켈레톤/스피너/진행률. 404·500·점검·결제/다운로드 예외 세트.

### guide / components / patterns / handoff (G-01~G-04)
- guide: 색 토큰(실측 출처 표기)·대비 검사기(실제 계산 4.5:1/3:1)·타이포 스케일·spacing·radius·elevation·모션(ms·easing 데모 버튼)·브레이크포인트·z-index.
- components: 8상태 토글 플레이그라운드 + 「스펙 보기」 오버레이(px·토큰명).
- patterns: 흐름도 3종(검색→구매→열람 / 환불 / 등록→검수→공개)·법적 UI 규칙(총액·사전선택·버튼 위계 Do/Don't·탈퇴 단계 수)·반응형 변환 규칙 표·콘텐츠 규칙(최대 길이·숫자 포맷).
- handoff: Figma 플랜 진단(Starter/Professional → 파일 구조 변경)·토큰 1:1 대응표(Figma 변수 ↔ CSS ↔ 코드)·네이밍·에셋·변경 이력 표.

### proposal.html — 제안 (검토자·발주자용)
- 범위 계산기(F1): 화면 ID 체크 + 반응형 토글 → 프레임 수·공수 재계산. 6주 승인 게이트(F18) 체크리스트. 뷰어 기능×구현 방식 매트릭스(F7). **납품 범위 선**: 포함(HTML/CSS/상태 JS/반응형/가이드) vs 개발사 몫(백엔드·데이터 바인딩·기존 코드 이식). 미팅 확인 20항목.

### admin.html (A-01~A-11, 데스크톱 1280+)
- 대시보드 KPI·기간 차트(canvas)·할 일 큐 / 회원 목록·상세(마스킹 해제 사유·반복 다운로드 플래그·CS 권한 제한) / 단지 목록·등록 폼(㎡ 입력 평 환산·중복 경고) / 도면 목록·등록 폼(업로드 진행률·타입 매핑·**출처 필수, 미입력 시 공개 비활성**·메타)·검수 상세(원본 vs 미리보기·체크리스트·반려) / 주문 목록·상세(**동의 시각·IP·도면별 첫 열람·다운로드 횟수·환불 가능액 자동 계산**·증명 자료 내보내기) / 역할×메뉴 권한 매트릭스.
- 관리자 저장이 공개 화면에 즉시 반영(localStorage 공유): 도면 가격·공개 상태 변경 → plan.html에서 확인.

## 4. 모션 강도
- 공개 홈: 중(리빌 stagger·풀블리드 패럴랙스·텍스트 라인 리빌·카운트업) / 플랫폼 화면: 중(카드 호버 리프트·스켈레톤·토스트·시트) / 뷰어: 즉답성(줌 이징 160ms) / 관리자: 약(차트 그리기·바 성장·토글) / 폼: 최소(진행바·단계 전환).
- `prefers-reduced-motion` 존중, transform 기반, `transition: all` 금지.
