## 1. 등장인물

| ID | 인물 | 원하는 것 | 불안한 것 | 데모에서 보는 법 |
|---|---|---|---|---|

## 3. 역할별 시나리오

### 3-1. 고객 — C1 인테리어 실장

| 단계 | 상황 | 데모 화면 | 이 기능이 없으면 |
|---|---|---|---|
| 발견 | 「○○아파트 84B 리모델링 상담」 예약 | `index.html` 통합검색(자동완성에 주소·준공·세대수) | 블로그·카페의 출처 불명 도면을 뒤짐 |
| 탐색 | 단지명 일부만 기억, 1차/2차 존재 | `search.html` 동명이 단지 구분줄 · `complex.html` 상단 경고 | **동명이 단지를 잘못 골라 구매** → 환불 분쟁 1순위 |
| 판단 | 84B가 확장형인지, 무료와 뭐가 다른지 | `plan.html` 미리보기(워터마크·치수 마스킹·200% 상한) · 무료 vs 구매 비교표 · 도면 메타 배지 | 미리보기 없으면 「열람 후 환불 불가」 고지가 법적으로 성립하지 않음 (F2) |
| 행동 | 84A·84B + 옆 단지 59A 함께 담음, 경비 처리 | `cart.html` 단지별 그룹·묶음 10%·이미 구매 경고 → `checkout.html` 증빙 선택(세금계산서 자동)·청약철회 동의·최종 확인·버튼에 최종 금액 | 증빙 요청 CS 폭주 · 총액이 마지막에 바뀌면 다크패턴 (F3) |
| 대기 | 가상계좌면 입금 확인 전 | `pending.html` 계좌 복사·기한·열람 불가 안내 | 「결제했는데 왜 안 보여요」 |
| 실행 | 상담 직전 치수 확인 → CAD 다운로드 | `complete.html` 첫 열람 확인 모달 → `viewer.html` 줌·방향 버튼·면적 레이어·워터마크 · 다운로드(JPG/PDF/DXF 실제 생성) | **첫 열람 시각이 없으면 분쟁 시 사업자가 증명 실패** (대법원 2018다214746) |
| 사후 | 3주 뒤 재상담 · 59A는 안 열어서 환불 · 경리팀 증빙 재발급 | `my.html` 도면함(기한·횟수) · `order.html` 도면별 열람 배지 · `refund.html` 미열람만 선택·예정액 계산 · 증빙 재발급 | 재구매(이중 결제) · 미열람분 환불 거부 시 가분적 콘텐츠 규정 위반 (F2) |

### 3-2. 관리자 — A2 콘텐츠 · A3 CS · A1 운영

| 단계 | 상황 | 데모 화면 (`admin.html`) | 없으면 |
|---|---|---|---|
| 단지 등록 | 신규 입주 단지 | `#/complex/new` 중복 단지 경고 · 타입·면적 표(㎡ 입력 → 평 자동) | 같은 단지 2개 · 평 단독 표기(계량법) |
| 도면 업로드 | 원본 DWG/JPG | `#/plan/new` 진행률 → 미리보기 자동 생성 결과(원본 vs 미리보기) | 원본이 미리보기로 노출 → 무료 유출 |
| 출처 기록 | 재작도인지 건설사 허락본인지 | 출처 유형 필수 + 허락 근거 · **미입력 시 「검수 요청→공개」 비활성** | 출처 불명 공개 → 분쟁 방어 불가 (F6) |
| 검수 | 원본 vs 미리보기, 타입 매핑 | `#/review/:id` 체크 5개 → 승인 활성 · 반려 사유 | 84A 도면이 84B 상품에 붙어 판매 |
| 공개 | 검수 통과분 | `#/plans` 일괄 공개(출처 없는 건은 차단 카운트) · 가격 클릭 수정 → 공개 화면 즉시 반영 | — |
| 주문 모니터링 | 입금 대기·결제 완료 | `#/orders` 상태 탭·환불 검토 대상 필터 · CSV | 입금 확인 누락 |
| 환불 처리 (A3) | 「안 열어봤어요」 | `#/order/:id` 고지 동의 시각·IP·고지 버전·도면별 첫 열람·다운로드 횟수·환불 가능액 자동 · 증명 자료 CSV | 증거 없으면 전액 환불 |
| 회원 관리 (A3/A1) | 사업자 인증, 공유 계정 의심 | `#/members` 마스킹 열·일괄 승인 · `#/member/:id` 반복 다운로드 플래그(IP 다수)·마스킹 해제 사유(운영 책임자만) | 1회 구매 다수 사용 |
| 경영 판단 (A1) | 매출·환불률 | `#/dashboard` KPI 5·30일 차트·할 일 큐 | 감으로 운영 |
