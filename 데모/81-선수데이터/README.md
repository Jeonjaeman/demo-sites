# ATHLEDGER 애슬레저 — 선수 실증 데이터 관리 웹 MVP (제안용 데모)

상지 절단·상지 기능 제한 선수의 신체·제품(스포츠브라·드로즈)·운동·IMU 센서 CSV 데이터를 저장·조회·비교·시각화하는 웹 MVP. **선수 웹(모바일 한 손) + 관리자 웹(데스크톱)**. 데이터는 전부 가상이며 실존 인물·단체·제품과 무관합니다. 운동 기록 기술 통계이며 의학적 판단이 아닙니다.

- 공개 URL: https://jeonjaeman.github.io/demo-sites/athledger/ (허브) · `/athledger/admin/` (관리자) · `/athledger/athlete/` (선수)
- 로컬: `python -m http.server 8040` (launch.json 포트 8040)

## 체험 시나리오 (입력 없이 클릭만)
1. 관리자 세션 상세(`#/session/SES-005`): 3D 드래그 · 부하/좌우/압박 · 자세 따라가기 · 1분/10초/재생 · 절단측/건측 축 · 재처리
2. CSV 업로드: 샘플 「단위」 → 매핑 → 물리 검사(정지 구간 1g · 각속도 · Hz · 방향) → 환산 적용 → 연결
3. 규격 검증기: 불량 8종 각각 경고/차단 사유
4. 세션 비교: 조건 다른 칩 → 공정 비교 → 버전 비교 프리셋
5. 자료 추출: 준식별자 토글(k<3 경고) → 실제 .xlsx 다운로드
6. 역할 「매핑 담당」 → 보관함 사유 → 접속기록
7. 선수 웹 ATH-0001: 세션 기록 → 「뒤집어 단 파일」 → 반전 보정 → 연결 → 평가 · ATH-0009: 차단 → 동의 → 열림

## 검증에서 고친 것
- 시계열 다운샘플이 구간 평균이라 진동이 사라짐(±28°가 ±3°로) → 구간 min/max 보존
- 세션/선수 화면을 떠나도 3D·각도 rAF 루프가 누적(성능 누수) → 라우트 이탈 훅으로 정리 · 바디 오프스크린 캐시
- 중복 지문이 BOM 때문에 불일치해 차단이 안 됨 → BOM 제거 후 지문
- 접속기록 시각 UTC → 로컬 · 자료 추출 표 가로 넘침 · 비교 기본 선택이 쌍 없는 선수
- 합성 데이터 워밍업 램프로 첫 1분 치우침이 ±90% → 램프 하한·보정 프로토콜 구간 추가
