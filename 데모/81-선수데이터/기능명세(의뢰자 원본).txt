업무 내용

[프로젝트 개요]
- 상지 절단 및 상지 기능 제한이 있는 장애인 선수의 신체·제품·운동 데이터를 통합적으로 저장하고, 조회·비교·시각화할 수 있는 웹 기반 데이터 관리 시스템(MVP)을 개발합니다.
- 관리자 1~3인이 사용하는 소규모 시스템이며, 선수는 본인 데이터만 업로드하고 확인합니다.
- 센서 하드웨어와 센서 데이터 수집용 앱은 별도 업체에서 개발 중이며, 센서 자체의 분석 알고리즘이나 실시간 측정 앱은 이번 범위에 포함하지 않습니다.
- 센서 앱과의 자동 연동, 선수별 움직임 불균형 분석, 기초 사이즈 추천은 후속 확장 범위로 이번 범위에서 제외합니다.

[클라이언트 소개]
- 정부지원사업을 통해 적응형 스포츠웨어 및 IMU 기반 움직임 측정 센서를 개발하고 있습니다. 현재 상지 절단 및 상지 기능 제한이 있는 장애인 선수를 위한 스포츠브라를 개발 중이며, 향후 선수 실증 및 수집 데이터 기반의 제품 개선을 계획하고 있습니다.

[프로젝트 배경 및 목표]
- 지금 상황: 스포츠브라 내에 IMU 센서와 자기센서를 부착해 운동 중 회전·기울기·속도 등의 데이터 값을 얻고자 합니다. 팔 절단 장애 선수는 절단 부위 반대쪽 팔의 보상움직임이 커서 한쪽으로 치우친 운동 동작이 지속되고 신체 불균형이 오기 쉽습니다. 센서 구축과 앱으로 데이터 값을 받아 띄우는 부분은 센서 개발 업체에서 진행 중이며, 수집한 선수 데이터를 카테고리별로 나누어 저장하고 관리할 시스템이 필요합니다. 현재 실제 선수 데이터와 센서 실측 데이터는 확보되지 않은 상태입니다.
- 목표: 선수 또는 관계자가 프로그램에 접속해 선수 정보와 착용한 스포츠브라·드로즈의 사이즈 정보 및 평가 피드백을 직접 기입하고, 센서를 통해 얻은 데이터를 해당 선수 정보 안에 저장할 수 있기를 바랍니다. 이후 선수 또는 종목의 데이터를 검색하면 해당 일자의 데이터를 엑셀·그래프로 쉽게 확인할 수 있기를 바랍니다.

[필수 과업 범위와 결과물]
1. 수행 범위
- 상세 기획: 요구사항 정의, 화면 설계, DB 구조 설계
- SW 개발: 선수용 웹, 관리자용 웹, 서버·DB 신규 구축
- 테스트: 실제 데이터 확보 전이므로 가상 데이터를 활용한 기능 구현 및 테스트

2. 상세 기능 요구 사항
2-1. 선수 화면 (웹)
- 정보 입력: 선수 정보(종목, 운동한 일자·시간 등) 및 착용한 스포츠브라·드로즈의 사이즈 정보, 평가 피드백 직접 기입
- 센서 데이터 업로드: 센서 앱에서 추출한 CSV 파일을 본인 운동 기록에 업로드
- 데이터 조회: 본인 운동 기록 및 센서 측정값 그래프 확인
- 데이터 분리: 익명 ID 기준 본인 데이터만 업로드·조회
2-2. 관리자 화면 (웹)
- 사용자 관리: 선수별 고유 익명 ID 부여, 기본정보·종목·신체 치수·상지 기능 특성 등록·수정·조회
- 제품 관리: 스포츠브라·드로즈 제품별 모델, 사이즈 및 버전 관리, 착용 평가 결과 기록
- 운동 기록 관리: 운동 날짜, 시간, 종목, 측정 세션 등을 선수별로 구분하여 저장
- 센서 데이터 관리: 기존 센서 앱에서 추출한 IMU 센서 CSV 데이터를 해당 선수의 운동 기록에 업로드하여 저장·연결
- 데이터 조회 및 시각화: 선수별·종목별·날짜별 기록 검색, 카테고리별 분류·시각화, 센서 측정값 그래프 확인 및 다른 운동 세션과 비교
- 자료 추출: 저장된 기록 Excel 또는 CSV 형식 다운로드
- 전체 데이터 접근: 관리자만 전체 선수 데이터 조회·관리
