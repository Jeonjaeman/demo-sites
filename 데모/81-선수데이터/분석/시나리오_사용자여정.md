# 81 ATHLEDGER — 시나리오 · 사용자 여정

> 기능 목록을 시간순 사용 흐름으로 재구성한 문서. 원자료는 `_리서치_원자료.md` 1~5장.

## 1. 등장인물

| 인물 | 하는 일 | 원하는 것 | 불안한 것 | 권한 (데모 구현) |
|---|---|---|---|---|
| **선수** (상지 절단·기능 제한 · 스포츠브라 대상이라 여성 위주) | 세션 기록 · CSV 업로드 · 평가 · 본인 그래프 | 내 몸에 맞는 옷 · 치우침을 눈으로 · **한 손으로 쉬운 입력** | 장애·신체 치수 노출 · 두 손/드래그 화면 · 그래프가 "진단"처럼 보임 | 본인 레코드만 (선수 웹 타 세션 → 0건) |
| **관계자** (코치·보호자) | 선수 대신 입력·업로드 | 여러 선수 빠른 대리 입력 | 다른 선수 세션에 잘못 올림 | 위임 범위만 · 입력자 ≠ 정보주체 표기 (C-02 체험 계정) |
| **관리자** (의뢰사 연구원·제품 담당 1~3인) | 등록·익명 ID·제품/버전·세션·업로드 대행·비교·추출 | 버전 비교 · 엑셀 · 결과보고 그래프 | 데이터 꼬임 · 개인정보 사고 · 11/30 검수 반려 | 전체 (실명 매핑은 매핑 담당 1인만) |
| **의뢰사 대표** (과제 책임자) | 과제 수행·결과보고·외주 검수 | 평가 통과 · 제품 개선 근거 | 외주 증빙 미비 → 사업비 불인정 | Owner · 계정 명의자 |
| **센서 업체** | CSV 생성 앱 개발 | 규격을 늦게 확정해도 되는 유연성 | 규격 변경 책임 공방 | 실데이터 접근 없음 · 규격 검증기(샘플만) |
| **주관·전문기관** | 검수조서·결과보고 확인 | 계약서 필수 기재 · 증빙사진 · 협약 내 완료 | — | — |
| **후속 유지보수 업체** | 인수 후 확장 | 하루 안에 로컬 실행 · 문서 | 계정이 전임 업체 명의 | 수탁사 계정 (접속기록 대상) |
| **법정대리인** (14세 미만일 때) | 동의 주체 | — | — | 동의 기록 |

겸직·대리: 관리자 = 대표 겸직 가능 → 권한을 묶음(선수관리·제품·매핑열람·추출·검수)으로 부여. 연구원이 현장에서 선수 대신 업로드 → 관리자 업로드 동선(`#/upload` 대리 표기).

## 2. 시간순 여정 — 선수 1명 × 세션 1회

| # | 단계 | 쓰는 화면 | 이 기능이 없으면 |
|---|---|---|---|
| 1 | 모집·동의 (개인정보 + **민감정보 별도** + 연구) | 관리자 선수 등록 동의 패널 | 장애·신체 정보를 동의 없이 저장 → 제23조 위반 소지 |
| 2 | 선수 등록 (익명 ID · 절단 측/수준 · 치수 · 의수) | `#/athletes` | 대응표가 엑셀로 떠돎 · 절단 측 없으면 좌우 비교를 선수끼리 합칠 수 없음 |
| 3 | 제품 배정 (브라·드로즈 · 버전 · 사이즈) | `#/products` · 세션 생성 | 어떤 버전을 입었는지 몰라 v1↔v2 비교 불가 |
| 4 | 센서 장착 (ID · 위치 · 방향 · 의수) | 세션 생성 → 측정 조건 프로필 | 조건이 다른 세션이 섞여 비교가 허상 |
| 5 | 운동 (시작 보정: 5초 정지 + 왼쪽 3초) | 센서 앱 (범위 밖) | 뒤집어 단 걸 아무도 모름 → 좌우 반전 |
| 6 | CSV 추출 | 센서 앱 | 엑셀로 열고 저장 → 타임스탬프 파괴 |
| 7 | 업로드·연결 (매핑 → 물리 검사 → 확정) | 선수 웹 `#/upload` · 관리자 `#/upload` | 다른 세션에 붙거나 단위 틀린 데이터가 조용히 저장 |
| 8 | 착용 평가 (7항목 1~5 · 부위 · 한 손 착탈) | 선수 웹 `#/eval` | 자유 텍스트만 쌓여 버전 비교 불가 |
| 9 | 본인 조회 (3D · 좌우 · 그래프) | 선수 웹 `#/session` | 판정처럼 보이면 불안 → 기술 통계 라벨 |
| 10 | 관리자 비교 (세션↔세션 · 버전↔버전 · 추이) | `#/compare` · `#/trend` | 조건 다른 세션 비교 → 잘못된 제품 결정 |
| 11 | 추출 | `#/export` | 104만 행 · 수식 주입 · 한글 깨짐 |

## 6. 체험 경로 (입력 없이 클릭만)

1. 허브 → 「관리자 · 세션 상세 열기」 → 3D 드래그 · 모드 전환 · 시계열 구간/재생 · 좌/우 축 토글 · 재처리
2. 관리자 「CSV 업로드」 → 샘플 「단위」 → 매핑 → 물리 검사(환산 적용) → 연결 → 세션 상세
3. 「규격 검증기」 → 불량 8종 버튼 → 각각 경고/차단 사유
4. 「세션 비교」 → 조건 다른 칩 → 공정 비교 토글 → 「버전 비교 프리셋」
5. 「자료 추출」 → 준식별자 토글(k<3) → 다운로드(실제 xlsx)
6. 역할 전환 「매핑 담당」 → 매핑 보관함 사유 입력 → 접속기록 확인
7. 선수 웹 체험 계정 ATH-0001 → 오늘 세션 기록 → 「센서를 뒤집어 단 파일」 → 반전 보정 → 연결 → 평가
8. 선수 웹 ATH-0009 → 업로드 차단 → 내 정보에서 동의 → 열림 · 주소창 `#/session/SES-019` → 0건
