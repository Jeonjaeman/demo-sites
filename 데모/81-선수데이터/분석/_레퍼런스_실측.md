# 데모81 선수 실증 데이터 관리 — 레퍼런스 실측 (3단계)

> 작성 2026-10-16 · 실측 담당 에이전트(opus) · 대상 성격: **대시보드·데이터 제품**(브랜드 사이트 아님) — 4단계 모션 강도표 "대시보드 = 약(절제)"를 전제로 이식한다.
> 이 문서는 **A. 도메인 레퍼런스(무엇을 만들까)** 와 **B. 디자인 레퍼런스(어떻게 보이게·움직이게)** 를 다룬다. Mobbin 갤러리 수집분(`레퍼런스_Mobbin.md`)은 구성 참고이며 수치 소스가 아니다 — 거기서 라이브 실측 후보로 꼽힌 Bevel·Superpower·Spline·Visitors는 전부 라이브로 열어 실측했다.
> 저장된 레퍼런스 라이브러리(`레퍼런스/registry.json`, 13건)에는 스포츠·헬스 데이터 제품이 없어 전부 새로 실측했다.

### 업계 공통 문법 (A1~A3 + 보조에서 반복 확인)
1. **KPI 줄 → 선수별 비교 → 세션 상세** 3단 위계(Fitogether Advanced Insights · Catapult Live · Bevel). 첫 화면은 숫자 3~4개.
2. **"기준 대비"로 말한다** — 정상 범위 밴드(Bevel), 목표선·임계선 점선(Catapult), 목표 대비 ±% 배지(Catapult), 시작→목표(앳플리). 절댓값만 보여주는 화면은 없다 → 우리 IMU 값도 **선수 본인 기준선(최근 N세션) 대비**로 보여야 한다.
3. **같은 축척 2판 나란히 비교** — Fitogether 경쟁사/자사 극좌표. 좌/우 비교 그래프(공고 미정 범위)의 시각 원형.
4. **기기·파일 단위 진행 상태** — Fitogether 기기 격자 `30% Extracting` · 앳플리 `연결중…`. 업로드는 "파일별 상태"가 보여야 한다.
5. **지표마다 고정 색**(Bevel 9색 + 40/20% 틴트, Superpower optimal/normal/out). 색은 지표를 따라가고 순위를 따르지 않는다.
6. **센서는 상체 뒤·중앙**(Catapult 조끼 견갑 사이 포드, Fitogether 조끼) — 스포츠브라 부착 위치와 비교 서술 가능.
7. 다크(Fitogether·Catapult)와 라이트(Bevel·Superpower)가 갈리지만, **분석 화면(선수 데이터)을 다크로 보여주는 쪽이 "전문 장비" 인상**을 만든다(Fitogether 제품 소개는 전부 슬레이트 다크).
