# 81 ATHLEDGER 애슬레저 — 화면 기획 (사이트맵 · 화면별 목적)

> 성격: **기능형 데이터 제품**(선수 웹 + 관리자 웹). 브랜드 사이트가 아니므로 CLAUDE.md의 브랜드 단락(풀블리드 히어로 등)은 쓰지 않고, **대시보드 UI/UX**(KPI·표·필터·차트·권한·상태 흐름)로 만든다.
> 두 표면을 나눈다 — **선수 웹은 모바일 한 손 기준**(F11: 입력자가 상지 장애인 → 폰 프레임, 탭만으로 완결), **관리자 웹은 데스크톱 대시보드**(좌 내비 · 중앙 콘텐츠 · 우 보조 패널).
> 모든 메뉴는 해시 라우팅으로 딥링크되는 독립 화면. 데모 데이터는 전부 가상.

## 사이트맵

```
index.html                      데모 허브 — 두 표면 진입 + 역할 설명 + 핵심 발견 5 (제안 검토 요약)
athlete.html  (폰 프레임)        선수 웹 — 익명 ID 로그인(PIN)
  #/home       오늘 — 최근 세션 1장 요약(치우침 방향·회전 비), 내 추이 미니, 「오늘 세션 기록」 큰 버튼
  #/sessions   내 기록 — 날짜별 세션 카드 (CSV 연결 여부·평가 여부 배지)
  #/session/:id 세션 상세 — 3D 바디(절단 측 반영·히트)·기울기/회전 그래프(구간 버튼: 전체/1분/10초)·좌우 분포(절단측/건측)·착용 제품·평가
  #/new        세션 기록 — 종목·일자·시간·착용 제품/사이즈·의수 → 저장 (프리필)
  #/upload/:id CSV 업로드 — 탭 1번 파일 선택 → 자동 검사(단위·Hz·방향·중복) → 결과 → 연결
  #/eval/:id   착용 평가 — 1~5 탭 버튼 × 7항목 + 부위 칩 + 메모 1줄
  #/me         내 정보·동의 — 익명 ID, 절단 측/수준, 동의 상태(민감정보 별도 동의·버전·만료), 위임(관계자) 관리, 탈퇴/삭제 요구
admin.html    (데스크톱)         관리자 웹 — 역할 3종(관리자·매핑 담당·수탁사) 전환
  #/dash       현황 — KPI(선수·세션·CSV 연결률·동의 미완·검수 진행률) · 최근 업로드 · 조건 경고 · 보관 만료 예정
  #/athletes   선수 관리 — 익명 ID 표(종목·절단 측/수준·동의·세션 수·최근 치우침) · 등록(동의 패널 → 미동의면 업로드 차단) · 14세 미만 법정대리인
  #/athlete/:id 선수 상세 — 프로필·3D 바디·세션 타임라인·추이 스파크·착용 제품 이력·평가 요약
  #/sessions   운동 기록 — 필터(선수·종목·기간·CSV 유무·조건) · 표 · 세션 생성(측정 조건 프로필)
  #/session/:id 세션 상세 — ★ 3D 바디 히트맵 + IMU 자세 스크럽 · 다채널 시계열(기울기·회전·각속도·자기장 신뢰도 음영) · 3축 산점 · 좌우 분포 · 측정 조건 지문 · 업로드 이력(원본 불변·재처리)
  #/compare    세션 비교 — 두 세션 선택 → 조건 지문 대조(다른 항목 빨간 칩 + 경고) · 공정 비교 토글 · 버전 비교 프리셋(같은 조건 쌍 자동 매칭)
  #/trend      기간 추이 — 선수별 세션 지표 날짜축 · 제품 버전 변경 세로선 · 조건 다른 세션은 다른 기호
  #/upload     CSV 업로드(관리자 대행) — 3단계: 파일·세션 선택 → 컬럼 매핑(규격/매핑 버전) → 물리 검사(1g·Hz·UTC 9시간·방향·중복 지문) → 통과/경고/차단 + 행 오류 CSV
  #/validator  규격 검증기 — 센서 업체용. 샘플 CSV만 판정, 저장 안 함 · 불량 픽스처 8종 버튼
  #/products   제품 관리 — 브라·드로즈 모델/버전(불변·새 버전만)/사이즈 · 센서 포켓 위치 · 버전별 착용 평가 평균 비교
  #/vault      매핑 보관함 — 매핑 담당만 · 실명↔익명 ID · 열람 사유 입력 → 접속기록
  #/export     자료 추출 — 세션 요약 xlsx / 원본 CSV(BOM) / 착용 평가 xlsx · 준식별자 포함/제외(구간화) · k<3 경고 · 104만 행 분할 안내 · 수식 무해화
  #/logs       접속기록 — 누가·언제·어떤 ID·무엇을(조회/다운로드) · 보관 2년 · 권한 변경 이력 3년
  #/consent    동의·보관 — 동의서 버전·IRB 승인/면제번호·보관 만료·파기 기록 · 위탁 현황(처리방침 문안)
  #/handover   인수인계 — 계정 소유표 · 저장소 구조 · ERD · 시드 · 권한 테스트 결과(선수 A→B 0건) · 용량 계산기
  #/review     검수·제안 검토 — 공고 조항 체크리스트(시연 경로·캡처) → 검수조서 초안 인쇄 · 발견 17 · 성공 기준 9 · 미정 범위 3 의견 · 일정 역산
```

## 조작 원칙 (F11)
- 선수 웹: 드래그·핀치 없음. 3D는 탭으로 뷰 전환(정면/측면/후면 버튼) + 자동 회전 토글, 그래프 확대는 구간 버튼, 평가는 탭 버튼, 업로드는 파일 버튼 1번. 터치 대상 44px 이상.
- 관리자 웹: 마우스 드래그 회전·휠 줌 허용(보조) + 같은 버튼 대안 제공.
- 판정어 금지(F10): 위험/정상/이상 ✗ → 치우침·분포·비율 ○. 색은 판정색이 아니라 방향색(절단측·건측).
