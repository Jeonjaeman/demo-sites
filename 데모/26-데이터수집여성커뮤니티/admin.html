1. 크롤러가 멈췄을 때

  1. 「크롤링 관리」에서 마지막 로그 확인 — 403이면 대상 정책 변경(협의 필요), 429면 자동 백오프 대기
  2. 준법 게이트 4종이 전부 켜져 있는지 확인 — 하나라도 꺼지면 수집이 서지 않습니다
  3. [지금 수집 실행]으로 수동 1회 — 로그에 신규/중복이 찍히면 정상

2. 새 대상 사이트를 추가할 때

  1. robots.txt를 먼저 확인(자동) — Disallow 경로는 수집에서 제외됩니다
  2. 딜레이 계산기에서 간격을 정하고 1시간 주기 성립 여부 확인 — 불가면 증분 수집으로
  3. 첫 회차는 10건 시범 수집 후 파싱 결과 검수

3. 원저작자가 삭제를 요청했을 때

  1. 신고 큐의 「저작권(제3자)」 유형으로 접수 — 즉시 카드 비공개(임시조치)
  2. 30일 카운트다운 동안 통지·공시가 자동 발송됩니다
  3. 만료 시 재게시/영구삭제를 선택 — 처리 이력이 방어 근거로 남습니다
