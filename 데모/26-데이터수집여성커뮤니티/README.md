## 체험 (클릭만으로)
1. 피드 상단 **노출 방식 4단 토글**(링크/발췌+링크/AI요약/전문) — 카드가 실제로 바뀌고 모드별 법적 위험도·대법원 인용 4요건 체크표 표시. 공고 3-2 「협의 필요」의 결론
2. 원문 삭제(404) 카드 — 본문 비공개·커뮤니티 댓글 보존
3. 상세 — 오늘의집 문법(720px+스티키 액션 레일), 신고·차단(하단 우측 회색 텍스트 버튼 문법)
4. 관리자 「크롤링 관리」 — **준법 게이트 4종**(하나 끄면 수집 버튼 잠김+2021도1533 경고), **[지금 수집 실행]** → 로그 실시간 append·중복 스킵 카운터, 본문 보관 0건(건당 배상 차단)
5. **딜레이 계산기** — 간격 10초면 회차 상한 180건, 초과 시 "증분 수집 전환" 경고 (1시간 주기×딜레이 필수의 산술 충돌)
6. 정책 판정기 — 불법촬영물 의무(매출·이용자 슬라이더), 가입 정책 3안 비교
7. 일정·매뉴얼 — D+14/4주/6주 마일스톤, **화면 내장 운영 매뉴얼**(신규 [산출물] 응답)
