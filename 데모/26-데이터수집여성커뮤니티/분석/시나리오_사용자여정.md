# HERLOOP — 시나리오·사용자 여정 (재작업)
## 등장인물
일반 이용자(안전한 공간·캡처 유출 불안) / 원저작 플랫폼(트래픽·색인 잠식 불안 — 삭제 요청권) / 운영자=의뢰자 1인(크롤러가 조용히 죽는 것·법적 통보 불안) / 의뢰자 발주 관점(45일 내 실물 — 두 번째 유찰 불안 ★재등록 공고의 실질 페르소나)
## 여정 (여정 0번 = 운영자가 크롤러를 처음 켜는 순간)
대상 등록 → robots 확인 → 딜레이 설정(계산기) → 시범 수집 → 검수 — 이 5단계가 D+14 체크포인트와 일치 / 이용자: 피드(노출 4단) → 상세(원문 안내·댓글) → 신고·차단 / 원문 삭제: 404 감지 → 카드 비공개 → 댓글 보존 / 신고: 접수 → 즉시 가림 → 임시조치 D-30 → 만료 분기
