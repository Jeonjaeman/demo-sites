# EXCARO 엑스카로 — 중고차 수출 영업·바이어 입찰 시스템 (제안 데모)

위시켓 「중고차 수출 영업 관리 및 바이어 입찰 웹 시스템 맞춤형 구축」 대응.
**모든 데이터·업체·차량번호는 가상입니다.**

## 화면

| 표면 | 파일 | 핵심 |
|---|---|---|
| 소비자 랜딩 | `index.html` | 동의 기반 차량 조회 → 무료 수출 문의 접수 (전화 1통 원칙) |
| 영업팀 어드민 | `sales.html` | 접수·자동배정 → 상담 체크리스트 → 입찰 관리(타이머·중지·재입찰) → 확정·서류 → ERP 전송 |
| 바이어 어드민 | `buyer.html` | 입찰 가능/내 입찰 · 정보 차단(고객정보·견적 비노출) · 블라인드 입찰(내 순위만) |

## 체험 시나리오 (클릭만으로)

1. `sales.html` — 「입찰 진행」 행 클릭 → 살아있는 24시간 타이머(데모 24분), 입찰 순위, 「모의 입찰 넣어보기」
2. **`buyer.html`을 새 창으로 나란히** 열고 입찰 제출 → 영업팀 화면에 실시간 반영
3. 바이어 상세에서 개발자도구 콘솔 → 응답 객체에 고객정보·견적 **필드 자체가 없음** 확인
4. `sales.html` 「협의·확정」 → 포터2 건에서 재입찰/확정 흐름, 모닝 건에서 서류 체크 → ERP 전송(실패 시뮬 포함)
5. `index.html` — 동의 체크 → 차량 확인 → 접수 → sales 신규 리스트에 즉시 등장
6. 우상단 「담당자 필터」 = 영업직원 마이페이지 (내 건만 상태별)

데모 배속: **실서비스 24시간 = 데모 24분**. 초기화는 우상단 「데모 초기화」.

## 발견 → 기능화 요약

- 국토부 API는 **소유자 동의 전제 + 운영 심의** → 동의 없인 조회 버튼 비활성
- 마감 직전 스나이핑 → **소프트클로즈** (마감 3h 내 입찰 시 5h 자동 연장)
- 마감 판정은 **서버 시각** — 마감 후 입찰은 거부됨
- "철저히 비노출" → **응답 필드 제거** (화면 숨김 아님)
- 알림톡 심사(영업일 ~3일) → **SMS 폴백** 기본
- ERP 전송 **멱등키 + 재시도 로그**, 수출 서류 5종 완비 전 전송 차단
- 재입찰 **2회 제한**, 블라인드 입찰(내 순위만)
