- **일정(60일)**: 2주 설계·디자인 시안 → 4주차 영업 어드민+국토부 → 6주차 바이어 입찰+ERP → 8주차 통합 테스트 (공고 마일스톤 그대로)

## 6.5 외부 연동 전략 — 국토부·카마트

두 연동이 일정 리스크 1·2순위. **개발 일정과 계약·심의 일정을 어댑터로 분리**하는 것이 핵심.

### 국토교통부 자동차종합정보 (본질: 동의·심의)
- **주 경로**: 공공데이터포털 정식 신청(의뢰자 명의). 개발계정 자동승인 → 착수 주 1부터 개발,
  **운영 심의를 같은 주 신청** (활용목적서에 랜딩 동의 UX 캡처 첨부)
- **동의 증빙**: 동의 체크 시 시각·문구 버전·수집 항목을 DB 로그 — 심의·감사·분쟁 대응
- **보조**: CODEF 등 민간 게이트웨이 자동차등록원부(을) API (인증 요건 착수 시 확인)
- **폴백(항상 탑재)**: 조회 실패·심의 지연에도 접수는 진행 — "차량 확인은 상담 시" 경로.
  조회는 전환율 부스터일 뿐 접수의 전제조건이 아니게 설계
- **운영**: 접수 시 1회 호출 후 케이스에 캐시 (쿼터·재조회 남발 방지)

### 카마트 시세·폐차기준가 (본질: 계약 리드타임)
- **주 경로**: 의뢰자 명의 직접 계약, 착수 주 1 컨택. `PriceProvider` 인터페이스 고정 —
  계약 전 수동입력·모의 구현체, 계약 후 카마트 구현체 교체 (**계약 지연이 개발을 못 막게**)
- **보조**: 금융데이터거래소 구매 또는 쿠콘(CODEF)·API스토어 리셀러 시세 API (조건 착수 시 견적)
- **폐차기준가 폴백**: 고철 시세 기반 자체 산식 (중량 × 고철 단가 − 해체비, 단가는 관리자 설정)
- **자체 대체(중기)**: 시스템에 쌓이는 모델·연식·주행·체크리스트별 **낙찰가 히스토리**로
  자체 기준가 산출 → 6개월 후 카마트 의존 축소 가능 (의뢰자 어필 포인트)
- **폴백 UI**: 미연동 상태 "기준가 미조회 + 수동 입력 허용" — 영업 무중단

### 공통 방어
- 두 신청·계약 모두 의뢰자(사업자) 명의 = 의뢰자 부담 항목
- 계약서 납기 기산 조항: API 심의·계약 기간은 납기에서 제외
- 4주차 "API 연동" 마일스톤은 개발계정 기준, 운영 전환은 심의 완료 시

## 8. 착수 전 확인 필요 (미팅 안건)

- 국토부 API **운영 심의** 소요 기간 — 오픈 일정과 직결, 착수 즉시 신청 권장

- 바이어 계정 발급·탈퇴 절차, 낙찰 후 실차 상이 시 감액 규정
- ERP/플로우 Webhook 명세 (수신 필드·인증 방식) — 내부 인력 협업
- 소비자 개인정보 보관 기간(데모 표기: 90일) 확정
