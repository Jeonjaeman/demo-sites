# EXCARO — 시나리오 · 사용자 여정

기능 목록을 시간순 사용 흐름으로 재배치한 문서. 여기서 드러난 구멍은 데모에 구현했거나 미팅 안건으로 남겼다.

## 1. 등장인물

| | 원하는 것 | 불안한 것 |
|---|---|---|
| 차주 (소비자) | 내 차 값 빨리·비싸게 확인 | 전화 폭탄 · 개인정보 유출 · 헐값 |
| 영업직원 | 내 건 진행 상황, 다음 할 일 | 건 놓침 · 중복 연락 |
| 영업팀장 | 균등 배분, 정체 건 발견 | 쏠림 · 방치된 접수 |
| 바이어 (수출업자) | 좋은 매물 선점, 정확한 상태 정보 | 사진·정보 부실 → 낙찰 후 실차 차이 |
| 사내 ERP/플로우 | 확정 건 자동 수신 | 중복·누락 전송 |

한 사람이 두 역할을 겸하는 경우: **팀장도 영업직원을 겸한다** (배정 셀렉트에 팀장 본인 없음 — 데모는 직원 3명에게만 배정. 실서비스에서 팀장 포함 여부 확인).

## 2. 시간순 여정

```
① 발견   차주가 랜딩 접속 — 차량번호·소유자명 입력
② 동의   소유자 본인 동의 체크 → 국토부 조회 → 차량 확인
③ 접수   연락처 입력 → 접수 완료 → 최소 보유 건수 기준 자동배정 (팀장 수동 재지정 가능)
④ 상담   담당자 전화 1통 — 체크리스트 6항목 + 메모 + 주행거리 → 저장 시 비교견적·폐차기준가 산출
⑤ 사진   차량 사진 업로드 (바이어 노출용)
⑥ 입찰   입찰 시작 → 바이어 전원에게 알림(알림톡/SMS) → 24시간 카운트다운
⑦ 경쟁   바이어 입찰 제출·수정 (블라인드 — 내 순위만) · 마감 3시간 내 입찰 시 5시간 자동 연장
⑧ 마감   시간 종료 or 영업팀 임의 중지 → 그 시점 최고가 확정
⑨ 협의   차주 희망가와 비교 → 수락 or 재입찰(최대 2회)
⑩ 확정   매입 확정 → 수출 서류 5종 추적 (매입계약서·신분증빙·대금증빙·말소등록·수출신고)
⑪ 전송   서류 완비 → ERP/플로우 Webhook (멱등키·실패 재시도)
```

## 3. 역할별 시야 차이 (권한 설계의 핵심)

| 데이터 | 차주 | 영업직원 | 팀장 | 바이어 |
|---|---|---|---|---|
| 차주 연락처·성명 | 본인 | 담당 건 | 전체 | **✗ (응답 필드 자체 없음)** |
| 비교견적·폐차기준가 | ✗ | 담당 건 | 전체 | **✗** |
| 차주 희망가 | 본인 | 담당 건 | 전체 | **✗** |
| 타 바이어 입찰가 | ✗ | 전체 (리스트) | 전체 | **✗ (내 순위만)** |
| 체크리스트·사진·메모 | ✗ | ○ | ○ | ○ (노출용) |
| 담당자 재배정 | ✗ | ✗ | ○ | ✗ |

## 4. 기능별 존재 이유

| 기능 | 없으면 벌어지는 일 |
|---|---|
| 규칙 자동배정 | 접수 폭주 시 팀장 병목 → 방치 건 → 차주는 타 업체로 |
| 담당자 필터(마이페이지) | 직원이 자기 건을 전체 목록에서 눈으로 골라야 함 |
| 상태별 리스트 | "입찰 걸어놓고 잊은 건"이 생김 |
| 체크리스트 6항목 고정 | 직원마다 묻는 게 달라 바이어 신뢰 하락 → 입찰가 하락 |
| 폐차기준가 표시 | 하한선 없이 협상 → 폐차보다 싸게 파는 사고 |
| 소프트클로즈 | 스나이핑에 경쟁 차단 → 낙찰가 하락 |
| 서버 시각 마감 | 클라이언트 시계 조작으로 마감 후 입찰 |
| 블라인드 입찰 | 최고가 +1 만원 눈치 입찰 → 경쟁 소멸 |
| 재입찰 2회 제한 | 무한 재입찰 → 바이어 피로 → 참여 이탈 |
| 서류 5종 게이트 | 서류 누락 채 ERP 등록 → 세무·환급 사고 |
| ERP 멱등키 | 재시도 시 중복 등록 → 재고 이중 계상 |
| SMS 폴백 | 알림톡 심사·반려 기간에 안내 두절 |

## 5. 비는 구멍 (공고에 정의 없음 → 미팅 확인)

1. 차주가 입찰 진행 중 **철회**하면? (바이어 신뢰 비용 — 철회 수수료/패널티 정책)
2. 낙찰 후 **실차 상태 상이** — 감액 절차·분쟁 기준 (ACV는 컨디션 리포트 보증으로 해결)
3. **동점 입찰** — 데모는 선입찰 우선. 정책 승인 필요
4. 입찰 참여 **0명**일 때 — 데모는 상담 상태로 회귀. 재발송·기준가 조정 등 후속 룰
5. 바이어 **등급/신용 관리** — 낙찰 후 미인수 바이어 제재
6. 담당자 **부재·퇴사** 시 건 일괄 이관
7. 소비자 개인정보 **보관·파기** 주기(데모 표기 90일) 및 처리방침 문안
8. 팀장의 겸임 여부 (배정 대상에 팀장 포함?)
