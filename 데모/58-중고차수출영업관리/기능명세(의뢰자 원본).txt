업무 내용

[프로젝트 개요]
- 중고차 수출 기업의 사내 영업팀 업무 효율화 및 바이어 입찰을 위한 웹 시스템 구축
  프로젝트입니다.
  소비자가 랜딩 페이지에 연락처와 차량번호를 남기면, 영업팀이 전화를 걸어 차량 상태를
  파악해 어드민에 입력하고, 이를 바탕으로 바이어들이 입찰가를 제시하는 B2B 성격의
  시스템입니다.

[프로젝트 배경 및 목표]
- 영업팀이 파악한 정확한 차량 정보를 바탕으로 바이어가 입찰하고, 최종 매입이 확정되면
  기존 사내 시스템인 플로우 또는 ERP로 데이터를 넘겨주는 매끄러운 업무 파이프라인을
  구축하고자 합니다.

[과업 범위]
1. 수행 범위
- 기획 및 디자인: 제공된 플로우 차트 및 화면 설계서 기반 고도화 기획, 영업팀 업무
  효율을 극대화하는 100% 맞춤형 반응형 웹 UI/UX 디자인
- SW 개발: 소비자용 랜딩 페이지, 영업팀 어드민, 바이어 어드민 웹 구축
- 외부 연동: 국토교통부 차량조회, 카마트 시세/폐차기준가, 사내 ERP/플로우 Webhook,
  카카오 알림톡 연동

2. 상세 기능 요구 사항

2-1. 소비자 랜딩 페이지
- 소유자명, 차량번호 입력 시 국토부 API 연동을 통한 기본 차량 정보 노출
- 전화번호 입력 후 무료 수출 문의하기 접수 완료

2-2. 영업팀 어드민 (팀장 및 영업직원)
- 신규 접수 건 리스트 및 담당자 배정 (규칙 기반 자동 배정 및 팀장 수동 지정 기능)
- 영업직원 마이페이지 (종합, 입찰전, 입찰중, 완료 상태별 리스트 관리 및 자동 갱신)
- 전화상담 체크리스트 입력 (사고유무, 침수이력, 구동방식, 에어컨, 썬루프, 기타옵션)
  및 상담 메모 작성
- 영업팀의 차량 사진 슬라이드 업로드 기능 (바이어 노출용)
- 차량별 비교견적 및 폐차기준가 자동 표시 (카마트 API 연동)
- 바이어 대상 입찰 요청 실행 (24시간 카운트다운 타이머 작동 및 임의 중지 기능)
- 입찰 중지 시 해당 시점의 최고 입찰가로 확정 처리
- 바이어 입찰 리스트 확인 및 고객 재상담 조율
- 가격 불일치 시 희망가 협의 후 재입찰 프로세스 처리
- 매입 확정 처리 및 매입 완료 시 사내 ERP 또는 플로우로 차량 정보 자동 전송

2-3. 바이어 어드민
- 바이어 로그인 및 마이페이지 (입찰 가능 리스트, 내가 입찰한 리스트)
- 차량 상세 정보 확인 (영업팀이 올린 사진, 체크리스트, 메모 노출 /
  고객정보, 비교견적, 폐차견적은 철저히 비노출)
- 입찰가 입력, 바이어 메모 작성 및 제출
- 마감 시간 전까지 내가 입찰한 리스트에서 입찰가 수정 기능
- 신규 입찰 요청 시 카카오 알림톡 수신

3. 비기능적 요구사항
3-1. 디자인: 사내 업무용 시스템이지만 사용성이 매우 중요하므로, 제공된 와이어프레임을
     바탕으로 세련되고 직관적인 맞춤형 UI/UX 디자인이 필요합니다.
3-2. 성능: 24시간 입찰 타이머 및 상태값 변경이 오류 없이 실시간으로 작동해야 합니다.

[기술/제조 스택]
- 프론트엔드: React.js, Vue.js 등 반응형 웹 프레임워크 제안 요망
- 백엔드: Node.js, Spring Boot 등 제안 요망
- 데이터베이스: PostgreSQL, MySQL 등 RDB
- 기타: 국토교통부 API, 카마트 API, 카카오 알림톡 API, 사내 ERP/플로우 Webhook 연동

[클라이언트 준비 사항]
- 문서 및 자료: 상세 프로세스 및 화면 와이어프레임이 포함된 기획 문서 PDF 제공
- 투입 인력 및 조직: 요구사항 정의 및 사내 ERP 연동 테스트를 적극적으로 지원할
  내부 인력 대기 중

[주요 일정]
- 희망 착수일: 계약 후 즉시 착수 희망
- 주요 마일스톤: 착수 후 2주 내 기획 고도화 및 맞춤형 UI/UX 디자인 시안 도출,
  4주 차 영업팀 어드민 핵심 기능 및 API 연동 구현, 6주 차 바이어 입찰 및 ERP 연동,
  8주 차 통합 테스트 진행
- 최종 오픈 희망일: 착수일로부터 2개월 이내

[지원 자격 및 우대 사항]
- 지원 자격: B2B 어드민 시스템 구축 및 외부 API 연동 경험이 풍부하며, 자체적인
  UI/UX 디자인 역량을 갖춘 업체 또는 팀
- 우대 사항: 중고차 관련 플랫폼 차량번호 조회 API 등 개발 경험이 있거나,
  사내 ERP/그룹웨어 연동 경험이 있는 파트너를 적극 우대합니다.
