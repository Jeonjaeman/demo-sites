# FORME — 쇼핑몰 연동형 사이즈·핏 추천 풀사이트 데모

정적 HTML/CSS/JavaScript로 만든 전면 실구동형 프런트엔드 데모입니다. 상품 탐색과 구매뿐 아니라 Cafe24형 임베드 위젯, 비회원·회원 추천, 자체/Kakao 인증 시뮬레이션, 신체 프로필, 옷장, 추천 이력, 계정 설정, 운영자 퍼널까지 하나의 제품 흐름으로 연결합니다.

현재 결과물은 실제 Cafe24 앱, OAuth, 서버 API, 데이터베이스 또는 결제 시스템에 연결되지 않습니다. 브라우저 저장소와 비동기 화면 상태로 운영 구조를 재현하며, 후속 비동기 adapter와 실연동 경계는 [임베드 가이드](docs/INTEGRATION.md)와 [API 계약](docs/API.md)에 명시합니다.

## 실행

```bash
npm install
npm run serve
```

브라우저에서 `http://127.0.0.1:4173`을 엽니다. UI 프리미티브는 `/showcase.html`에서 확인할 수 있습니다.

## 데모 범위

- 커머스: 홈, 상품 목록·검색·필터, 상품 상세·실측표, 관심상품, 장바구니, 데모 결제, 주문 완료·이력
- 핏 위젯: 접힘·펼침, 빠른 입력, 분석, 추천 결과, 추천 불가·오류, 추천 사이즈 옵션 적용
- 회원: 비회원 이용, 자체 로그인·가입, Kakao 연결 시뮬레이션, 비밀번호·약관·개인정보·탈퇴 상태
- My Fit: 신체·핏 프로필, 추천 이력과 피드백
- 옷장: 관심상품과 분리된 보유 의류 목록, URL/수동 등록, 상세·수정·삭제, 중복·가져오기 실패 폴백
- 운영자: 별도 로그인 시뮬레이션, 읽기 전용 추천 퍼널·상품 요약·임베드 상태
- 플랫폼 경계: Cafe24-first ScriptTag 계약, 상품 컨텍스트, 호스트 옵션 반영, event bridge, 로컬 비동기 API adapter

대표 라우트는 `#home`, `#shop`, `#product/:id`, `#cart`, `#checkout`, `#order/:id`, `#account`, `#auth`, `#wardrobe`, `#account/settings`, `#embed`, `#admin`, `#terms`, `#privacy`입니다. 실제 화면 링크는 헤더·푸터와 플랫폼 메뉴에서 확인할 수 있습니다.

## 검증 흐름

1. 상품 상세에서 접힌 핏 위젯을 열고 키, 몸무게, 선호 핏을 입력합니다.
2. 추천 결과에서 추천 사이즈를 적용해 상품 옵션과 구매 버튼이 갱신되는지 확인합니다.
3. 장바구니와 데모 주문을 완료해 `widget_open → recommendation_start → recommendation_result → size_applied → add_to_cart → purchase` 퍼널이 연결되는지 확인합니다.
4. 비회원 추천 후 로그인해 프로필·추천 이력이 저장되는지 확인합니다.
5. 옷장에서 지원 URL, 중복 URL, 미지원 URL과 수동 등록·수정·삭제를 확인합니다.
6. 계정 설정에서 Kakao 연결·해제, 동의 상태, 탈퇴 후 회원 파생 데이터 정리를 확인합니다.
7. 운영자 화면에서 추천 퍼널과 임베드 상태가 사용자 이벤트에 따라 갱신되는지 확인합니다.

자동 검증은 다음 명령으로 실행합니다.

```bash
npm test
```

현재 포함된 Playwright 기본 스위트는 구매 여정, 커머스 로그인·지속성, 접근성 대화상자, 입력 오류와 모바일 가로 오버플로를 검증합니다. 위의 인증·옷장·임베드·운영자 시나리오는 함께 적힌 수동 검증 흐름으로 확인합니다. 테스트는 로컬 서버가 필요한 경우 별도 터미널에서 `npm run serve`를 먼저 실행합니다.

상품 이미지·모션을 Higgsfield로 제작할 때는 `HIGGSFIELD_ASSET_BRIEF.md`의 파일명, 가상 모델 정책, 일관성 규칙을 사용합니다. 인물이 필요한 에셋은 실제 인물이 아닌 가상 성인 모델만 사용합니다.

## 전체 구매 여정

홈·Shop 상품 탐색 → 상품 상세 → 임베드 핏 추천 → 추천 사이즈 적용 → 장바구니 → 데모 주문 → 추천·구매 귀속 → My Fit/옷장 재사용으로 이어집니다. 비회원은 추천 결과까지 사용할 수 있고, 프로필·옷장·이력 저장 시 회원 전환을 안내합니다.

상품·장바구니·회원·주문·핏 프로필·옷장·추천·이벤트는 브라우저 저장소에 유지됩니다. 외부 결제, 서버 인증, 택배, 실제 재고, Kakao OAuth와 Cafe24 설치는 시뮬레이션입니다. 브라우저 저장소는 보안 경계가 아니므로 실제 개인정보나 자격 증명을 입력하지 마세요.

상품 이미지 6종은 인증된 Higgsfield MCP의 `recraft_v4_1` 모델로 생성했으며 인물을 사용하지 않았습니다. 향후 인물 이미지가 필요한 경우 가상 성인 모델 정책을 따릅니다.
