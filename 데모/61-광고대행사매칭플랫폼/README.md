# ADRING 애드링 — 광고대행사 역경매 매칭 플랫폼 데모
위시켓 「광고대행사 매칭 반응형 웹 플랫폼 구축」 (2,500만·90일·마감 8/18) 대응.
- 사용자: https://jeonjaeman.github.io/demo-sites/adring/
- 관리자: https://jeonjaeman.github.io/demo-sites/adring/admin/

## 체험 (클릭만으로)
1. 요청서 4스텝 프리필 — 3단계에서 텍스트를 지우면 품질 점수 실시간 하락(60 미만=검증 대기)
2. 제안 비교 — 월/총 환산·검증 지표순 정렬, 「이 순위는 무엇으로?」 모달, 유효 D-카운트다운, 만료·협의 격리
3. 역할 전환 토글 — 소상공인/제안 전 대행사/낙선/관리자로 같은 화면의 마스킹이 실제로 바뀜
4. 매칭 확정 — 2단계 동의(대행사 특정 재동의) 없이는 확정 불가
5. 대행사 화면 — 「매출 보장」 경고, 010 입력 제출 차단, 동일 문구 100%=차단, 국세청 대조 분기
6. 관리자 — 수익모델 시뮬레이터·리뷰 저장 잠금·동일 실체·상태머신·통판 50건 경보
