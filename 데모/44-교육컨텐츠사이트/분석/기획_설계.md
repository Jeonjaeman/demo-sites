# CLASSKIT 클래스킷 — 기획·설계

> 학부모·교사 대상 교육 콘텐츠(시리즈) 소개·결제 웹사이트 (크몽 공고) · 제안용 데모
> 1단계(랜딩·무료체험·상담·소개) 중심 · 모든 데이터는 시연용 가상값

---

## 0. 공고 요약

- 의뢰: 교수(개인) · 정부지원사업 연계 · 세금계산서 필요 · 예산 **900만원 / 1.5개월(1단계 한정)** · 선금 10%
- **학부모·교사 대상 교육 콘텐츠(시리즈=유인물·수업 가이드) 온라인 소개·결제** (인터넷 강의 X)
- **단계별 발주**: 1단계 견적 요청 + 2·3단계 참고
- 스킬: HTML·CSS·JS·NodeJS·Wordpress·MongoDB · 콘텐츠 변경 자유도 중요

### 단계 구성
- **1단계(필수)**: 랜딩 · 무료체험 폼(이름/연락처/자녀 학년 → 즉시 알림) · 상담 문의 폼 · 시리즈 소개(결제X) · 샘플 영상(유튜브) · 반응형 · 법적 페이지
- **2단계**: 실제 결제 · 다운로드 워터마크(레포트월드류) · 장바구니 · 후기 · B2B 문의 분리
- **3단계**: 다국어 · 관리자 · 회원/마이페이지 · 구독결제

## 1. 명시된 니즈 vs 숨은 니즈

| 구분 | 내용 |
|---|---|
| 명시 | 소개·무료체험·상담·샘플·반응형·법적 페이지(1단계) |
| 숨은 ① | 무료체험 폼의 **“자녀 학년” = 아동 개인정보** → 법정대리인 동의 필요(미동의 시 형사처벌) |
| 숨은 ② | 콘텐츠는 다운로드형 → **청약철회 제한**이 되려면 “불가 고지 + 무료체험/샘플”이 전제 |
| 숨은 ③ | 유인물은 **유출되면 사업이 끝남** → 워터마크·다운로드 로그를 1단계부터 설계에 반영 |
| 숨은 ④ | 정부지원 결제 → **세금계산서·개발 업종·정산 서식** 안 맞으면 지급 막힘 |
| 숨은 ⑤ | 단계별 발주지만 **1단계 데이터 모델이 2·3단계를 좌우** |

## 2. 웹 리서치 — 치명적 발견 (근거)

| 우선순위 | 발견 | 근거 |
|---|---|---|
| **형사처벌** | 만 14세 미만 아동(자녀) 정보는 **법정대리인 동의 필수** — 미동의 수집 시 5년 이하 징역/5천만원 벌금·매출 3% 과징금 | [개인정보보호법 §22의2 (privacy.go.kr)](https://www.privacy.go.kr/front/contents/cntntsView.do?contsNo=75) |
| **환불 분쟁** | 디지털콘텐츠는 다운로드 시작 시 청약철회 제한, 단 **불가 고지 + 시험사용(무료체험·샘플)** 없으면 무효 | [전자상거래법 청약철회 (law.go.kr)](https://www.law.go.kr/lsInfoP.do?lsId=009318) |
| **콘텐츠 유출** | 유인물 재배포 억제 = 구매자 ID **워터마크·다운로드 로그**(레포트월드류) | 레포트월드 방식 · 콘텐츠 유출 방지 실무 |
| 정산 | 정부지원 결제 — 세금계산서·개발 업종·단계별 산출내역 | 정부지원사업 정산 실무 |

## 도메인 레퍼런스

- **아이스크림**(초등 교육 플랫폼·650만 콘텐츠·교사 70%) · **티처빌/티처몰**(교육 쇼핑) · **쌤동네**(교사 지식공유)
> 아이스크림 실측: 흰 배경·NanumSquareNeo·액센트 #ffcc00·radius 20(둥근·친근). 국내 교육 톤 = 따뜻·친근.

## 디자인 레퍼런스 (메트릭 이식 · 갤러리)

- **Linear**(64px/−0.022em·pill) / **Vercel**(radius4·−0.06em·모노)
> 시스템: 크림/페이퍼 배경 + 테라코타(자료·따뜻함) + 스칼라 그린 · 국내 교육 친근함(둥근 radius) · 가격/수치 모노.

## 3. 화면 구성 (발견을 기능으로)

- **무료체험 신청 폼** — 이름/연락처/자녀 학년 + **법정대리인 동의 게이트**(동의 없이 접수 차단) + 즉시 알림(이메일/카톡) · 자녀는 학년만 최소수집
- **콘텐츠 보호·환불 진단** — 구매자 워터마크 토글 + 청약철회 불가 고지 토글 → 유출·환불 리스크 실시간 판정
- 시리즈 소개(결제 없이·샘플 영상) · 상담/B2B 문의 분리 · 관리자 접수 현황 · 리스크 6건 · 단계별 견적
- ② 풀블리드 statement · ① 마우스 카드 · ⑤ 텍스트 애니

## 4. 제안 스택·일정

- 1단계: 정적/가벼운 SPA + 폼 백엔드(Node) + 접수 알림(이메일/카톡) + 콘텐츠·후기 데이터 모델
- 콘텐츠 변경 자유도 → 운영팀 편집(관리자/헤드리스 CMS) 고려, 2·3단계(결제·워터마크·구독·B2B·다국어) 확장을 막지 않는 모델
- 일정: **약 1.5개월(1단계)** · 정부지원 정산·세금계산서 전제 · 2·3단계는 1단계 반응 후 정식 산정

## 5. 레드팀 검수(AI스러움 제거)

- 유아용 과한 원색·풍선 클리셰 회피 → 크림/페이퍼 + 테라코타의 따뜻한 “자료” 톤
- 무료체험 폼을 히어로 주인공으로, 동의 게이트를 실제 동작으로(장식 아님)
- 폼/랜딩 성격이라 모션 절제(리빌·카운트업)
