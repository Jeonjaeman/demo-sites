# CLASSKIT 클래스킷 — 학부모·교사 교육 콘텐츠 소개·무료체험 (제안용 데모 · 1단계)

학부모·교사 대상 교육 콘텐츠(유인물·수업 가이드) 시리즈를 소개하고 무료체험으로 이어지는
1단계 사이트. 예쁜 소개 뒤에서 **아동 개인정보·콘텐츠 유출·환불 규정**을 먼저 챙겼습니다.

공개 URL(별칭): `https://jeonjaeman.github.io/demo-sites/classkit/`

## 체험 시나리오

1. **무료체험 신청**: 이름·연락처·자녀 학년 입력 후 신청 → **법정대리인 동의 없이는 접수가 막힘**. 동의하면 “담당자 즉시 알림 발송(이메일+카톡)” + 관리자에 접수됨.
2. **상담 문의** 접수 → 관리자 현황에 실시간 추가(B2B는 자동 분리 태그).
3. **콘텐츠 보호**: ‘구매자 워터마크’와 ‘환불 불가 고지’ 토글을 켜고 끄면 유출·환불 리스크 판정이 실시간으로 바뀜(둘 다 켜야 “안전”).

## ⚠️ 착수 전 확인 (미팅)

- 자녀 정보 수집 범위(학년만?)·법정대리인 동의 문안 · 다운로드형 환불 정책·청약철회 고지
- 콘텐츠 워터마크 방식·다운로드 로그(2단계) · 콘텐츠 변경 자유도(스택 선택) · 정부지원 정산·세금계산서

## 디자인 실측

- 도메인: **아이스크림**(흰 배경·NanumSquareNeo·#ffcc00·radius20 친근), **티처빌·쌤동네**
- 디자인: **Linear**(64px/−0.022em·pill), **Vercel**(radius4·−0.06em·모노) — 메트릭 이식
- 시스템: 크림/페이퍼 + 테라코타(자료·따뜻함) + 스칼라 그린 · 국내 교육 친근함(둥근 radius)

## 기술 구성

- 정적 HTML/CSS/JS(빌드 없음) · Pretendard · 외부 라이브러리 미사용
- 폼 검증·동의 게이트·접수 집계·콘텐츠 보호 판정 **실동작**(하드코딩 없이 상태 반영)
- 100vw 풀블리드 · `overflow-x:clip` · `prefers-reduced-motion` 존중

## 검증 결과

- 콘솔 0 · 데스크톱/모바일(375) 가로 오버플로 0 · 이미지 5장 로드
- 무료체험(미동의 차단→동의 후 알림+접수) · 상담 접수 · 콘텐츠 보호 토글(환불위험↔안전) · 시리즈·리스크·견적 렌더

> 모든 시리즈·후기·수치·접수는 시연용 가상값이며 실존 자료·인물과 무관합니다.
> 다운로드형 콘텐츠는 청약철회가 제한될 수 있으며, 구매 전 무료체험·샘플을 제공합니다.
