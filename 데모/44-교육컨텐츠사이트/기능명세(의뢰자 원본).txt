1. 프로젝트 개요
학부모 및 교사 대상 콘텐츠(시리즈) 상품을 온라인에서 소개 및 결제할 수 있는 웹사이트를
구축합니다. 콘텐츠란, 교육에 참고할 수 있는 유인물, 수업 가이드 등의 자료를 의미합니다.
(인터넷 강의 X) 향후 콘텐츠 및 상품 변경의 자유도가 중요합니다.

2. 프로젝트 목적
- 콘텐츠(시리즈) 상품의 온라인 소개 및 판매
- 무료체험 신청 및 상담 문의 접수/관리
- 운영팀이 직접 콘텐츠 및 후기 등을 수정할 수 있는 관리자 기능 제공
- 기관(B2B) 라이선스 문의의 별도 관리
- 다국어 지원 및 구독형 결제 도입

3. 의뢰 범위
- 턴키 (단, 디자인 시안은 제공 예정. 미팅 시 공유)
- 플랫폼: Web, 모바일 반응형 포함
- 전체를 한 번에 발주하지 않고 단계별로 진행. 우선 1단계 견적을 요청, 2·3단계는 참고용으로 함께 검토.

4. 단계별 기능 상세

■ 1단계 (필수, 최우선)
- 메인 랜딩 페이지 (디자인 시안 기준)
- "무료체험" 신청 폼 → 이름/연락처/자녀 학년 입력 → 신청 즉시 담당자에게 알림(이메일 또는 카카오톡 등)
- "상담 문의" 폼 (일반 문의용)
- 시리즈(상품) 소개 페이지 — 이 단계에서는 결제 기능 없이 소개만
- 샘플 수업 영상 삽입 (유튜브 영상 링크 연결 방식으로 충분)
- 모바일에서도 깨지지 않는 반응형 디자인
- 이용약관, 개인정보처리방침 등 법적 필수 페이지

■ 2단계 (1단계 반응 확인 후 진행)
- 실제 결제 기능 (신용카드, 간편결제 등)
- 상품 다운로드 후 보안 기능 (레포트월드 https://www.reportworld.co.kr/ 처럼, 구매회원의 아이디를 워터마크로 넣는 수준)
- 장바구니 기능
- 상품 후기(별점 + 텍스트) 등록 및 노출 기능
- 기관 라이선스 문의를 별도로 관리하는 B2B 문의 관리 기능 (일반 문의와 분리)

■ 3단계 (확장, 시점 미정)
- 영어 등 다국어 페이지
- 운영팀이 직접 콘텐츠(시리즈, 후기, 통계 숫자 등)를 수정할 수 있는 관리자 페이지
- 회원가입/로그인, 마이페이지
- 구독형 결제(정기결제)
