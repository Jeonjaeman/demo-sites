■ 요구사항 대응 (공고 항목 그대로)

1) 데이터 수집·연동
   - 구글 폼 실시간 연동 (Apps Script onFormSubmit → 웹훅 즉시 수신)
   - 응답 검증 5규칙 : 문항 미응답 / 리커트 범위 이탈 / 규준 적용 불가 연령 / 코드 형식 오류 / 무성의 응답(직선 반응)
     → 오류 건은 채점 중단 후 담당자 알림, 경고 건은 채점하되 결과지에 신뢰도 경고 표기
   - 검사자 고유코드(KT-YYMM-NNNN)로 결과지·저장파일·메일 발송을 하나의 키로 연결

2) 채점 엔진
   - 역채점 문항 자동 반전(환산 = 6 − 응답), 문항별 가중치 적용
   - 요인별 가중치 합을 고정해 6개 요인의 원점수 스케일을 동일하게 유지
   - 연령 3구간 × 성별 2구간 × 6요인 규준표 매핑
   - Z = (원점수 − M) / SD → T = 50 + 10Z → 백분위 = 정규분포 누적확률
   - 결측 보정(요인당 2개 이하 가중평균 보정, 3개 이상 채점 보류)
   - 3축(에너지·정서·조절) → 8가지 동물 유형 판별 + 경계선 사례용 확신도(%) 산출

3) 동적 PDF 결과지
   - A4 12페이지 : 표지 / 검사안내 / 종합요약 / 방사형 프로파일 / T점수·백분위 / 요인상세 3p /
     유형 심층해설 / 4주 코칭플랜 / 부록(문항 원자료) / 규준·고지
   - 방사형·막대·정규분포 차트를 점수에 맞춰 동적 생성 (외부 차트 라이브러리 의존 없음)
   - 점수 구간별 해석문구 30블록 자동 바인딩, 판별된 유형 일러스트 자동 삽입 (8종 제작 완료)
   - 저장 : 로컬/ZIP · Google Drive · S3(암호화) 선택 + 보호자 메일 자동 발송

4) 비기능 요구사항
   - 성능 : 12페이지 부당 약 1.3초, 100부 일괄 약 2분
   - 레이아웃 : 13명 × 12페이지 = 156페이지 전수 렌더 검사 → 페이지 넘침 0건
     (이 검사 도구를 납품물에 포함합니다. 문구를 수정한 뒤에도 깨짐 여부를 즉시 확인할 수 있습니다)
   - 보안 : 저장 데이터 AES-256 암호화 / 아동 실명 가명처리(DB에는 코드만) / 다운로드 링크 만료 /
     보관기간 경과 자동 파기 / 열람·발급·수정·파기 감사 로그 / 역할 3단계 권한


■ 기술 스택 — Node.js + Puppeteer 제안
요구사항의 핵심은 "제공된 디자인 샘플과 동일한 형태의 고해상도 PDF"입니다.
ReportLab은 좌표 기반이라 디자인을 코드로 다시 그려야 하지만, Puppeteer는 퍼블리싱한 HTML/CSS를
브라우저가 그대로 인쇄합니다. 지금 보시는 결과지도 동일한 방식으로 만들어졌습니다.

운영 형태는 ① PC 실행형(RPA, 서버비용 0원) ② 서버 상시 구동형(제출 즉시 무인 발송) 중
선택 가능하며, 동일 엔진을 쓰므로 계약 후 협의로 정하면 됩니다.
