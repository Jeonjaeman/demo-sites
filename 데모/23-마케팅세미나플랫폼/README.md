## 체험 시나리오 (데모 포인트)

**랜딩**
1. **수익 계산기** — 슬라이더 3개(방문객·객단가·재방문율)를 움직이면 개선 효과가 실시간으로 계산됩니다. 99,000원을 작아 보이게 만드는 전환 장치입니다.
2. **지역·회차** — 권역 탭을 바꾸면 해당 지역 회차가 나옵니다. **잔여 좌석 = 정원 − 확정 − 입금대기**로 계산되며, 0이 되면 버튼이 잠기고 "마감"으로 바뀝니다.
3. **예약 3단계** — 정보 입력(누락 시 차단) → 결제 수단 → 완료. **가상계좌를 고르면 24시간 좌석 홀딩 안내**가 뜨고, 완료 화면에 실제 **알림톡 카드 미리보기**가 나옵니다.

**관리자 (워드프레스 UI)**
4. **지역 페이지 ★ 핵심** — "56개 일괄 수정 실행" 버튼을 눌러 보세요. **복제 방식은 약 1.9시간**이 걸리는 것을 진행바로 보여주고, CPT 방식은 **1분**임을 비교합니다.
5. **알림톡 템플릿** — 승인 4건 / 심사중 1건 / **반려 1건**. 반려 사유는 "광고성 메시지"입니다.
6. **예약자 관리** — 환불 버튼을 누르면 상태가 바뀌고, **CSV가 실제 파일로** 다운로드됩니다(UTF-8 BOM).

## ⚠️ 착수 전 확인이 필요한 항목

- **56개 페이지를 "복제"하면 유지보수가 감당되지 않습니다** — 공통 내용 한 줄이 바뀌면 56개를 전부 고쳐야 합니다. → **커스텀 포스트 타입 + 단일 템플릿**으로 바꾸면 템플릿 1곳 수정으로 끝나고, 담당자 입력도 더 쉬워집니다. **과업을 늘리자는 게 아니라 내부 인력의 반복 작업을 없애는 방향입니다.**
- **가상계좌와 정원 60명 마감이 충돌합니다** — 미입금 예약을 정원에 넣으면 빈자리인데 마감되고, 안 넣으면 초과 입금이 발생합니다. → **24시간 좌석 홀딩 + 만료 시 자동 해제·대기자 알림**.
- **알림톡 심사가 40일 일정을 밀어냅니다** — 검수는 1~2일이지만 반영까지 최대 2개월이 걸릴 수 있고, **광고성 문구는 반려**됩니다. → 착수 즉시 심사 신청(개발과 병행) + **SMS/이메일 폴백**.
- 그 외 지역 페이지 SEO 유사 콘텐츠, 플러그인 충돌, 회차 누적 아카이브를 함께 반영했습니다.
