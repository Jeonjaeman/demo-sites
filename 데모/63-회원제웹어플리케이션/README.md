# INCIRCLE 인서클 — 회원제 커뮤니티 웹앱 데모
위시켓 「회원제 커뮤니티 웹 애플리케이션 구축」 공고 (2,000만·60일·마감 8/20·Supabase 필수) 대응.
- 커뮤니티: https://jeonjaeman.github.io/demo-sites/incircle/
- 관리자 백오피스: https://jeonjaeman.github.io/demo-sites/incircle/admin/

## 체험 (클릭만으로 — 타이핑 불필요)
1. 상단 **계정 상태 전환기** 6시야(비로그인/승인대기/1·2·3등급/관리자) — 같은 게시판 목록이 시야마다 실제로 달라지고, 「RLS 콘솔」에 그 시야의 정책 SQL·반환 행수가 표시됩니다. 승인 대기 시야가 핵심: **로그인은 되어 있는데 0행**
2. **강의영상 게시판**(2등급+) — 영상 보호 3안(유튜브 임베드/Vimeo 도메인 제한/자체 스토리지) 실비교. 회원 수·시청량 슬라이더로 월 비용 실계산. 「URL을 아는 누구나 시청 가능 — 왜?」 배지 → videoId 추출 시연
3. **자료실·갤러리**(3등급 다운로드) — 다운로드하면 canvas로 **파일 자체에 열람자·시각·토큰이 각인된 PNG가 실제로 생성**됩니다. 오버레이 모드 토글 → "개발자도구로 제거" 시연(대조군). 서명 URL 만료 카운트다운
4. 상세 → **신고** → 목록에 "임시조치됨" 자리가 남습니다(공시 의무)
5. 관리자 「오늘 할 일」 — 승인 큐(24h SLA 초과 경고·초대 추천인·거절 사유 통보), 공지 CMS(즉시/예약 발행)
6. 「권한 매트릭스」 — 게시판 6종×액션 4종 **72칸**, 값 변경 시 등급별 미리보기 즉시 갱신 + 자동 승급 규칙 시뮬(분포 실계산)
7. 「신고·회원」 — 44조의2 법정 상태머신(조치→양측 통지→공시→D-30→만료 분기), **마스킹 방식 토글**(클라이언트 모드에서 API 응답에 원문이 실리는 것 대조), 탈퇴 3안 영향 실집계+약관 문구 생성
8. 「보안·RLS」 — 자가진단 8항목(위험 점수 실계산·기존 바이브 코딩 데모 인수 점검표), **RLS 성능 시뮬**(70명 0.3초 → 4,000명 18.5초), 정책 진단기(42P17 재귀 좌우 대조), **유출본 역추적**(토큰 WM-K7Q2XN 프리필)
9. 「인프라·활동 로그」 — 리전 선택 → 국외이전 배지·처리방침 문구 자동 생성, 플랜·비용 실계산(무료=백업 요구 미충족 경고), 프로바이더 검수 상태머신(체크리스트 미완료 시 진행 차단), 활동 로그(보존 D-카운터·삭제 잠금)
