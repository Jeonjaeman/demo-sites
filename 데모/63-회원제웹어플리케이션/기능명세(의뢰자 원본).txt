- 게시판, 강의 영상, 갤러리 등의 기능을 통해 회원 간 정보 공유가 가능한 커뮤니티를 구축하는 것을 목표로 합니다. 철저한 권한 관리 및 보안 기능 적용을 통해 안전한 서비스 운영 환경을 조성합니다.

[과업 범위]
1. 수행 범위
- 상세 기획: 화면설계서(IA/스토리보드), 데이터베이스 설계, API 명세
- UI/UX 디자인
- 프런트엔드/Client 개발
- 백엔드 개발
- 서버/DB/인프라 구성 (Supabase)

2. 상세 기능 요구 사항
2-1. 회원 시스템
- 회원가입 및 승인심사: 관리자 승인 절차를 거쳐야 가입이 완료되는 구조
- 소셜로그인: 카카오, 네이버 계정 연동 로그인
- 권한 3단계: 등급별 게시판 열람 및 기능 접근 제어

2-2. 게시판 시스템
- 게시판 6종: 댓글, 첨부파일, 북마크, 조회수, 신고 및 블라인드 처리 기능 공통 적용
- 강의영상 게시판: 유튜브 영상 연동(임베드) 방식으로 운영, 별도 영상 저장소 불필요
- 갤러리 게시판

2-3. 관리자 백오피스
- 회원관리 및 가입승인 처리
- 공지사항 CMS
- 신고 처리
- 활동 로그 관리

3. 비기능적 요구사항
3-1. 성능/규격: 초기 회원 70명 기준으로 구축하되, 향후 3,000~4,000명 규모까지 무리 없이 확장 가능한 구조로 설계
3-2. 보안/인증: Supabase RLS(Row Level Security) 기반 접근제어, 개인정보 서버측 마스킹, 게시물/자료 열람 시 워터마크 삽입 및 열람 이력 추적, 데이터 자동 암호화 백업 적용
