# INCIRCLE 인서클 — 기획/설계 (회원제 커뮤니티 웹앱 · Opus 분석 → Fable 구축)

## 발주 컨텍스트 판독
- "아이디어만 있는 상태" + 산출물 1번이 화면설계서 → **요구사항은 착수 후 반드시 바뀐다.** 기획 확정 구간(스토리보드 승인 게이트)을 견적에 별도 배치
- "IT 관리 경험 없음" + 산출물에 운영 매뉴얼 → 납품이 아니라 **인수인계**가 진짜 요구
- "기존 데모(바이브 코딩) 공유 가능" → 이미 만들다 막힌 상태. **인수 1일차 = service_role 키 점검·회전** (프론트 번들 유출 패턴 다수 보고)
- "협업 인력 없음" → 관리자 백오피스는 기능 나열이 아니라 **오늘 처리할 일 큐** + 자동화

## 핵심 발견 → 기능 (근거 URL은 리서치 원문 — 에이전트 산출 보존)
- **A1 ★유튜브 임베드 ↔ 보안 3종 모순 (승부처)**: 미등록 영상은 소스에서 videoId 추출로 비회원 시청 가능, 비공개는 임베드 불가, 멤버십은 자체 페이월 불가 → 강의영상 게시판만 권한 3단계·워터마크·열람이력 전부 무효 → **「영상 보호 3안 선택기」**(유튜브/Vimeo 도메인제한/자체 스토리지+서명URL — 비용·공수 실계산) + **노출 범위 진단 배지**(iframe src에서 videoId 실제 추출 시연)
- **A3 ★승인제 ↔ Supabase Auth 충돌**: 가입 순간 세션 발급 → 승인 대기자는 이미 authenticated. 정책 하나 빠지면 그 테이블 전체 노출. 해법 = JWT 클레임(Custom Access Token Hook) → **「계정 상태 전환기」** 6시야(비로그인/대기/1·2·3등급/관리자) 원클릭 전환 + 시야별 RLS 정책 SQL·반환 행수 콘솔
- **A4 RLS 무한 재귀(42P17)**: profiles를 profiles 정책에서 조회 → **「정책 진단기」** naive vs SECURITY DEFINER 좌우 대조 실행
- **A2 네이버는 Supabase 기본 프로바이더 아님**(카카오만 네이티브·네이버 Custom OIDC) + **C7 검수**(카카오 비즈앱=사업자번호, 네이버 3~4영업일·스크린샷 필수) → **「프로바이더 구성+검수 체크리스트」** 상태머신
- **B1 활동 로그 = 법정 접속기록**(1년 보존, 관리자 열람도 기록 대상) → 보존 카운터·삭제 잠금·"관리자의 회원정보 열람" 필터
- **B3 신고·블라인드 = 정보통신망법 44조의2 절차**(양측 통지·게시판 공시·30일·약관) → **법정 상태머신 큐** + 목록에 "임시조치됨" 자리 유지
- **B4 서버측 마스킹**: 클라 마스킹은 네트워크 응답에 원문 → **마스킹 방식 토글 + API 응답 원문 패널 대조**, 해제는 사유 입력→로그 기록
- **C1 ★RLS 성능 함정**: naive auth.uid()는 70명에선 멀쩡, 4,000명에서 죽음(공식 실측 11,000ms→10ms, initplan 래핑·인덱스 100배) → **「RLS 성능 시뮬레이터」** 회원수×정책 패턴 실계산 막대
- **C2 보안 자가진단 8항목** — 기존 바이브 코딩 데모 인수 점검표 겸용
- **C3 서명 URL은 발급 후 RLS 무관** → 만료 선택+카운트다운, 이력 단위는 다운로드가 아니라 **URL 발급**
- **C4 자동 백업은 유료 플랜 전제**(무료: 백업 없음·7일 미사용 정지) + **B2 리전=국외이전**(서울 리전이면 비해당) → **「인프라·비용 시뮬레이터」**(리전 배지·처리방침 문구 자동 생성·월 비용 항목별 계산)
- **C5 워터마크**: CSS 오버레이는 개발자도구로 제거 가능 → **canvas 서버 합성 시뮬(파일 자체 각인) vs 오버레이 제거 실증** + **「유출본 역추적」**(토큰→열람 이력 특정)
- **C6 승인 대기 = 이탈 1순위** → 대기 중 공개 라운지 1종·승인 SLA 위젯(24h 초과 경고)·초대 링크 자동승인
- **D1 등급≠권한**: 게시판 6종×등급 3단×액션 4종 = **72칸 권한 매트릭스**(변경 즉시 회원 시야 미리보기 갱신) + 자동 승급 규칙(가입기간+방문+글수) 시뮬
- **D2 탈퇴 시 게시물 3안**(익명화/비공개/삭제) — 영향 건수 실집계 미리보기
