# DENTDESK 덴트데스크 — 치과 데스크 통합 CRM 데모
위시켓 「치과 데스크 통합 관리 시스템 구축」 공고 (1,500만·60일·마감 8/20) 대응.
- 데모: https://jeonjaeman.github.io/demo-sites/dentdesk/

## 체험 (클릭만으로)
1. **예약 캘린더** — 타임라인(진료실›체어 2단 그룹), 축 토글(체어/의사/위생사 — 스케일링은 위생사 축에서만 온전히 보임), 상태 5종 색, 점심·정비 블록, 현재시각 라인. **충돌 시뮬레이터** 켜고 빈 칸 클릭→저장 = 저장 거부+인접 슬롯 제안(낙관적 잠금). 예약 클릭 = 당일 취소→대기 목록 점수 매칭
2. **환자** — 마스킹 기본·「표시」 클릭=열람 기록 실증가, 역할별 CSV 차단(데스크), 상세=**기록 경계선**(데스크 응대/진료기록 읽기전용) + 처치명 입력 시 저장 차단(의료법 22조)
3. **수납·미수** — 현금 10만↑ 영수증 미발행 = 가산세 20% 경고, 시효 D- 컬럼, 분납 상태, 단계 워크플로, 확인서 파일 생성, 위약금 계산기(치협 기준)
4. **문자·알림톡** — **발송 유형 판정기**: 문구에 "할인"을 넣어 보세요 → 광고성 판정·알림톡 잠금·(광고)+수신거부 삽입·대상 312→88명 차감·22시 발송 시 08시 이월. 리콜 탭 = **규칙 빌더**(스케일링 연 1회·1/1 리셋 → 1월 스파이크)·반려 템플릿 사유
5. **통계** — 3단 매출(발생/수납/청구대기)·삭감 슬라이더·노쇼율 정의 3종 토글·리마인드 효과 시뮬(실측 22%↓ 기준)
6. **설정·보안** — **SSOT 3지선다**(전자차트 주인 선택 시 캘린더가 실제 읽기전용)·이중입력 비용 실계산·EMR 등급 스위처(요건+견적 재계산)·열람 이력(원장 전용·2년 D-·삭제 잠금·이상 접근 탐지)·유출 72h 판정·이관 시뮬
