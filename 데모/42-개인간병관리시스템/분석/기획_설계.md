# CAREON 케어온 — 기획·설계

> 개인간병 업체 운영 관리(배정·회비·준법) · 제안용 데모
> 모든 간병사·환자·연락처·회비·수치는 시연용 가상값

---

## 0. 의뢰 원문(요약)

“저희는 개인간병 업체다보니 엑셀작업과 실무진이 배정현황이나 회비입금 현황 등등 전반적으로
사무실에서나 밖에서도 볼 수 있는 프로그램을 만들고싶습니다.”

→ 핵심어: **개인간병 업체 · 엑셀 대체 · 실무진(간병사) 배정현황 · 회비입금 현황 · 사무실+외부(모바일) 접근**

---

## 1. 시나리오로 재구성한 니즈

의뢰 문장은 짧지만, “간병사를 배정하고 회비를 걷는다”는 한 줄에 업(業)의 성격이 다 들어 있습니다.
이건 **간병인 유료직업소개/협회 모델**입니다. 그래서 단순 엑셀 대체가 아니라 **법적 성격을 가진 운영**입니다.

| 구분 | 내용 |
|---|---|
| 명시된 니즈 | 배정현황·회비현황을 사무실/외부에서 보는 프로그램 |
| 숨은 니즈 ① | 엑셀을 그대로 옮기면 **위법 리스크가 커짐** — 배정+관리·감독이 한 화면에 섞이면 불법 근로자공급 소지 |
| 숨은 니즈 ② | 회비를 걷는 순간 **유료직업소개사업(등록 대상)** — 시스템이 사업 성격을 드러냄 |
| 숨은 니즈 ③ | “밖에서도 본다” = **환자 건강정보(민감정보)가 외부 노출** → 역할·마스킹 필요 |
| 숨은 니즈 ④ | 엑셀 = 동시 편집 충돌·집계 불일치 → 미납/수납률이 사람마다 다르게 세어짐 |

| **불법 근로자공급** | 소개소가 **모집·관리·감독까지 개입·지배하면 불법 근로자공급(§33)** → 강남지방노동사무소 간병소개소 고발 사례 | [메디칼타임즈 — 간병인문제](https://www.medicaltimes.com/Mobile/News/NewsView.html?ID=5996) |

| **민감정보** | 환자 질환·병력은 **개인정보보호법 §23 민감정보** — 별도 동의·최소수집·접근 최소범위 | 개인정보보호법 §23 · 의료·요양 개인정보 실무 |
| **투명 정산 표준** | 케어닥 등은 **카드·계좌 투명 정산 + 간병인 전원 배상책임보험** | [케어닥](https://apps.apple.com/kr/app/id1495648148) · [케어네이션](https://www.carenation.kr/) |

## 4. 화면 구성 (발견을 기능으로)

| 화면 | 발견 대응 |
|---|---|
| 히어로 + 미니 프리뷰 | 배정률·수납률·미납 요약(실집계 미리보기) |
| ② 풀블리드 statement | “배정은 소개까지, 관리·감독은 선을 넘는다” |
| ① 마우스 카드 4기둥 | 배정·회비·민감정보·어디서나 |
| **운영 대시보드** | 배정 현황(필터·간병비)·회비/정산(수납률·미납 실집계)·준법 검토(가중 게이지) |
| **역할 전환(관리자/간병사)** | 외부 간병사 화면에서 담당 외 질환·보호자 연락처 **마스킹**, 타 간병사 회비 비공개 |

| 견적 | 3가지 플랜 — BASIC 120만~ / STANDARD 190만~(추천) / PREMIUM 250만~ (VAT 별도) |

## 5. 제안 스택 · 일정

- 프론트: 정적 SPA(데모) → 실제는 React/Vue + 인증·역할(RBAC)
- 데이터: 배정/회비/간병사/의뢰 · 감사로그 · 엑셀 가져오기(현행 자료 이관)
- 보안: 역할별 최소권한 · 민감정보 접근통제/마스킹 · 외부 접속 세션
- 일정: 플랜별 **BASIC 3~4주 / STANDARD 4~6주 / PREMIUM 6~8주**. 미팅에서 현행 엑셀·회비 규칙·계약형태(소개/도급/고용) 확인 선행
