# CAREON 케어온 — 개인간병 업체 운영 관리 (제안용 데모)

엑셀로 하던 **간병사 배정현황·회비 입금현황**을 사무실에서도 밖에서도.
배정·회비·준법을 한 화면에서 관리하되, **위법이 되기 전에 경계를 짚어 주는** 운영 프로그램.

공개 URL(별칭): `https://jeonjaeman.github.io/demo-sites/careon/`

---

## 화면

| 영역 | 무엇을 보여주나 |
|---|---|
| 히어로 + 미니 프리뷰 | 배정률·수납률·미납 요약(실집계) |
| ② 풀블리드 statement | “배정은 소개까지, 관리·감독은 선을 넘는다” |
| ① 마우스 카드 | 배정 · 회비 · 민감정보 · 어디서나 |
| **운영 대시보드** | 배정 현황 · 회비/정산 · 준법 검토 (실연산) |
| **역할 전환** | 관리자 ↔ 외부 간병사 (민감정보 마스킹) |
| 리스크 6건 | 발견 → 대응 → 근거(법령·판례) |
| 견적 | 공수표(18일 · 90만원) |

## 체험 시나리오

1. **배정 현황** 탭에서 필터(공석)를 눌러 미배정만 골라 보기 — 건수·표가 실제로 바뀜.
2. **역할을 ‘외부 간병사’로** 전환 → 담당 외 환자 질환·장소·보호자 연락처가 **마스킹**되고, 회비 탭은 **내 것만** 남음.
3. **회비/정산** 탭에서 수납/미납액이 실집계(수납 28만 / 총 56만 / 미납 28만).
4. **준법 검토** 탭에서 필수 항목(유료직업소개 등록·소개 경계·민감정보)을 끄면 즉시 **운영 불가 위험**으로 판정.

## ⚠️ 착수 전 확인 (미팅)

- **유료직업소개사업 등록 상태**(미등록이면 등록이 먼저)
- **회비 성격**(간병사 소개회비 vs 환자 간병비 수납) · **간병사 계약형태**(소개/도급/고용)
- **환자 건강정보 수집 동의** 절차 · 현행 엑셀 항목/규칙(회비 금액·연체)
- 외부 접속 대상·기기 · 서버/호스팅 · 문자·알림 발송 채널
