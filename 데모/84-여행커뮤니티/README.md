# NOLPAN 놀판 — 중장년 여행·여가 커뮤니티 모바일 웹 (제안용 데모)

위시켓 공고 「여행·여가 커뮤니티 모바일 반응형 웹 및 안드로이드 웹뷰 앱 구축」(400만 원 VAT 별도 · 45일)에 대한 제안 데모입니다.
**사용자 화면 13페이지 전부 동작**, 관리자 화면은 범위 밖(지원서에서 그누보드5 기본 관리자 + 커스텀으로 답함). 모든 글·회원·사진은 가상입니다.

- 데모: https://jeonjaeman.github.io/demo-sites/nolpan/
- 검토 항목(14건): https://jeonjaeman.github.io/demo-sites/nolpan/review/
- 로컬: `python -m http.server 8037 --directory 데모/84-여행커뮤니티` (launch.json `nolpan`)

## 체험 시나리오 (타이핑 없이)
1. 홈 → 「가」 버튼으로 「더 크게」 → 목록 사진이 아래로 내려가고 탭이 2줄로 바뀜
2. 내 정보 → 체험 계정 「자기신고 회원」 → 국내여행 정선·하이원 → 본문 잠금 → 「본인확인하고 열기」 → 모의 인증 → 해제
3. 글쓰기 → 「예시 · 등록이 막히는 글」 → 등록 불가 + 하이라이트 → 「정상 글」 → 「샘플 사진 3장」 → 등록 → 목록 맨 위에 하이라이트
4. 글 상세(정선 셔틀) → ⋯ → 신고 → 접수 → 「차단하기」 → 그 회원 댓글·글이 사라짐 → 내 정보 → 차단한 회원에서 해제
5. 가입 → 3단계 「생년월일 입력」 → 예시 2007-12-31 → 연 나이 성인 / 민법 토글 → 미성년
6. 회원 탈퇴 → 집계 → 삭제 선택 → 2단계 확인
