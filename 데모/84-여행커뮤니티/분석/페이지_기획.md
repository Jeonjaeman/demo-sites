# 놀판 NOLPAN — 페이지 기획 (구축 전 확정 · 2026-10-20)

> 데모 범위: **사용자 화면 MVP** (관리자 없음 — 지원서에 범위·일정으로 답함). 모바일 우선 반응형 웹.
> 데스크톱(≥1024px)에서는 좌측에 「데모 안내 패널」(화면 인덱스·검토 항목·글자 크기 체험), 우측에 앱 화면(최대 480px 폭, 폰 프레임 느낌 없이 카드형 셸)을 둔다. 모바일(<1024px)에서는 앱 화면만 전체 폭.
> 원페이지 금지 원칙에 따라 **메뉴·화면마다 독립 HTML**로 분리하고 딥링크(`post.html?id=`)가 동작한다. 공통 헤더·하단 탭바·JS/CSS/데이터는 분리 파일로 공유하고 내비에 `aria-current`를 넣는다.

## 2. 페이지별 기획

### index.html — 홈
- 목적: 오늘 올라온 것 중 볼 만한 걸 30초 안에 고르게 한다. 허브로서 3대 게시판으로 보낸다.
- 방문자가 할 일: 배너 보기 → 3대 탭 중 하나 선택 → 인기글 눌러 상세로.
- 섹션: ① 헤더(로고 · 검색 · 알림 · 「가」 글자 크기) ② 프로모션 배너 슬라이드(3장, 스와이프·점·자동전환·「광고」 표기, 일시정지) ③ 3대 메뉴 탭(큰 아이콘+글자, 각 게시판 오늘 글 수) ④ 실시간 인기글 피드(제목·게시판·사진 썸네일·좋아요·댓글·시간, 「광고·협찬 글 제외」 토글 → 실제 재계산) ⑤ 라운지 새 사진(가로 스크롤 4장) ⑥ 하단 탭바(홈·해외·국내·라운지·내정보) + 글쓰기 플로팅.
- 다음 유도: 각 섹션 끝 「전체 보기 →」.

### overseas.html — 해외여행
- 목적: 지역 → 분류 2단 탐색으로 원하는 후기를 3탭 안에.
- 섹션: 게시판 상단 커버(지역 사진 + 지역명 + 회원 수) → 지역 탭(다낭·호이안 / 마카오 / 필리핀 — 글자 크기 「더 크게」에서는 2줄 그리드) → 분류 칩(전체·숙소·맛집·후기) → 목록(제목 2줄 clamp·메타·썸네일·광고 라벨) → 더 보기(페이지네이션 버튼, 무한스크롤 아님 — 중장년).
- 마카오·필리핀 탭: 상단 안내 「카지노 이용 후기는 금지, 리조트·맛집·교통만」 + 자기신고 회원이면 본문 잠금 카드(「본인확인하고 열기」).

### domestic.html — 국내여행
- 지역 탭: 정선·하이원 / 강릉 / 속초. 분류: 명소·맛집·교통.
- 정선·하이원 탭 상단 고정: 게시판 규칙(허용·금지 주제) + 「도박문제 상담 1336」 + 외부 링크 경고 안내. 자기신고 회원 본문 잠금.

### lounge.html — 여행 라운지
- 탭 5개: 자유수다·후기·Q&A·사람들 이야기·사진 갤러리. Q&A는 「답변 완료」 배지, 갤러리는 2열 그리드(시간 배지·좋아요) → 탭하면 post로.

### post.html — 글 상세
- 상단: 게시판 경로 칩, 광고·협찬 라벨(해당 시), 제목(대형), 작성자(이니셜 아바타·닉네임·업체 배지·성인확인 배지·시간·조회).
- 본문: 사진(가로 스와이프·확대), 본문 텍스트(이스케이프), 외부 링크는 경고 시트 경유.
- 액션 행: 좋아요(카운트 즉시 반영·burst) · 댓글 수 · 공유 · 「⋯」(신고·차단·내 글이면 수정·삭제).
- 댓글: 원댓글 → 1단 답글(들여쓰기 + 세로 연결선), 「답글 N개 보기」 접기, 삭제된 원댓글 자리 유지, 하단 고정 입력창(「댓글 남기기」·답글 모드 표시). 빈 상태 「첫 댓글을 남겨 보세요」.
- 상태: 신고 누적 「검토 중」 글(본문 가림 + 작성자에겐 사유·이의제기), 차단한 회원 글 접근 시 숨김 안내.
- 신고 시트: 사유 6종(각 한 줄 설명) → 접수 완료(처리 안내 + 「이 회원 차단하기」) → 차단 시 목록·상세에서 그 회원 글·댓글이 실제로 사라짐.

### write.html — 글쓰기
- 순서: 게시판 선택(해외→지역→분류 / 국내 / 라운지) → 사진(최대 10장, 썸네일 그리드, 개별 삭제, 대표 지정, 「남은 N장」, canvas 리사이즈·EXIF 제거 배지·용량 표시, HEIC 안내, 「샘플 사진 넣기」) → 제목 → 본문 → 「업체에서 대가를 받았어요」 체크 → 하단 고정 「임시저장 / 등록」.
- 작성 가드: 입력 즉시 검사. 차단 등급(온라인카지노·바카라·토토·꽁머니·가입코드·텔레그램·단축URL·급전·당일대출·차량담보·유흥 알선)은 등록 비활성 + 하이라이트 + 사유. 경고 등급(베팅·칩 환전·연락처 패턴)은 「게시판 규칙 확인」 체크 후 등록. 「예시로 보기」 3버튼(정상 글 / 차단 예 / 경고 예).
- 하단 상시 고지: 「누구나 볼 수 있는 글입니다 · 게시판 규칙」.
- 등록 → 토스트 → post.html로 이동(새 글이 목록 맨 위에 실제로 들어감 — localStorage).

### search.html — 검색
- 프리필 검색어 + 추천 칩(「다낭 맛집」「하이원 셔틀」「풀빌라」). 범위 토글(제목·본문·댓글). 블라인드·차단 글 제외 표시. 하이라이트.

### notify.html — 알림
- 내 글의 댓글·답글·좋아요 목록, 읽음 처리, 「모두 읽음」. 앱에서는 푸시 안내 배너.

### signup.html — 가입 4단계
1. 시작: 카카오·네이버·일반 가입 큰 버튼(모의) + 「성인 전용 커뮤니티」 고지.
2. 약관: 필수 2·선택 1 체크(전체 동의), 금지 콘텐츠 요약 카드(UGC 정책 ①②), 보관 항목 고지.
3. 연령 확인: ① 휴대폰·간편 본인확인(권장, 모의 시트에서 샘플 인물 선택 → 「성인 확인 완료·수단·일시」) ② 생년월일 입력(임시) — 입력 즉시 「오늘 기준 판정」(청소년보호법 연 나이 / 민법 만 나이 토글), 미성년이면 다음 버튼 비활성 + 안내, 통과해도 「자기신고 회원」 배지. 「예시로 보기」 경계 사례 3개.
4. 닉네임·프로필: 닉네임 중복 검사(모의), 이니셜 아바타 색 선택 → 완료 → 홈.
- 상단 「2/4」 진행 표시, 뒤로가기 유지.

### my.html — 마이페이지
- 프로필 카드(아바타·닉네임 수정·가입 경로·성인확인 상태 배지 + 「저장되는 항목」 펼침), 내 글/내 댓글 탭(실제 집계), 차단한 회원(해제), 글자 크기(→ text.html), 알림 설정, 약관·개인정보, 로그아웃, 회원 탈퇴(→ withdraw.html).
- 회원 상태 전환 데모: 「체험 계정 바꾸기」 — 본인확인 회원 / 자기신고 회원 / 업체 회원 / 비회원 — 전 화면 권한이 실제로 바뀜(③ 시야 차이 표).

### text.html — 글자 크기 설정
- 3단계 라디오(기본·크게·더 크게) + 「기기 설정 따르기」 토글(안내) + 실시간 미리보기(목록 카드·본문·버튼) + 「단계가 올라가면 바뀌는 것」 설명(썸네일 위치·탭 2줄·말줄임 없음). 선택 즉시 전체 사이트 반영·유지.

### withdraw.html — 회원 탈퇴
- 내 글 N·댓글 M 집계 → 「남기기(탈퇴한 회원 표시) / 모두 삭제」 선택 → 보관 고지(재가입 제한용 식별값 1년) → 큰 버튼 2단계 확인 → 완료(「앱 밖에서 탈퇴 요청하기」 링크).

### review.html — 검토 항목
- 리서치 발견 14건을 카드로: 등급·한 줄 요약·근거 링크·「데모에서 확인하기」 버튼(해당 화면·상태로 이동). 데모 범위 밖 항목은 「지원서로 답함」 표기. 모든 데이터 가상 고지.

## 3. 셸 공통
- 헤더 56px(safe-area 더함): 뒤로/로고 · 제목 · 검색 · 알림(배지) · 「가」 글자 크기 팝오버(3단계).
- 하단 탭바 64px + safe-area: 홈·해외·국내·라운지·내정보, 아이콘+글자 항상, 말줄임 금지, 현재 탭 `aria-current`.
- 글쓰기 플로팅 버튼(목록 화면), 토스트, 바텀시트(신고·외부 링크 경고·본인확인 모의·게시판 선택).
- 「앱 화면으로 보기」 토글(데스크톱 안내 패널): 상태바·제스처 바 오버레이 + safe-area 값 주입.
- 상태 저장: localStorage `nolpan.*` (글자 크기, 체험 계정, 새 글·댓글·좋아요·차단·신고·읽음).
- 모션 강도 「중」: 리스트 진입 stagger, 카드 탭 프레스, 좋아요 burst, 스켈레톤, 토스트, 배너 스냅. `prefers-reduced-motion` 존중.

## 4. 샘플 데이터 (전부 가상)
- 게시판 3대 × 지역 × 분류, 글 ~40건(사진 있는 글 16건), 댓글 ~80건(답글 포함), 회원 12명(업체 1·자기신고 1·검토 중 글 작성자 1), 배너 3장, 알림 6건.
