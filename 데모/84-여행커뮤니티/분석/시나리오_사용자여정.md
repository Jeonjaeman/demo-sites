# 놀판 NOLPAN — 시나리오 · 사용자 여정

> 공고: 여행·여가 커뮤니티 모바일 반응형 웹 및 안드로이드 웹뷰 앱 구축 (위시켓 · 400만 원 VAT 별도 · 45일) · 분석 2026-10-20
> 기능 목록을 **시간순 사용 흐름**으로 다시 배치해, 공고에 없는 예외 상황(비는 구멍)을 찾았습니다. 모든 인물·데이터는 가상입니다.

## 1. 등장인물

| 코드 | 인물 | 무엇을 원하나 | 무엇을 불안해하나 |
|---|---|---|---|

## 3. 역할별 시나리오

### A · 해외여행 회원 「다낭 처음 가는 60대 부부」
홈 배너(광고 표기) → 「해외여행」 → 다낭·호이안 탭 → 「맛집」 칩 → 쌀국수집 글(사진 1장·카드 안 됨·현금) → 댓글 「숙소 이름도?」 → 좋아요 → 글쓰기로 「유심 vs 로밍」 질문 → 글자가 작아 헤더 「가」를 눌러 「크게」 → 다음 방문에도 유지.
- 데모에서 확인: `index.html` → `overseas.html?region=danang&cat=food` → `post.html?id=101` → `text.html`

### B · 정선·하이원 회원 「주말 셔틀 타는 사람」
「국내여행」 → 정선·하이원 탭 상단 **게시판 규칙**(허용/금지 + 1336) → 셔틀 글 → 댓글 답글. 어느 날 「집에서도 똑같이 즐기는 법」 글이 올라옴 → ⋯ → 신고(불법 도박·카지노 홍보) → 「이 회원 차단」 → 그 회원 글·댓글이 사라짐. 운영진 검토 중에는 글이 「검토 중」으로 가려짐.
- 데모: `domestic.html?region=jeongseon&rules=1` → `post.html?id=201` → `post.html?id=206`(검토 중 화면)

### 자기신고 회원 「생년월일만 입력한 사람」
가입 3단계에서 「생년월일 입력」 경로 → 통과 → 「자기신고」 배지 → 정선·마카오·필리핀 게시판 **본문 잠김** + 「본인확인하고 열기」 → 모의 본인확인 → 잠금 해제.
- 데모: `my.html#account`에서 「자기신고 회원」 선택 → `domestic.html?region=jeongseon` → `signup.html?step=3&verify=1`

### E · 업체 회원 「풀빌라 예약센터」
글쓰기에서 「업체에서 대가를 받았어요」 체크 → 목록·상세에 「광고·협찬」 라벨 → 홈 인기글에서 「광고·협찬 글 제외」 토글로 빠짐. 업체 배지가 닉네임 옆에 붙음.
- 데모: `post.html?id=103` · `index.html`(토글)

### F · 불법 홍보자
글쓰기에 「온라인카지노 첫 충전 … 가입코드 … 텔레그램」 입력 → **등록 버튼 비활성** + 걸린 단어 하이라이트 + 사유. 단축 URL도 차단. 경고 등급(베팅·전화번호)은 규칙 확인 체크 후 등록되고 운영진이 한 번 더 봄.
- 데모: `write.html` → 「예시 · 등록이 막히는 글」

### G · 미성년 가입 시도자
생년월일 2009-06-30 입력 → 「청소년보호법 기준 청소년 · 가입할 수 없습니다」 → 다음 버튼 비활성. 모의 본인확인에서 청소년 인물을 고르면 「가입할 수 없습니다 · 입력 정보 저장 안 함」.
- 경계: 2007-12-31생은 연 나이로 2026년 1월 1일부터 성인(만 18세) → 통과. 민법 기준 토글이면 차단. 의뢰자가 기준을 정해야 함.

### 탈퇴하는 회원
`withdraw.html` → 내 글 N·댓글 M **실제 집계** → 「남기기(탈퇴한 회원 표시) / 모두 삭제」 → 보관 고지(재가입 제한용 식별값 1년) → 버튼 2단계 → 완료 + 웹 삭제 링크(플레이 요건).

## 6. 비는 구멍 (미팅 확인 필요)

1. 청소년 판정 기준 — 청소년보호법(연 나이) vs 민법(만 나이)
2. 성인확인 수단 — 본인확인기관 계약 주체·비용, 자기신고 허용 여부와 권한 범위
3. 비회원 열람 범위 — 목록/본문/사진/검색엔진 노출
4. 강원랜드 게시판 허용 주제 — 숙소·교통·맛집만인가, 게임 후기까지인가. 금지 목록 확정
5. 마카오·필리핀 카지노 언급 범위
6. 업체 회원 정책 — 가입 허용, 배지, 제휴 표시, 홍보 전용 게시판
7. 신고 처리 주체·시간·자동 가림 기준·이의제기 절차
8. 블라인드 vs 삭제 — 댓글 처리, 작성자 본인 열람
9. 답글 깊이(1단 권장)와 원댓글 삭제 시 자리 유지
10. 탈퇴 시 글·댓글 처리 기본값, 강제 탈퇴자 재가입 제한 기간
11. 소셜 계정 충돌(카카오 가입자가 네이버로 로그인) 병합 규칙
12. 사진 한도(장수·용량·동영상)
13. 앱 배포 방식 — 스토어 출시(AAB) vs APK 직접 배포, 계정 명의, iOS 포함 여부(공고 태그에만 iOS)
14. 푸시 알림 포함 여부
15. 공지 고정 범위(전체/게시판별)
16. 인기글 산정 가중치·광고 글 제외 기본값
17. 검색 범위
18. 기존 네이버 카페 회원·글 이관 여부
19. 배너 클릭 집계 보고 필요 여부

## 7. 의뢰자 기획의 잘된 부분
1. **모바일 웹 → 웹뷰 패키징 순서**가 맞습니다. 코드베이스 하나로 웹·앱을 운영해 400만 원 예산에 현실적입니다.
2. **미성년 가입 제한을 필수 과업으로** 넣었습니다. 대부분의 커뮤니티 공고가 빠뜨리는 항목입니다.
3. **IA가 이미 정해져 있습니다.** 3대 메뉴, 지역 탭 × 분류, 라운지 5종이 네이버 카페 문법과 맞아 45일 일정이 성립합니다.
4. **배너의 노출 순서·URL 연결까지 정의**해 수익 모델이 구체적입니다.
