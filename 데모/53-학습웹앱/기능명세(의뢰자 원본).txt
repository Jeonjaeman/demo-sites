아하(Aha) 문법 — 개발 견적요청 및 진행계획서
개발사/개발자 전달용 · v2.0 (1차 MVP 확정본)

1. 프로젝트 개요
질문형(추론형) 방식으로 영어 문법을 학습하는 웹앱과, 콘텐츠(문법 유닛)를 강사가
직접 등록·관리하는 CMS를 만드는 프로젝트입니다.
목적: 자체 학원 학생들의 문법 학습 지원이 1차 목적이며(수익화 대상 아님), 이후 세
미나를 통해 도입을 원하는 타 학원에 라이선스 형태로 제공하는 것이 2차 목적입니다.
핵심 원칙: 개발자는 앱과 CMS라는 '틀'만 만듭니다. 콘텐츠는 전적으로 운영자가
CMS를 통해 직접 채워 넣습니다.
참고 레퍼런스: https://eloquent-bombolone-ea3f28.netlify.app (현재 운영 중인 샘플
앱, UI 톤과 인터랙션의 기준이 됩니다)

2. 전체 개발 단계
이번 발주는 1차(MVP)만 포함합니다. 2차는 실제 도입 학원이 확보된 시점에 별도 발주합니다.
- 1차(이번 발주): 학생용 웹앱 + CMS(콘텐츠 등록/게시). 우리 학원에서 바로 파일럿 운영 가능한 범위.
- 2차(추후 별도 발주): 도입 학원 계정, 90일 무료체험 자동 만료, 구독 상태 수동 전환 등 도입 학원 관리 기능.

3. 1차 MVP 상세 범위

3.1 학생용 웹앱
웹앱(브라우저 기반)입니다. 네이티브 앱(앱스토어 설치형)이 아닙니다. 태블릿 터치와
마우스 클릭 모두 지원해야 합니다.
- 학습 흐름(문법 유닛 1개 기준): 질문 → 그림/예시 선택 → 추론 질문 → 선택형 답
  변(오답 시 1줄 힌트만 제공 후 진행) → 설명 → Aha! 정리 → 응용 질문 3~4개 →
  백지테스트 안내로 마무리
- 그림/예시는 이미지 업로드 대신 이모지 또는 고정 아이콘 세트 사용 (스토리지·업
  로드 로직 불필요, 비용 절감)
- 로그인 없음, 개인 데이터 저장 없음. 강사가 지정한 유닛을 목록에서 골라 진행
- 동일 유닛 재학습 시 선택지 순서 랜덤화 등 최소한의 변화 장치 (순서 암기로 통과
  하는 것 방지)
- 가능하면 PWA 설정(홈 화면 아이콘 추가) 포함 — 개발 범위 내 경미한 추가 작업

3.2 CMS (콘텐츠 관리)
- 유닛 등록 폼: 제목, 핵심 질문, 예시(이모지 선택), 추론 질문, 선택지, 오답 힌트, 설명, Aha 문장, 응용 예시 3~4개
- 게시 즉시 학생 앱에 반영 (별도 승인 절차 없음)
- 복제(Duplicate) 기능 — 기존 유닛을 복제해 새 유닛 빠르게 제작
- 검색 기능 (제목/키워드)
- 미리보기는 별도 화면 대신 게시 후 실제 학생 화면 링크를 새 탭으로 확인하는 방식으로 간소화 가능
