# AHA! 문법 — 추론형 영어 문법 학습 웹앱 + CMS (제안용 데모)

"아하(Aha) 문법 — 개발 견적요청 및 진행계획서 v2.0 (1차 MVP)" 대응.
지정 레퍼런스(netlify 샘플 앱)를 **20화면 전체 실측**해 UI 톤·인터랙션을 그대로 잇고,
공고의 1차 MVP 범위(학생 웹앱 + CMS)를 **전부 동작하는 형태**로 구현했습니다.

| 표면 | 내용 | URL(별칭) |
|---|---|---|
| 학생 웹앱 | 유닛 목록 → 학습 흐름 8단계 → 백지테스트·인쇄 | `…/aha/` |
| CMS | 유닛 등록·게시(즉시 반영)·복제·검색·미리보기 | `…/aha/admin.html` |

## 공고 요구 → 데모 매핑 (전부 동작)
- **학습 흐름 8단계 그대로**: 질문 → 그림/예시 선택(이모지) → 추론 질문 체인 → 선택형 답변(**오답 시 1줄 힌트만 제공 후 진행** — 정답 표시·재시도 없음) → 설명(HUNT) → Aha! 정리 카드 → 응용 3~4개 → 백지테스트 안내(+AHA NOTE 인쇄)
- **이모지/고정 아이콘**: 이미지 업로드 로직 자체가 없음 (공고 비용 절감안 그대로)
- **로그인·개인 데이터 없음**: 저장하는 개인 데이터 0 — 화면에 명시
- **선택지 랜덤화**: 유닛 시작 시 전 문항 셔플 — "처음부터 다시"를 누르면 순서가 바뀌는 걸 바로 확인
- **PWA**: manifest + 최소 서비스워커 — 홈 화면 추가 설치
- **CMS**: 공고 폼 필드 전부(제목·핵심질문·예시 이모지 팔레트·추론 질문/선택지/정답/힌트·설명·Aha 문장·응용 3~4) · 게시 즉시 학생 앱 반영(승인 없음) · **모든 유닛 수정 가능**(샘플 유닛도 수정하면 수정본이 학생 앱에 반영, 「원본 복원」으로 되돌리기) · 복제 · 검색 · **미리보기 = 실제 학생 화면 새 탭**(공고 간소화안)

## 체험 시나리오 (클릭만)
1. 학생 앱 → "셀 수 없는 명사의 비밀" → START → 빵 고르기 → 추론에서 **일부러 틀려보기** → 1줄 힌트 확인
2. 끝까지 진행 → Aha! 카드 → 응용 4문항 → 백지테스트 시트 → "AHA NOTE 인쇄"
3. "처음부터 다시" → 선택지 순서가 바뀐 것 확인 (랜덤화)
4. CMS → 프리필된 "some과 any" 그대로 **게시** → 학생 앱 목록에 즉시 등장
5. CMS → 샘플 유닛 **복제** → 검색("명사") → **미리보기** 새 탭

## ⚠️ 착수 전 확인 (미팅)
추론 질문 권장 개수 · 응용 문항 유형(모두 고르기 포함 여부) · 백지테스트 커스텀 여부 · 유닛 공개 범위 · PWA 오프라인 범위 · 2차(라이선스) 대비 데이터 구조 · 호스팅

## 레드팀 4종 검수 결과
- **① 디자인**: 레퍼런스 실측값 그대로(색·radius·타이포·게이팅) — 같은 계열로 보이는지 기준
- **② 인터랙션**: 선택지 stagger·정답 pop/오답 shake·힌트 슬라이드·Aha 카드·진행바
- **③ 실측 QA**: 오버플로 0 · 콘솔 0 · 자동 완주 통과(finish·시트·인쇄 버튼·진행 100%)
- **④ 요구사항 충족(발주 문서 조항별)**: 11항 전항 ✓ — "오답 시 1줄 힌트만 제공 후 진행"·"미리보기=새 탭" 문구 그대로 (분석/기획_설계.md 3장)

## 검증 결과
- 유닛 목록 2 → 커버 → 예시 5(선택 전 다음 비활성) → 추론(오답 힌트+정답 표시) → 완주(시트·Teacher Check·인쇄·재시작·진행 100%)
- CMS: 프리필 게시→목록 3·학생 앱 4유닛 반영 · 검색 1건 · 복제 · 미리보기 딥링크 — 전부 통과
- 랜덤화: 재시작 4회 비교로 순서 변화 확인 · 콘솔 에러 0 · 오버플로 0
