업무 내용

[프로젝트 개요]
- 국제 청소년 창작 어워드 플랫폼

[프로젝트 배경 및 목표]
국내외 청소년이 다양한 창작 분야(미술, 도서·문학, 음악, 공연, 디자인, 미래창작)의 국제 공모전을 확인하고 온라인으로 작품을 출품하며, 심사 결과와 해외 전시·출판·공연 프로그램까지 확인할 수 있는 통합 플랫폼을 구축합니다. 단일 공모전 홍보 사이트가 아니라 국가·도시·장르를 지속적으로 추가할 수 있는 확장형 운영 플랫폼으로 설계하며, 참가자·보호자, 심사위원, 관리자 3개 사용자 유형별 화면과 권한을 제공합니다.

[과업 범위]
1. 수행 범위
- 상세 기획: 정보구조(IA) 설계, 화면 전환 플로우 설계, 관리자 기능 정의
- UI/UX 디자인(PC/태블릿/모바일 반응형, 클릭 가능한 프로토타입 포함)
- 프런트엔드/Client 개발
- 백엔드 개발
- 서버/DB/인프라 구성
- 다국어(영어/한국어) 처리
- 결제(PG) 연동

2. 상세 기능 요구 사항
2-1. 메인/공통
- 다국어 전환: 영어 기본, 한국어 전환 기능 제공
- PC 헤더: 로고, 공모전, 전시·공연, 수상작, GYCA소개, 공지사항, 로그인, 작품접수 메뉴
- 모바일 헤더: 로고, 작품접수, 햄버거 메뉴(세로 드로어)
- 메인 구성: Hero, 현재 접수 중인 공모전 카드(3개), GYCA 프로그램(분야별), Global Stages(도시별), Featured Winners, News&Notice, Footer
- 로그인 상태에 따라 로그인 버튼이 마이페이지 버튼으로 전환

2-2. 공모전(AWARDS) 관리
- 공모전 목록: 분야, 도시, 상태(접수예정/접수중/심사중/결과발표/종료) 필터 및 검색
- 공모전 상세페이지: 개요, 주제, 모집부문, 참가대상, 제출작품, 심사기준, 전체일정, 시상 및 혜택, 해외본선, 참가비, 유의사항, FAQ 표준 템플릿
- 관리자의 공모전 생성/기존 공모전 복사: 국가, 도시, 분야, 공모전명, 접수기간, 참가연령, 참가비, 모집요강, 제출자료, 심사방식, 수상내역, 협력기관, 결과발표일 개별 설정
- 협력기관 노출 상태 구분: 계약·협력 확정 전에는 공식 Partner로 표시되지 않도록 관리자가 상태 제어
- 신규 공모전 등록 시 메인 화면 자동 노출

2-3. 회원/인증
- 회원 유형: 학생/보호자, 기관, 심사위원, 관리자
- 미성년자 보호자 동의 프로세스
- 단일 로그인 화면에서 계정 권한별로 참가자/심사위원/관리자 대시보드로 자동 분기

2-4. 작품 접수(APPLY) 시스템
- 접수 5단계: 01 참가자정보 → 02 작품정보 → 03 파일업로드 → 04 확인/결제 → 05 접수완료
- 공모전·분야(미술/도서/음악 등)별로 제출품 항목 상이하게 설정
- 파일 업로드: 이미지, PDF, 영상 URL, 음원, 포트폴리오 등 항목별 미리보기 제공
- 단계 이동 시 자동 임시저장, 이탈 후 재로그인 시 이어서 작성 가능
- 접수완료 화면: 접수번호, 접수증(PDF), 결제정보, 결과발표일 안내

2-5. 결제
- 참가비 결제 및 환불규정 동의
- 결제 성공/실패 분기 처리(실패 시 재시도, 문의 안내)
- 해외 본선 참가비 별도 결제

2-6. 참가자 마이페이지
- 탭 구성: 내 접수, 심사 결과, 결제 내역, 인증서, 개인정보
- 접수 상태(임시저장/접수완료/심사중/본선진출/최종수상)별 버튼 및 이동 분기
- 수상 등급(Grand Prize/Gold/Silver/Bronze/Finalist) 노출
- 인증서(영문/국문) 다운로드
- 해외 본선 신청(장소, 일정, 참가비, 등급별 지원내역, 여권 영문명) 및 결제

2-7. 심사 시스템
- 심사위원 대시보드: 담당 공모전, 배정 작품 수, 심사 완료/잔여, 마감일 KPI 표시
- 심사 화면: 작품(이미지/영상/PDF/음원), 평가항목(창의성, 주제이해, 표현력, 완성도, 발전가능성), 심사평 입력, 이전/임시저장/심사완료/다음작품 버튼
- 공정성을 위해 참가자 이름·소속 등 식별정보 기본 비공개 처리
- 심사완료 확정 시 최종 확인창 및 제출 후 점수 수정 제한 여부 안내

2-8. 수상작(WINNERS)/국제프로그램/전시·공연
- 수상작 갤러리: 연도, 분야, 국가, 수상등급 필터 및 검색(참가자명, 접수번호, 작품명, 국가, 부문)
- 수상작 상세: 작품, 참가자 공개정보, 작품설명, 수상명, 심사평
- 미성년자 개인정보 공개범위를 관리자 및 보호자 동의 기준으로 설정 가능
- International 페이지: 도시(비엔나, 스폴레토, 프라하, 바르셀로나, 뉴욕 등) 기반 UI, 도시 클릭 시 해당 도시의 공모전/전시/공연/출판 프로그램 노출
- 전시(Exhibitions), 공연(Performances) 아카이브 페이지: 장소, 일정, 참여작가/연주자, 사진, 영상

2-9. 관리자 대시보드
- 메뉴: 공모전관리, 접수자관리, 작품관리, 심사위원관리, 심사배정, 결제관리, 결과발표, 인증서발급, 해외본선관리, 공지·문의관리
- 접수관리: 검색·필터·수정이력·엑셀 다운로드
- 심사관리: 심사위원 등록, 작품 자동/수동 배정, 진행률 확인
- 결과관리: 수상등급 지정, 공개 예약, 참가자 알림 발송
- 인증서: 영문·국문 인증서 일괄 생성 및 다운로드
- 커뮤니케이션: 대상자별 이메일·문자·공지 발송

* 첨부파일 참고 부탁드립니다.
