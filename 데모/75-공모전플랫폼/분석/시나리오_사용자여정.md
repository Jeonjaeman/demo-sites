> 가상 어워드 「GYCA — Global Youth Creative Awards」. 모든 공모전·수상자·작품은 가상.

## 1. 등장인물
| 인물 | 원하는 것 | 불안한 것 |
|---|---|---|
| 참가 학생(국내) | 국제 수상 이력·인증서·해외 전시(입시 포트폴리오) | 참가비가 아까울지, 진짜 어워드인지, 심사가 공정한지 |
| 참가 학생(해외) | 접수·결제가 자기 나라 방식으로 | 원화 결제·한국 시각 마감·한글 안내 |
| **보호자** | 자녀 정보 공개 통제·총비용 | 아이 실명·사진이 남는 것·수상 후 추가 결제 |
| 심사위원(국제) | 작품만 보고 빠르게 채점 | 제자·자국 참가자를 모르고 심사·점수 수정 불가 |
| 관리자(의뢰자·IT 경험 없음) | 개발자 없이 공모전 복제·개설·통합 운영 | 마감 서버·결제 사고·**협력기관 계약 전 노출** |
| 협력기관(La MaMa 등) | 로고·명칭이 승인 범위 안에서만 | 계약 전 "Official Partner" 표기 |

★ 겸업: 보호자 = 동의자+결제자+철회자(한 계정에 묶여야 증명 가능) · 심사위원 = 심사자+본선 멘토(이해충돌) · 관리자 1인 = 운영+정산+개인정보 처리자(위험 동작 로그가 유일 방어선).

## 2. 시간순 여정 (설계서 없는 지점 = 발견)
발견(다국어 없으면 이탈) → 요강 정독(부문별 제출물 다름) → **신뢰 검증(참가비 어워드 = vanity 의심 기본값 → 심사위원·배점·통계 없으면 결제 전 이탈, F-16)** → 가입·동의(**14세 미만 체크박스만 = 위법, F-02/03**) → 접수 01 참가자(여권 영문명 여기서) → 02 작품(부문별 폼) → **03 업로드(파일 메타데이터에 실명 → 블라인드 깨짐, F-06)** → 이탈·복귀(임시저장) → **04 결제(미성년 단독 = 취소 가능, F-01)** → 결제 실패/제3상태 → 05 완료(접수증) → 심사 대기(진행 표시 없으면 문의 폭주·환불 요청) → **심사(이해충돌·점수 편차 미보정, F-07/08)** → 결과 확정(동점·정원) → **결과 발표(미수상자 화면이 설계서에 없음 — 대다수가 보는 화면)** → 인증서(검증 수단, F-20) → **수상작 공개(미성년 실명·사진 범위·저작권 근거, F-13/04)** → 본선 진출 → **본선 결제(총비용 공개 없으면 전환 안 됨, F-16)** → 해외 이송(**국외이전 동의, F-05**) → 전시·공연 → 사후(삭제 요구권).

## 3. 역할별 시야 차이 (같은 작품, 세 화면 = 권한 매트릭스)
| 데이터 | 참가자 | 심사위원 | 관리자 |
|---|---|---|---|
| 이름·학교 | 본인 전체 | **비공개(접수번호만)** | 전체+열람 로그 |
| 업로드 파일 | 원본 파일명 | **익명화본(파일명=번호, 메타 제거)** | 원본+익명화본 |
| 점수 | 최종 등급만 | 자기 점수만(담합 방지) | 전 위원+편차·정규화 |
| 결제 정보 | 본인 영수증 | **접근 불가**(참가비 낸 사람 편향 차단) | 전체+환불 |
| 이용허락 범위 | 본인이 고른 값 | 접근 불가 | 전체 — **미허락 항목은 게시 버튼 비활성** |
→ 데모 「역할 전환」(mypage↔judge↔admin 버튼)이 이 표를 말이 아니라 화면으로 증명 + 타이핑 없이 체험(경쟁은 로그인 게이트).
