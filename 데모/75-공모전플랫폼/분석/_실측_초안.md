### 1-4. 요강(공모 안내) 페이지 문법 — 실측 섹션 순서

**Scholastic 「How to Enter」** — 번호 붙인 3스텝, 각 스텝이 대문자 CTA로 끝난다
```
1. CREATE YOUR ACCOUNT   → 「We'll ask for:」 수집 항목을 가입 전에 전부 나열
                            (이름·학년·이메일·보호자 성명과 이메일·집주소·학교)
                            → CTA: CREATE YOUR ACCOUNT
2. UPLOAD YOUR WORK      → 「부문이 제출물을 결정한다」(사진 장수·글자수 등)
                            글쓰기는 포털 텍스트 필드 직접 입력, PDF 불가
                            교사(educator)를 작품에 연결 → 교사가 편집·결제 가능
                            → CTA: VIEW CATEGORIES / TIPS FOR DOCUMENTING YOUR WORK
3. PAY FOR YOUR ENTRY    → $15/건 · $40/포트폴리오 · 지역별 결제수단(Stripe·현금·수표·학교 일괄)
                            → fee waiver(참가비 면제) 운영, 증빙 요구 안 함
```
**GYCA에 직결되는 4가지 (전부 리서치 발견과 맞물림)**
1. **수집 항목 사전 공개** — 「We'll ask for:」에 *보호자 성명·이메일*이 명시. F-02 연령 게이트를 문서가 아니라 **가입 전 화면 문구**로 처리한 사례.
2. **제3자 대납 구조** — 교사가 학생 작품에 연결되어 **결제를 대신 완료**한다. F-01(미성년 단독 결제 취소권)의 실제 업계 해법이 "보호자/교사 결제 경로"임을 보여주는 근거.
3. **글쓰기 부문 PDF 불허 · 텍스트 필드 입력** — 결과적으로 PDF 메타데이터 유출(F-06)이 원천 차단된다.
4. **fee waiver** — F-16(vanity award 의심 해소)의 표준 장치. 문구 요지는 "재정 증빙을 요구하지 않고 신뢰한다, 낼 수 있으면 내 달라(비영리 운영)".

**James Dyson Award 「How to enter」** — 아이브로 + H2 쌍으로 7블록
```
TAKE YOUR FIRST STEP (H1)
ELIGIBILITY REQUIREMENTS        → Who can enter?        (개인/팀, 팀 리더 자격 조건)
PARTICIPATING COUNTRIES...      → Invention knows no limits (참가 가능 28개국 전체 열거)
PAST WINNERS                    → Where are they now
STEP-BY-STEP                    → HOW JUDGING WORKS     (3단계 × 월 라벨 × 심사 주체·기준)
                                → WHAT WE NEED TO SEE   (H4: Images / Video)
IP and Copyright                → Know your rights      (H4 2개)
```
- **HOW JUDGING WORKS**: Stage 1(7~9월, 국가별 전문가 패널 3건 선발) → Stage 2(9월, Dyson 엔지니어 20건으로 압축) → Final(10월, James Dyson 본인 + IP팀 특허 저촉 검토). **누가·언제·무엇을 보는지**를 전부 공개 = F-16 신뢰 장치.
- **참가 가능 국가 전체 열거** = F-03(국가별 동의 연령 분기)의 UI 진입점이 이미 존재해야 함을 보여준다.
- 제출 정보가 **"공모 갤러리에 그대로(word for word) 게시된다"**고 미리 고지 + **"영어로 제출해야 한다"**는 언어 정책 명시.

```

March 9, 2026, 2 PM CET    Extended Submission Deadline      ← ★ 마감에 시각+타임존

### 1-5. 빈 상태(empty state) 문법 — Scholastic 갤러리 실측

접속 시점(2026-09-01) Scholastic 온라인 갤러리는 연례 점검 중이었고, 화면에는 **이유 + 돌아올 시점**이 한 문장으로 안내되어 있었다(가을에 다시 오라는 취지). 404 페이지도 빈 화면이 아니라 **6개 복구 경로**(참가 방법·장학금·프로그램·갤러리·후원·내 지역)를 제시한다.

--color-lightGray  #f6f6f6
--color-white      #fff        ← 본문 텍스트
```
→ **다크 베이스(#111) + 액센트 3색(골드·블루·오렌지) + 뉴트럴 2단.** 「국제 어워드의 품격 = 절제된 2~3색 + 골드」에 대한 **실측 근거**가 바로 이것이다.

**타이포**
| 요소 | 실측 |
|---|---|
| H1 | **80px / lh 64px = 0.800 / w400 / ls −0.04em / `Clarkson` / #fff** |
| 리드 본문 | **24px / 26.4px = 1.100 / w400 / ls −0.02em** |
| 특징 | 굵기가 아니라 **크기와 자간**으로 위계를 만든다 (w400인데 80px) |

**그리드 (rem = 10px, `62.5%` 기법)**
```
--columns 12 · --columnWidth 9.5rem(95px) · --columnGap 2rem(20px) · --sideMargin 4rem(40px)
--headerHeight 8.8rem(88px) · --bottomMargin 3.6rem(36px) · --arrowGap 2rem(20px)
검증: 12×95 + 11×20 = 1,360px  → max-width 1360px 실측과 일치. 본문 칼럼 720px.
```

**인터랙션**
```
transform 51개 · will-change 73개
라이브러리 : GSAP + ScrollTrigger + Lenis + THREE.js
내비 : 「01 Logo · 02 Typography · 03 Color …」 번호형 챕터 내비
로딩 : 「Aa 100%」 타이포그래픽 프리로더 (퍼센트 카운트업)
```
→ **번호형 챕터 내비**는 GYCA 요강의 1~12 번호 구조와 같은 문법이다. 의뢰자 설계서의 번호 매김이 "촌스러운 나열"이 아니라 **어워드급 에디토리얼 장치**로 승격될 수 있음을 보여준다.

### 3-4. B-3 · Prix Ars Electronica — 기관 레퍼런스 (수상작 아님)

*선정 이유: 1987년부터 운영되는 국제 창작 어워드. **오픈소스 폰트로 기관 권위를 만드는 방법**의 실물.*

본문  : 20px / 32px (1.600)   ← 넉넉한 행간 = 기관 신뢰 톤

구조  : 다크 카드 7개 그리드(Winners · Juries · Categories · FAQ · About

**③ 부문 6색 시스템 (근거: Aardvark `--faq-color-*` 6쌍 base+soft)**

**④ 타이포 — 어워드 수치로 (근거: Aardvark H1 120px/lh 0.800/ls −0.01em, Squarespace H1 80px/lh 0.800/ls −0.04em)**

**⑤ 레이아웃 — 12칼럼 1360px + 풀블리드 3종 (근거: Squarespace 12×95+11×20=1360, Aardvark 전 섹션 100vw)**
