# REONIX 레오닉스 — 반도체 제조 기업 브랜드 사이트 (데모)

위시켓 「반도체 제조 기업 웹사이트 구축」 공고 대응 데모.
**hanvit-ind.com을 브라우저로 전수 실측**해 같은 단락 구성·인터랙션·애니메이션을
가상 반도체 브랜드로 재구현했습니다 (카피·이미지·코드는 전부 자체 제작 — 메인 페이지만).
**회사·제품·연락처 등 모든 정보는 가상입니다.**

- 데모: https://jeonjaeman.github.io/demo-sites/reonix/

## 구성 (레퍼런스 실측 → 반도체 재해석)

디자인 시스템은 레퍼런스 CSS 선언값을 그대로 이식했습니다 — 컨테이너 94%/1680px,
타이포 vw 스케일(히어로 fz-120·스테이트먼트 fz-80·서브타이틀 fz-58·대형 워드 fz-100),
섹션 상하 m200(192~320px), 카드 radius 20, 헤더 100px, 구조 분기 812px.

| 단락 | 인터랙션 |
|---|---|
| 히어로 (팹 시네마틱 영상 · 100vh) | 라인별 마스크 리빌 (fz-120 Inter 디스플레이) |
| 스테이트먼트 (fz-80) | ★핀 스크럽 — 웨이퍼 영상(27vw·510/290)이 100vw 풀스크린 확장, 오버레이 텍스트, 헤더 자동 숨김 |
| Industries 3카드 (544/652) | 스태거 리빌·호버 줌 |
| Products 5열 (★풀블리드 900px) | ★호버 시 flex 1→1.4 확장·다크 패널 페이드·상세 등장 (모바일: 탭 오픈) |
| Services (100vh 풀블리드) | ★배경 스왑 + 정사각 글라스 카드 3장 — 비활성 blur(40px) 유리 / 활성 흰 배경·scale 1.05·마스크 리빌 |
| R&D | 정사각 영상 + 2×2 리스트 (아이콘 46px) |
| Merit | 4행 — 좌 텍스트 / 우 ★fz-100 대형 워드(Certified·One-Site·Flexible·Reliable), 호버 시 그라디언트 채움 |
| Careers / Catalog | ★풀블리드 2분할 패널 (m130 6%) — 배경 줌·linkBtn 원형 32px |
| GNB (100px) | 투명→솔리드 전환·★호버 메가 패널(슬로건+dep2/dep3)·전체메뉴 오버레이 |

**메뉴·바로가기 클릭 시 페이지 이동 없이 토스트로 안내합니다** — "페이지 이동은 실제 작업 시 반영" (데모 범위: 메인 1페이지).

## 미디어

전부 Higgsfield 생성 (실존 IP·로고·텍스트 배제):
- 영상 3편 (팹 클린룸·웨이퍼 매크로·연구 장비) — 1440p 압축 311~569KB, 뷰포트 밖 자동 정지
- 이미지 15장 (산업 3·제품 5·서비스 배경 3·배너 2·포스터 2) — webp 10~154KB

## 기술

- 순수 HTML/CSS/JS — **외부 라이브러리 0** (레퍼런스의 GSAP ScrollTrigger·Lenis 연출을
  sticky + 스크롤 진행도 보간으로 자체 구현)
- prefers-reduced-motion 대응 · 백그라운드 탭 rAF 정지 시 동기 폴백
- 반응형: 1080px(그리드 재배치) · 812px(전체메뉴 전환·sec4 탭 오픈·모바일 스크럽 경로)

## 체험 시나리오

1. 스크롤만 하세요 — 히어로 리빌 → 스테이트먼트에서 화면이 잠기며 영상이 풀스크린으로 확장
2. Products 5열에 마우스를 올리면 해당 제품이 넓어지며 상세가 열립니다
3. Services 리스트를 호버하면 배경 전체가 바뀝니다
4. 상단 메뉴 호버 → 메가 패널(2·3뎁스), 클릭 → "실제 작업 시 반영" 토스트
5. 우상단 햄버거 → 전체메뉴 오버레이
