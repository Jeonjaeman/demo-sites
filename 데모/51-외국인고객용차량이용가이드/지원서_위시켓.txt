[1] 핵심 검토 3가지

1. 현위치 지도는 위치기반서비스사업 신고 대상입니다.
   이용자 현재 위치를 수집해 주변 지점을 보여주는 순간 위치정보법상 LBS
   신고와 개인위치정보 동의가 필요합니다. 데모는 동의 게이트(거부 시 목록만)
   + 위치 미저장 원칙으로 설계했고, 신고 주체·일정을 착수 전에 확정하는
   것이 안전합니다. 미신고 기간에는 목록만 먼저 오픈하는 단계안도 가능합니다.

2. 안전 문구의 오역은 "품질 수용"과 별개의 배상 리스크입니다.
   경유/가솔린 오주유, 경고등 대처가 잘못 번역되면 분쟁이 됩니다.
   → 데모는 주의사항에 기계번역 배지 + 한국어 원문 병기를 적용했고,
   운영에서는 렌터카 용어집(주유·보험·반납)으로 번역 품질을 고정합니다.

3. 반납 시점이 렌터카 분쟁의 최다 구간이라, 체크리스트를 앱에 넣었습니다.
   연료·소지품·외관 사진 4장·지정 주차·키 반납을 게이지로 체크하는 화면을
   공고 요구에 더해 제안합니다. 고객은 분쟁을 예방하고, 지점 스태프는
   확인 작업이 줄어듭니다. (범위 조정 가능한 추가 제안입니다)

그 외 - QR 즉시 열림과 스토어 배포는 모바일웹+하이브리드 셸 구조로 풀고
   (순수 웹뷰는 정책 4.3 반려 리스크), 번역은 저장 시 1회 번역+캐시로
   조회당 API 비용을 0원으로 고정하며, QR은 차종 고정 링크라 원고를
   수정해도 재인쇄가 필요 없습니다.

[2] 요구사항 반영 현황 (데모에서 확인)

  QR/링크 진입 → 차종 가이드 자동 열람     ✓ 딥링크 + 실스캔 QR
  게시글형 가이드(특징·주의사항·비상연락처)  ✓ 아코디언 4섹션·탭투콜
  다국어 자동 표시(EN·中·日, 한국어 원고)   ✓ 언어 온보딩·기계번역 배지·원문 병기
  주변 지점·반납 장소 지도(경로 아님)        ✓ 동의 게이트·거리 정렬
  문의 = 기존 채팅 외부 연결(신규 아님)      ✓ 화면에 명시
  관리자 등록·수정·삭제 + QR·링크 발급       ✓ 수정해도 QR 불변 + A4 인쇄 시트
  스코프 밖(예약·결제·내비·신규 채팅 등)     미포함 확인 — 화면 문구로 명시
