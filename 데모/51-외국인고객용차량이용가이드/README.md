# KEYRING 키링 — 외국인 고객용 차량 이용가이드 앱 (제안용 데모 · v2)

위시켓 공고(외국인 고객용 차량 이용가이드 모바일 앱 개발, 협의·80일) 대응.
공고의 사용자 스토리를 **실제 앱 흐름(3파트 7화면 + 하단 탭)**으로 만들었습니다 —
언어 온보딩 → QR 스캔 → 가이드 자동 열림 → 반납 체크리스트 → 지점 지도 → 기존 채팅 연결.

## v2에서 좋아진 것 (재작업 포인트)
- **하단 탭 5개(홈·가이드·반납·지점·문의)** — 화면 나열이 아니라 실제 앱 네비게이션
- **언어 온보딩** — 첫 스캔 시 4개 언어 대형 버튼(여행자 UX), 이후 상단 스위처
- **가이드가 게시글→아코디언 4섹션**(시동·기어/주유·충전/주의사항/반납 안내)으로 구조화
- **반납 체크리스트 신설** — 연료·소지품·사진 4장·지정 주차·키 반납, 체크 게이지·완료 안내 (반납 분쟁 = 렌터카 최다 분쟁 구간을 기능으로 방어)
- **관리자 A4 인쇄 시트** — 차종명+QR+4개 언어 안내를 인쇄 레이아웃(@media print)으로, 버튼 한 번에 인쇄
- 이모지 전량 제거 → **자체 SVG 라인 아이콘 18종**

## 핵심 구현
- **QR → 자동 열림**: 카드 탭=스캔 시뮬 + `#car=` 딥링크 — 관리자 발급 QR을 실제 폰으로 찍으면 해당 차종이 열림(qrcodejs)
- **자동번역 표시**: 3차종 × KO/EN/中/日 — 기계번역 배지, **안전 주의사항 한국어 원문 병기**
- **지도**: 위치 동의 게이트(동의=현위치 거리 정렬/거부=목록만) · 캔버스(dpr) · "경로 안내 아님" 명시
- **문의**: 기존 상담 채팅 외부 연결(신규 채팅 아님 — 공고 스코프)
- **관리자**: 한국어 원고 등록(프리필)→QR·링크 즉시 발급, 수정해도 QR 불변, 미리보기 링크

## 체험 시나리오 (클릭만)
1. 언어에서 English → QR 카드(Electric SUV) 탭 → 가이드 자동 열림(EN·기계번역 배지)
2. 주의사항 아코디언 → 영어 항목 아래 한국어 원문 병기 확인 → 日本語로 전환
3. 하단 탭 「반납」 → 체크 5개 탭 → 게이지 100% → 완료 안내
4. 「지점」 → 위치 동의 → 거리 정렬 / 거부 시 목록만
5. 관리자 → 「등록 + QR 발급」(프리필) → QR 실스캔 → 「A4 인쇄 시트」 버튼 → 인쇄 미리보기
