# KEYRING 키링 — 외국인 고객용 차량 이용가이드 앱 (제안용 데모)

위시켓 공고(외국인 고객용 차량 이용가이드 모바일 앱 개발, 협의·80일) 대응.
공고의 **사용자 스토리 4건을 그대로 동작하는 흐름**으로 만들었습니다 —
QR 스캔 → 차종 가이드 자동 열림 → 자동번역 표시 → 주변 지점 지도 → 기존 채팅 연결.

| 표면 | 내용 | URL(별칭) |
|---|---|---|
| 고객 앱 (폰 프레임) | QR 진입·가이드·지도·문의 4화면 | `…/keyring/` |
| 관리자 | 가이드 등록·수정·삭제 + QR·링크 발급 | `…/keyring/admin.html` |

베이스: `https://jeonjaeman.github.io/demo-sites/`

## 핵심 구현
- **QR → 자동 열림**: 카드 탭 = 스캔 시뮬 + `#car=` 딥링크 — **관리자에서 발급한 QR을 실제 휴대폰으로 찍으면 해당 차종 가이드가 열립니다** (qrcodejs로 실생성)
- **자동번역 표시**: 차종 3종 × KO/EN/中/日 — 기계번역 배지, **안전 주의사항은 한국어 원문 병기**(오역 분쟁 차단 설계)
- **게시글 가이드**: 차량 특징·주의사항·비상연락처(탭투콜) — 이미지+텍스트
- **지도**: **위치 동의 게이트**(동의 시 현위치 기준 거리 정렬 / 거부 시 목록만) · 캔버스 지도(dpr) · "경로 안내 아님" 명시
- **문의**: 기존 외국인 상담 채팅 **외부 연결** (신규 채팅 아님 — 공고 스코프 그대로)
- **관리자**: 한국어 원고 등록(프리필) → 저장 즉시 QR·링크 발급 · 수정해도 QR 불변(재인쇄 불필요) · 등록한 차종이 고객 앱에 실반영

## 체험 시나리오 (클릭만)
1. QR 카드(전기 SUV) 탭 → 가이드 자동 열림 (기본 EN·기계번역 배지)
2. 언어를 日本語로 → 전체 화면 즉시 전환, 주의사항엔 한국어 원문 병기
3. 지도 → 위치 동의 → 현위치 기준 거리 정렬 / "동의 없이"를 누르면 목록만
4. 문의 → 기존 채팅 외부 연결(새 창 시뮬)
5. 관리자 → "등록 + QR 발급" 클릭(프리필) → QR 발급 → 휴대폰으로 스캔하면 실제로 열림

## ⚠️ 착수 전 확인 (미팅)
LBS(위치기반서비스) 신고 주체·일정 · 번역 엔진·비용 부담 · QR 발급 주체 · 기존 채팅 연동 조건 · 지점 데이터 관리 주체 · 스토어 배포 방식(하이브리드)

## 디자인·기술
- 클린 화이트 + 트러스트 블루 · 여행자용 큰 터치 타겟 · Pretendard
- 정적 HTML/CSS/JS + qrcodejs(QR 실생성) · 지도 캔버스 자체 구현(dpr)
- 차량 3종 AI 생성(실존 모델·번호판·로고 없음 검수)
- 실구축 제안: 모바일웹 + 하이브리드 셸(스토어용) · 번역은 저장 시 1회+캐시

## 레드팀 4종 검수 결과
- **① 디자인**: 차량 이미지 3종 검수 통과(프레임·텍스트 없음) · 단일 블루 액센트 일관
- **② 인터랙션**: QR 스캔라인·화면 전환·언어 즉시 전환·탭투콜·동의 게이트 전환·토스트
- **③ 실측 QA**: 4화면 × 폰 프레임 rect 전수 — 오버플로 0 · 콘솔 에러 0
- **④ 요구사항 충족(클라이언트)**: 요구 7항 전부 구현 + 스코프 밖 7항 미포함을 화면 문구로 명시("경로 안내 아님"·"기존 채팅 연결") + 협의 항목은 확인 요청으로 배치

## 검증 결과
- QR 스캔→가이드 자동·EN 기본·기계번역 배지·원문 병기·日 전환·동의 게이트 전/후(— → km)·지도 렌더·외부 채팅·딥링크(#car=van) — **11개 체크 전부 통과**
- 관리자: QR 실렌더·등록→목록 4행·신규 차종 딥링크 QR — 통과

> 회사·지점·차종·연락처 전부 가상이며, 차량 이미지는 AI 생성(실존 모델 아님)입니다.
