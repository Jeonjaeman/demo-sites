# KEYRING 키링 — 시나리오·사용자 여정

> 모든 인물·데이터는 가상입니다.

## 1. 등장인물
| 인물 | 원하는 것 | 불안한 것 |
|---|---|---|
| 외국인 고객 (대만 관광객 등) | 지금 탄 차의 사용법을 내 언어로, 검색 없이 | 한국어만 있는 안내지 · 오주유·사고 시 대처 |
| 운영 담당자 (비개발자 1인) | 한국어 원고 하나만 등록하면 끝 | 언어별 4벌 원고 관리 · QR 재인쇄 비용 |
| 발주처 (렌터카 회사) | 계약 즉시 착수·빠른 완료 (1순위 일정) | 콘텐츠 미준비 상태로 시작하는 리스크 |
| 고객센터 | 채팅은 지금 쓰는 그대로 | 채팅이 두 개로 갈라지는 것 |

## 2. 외국인 고객 여정 (시간순)
| 단계 | 상황 | 화면 | 이 기능이 없으면 |
|---|---|---|---|
| 인수 | 차에 붙은 QR 스캔 | 01→02 자동 열림 | 검색·URL 입력 — 현장에서 이탈 |
| 탑승 직후 | 시동·주유구·기어 확인 | 02 특징 | 콜센터 전화 폭주 |
| 언어 | 자동 표시 + 스위처 | 02 langs | 한국어 장벽 그대로 |
| 주행 중 | 경고등·규정 확인 | 02 주의사항(원문 병기) | 오역 사고 → 배상 분쟁 |
| 긴급 | 사고·고장 | 02 비상연락처 탭투콜 | 번호 찾다 골든타임 상실 |
| 반납 전 | 가까운 반납 장소 | 03 지도(동의 게이트) | 지점 헤매다 연체 |
| 궁금증 | 상담 | 04 외부 채팅 연결 | 언어 안 되는 전화뿐 |

## 3. 운영 담당자 여정
| 단계 | 화면 | 데모 동작 |
|---|---|---|
| 신규 차종 도입 | admin 등록 폼(프리필) | 한국어 원고 저장 → **QR·링크 즉시 발급(실스캔 가능)** |
| 원고 수정 | 목록 → 수정 | 같은 QR 유지 — 재인쇄 불필요 |
| 차종 제외 | 삭제 | 인쇄된 QR은 만료 안내로 연결(확인 다이얼로그에 명시) |

## 4. 공고 스코프 대조 (레드팀 ④)
| 공고가 뺀 것 | 데모 처리 |
|---|---|
| 경로 안내·내비 | 지도 하단에 "경로 안내 아님" 명시 |
| 채팅 신규 구축 | "기존 채팅 외부 연결" 문구 + 새 창 시뮬 |
| 언어별 수기 원고 | 관리자에 한국어 입력만 존재 |
| 예약·결제·리뷰 | 미포함 |
| 스페인어 등 추가 언어 | KO/EN/ZH/JA만 |

## 5. 비는 구멍 (착수 미팅 확인)
1. **LBS 신고** — 신고 주체(발주처 명의)·일정. 미신고로 위치 기능 오픈 불가 시 목록만 먼저 오픈하는 단계안
2. **번역 엔진·비용 부담** — 공고 명시 "미지정, 협의" → 착수 주 품질 비교(렌터카 용어 20문장) 후 확정
3. **QR 발급 주체** — 관리자 페이지 발급(데모 방식) vs 별도 처리 (공고 "협의 항목")
4. **승인 단계** — 없음이 기본, 필요 시 노출 토글로 대체 가능
5. **기존 채팅 연동 조건** — URL·전달 파라미터 범위 (공고 명시 확인 필요 항목)
6. **지점·반납 장소 데이터** — 발주처 제공 vs 관리자 직접 관리 (공고 미정)
7. **스토어 배포 여부** — QR 진입 흐름과 심사 리스크 고려한 하이브리드 협의 (공고 미논의 명시)
