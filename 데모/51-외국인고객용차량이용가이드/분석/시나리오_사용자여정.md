## 1. 등장인물
| 인물 | 원하는 것 | 불안한 것 |
|---|---|---|
| 외국인 고객 | 지금 탄 차의 사용법을 내 언어로, 검색 없이 | 한국어 안내지 · 오주유·사고 대처 · 반납 분쟁 |
| 운영 담당자 (비개발자 1인) | 한국어 원고 하나 등록으로 끝 | 언어별 4벌 관리 · QR 재인쇄 비용 |
| 발주처 | 계약 즉시 착수·빠른 완료 (1순위 일정) | 콘텐츠 미준비 상태 리스크 |
| 지점 스태프 | 반납 시 확인 항목이 미리 끝나 있는 것 | 연료·소지품·파손 분쟁 |

## 2. 외국인 고객 여정 (시간순)
| 단계 | 상황 | 화면 | 이 기능이 없으면 |
|---|---|---|---|
| 인수 | 차에 붙은 QR 스캔 | 00 온보딩(첫 1회) → 03 가이드 자동 | 검색·URL 입력 — 현장 이탈 |
| 언어 | 큰 버튼으로 언어 선택 | 00 | 언어 설정을 못 찾음 |
| 탑승 직후 | 시동·기어 확인 | 03 아코디언 「시동·기어」 | 콜센터 전화 폭주 |
| 주유/충전 | 유종·충전구 확인 | 03 「주유·충전」 | **오주유 = 최다 고액 분쟁** |
| 주행 중 | 경고등·규정 | 03 「주의사항」(원문 병기) | 오역 사고 → 배상 분쟁 |
| 긴급 | 사고·고장 | 03 비상연락 탭투콜 | 골든타임 상실 |
| 반납 전 | 준비 확인 | **04 체크리스트(게이지)** | 연료·소지품·사진 분쟁 |
| 반납 장소 | 가까운 지점 | 05 지도(동의 게이트) | 지점 헤매다 연체 |
| 궁금증 | 상담 | 06 외부 채팅 | 언어 안 되는 전화뿐 |

## 3. 운영 담당자 여정
| 단계 | 화면 | 데모 동작 |
|---|---|---|
| 신규 차종 | admin 등록(프리필) | 저장 → **실스캔 QR·링크 즉시 발급** |
| 인쇄 | A4 인쇄 시트 | @media print — 차종명+QR+4개 언어 안내 레이아웃 |
| 수정 | 목록 → 수정 | 같은 QR 유지(재인쇄 불필요) |
| 확인 | 미리보기 | 새 탭에서 해당 차종 딥링크 |
| 삭제 | 삭제 | 인쇄 QR은 만료 안내 연결(다이얼로그 명시) |

## 4. 공고 스코프 대조 (레드팀 ④)
| 공고가 뺀 것 | 데모 처리 |

| 추가 언어 | KO/EN/ZH/JA만 |

## 5. 비는 구멍 (착수 미팅 확인)
1. **LBS 신고** — 주체(발주처 명의)·일정, 미신고 기간 목록만 오픈하는 단계안
2. **번역 엔진·비용 부담** — 착수 주 렌터카 문장 20개 품질 비교 후 확정
3. **QR 발급 주체** — 관리자 발급(데모 방식) vs 별도 (공고 협의 항목)
4. **승인 단계** — 기본 없음, 필요 시 노출 토글로 대체
5. **기존 채팅 연동 조건** — URL·파라미터 (공고 명시 확인 필요)
6. **지점·반납 장소 데이터** — 제공 방식·관리 주체 (공고 미정)
7. **반납 체크리스트의 사진 저장 여부** — 저장하면 분쟁 증빙에 유리하나 보관·파기 정책 필요
8. **스토어 배포 여부** — 하이브리드 협의 (공고 미논의 명시)
