# KEYRING 키링 — 기획·설계 (v2 재작업)

> 외국인 고객용 차량 이용가이드 모바일 앱 개발 (위시켓, 협의·80일·지원 67) · 제안용 데모
> 회사·지점·차종·연락처 전부 가상 · 차량 이미지는 AI 생성(실존 모델 아님)

## 0. 공고 요약
- 렌터카 회사가 외국인 고객에게 **차종별 이용 가이드**를 제공하는 모바일 앱 (Android/iOS + 기획·디자인 포함)
- **QR 스캔 → 해당 차종 가이드 자동 열림** (차종마다 QR·링크 각각 발급)
- 관리자가 등록한 **한국어 원고 → 영어·중국어·일본어 자동(기계) 번역 표시** — 언어별 수기 등록 아님, 품질 저하는 발주처 수용
- 가이드 = 게시글(텍스트+이미지): 주의사항·차량 특징·비상 연락처
- **위치 지도**: 현재 위치 기준 주변 지점·반납 장소 (경로 안내·내비 아님)
- **문의**: 기존 외국인 상담 채팅으로 **외부 연결** (신규 채팅 아님)
- 관리자: 가이드 등록·수정·삭제 + 링크·QR 관리(발급 방식 협의)
- 콘텐츠 거의 미준비 → 유연한 등록 구조 · 승인 단계 없음(협의) · 우선순위: 일정 > 금액 > 완성도

## 1. 명시 vs 숨은 니즈
| 구분 | 내용 |
|---|---|
| 명시 | QR 진입·자동번역·지도·외부 채팅·관리자 |
| 숨은 ① | **현위치 지도 = 위치기반서비스사업 신고** — 개인위치정보 수집 시 LBS 신고·동의 필요 |
| 숨은 ② | 안전 문구(연료 오주유·경고등) **오역 = 배상 분쟁** — 원문 병기 설계 필요 |
| 숨은 ③ | QR → 즉시 열림은 웹이 정답, 순수 웹뷰는 스토어 정책 4.3 반려 리스크 → 모바일웹+하이브리드 셸 |
| 숨은 ④ | 번역 API 비용 — 저장 시 1회 번역+캐시가 정석 (조회당 과금 차단) |
| 숨은 ⑤ | 가이드 수정 시 QR 재인쇄 비용 → **차종 고정 링크 + 내용만 갱신** |
| 숨은 ⑥ | 반납 시점이 분쟁 최다 구간(연료·소지품·파손) → **반납 체크리스트**가 고객·지점 모두를 보호 |
