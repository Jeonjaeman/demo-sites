# ONDO — 시나리오 · 사용자 여정

> 모든 인물·업체는 가상.

## 1. 등장인물

| 인물 | 누구인가 | 원하는 것 | 불안한 것 |
|---|---|---|---|
| 김공장 (58·공장장) | 노안 — 작은 글씨가 부담 | 한 화면에서 전체 상태 즉시 파악 | 이탈을 놓쳐 회수·행정처분 |
| 응우옌 반 안 (29·현장) | 베트남 국적 — 한국어 읽기 느림 | 자기 언어로 된 화면·아이콘 중심 조작 | 오독으로 잘못된 조치 |
| 박품질 (41·품질관리) | HACCP 팀장 | 기록이 심사에서 그대로 통과 | 수기 기록 누락·위변조 의심 |
| 최대표 (SaaS 운영사) | 영업 시연이 곧 매출 | "시연 가능한" 화면 완성도 | MVP 화면으로는 계약이 안 됨 |
| 색각이상 근로자 (통계상 남성 약 5~8%) | 적록 구분 곤란 | 색 말고도 상태를 알 수 있는 화면 | 빨강/초록만으로 표시된 경보 |

## 2. 핵심 통찰

이 SaaS의 구매 이유는 "예쁜 대시보드"가 아니라 **스마트 HACCP 인증 요건(자동 모니터링·
전자 기록·위변조 방지·이상 알림)의 충족을 심사관과 고객사에게 보여주는 것**이다.
리뉴얼은 그 4요건이 화면에서 즉시 보이게 만드는 작업이고, 접근성(고령자·외국인·색각)은
장식이 아니라 "현장에서 실제로 조작되는가"의 문제다.

## 3. 시간순 여정 — 이탈 발생 1건의 생애

| 단계 | 상황 | 화면 | 없으면 |
|---|---|---|---|
| 감지 (15:02) | 급속 냉각기 11.8℃ — CL 초과 | 센서 자동기록 → 상태 실계산 | 수기 기록은 다음 라운드까지 미감지 |
| 알림 (즉시) | 현장·품질 폰에 푸시 | 앱 푸시 배너 + 알림함 | 이탈 알림 없으면 인증 요건 미달 |
| 확인 (15:03) | 알림 탭 → 해당 설비 화면 | 상세(대형 온도·CL·24h 차트) | 화면 찾아 헤매면 골든타임 상실 |
| 조치 (15:05) | 필터 교체·배치 격리 입력 | 개선조치 모달(프리필) | 조치 미기록 = 심사 부적합 |
| 복귀 (15:07) | 정상 확인·전자기록 저장 | 해시 체인에 기록 연결 | 기록 수정 가능하면 위변조 의심 |
| 보고 (익일) | 일일 기록부 출력 | 리포트(판정·해시)·PDF/CSV | 수기 전사 반복·오기 |

## 5. 기능별 존재 이유

| 기능 | 존재 이유 |
|---|---|
| 다크 테마+보라 | 공고 문구 그대로 + 공장 상황실 저조도 환경에서 눈부심 감소 |
| 큰 글씨 3단계 | 고령 공장장 — 문구가 아니라 토글로 실제 구현 |
| 신호등 = 색+아이콘+텍스트 | 색각이상 근로자도 상태 판별 — 공고의 두 요구(신호등·접근성)를 동시에 충족 |
| 색각 보조 모드 | 적록→청/주황 팔레트 실전환 |
| KO/EN/VI | 현장 인력 구성(베트남 비중) — 인증원 다국어 교육과 같은 언어 축 |
| 공장 현장도 | 공고 명시 — 구역 기준으로 "어디가 문제인지" 공간적 파악 |
| 해시 체인 표시 | 위변조 방지(인증 요건)를 심사관·고객사에게 보이는 형태로 |
| 이탈 시뮬 버튼 | 영업 시연용 — 시연 중 실제 이탈을 기다릴 수 없음 |
| 점검 저장 게이팅 | 전 항목 응답 없이 저장 불가 — 형식적 점검 방지 |
| PDF 공유 시트 | 식약처 제출·본사 보고 — 현장에서 바로 전송 |

## 6. 비는 구멍 — 미팅 확인

1. **기존 MVP 코드 상태**: "타 개발자 중단 코드" — 리팩토링 범위가 견적 변수. 코드 리뷰 후 확정 조항 제안
2. **센서 연동 방식**: 센서→Supabase 수집 경로(게이트웨이? 폴링?)가 이미 있는가 — 앱 실시간성의 전제
3. **푸시 대상 정책**: 이탈 시 누구에게(전원? 당직?), 미확인 시 에스컬레이션 규칙
4. **점검 항목 관리**: 점검 체크리스트를 관리자가 편집하는 기능이 범위인가
5. **리포트 양식**: 식약처 제출 양식 확정본(현재 데모는 일반 기록부 형식) — 실제 서식 반영 필요
6. **언어 범위**: VI 외 추가 언어(인니·크메르·중국어) 시점, 번역 감수 주체
7. **오프라인 대응**: 공장 Wi-Fi 음영 구역에서 점검 입력 — 로컬 큐 후 동기화 필요 여부
8. **정부지원과제 산출 문서**: 과제 정산용 산출물 목록(회의록·검수서) 추가 여부
