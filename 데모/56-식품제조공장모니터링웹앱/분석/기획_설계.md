## 2. 리서치 발견 (근거 URL)

**① 「신호등 컬러 기반」을 그대로 만들면 접근성 목표와 충돌합니다 (최우선)**
공고는 신호등 상태 표시와 "고령자·외국인 접근성"을 함께 요구합니다. 그런데 적록색각이상
사용자는 신호등의 빨강/초록을 구분하지 못합니다 — 색상만으로 상태를 전달하면 안 되고
아이콘·텍스트 등 다른 시각 신호를 병행해야 하며, 적녹 대비를 피하고 파랑·주황 계열이 권장됩니다.
→ **기능화**: 모든 상태 배지 = 색+전용 아이콘(✓/▲/✕)+텍스트 3중 병행. 설정에 **색각 보조
모드** 토글 — 켜면 팔레트가 초록/빨강 → 파랑/주황으로 실전환(html[data-cvd]).
- https://uxkm.io/accessibility/a11yCreationTech/01-web/06-use-of-color
- https://www.remain.co.kr/page/designsystem/color-wraning.php

**② 이 SaaS의 본질은 "스마트 HACCP 인증 요건 충족"입니다**
식약처 고시로 스마트 HACCP(CCP 모니터링 자동기록관리시스템) 법적 근거가 마련되었고, 인증
요건은 **자동 모니터링·전자 기록·위변조 방지·이상 알림 4가지**입니다. UI 리뉴얼은 예쁘게가
아니라 이 4요건이 화면에서 보이게 만드는 일입니다.
→ **기능화**: ⑴ 자동기록 KPI(AUTO-SENSOR 표기) ⑵ 전자기록 해시 체인 화면(이전 해시←현재
해시 연결·무결성 검증 배지) ⑶ 이탈 시 개선조치 입력 → 전자기록 저장 흐름 ⑷ 리포트에 기록
해시 컬럼.
- https://www.fsnews.co.kr/news/articleView.html?idxno=37053 (법적 기준 마련)
- https://brunch.co.kr/@7c6d06178c07410/5 (4대 요건)

**③ 외국인 근로자 언어 구성 — 베트남어가 우선순위**
식품 제조 현장 외국인 근로자는 베트남·인도네시아·캄보디아·중국 국적 비중이 높고,
한국식품안전관리인증원의 다국어 식품안전 교육도 영어·중국어·**베트남어** 3개 언어로 제작됩니다.
→ **기능화**: 데모 다국어 = KO/EN/**VI** 3개 언어 즉시 전환(화면 전체). 실구축에서 언어 추가는
사전 파일 추가로 확장.
- http://www.enewstoday.co.kr/news/articleView.html?idxno=2453671
- https://www.kmcn.kr/news/article.html?no=9331 (안전교육 19개 언어 확대)

## 6. Supabase 연동 방식 (실구축)

- 조회: 기존 테이블(equipment·readings·alerts) Realtime 구독 → 웹/앱 동일 스토어
- 인증: Supabase Auth 기존 계정 체계 유지(권한 3롤은 RLS 정책으로)
- 알림: DB 트리거(한계 이탈) → Edge Function → FCM/APNs 푸시. 기록 위변조 방지는 해시 체인
  컬럼(prev_hash) 추가로 인증 요건 가시화
- 앱: **React Native(Expo)** 제안 — Supabase JS SDK 재사용으로 웹 로직 공유(공고 태그 Flutter도
  가능하나 기존 Next.js 코드 자산 재사용 관점에서 RN 우위. 미팅에서 협의)
