# ONDO 온도 — 식품공장 스마트 HACCP 모니터링 (데모)

위시켓 「식품 제조공장용 모니터링 웹 UI 리뉴얼 및 모바일 앱 구축」 대응 데모.
공고의 디자인 요구(다크+보라 포인트·큰 글씨·신호등 상태·최소 조작)를 문구 그대로 구현하고,
접근성(고령자·외국인·색각)과 스마트 HACCP 인증 요건(자동기록·위변조 방지·이상 알림)을
동작하는 기능으로 만들었습니다. **모든 데이터·업체명은 가상입니다.**

- 웹 대시보드: https://jeonjaeman.github.io/demo-sites/ondo/
- 모바일 앱 화면: https://jeonjaeman.github.io/demo-sites/ondo/mobile.html

## 체험 시나리오 (입력 없이 클릭만으로)

1. 상단 **「⚡ 이탈 시뮬레이션」** — 푸시 배너 → KPI 이탈 1 → 해당 설비 상세 자동 오픈 → 개선조치 모달(프리필) → 저장 → 정상 복귀 + 해시 기록
2. 설비 카드/현장도 온도 태그 클릭 → 24h 차트(CL 점선·이탈 포인트)와 위변조 방지 해시 체인
3. 우상단 **한국어/EN/Tiếng Việt** — 전 화면 즉시 전환 (외국인 근로자)
4. **A/A+/A++** — 큰 글씨 3단계 (고령자)
5. 설정 → **색각 보조 모드** — 신호등 팔레트가 청/주황으로 실전환 (상태는 항상 색+아이콘+텍스트 병행)
6. 점검 — 6항목 전부 응답해야 저장 활성화
7. 리포트 — 판정 실계산 기록부, PDF 저장(인쇄)·CSV 다운로드
8. 모바일 화면에서 같은 흐름(푸시·점검·공유 시트) 반복 체험

## 핵심 발견 3건 (근거 URL: 분석/기획_설계.md)

1. **신호등 컬러만으로는 색각이상 근로자가 상태를 구분 못함** — 공고의 신호등 요구와 접근성 요구가 충돌하는 지점. 색+아이콘+텍스트 3중 병행 + 색각 보조 모드로 동시 충족.
2. **스마트 HACCP 인증 4대 요건**(자동 모니터링·전자 기록·위변조 방지·이상 알림)이 이 SaaS의 본질 — 해시 체인·자동기록 표기·이탈 알림 흐름으로 화면에 가시화.
3. **9월 납기에는 앱스토어 심사 기간이 포함**되어야 함 — 내부 테스트 트랙 선오픈 + 심사 병행 제안.

## 기술 구성

- 순수 HTML/CSS/JS · 외부 라이브러리 0 (차트 canvas 자체 구현·dpr 대응)
- 상태 판정은 온도 vs 한계(CL) **실비교** — 하드코딩 없음. 시계열은 시드 기반 결정적 생성
- 접근성: html[data-fs] 글자 3단계 · html[data-cvd] 색각 팔레트 전환 · 터치 타겟 44px+ · reduced-motion
- i18n: KO/EN/VI 사전 구조 · CSV UTF-8 BOM · @media print 리포트
