## 게임이 실제로 동작합니다 (상태 변화 전부)

카드 3D 플립(420ms) → 두 장째 입력 잠금 → 매칭 성공(라임 펄스+진행바+진동) /
오답(셰이크 후 재뒤집힘) → 타이머 10초 미만 적색 → 클리어 시 기록에 따라
성공/신기록 자동 분기, 시간초과 시 실패 화면. 일시정지(타이머 정지)·힌트(남은 한 쌍 1.2초 공개)까지.

## 체험 시나리오 (클릭만)
1. 스플래시 → 홈 자동 진입 → "카드 맞추기" → 덱 선택 → 난이도 → 카운트다운 → 플레이
2. 카드를 맞추면 매칭 펄스, 틀리면 셰이크 — 전부 맞추면 성공/신기록 화면 + 콘페티
3. 결과 공유 → SNS 공유 카드 시안 / 컬렉션 → 카드 탭 → 홀로그램 스윕
4. 좌측 인덱스(데스크톱)나 하단 바(모바일)로 20화면 전부 개별 확인

## 디자인·기술
- 도메인: **im-fine.co.kr(의뢰자) 실측** — 블랙 #000·화이트·경량 200 대형 타이포·lh 1.0 → "매거진스러운"의 기준점을 의뢰자 톤에서 가져옴 / Weverse·포토카드 컬렉션 문법 / 메모리 게임 표준(난이도=그리드 확장)
- 디자인: 잉크 블랙 + 오프화이트 + 네온 라임 단일 액센트 · Pretendard · Linear 이징
- 가상 그룹 LUMIN 6인 에디토리얼 포토카드 — Higgsfield 생성(실존 인물 아님 명시), 레드팀 검수로 인쇄물 프레임·로고 전량 제거(재생성+크롭)
- 정적 HTML/CSS/JS · 외부 라이브러리 없음 · 콘페티 canvas(dpr) · `prefers-reduced-motion` 존중

## 레드팀 3종 검수 결과
- **① 디자인(애플·삼성 감각)**: 생성 이미지 8장 전수 육안 검수 → VOGUE 로고·종이 테두리·바코드 검출 → 전량 재생성+크롭 교정. 블랙+라임 단일 액센트·타이포 위계 유지
