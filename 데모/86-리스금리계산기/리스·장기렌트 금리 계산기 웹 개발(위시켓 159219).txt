[프로젝트 개요]
- 리스·장기렌트 이용 고객이 월 납입금으로 실제 적용 금리와 총 이자를 확인하는 계산기와, 상담 고객을 관리하는 관리자 웹을 개발합니다.
- 기획과 화면 디자인(인터랙티브 시안)은 완성되어 있어 시안 기준으로 개발합니다.

[프로젝트 배경 및 목표]
- 지금 상황: 기획과 화면 디자인은 AI 도구로 제작해 완료한 상태이고, 화면별 기능·DB 구조·API 목록을 정리한 요구사항정의서도 준비되어 있습니다. 이번에는 이를 실제 서비스로 개발합니다.
- 끝나면 이렇게 되기를 바랍니다: 고객은 계산기에서 본인 계약의 금리와 이자를 확인하고, 그 과정에서 들어온 문의와 승계 상담을 관리자 웹에서 한 곳에 모아 관리합니다.

[필수 과업 범위와 결과물]
1. 수행 범위
- 기획 및 디자인: 완성된 인터랙티브 시안과 요구사항정의서를 제공하므로 신규 기획·디자인 작업은 없습니다.
- SW 개발: 고객용 반응형 웹, 관리자 웹, 서버 API, DB 신규 구축
- 배포: 웹 서비스 오픈

2. 상세 기능 요구 사항
- 화면별 디자인은 첨부된 PDF에 있습니다.
2-1. 고객용 웹 (모바일·태블릿·폴드·PC 반응형)
- 고객 정보 입력: 차량번호·성함·전화번호·개인정보 동의 입력 및 입력 검증
- 금리 계산기: 리스/장기렌트 구분, 입력값 기준 금리·총 이자·회차별 상환표 표시
- 금리 분석 보고서: A4 인쇄·PDF 저장, 확대·축소, 공유 링크 발급 (없는 링크 안내 화면 포함)
- 승계 상담 신청: 계산기 화면에서 상담 신청 접수
- 상태 화면: 로딩·오류·빈 화면 등
2-2. 관리자 웹 (PC)
- 관리자 계정·권한: 관리자 로그인, 메인/서브 관리자 권한 관리
- 고객 DB 목록: 필터·정렬·검색, 엑셀 다운로드, 삭제(기록 남김)
- 승계 상담 계산: 시세·정산서 입력 시 처리 방법별 손익, 할부총액, 승계 수수료(수수료율과 양방향 계산), 주행거리 초과 위약금 실시간 계산
- 상담 관리: 미래 승계시점 예상 가격 그래프, 메모, 진행상태, 차량 정보(옵션 태그 입력)
- 고객 제공 리포트: 금액 수정, 고객 링크 발급, 이미지 저장
2-3. 서버·DB
- 계산 처리: 모든 계산 서버 처리 (계산식은 영업기밀로 화면 코드 포함 금지)
- DB·API: 고객·상담·견적·메모·관리자 DB 설계 및 API 개발
- 개인정보 보호: 개인정보 암호화, 관리자 열람·다운로드 기록

3. 결과물
- 전체 소스코드와 계산 로직 (소유권은 발주사에 귀속, 계약서에 명시)
- DB 스키마
- 배포·운영 매뉴얼

[클라이언트 준비 사항]
- 준비된 것: 전체 화면 인터랙티브 디자인 시안, 요구사항정의서(화면별 기능, DB 구조, API 목록, 입력 규칙)
- 계산식·감가율 상세 자료는 NDA 체결 후 별도로 전달합니다.

[오픈 시점과 예산]
- 목표 시점: 정해진 오픈 날짜는 없습니다.
- 희망 착수: 계약 후 즉시
- 예산: 300만원
