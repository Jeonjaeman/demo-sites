## 1. 사이트맵

```
고객 (반응형 344 폴드 ~ 1440 PC)
├─ index.html            인트로 → 시작(배너 + 기본 정보)
├─ calc.html             계산기(리스/장기렌트) → 결과 → 보고서 / 승계 상담 신청(시트)
├─ report.html?t=        금리 분석 보고서(A4·N장) · 링크 복사 · 인쇄/PDF · 없는 링크

├─ admin/index.html      로그인(메인/서브 원클릭 체험)

├─ admin/consult.html    상담 관리 + 승계 상담 계산 + 고객 리포트 발급
```

## 2. 페이지별 기획

### index.html — 시작
- 목적: 유튜브에서 넘어온 고객이 10초 안에 「내 계약 검증」을 시작하게 한다.
- 할 일: 차량번호·성함·전화번호 입력 + 수집·이용 동의 → 확인.
- 섹션: 인트로(로고 마스크 리빌·건너뛰기) → 배너(이미지 위 실제 텍스트·10초 스톱워치) → 기능 카드 3 → 기본 정보 카드.
- 발견 반영: 하·허·호 번호(대여사업용) 입력 시 「렌터카 번호예요 — 장기렌트로 계산해요」 안내 + 계산기 탭 자동 선택 / 지역명 번호(서울12가3456) 허용·정규화 / 「제공 동의」를 「수집·이용 동의(필수)」+「상담 연락 동의(선택)」로 분리.
- 다음: calc.html (리드 1건 생성 → 관리자 DB 「금리계산만」 탭에 바로 보임).

### calc.html — 계산기
- 목적: 내 계약의 실제 금리·총 이자·회차별 상환표를 확인.
- 할 일: 조건 입력(예시 값 원클릭) → 결과 확인 → 보고서 열기/링크 복사 → 승계 상담 신청.
- 섹션: 안내 박스 → 계산 조건 카드(리스/장기렌트·7개 입력·기간 칩·초기화) → 결과(이율 카드·총 이자·총 납부·원금/이자 구성 그래프·상환표·연도 요약) → 전화 안내 → 승계 배너 → 하단 고정 CTA.
- 상태: 빈 / 로딩 스켈레톤 / 오프라인(입력값 보존) / 오류 500 / 입력 모순(월 리스료로 원금도 못 갚음).
- 발견 반영: 보증금 반영 실질 금리(시안 방식 값과 나란히) · 장기렌트 포함 비용(보험·세금·정비) 차감 금리 · 1회차 납입 시점(선납/후납) 차이 · 계산은 전부 API 호출(화면 코드에 계산식 없음).
- 다음: report.html(링크 발급) / 승계 상담 신청 시트 → 관리자 「승계상담 신청」 탭.

### report.html — 금리 분석 보고서
- 목적: 계산 결과를 A4 문서로 보관·출력·공유.
- 섹션: 상단 바(로고·제목·A4·N장·링크 복사/인쇄) → 회색 뷰어 + A4 시트 N장(1장 요약·계약 조건·비용 구성·연도 요약 / 2~N장 회차별 상환표) → 확대·축소 플로팅.
- 공유 링크: 추측 불가 토큰 · 30일 보관 · 링크로 연 사람에게는 이름·번호 마스킹, 전화번호 뒤 4자리 확인 시 전체 표시.
- 없는 링크 / 만료 링크: 시안 11쪽 화면.

### transfer.html — 승계 리포트
- 목적: 관리자가 계산한 처리 방법별 손익을 고객이 링크로 확인.
- 섹션: 고객·차량 요약 → 처리 방법별 고객 손익(추천 배지) → 미래 승계시점 예상 가격 그래프 → 안내 → 재견적 신청(30일 1회).
- 토큰 없으면 「예시 화면」 배너(시안 13쪽).

### admin/customers.html — 고객 DB
- 목적: 계산기·상담에서 들어온 고객을 한 곳에서 처리.
- 섹션: 헤더(CAR PASS·관리자·브랜드·새로고침·권한 배지·관리자 관리·로그아웃) → 제목+엑셀/승계 상담 추가 → KPI 4 → 탭(전체·승계상담 신청·금리계산만·서브관리자 등록) → 세그먼트(상담 미확인/확인)·정렬·검색 → 표(12열) → 페이지네이션.
- 발견 반영: 엑셀 다운로드 = 사유 입력 → xlsx(문자열 셀 고정으로 수식 주입 차단) → 기록 / 삭제 = 사유 필수·소프트 삭제·기록 / 서브 관리자는 본인 고객만·전화번호 마스킹 / 암호화된 전화번호도 뒤 4자리 검색(블라인드 인덱스).

### admin/consult.html — 상담 관리
- 목적: 한 고객의 승계 상담을 계산하고 진행·기록하고 리포트를 발급.
- 섹션: 고객·차량 정보(옵션 태그) → 진행상태 스텝 → 승계 상담 계산(시세·정산서 → 처리 방법별 손익·할부총액·승계 인수 총액·수수료 금액↔율 양방향·주행거리 초과 위약금, 실시간) → 미래 승계시점 예상 가격 그래프 → 메모 타임라인 → 고객 리포트(금액 수정·링크 발급·이미지 저장).

### admin/managers.html · admin/logs.html
- 관리자 관리: 메인만 접근(서브는 403 화면). 서브 관리자 추가·권한(열람 범위·엑셀·삭제·리포트 발급)·비활성.
- 접속기록: 로그인·열람·다운로드(사유)·삭제(사유)·링크 발급 전부. 기간·행위·관리자 필터, 월 1회 점검 표시.

### proposal.html — 제안 노트 (데모 전용)
- 발견 → 데모 기능 매핑, 아키텍처(계산 모듈 서버 전용), 주차별 일정·중간 확인 시점, 완료 기준.

## 3. 공통
- 고객 공통: 헤더(로고 / 뒤로가기+제목), 하단 고정 승계 상담 CTA, 토스트, 바텀시트.
- 관리자 공통: 상단 헤더 + 현재 페이지 표시(aria-current), 권한별 메뉴.
- 데이터: 브라우저 저장소에 「가상 DB」(시드 46건 + 체험 중 생성분), 전화번호·성함은 WebCrypto AES-GCM 암호문 + HMAC 블라인드 인덱스로 저장.
- 계산: `assets/js/server/engine.worker.js`(서버 역할) — 화면 스크립트는 `API.post('/api/v1/...')`만 호출.
- 데모 패널: 좌하단 DEMO — 화면 바로가기·상태 미리보기·API 로그·DB 원본 보기·초기화.
