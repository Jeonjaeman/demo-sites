## 체험 시나리오 (입력 없이 클릭만으로)
1. 시작 → 「예시 값 채우기」 → 확인 → 계산기 빈 상태의 「예시 값으로 계산해 보기」 → **연 13.11%** + 「보증금을 빼지 않고 계산하면 8.13%」
2. 「계산 기준」 → 「반영 안 함(시안 방식)」 → 8.13% · 「출고일(선납)」 → 13.53%
3. 「금리 분석 보고서 보기」 → 확대 · 인쇄 · 링크 복사 → 다른 브라우저로 열면 「강\*서」 → 뒤 4자리 `2929`
4. 하단 「승계 상담 신청」 → 접수 → 관리자 고객 DB 맨 위에 나타남
5. 관리자 → 「메인 관리자로 체험」 → 「자동 입력」 → 검색 `강은`(안 됨) / `강은서` / `2929` → 강은서 행 → 금융리스 전환 · 수수료율 2.5% → 금액 자동 → 리포트 금액 수정 → 링크 발급 → 폐기
6. 좌하단 **DEMO** 패널: 화면 바로가기 · 상태 미리보기(로딩·오프라인·오류) · API 로그(화면은 계산식 없이 요청만) · DB 원본(암호문)
