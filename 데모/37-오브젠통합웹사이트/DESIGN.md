# OBZEN Integrated — B안 "SPECTRUM / One Focus" 디자인 시스템

A안(34번 · Signal Loom · 다크 라인 시스템맵)과 **같은 요구사항을 정반대 비주얼 언어**로 푼 재구축본.
이전 B안("Confluence")이 A안과 개념(두 스트림 합류)·팔레트(버건디/네이비/틸)가 사실상 겹쳐
"A의 라이트 변주"로 보였던 문제를 백지화하고, 개념·색·타이포·그래픽을 전부 교체했다.

## 0. 컨셉 — One Focus (하나의 초점)
합병을 "두 강의 합류"가 아니라, **흩어진 데이터 스펙트럼이 오브젠이라는 하나의 렌즈(초점)를 지나
'다음 행동'이라는 단일 빛으로 모이는 것**으로 재해석한다.
시그니처 그래픽 = **이클립스 렌즈**(오브젠 원 + 잘레시아 원이 겹쳐 하나의 밝은 초점) + **스펙트럼 빔**.
핵심 문장: **"흩어진 데이터를 하나의 초점으로."**

## 1. A안과 최대 대비 (전혀 다른 스타일)
| 축 | A안 (Signal Loom) | **B안 (SPECTRUM)** |
|---|---|---|
| 밝기/온도 | 다크 잉크·차가움 | **라이트 웜 페이퍼·따뜻+비비드** |
| 컬러 | 버건디·네이비·틸 | **인디고#4b3bff→마젠타#ff3d9a→앰버#ffb020** (A와 무겹침) |
| 타이포 | 절제된 산세리프 570 | **헤비 산세리프 800/900 + Fraunces 세리프 에디토리얼 대비** |
| 그래픽 | 추상 라인 시스템맵(선) | **채워진 오로라 메시·이클립스 렌즈·스펙트럼 빔·컬러 블록** |
| 모션 | 상태·흐름 최소 | **스크롤 구동 키네틱(이클립스 오버랩·대형 카운트업·게이지)** |
| 무드 | 엔지니어링 거버넌스 절제 | **브랜드 매거진/애뉴얼리포트 화려** |

## 2. 토큰
| Token | Value | 역할 |
|---|---|---|
| `--paper` / `--paper2` | `#f7f4ee` / `#efe9df` | 웜 아이보리 기조·교차 섹션 |
| `--ink` / `--ink2` | `#16131d` / `#3a3348` | 본문(웜 블랙) |
| `--indigo` | `#4b3bff` | 주요 액션·오브젠 원 |
| `--magenta` | `#ff3d9a` | 강조·잘레시아 원 |
| `--amber` | `#ffb020` | 스펙트럼 끝·포커스 |
| `--grad` | `linear-gradient(100deg,#4b3bff,#7b5cff,#ff3d9a,#ffb020)` | 오로라 스펙트럼 |
| `--card`/`--line` | `#fffdf9`/`#e6dfd2` | 카드·경계 |

- 타이포: 헤드라인 `Pretendard` weight 800(clamp 42→96px, ls −.045em) + 악센트 `Fraunces` italic. 라벨 `Space Grotesk`.
- 컨테이너 max 1200px, 섹션 패딩 clamp(72,132)px, radius 13/20px.

## 3. 그래픽 (적극 활용 — A와 정반대로 "채움")
- **히어로 오로라 메시**: 4겹 radial-gradient + 느린 drift 애니메이션(블러).
- **이클립스 렌즈**: 두 원(인디고·마젠타) `mix-blend-mode:multiply` 겹침 + 점선 회전 링 + 중앙 "ONE FOCUS".
- **스펙트럼 빔 바**: 그라디언트 바.
- **IR 대형 카운터 + 게이지 바**: 큰 숫자 카운트업 + width 성장.
- **연혁 타임라인**: 그라디언트 스파인 + 합병 노드 강조.
- 아이콘/노드는 자체 SVG. 래스터 스크린샷을 UI로 쓰지 않는다.

## 4. 모션
- 리빌: IntersectionObserver + **450ms 폴백 타이머**(컴포지팅 정지 환경에서도 콘텐츠 표시 보장). translateY+opacity, stagger.
- 카운트업: rAF easeOutCubic(1.2s) — **초기 최종값 선표시**로 rAF 미실행 시에도 값 노출.
- 게이지 바: 렌더마다 width 재적용(언어 토글 포함).
- 아코디언: `grid-template-rows 0fr→1fr`(높이 계산 불필요).
- 이클립스 오버랩: CSS keyframes 왕복.
- `prefers-reduced-motion`: 애니메이션·트랜지션 비활성.

## 5. 컴포넌트
- 헤더: 히어로 위 투명 → 스크롤 후 blur 반투명. 전체 재렌더 없음.
- 통합검색: 네이티브 `dialog`, `/` 단축키, 실시간 결과 개수, 결과 클릭 시 섹션 이동.
- 뉴스룸: 유형 필터 칩(전체/공지/IR/보도자료) + `Blob`(UTF-8 BOM) 가상 문서 다운로드.
- 서비스 아코디언: 배타적 오픈, 합병 전 출처(was)→통합 제품(now) 표기.
- 문의: 네이티브 검증, 명시적 요약, 네트워크 전송 없음.
- 관리자 CMS: `localStorage` CRUD(추가/수정/삭제/초기화), 국·영 제목 동시 관리, 공개 뉴스룸 즉시 반영.
- 다국어: KO/EN 토글 — `data-ko`/`data-en` 스왑 + 리스트 재렌더.
- 접근성: skip link, 단일 h1, 시맨틱 섹션, 가시 포커스, 다이얼로그 Escape·backdrop 닫기, `aria-live`.

## 6. 레퍼런스 (방향 근거 — 정직 표기)
- **도메인**: OBZEN 공식(오브젠·잘레시아 합병 맥락·통합 IR 성격) / IR·기업 홈 관행(연혁·뉴스룸·문의 구조).
- **디자인 방향(수치 실측 아님·톤 참조)**: 라이트 그라디언트 브랜드 사이트 계열(Stripe·Framer·Linear의 밝은 톤)에서 **비비드 그라디언트 + 대형 에디토리얼 타이포 + 여백 리듬**의 방향만 참고했다. 이전 B안 문서의 "SOTD 실측 수치"는 근거를 재확인하기 어려워 제거했고, 본 시스템의 색·타이포·그래픽·인터랙션은 이 제안을 위해 새로 설계했다.
- 폰트: 유료 커스텀 대신 오픈 폰트(Pretendard·Fraunces·Space Grotesk)로 구성.

## 7. 데이터·사실성 원칙
- 회사명·합병 맥락 등 공개 확인 가능한 사실만 실제로 다룬다.
- 실적·재무·IR 문서·연락처·연혁 연도는 임의 생성하지 않고 화면에 **"제안용 가상 데이터"**로 표기한다.
- 실제 구축 시 공시·IR·개인정보·보안 문구는 법무·IR·브랜드 책임자 검수를 거친다.
