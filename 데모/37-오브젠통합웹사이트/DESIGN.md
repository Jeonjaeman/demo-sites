# OBZEN Integrated — B안 "Confluence" 디자인 시스템

A안(34번 · Signal Loom, 다크 시스템맵)과 같은 요구사항을 **다른 관점**으로 푼 두 번째 제안이다.
A안이 "통합 플랫폼을 시스템으로 증명"한다면, B안은 **합병이라는 사건을 브랜드 서사로 전달**한다.

## 0. 컨셉 — 합류(合流)

두 회사(오브젠·잘레시아)를 두 개의 강물로 보고, 합병을 두 흐름이 하나의 강으로 **합류**하는
순간으로 전개한다. 스크롤이 곧 서사이며, 각 섹션은 브랜드 필름의 챕터다.

- 오브젠 = 고객 데이터 흐름 (버건디)
- 잘레시아 = 경영 데이터 흐름 (네이비)
- 합류점 = 통합 지능 (티일)
- 다음 행동 = 의사결정 시점 (오렌지)

핵심 문장: **"두 개의 흐름, 하나의 오브젠. 데이터에서 다음 행동까지."**

## 1. 챕터 구조 (스크롤 서사)

| Ch | 섹션 | 역할 | 명암 |
|---|---|---|---|
| 00 | 히어로 | 두 흐름의 합류 브랜드 이미지 | 페이퍼 |
| 01 | 두 회사 (회사소개) | 합병 전 각자의 강점 분리 제시 | 페이퍼 |
| 02 | 합병의 순간 | convergence 모션 — 두 선이 만나는 다크 시네마 | **다크** |
| 03 | 하나의 오브젠 | 통합 선언 + 시너지 카운트업 | 페이퍼2 |
| 04 | 연혁 | 두 길이 하나로 모이는 타임라인 | 페이퍼 |
| 05 | 통합 서비스 | 제품 아코디언 (합병 전/후 표기) | **다크** |
| 06 | 뉴스룸·IR | 필터 + 가상 문서 Blob 다운로드 | 페이퍼 |
| 07 | 문의 | 폼 검증 + 개인정보 안내 | **다크** |

밝은 페이퍼 챕터와 다크 시네마 챕터를 교차시켜 "합병의 순간"과 "통합 서비스"를 강조한다.
같은 카드 그리드를 반복하지 않는다.

## 4. 모션 (강도 = 중 · IR 홈이므로 절제)

- 스크롤 리빌: `getBoundingClientRect` 기반, opacity+translateY, data-delay stagger
- 시너지 수치: 카운트업(easeOutCubic, 1.4s) — rAF 애니메이션 + setTimeout 최종값 보장
- convergence: 두 SVG 선이 stroke-dashoffset 드로우로 합류점까지 그려짐(0.25s stagger)
- 아코디언: `grid-template-rows 0fr→1fr` 트랜지션(높이 계산 불필요·견고)
- 카드 호버 리프트, 인덱스 행 hover 확장
- `prefers-reduced-motion`에서 애니메이션·트랜지션 비활성

### ★ 구현 노트 — IntersectionObserver 대신 스크롤 기반
자동화·백그라운드 탭 등 **컴포지팅이 멈춘 환경에서 IntersectionObserver 콜백이 프레임을
그리지 않아 리빌이 지연되는 문제**를 확인했다. 리빌·카운트·드로우를 `getBoundingClientRect`
기반 스크롤 핸들러로 구현해 어떤 환경에서도 콘텐츠가 표시되도록 했고, 카운트업은
`setTimeout`으로 최종값을 보장한다. 사용자 브라우저에서의 동작은 동일하다.

## 5. 컴포넌트

- 헤더: 히어로 위 투명 → 스크롤 후 blur 반투명, 스크롤 시 전체 재렌더 없음
- 통합검색: 네이티브 `dialog`, `/` 단축키, 실시간 결과 개수
- 아코디언: 배타적 오픈, 선택 영역만 갱신
- IR 인덱스: 유형 필터 + `Blob` 가상 문서(UTF-8 BOM)
- 문의: 지속 라벨, 네이티브 검증, 명시적 요약, 네트워크 전송 없음
- 관리자: `localStorage` CRUD, 패널 편집, 스코프 갱신, 초기화
- 접근성: skip link, 랜드마크, 단일 h1, 가시 포커스, 다이얼로그 초점 트랩·Escape·복원, `aria-live`

## 6. A안과의 차이 (같은 요구사항, 다른 제안)

| | A안 (Signal Loom) | B안 (Confluence) |
|---|---|---|
| 관점 | 통합 플랫폼을 **시스템**으로 증명 | 합병을 **브랜드 서사**로 전달 |
| 첫인상 | 다크 라이브 시스템 맵 | 밝은 에디토리얼 + 두 흐름 합류 |
| 타이포 | weight 570 · 모노 라벨 | weight 200 Thin 에디토리얼 |
| 구성 | 플랫폼·산업·거버넌스 탭 | 챕터형 스크롤 필름(합병의 순간·연혁) |
| 적합 | 제품·기술 신뢰 강조 | 통합 정체성·투자자 스토리 강조 |

두 안 모두 동일한 기능 세트(회사소개·합병·서비스·뉴스IR·문의·통합검색·관리자·다국어)를 만족한다.
미팅에서 의뢰자의 브랜드 방향에 따라 선택하거나 두 안을 절충한다.

## 7. 데이터·사실성 원칙

- 회사명·제품명·합병 맥락 등 공개 확인 가능한 사실만 실제로 다룬다.
- 실적·재무·연락처·IR 문서·연혁 연도는 임의 생성하지 않고 화면에 "제안용 가상 데이터"로 표기한다.
- 실제 구축 시 공시·IR·개인정보·보안 문구는 법무·IR·브랜드 책임자 검수를 거친다.
