# 시나리오 · 사용자 여정 — OBZEN Integrated (B안 · SPECTRUM)

## 1. 등장인물
| 역할 | 누가 | 무엇을 원하나 | 무엇을 불안해하나 |
|---|---|---|---|
| **투자자·이해관계자** | IR 자료를 찾는 사람 | 합병이 무엇을 바꾸는지, 연혁·성과·최신 소식 | 합병 후 회사가 안정적인가, 정보가 최신인가 |
| **잠재 고객·파트너** | 데이터·AI 도입 검토 | 통합 후 무엇을 해주는 회사인지, 어떻게 문의 | 두 회사가 하나로 잘 붙었나(중복·혼란) |
| **오브젠 운영 담당자** | 뉴스·공지 갱신 | 코드 없이 소식 추가·수정 | 개발자 없이 못 바꾸면 방치됨 |

## 2. 시간순 여정
| 단계 | 상황 | 쓰는 화면 | 없으면 |
|---|---|---|---|
| 첫인상 | "오브젠이 잘레시아랑 합쳤다는데?" | 히어로(이클립스) | 합병 메시지가 안 꽂힘 |
| 이해 | 두 회사가 뭘 하던 곳인가 | 회사소개(정체성 카드) | 통합의 의미 불명확 |
| 신뢰 | 언제·어떻게 합쳐졌나 | 연혁 타임라인(합병 노드) | IR 신뢰 근거 부족 |
| 판단 | 통합하면 뭐가 좋아지나 | 통합 서비스 아코디언 | 제품 나열만으론 설득 안 됨 |
| 근거 | 규모·성과 숫자 | 통합 스냅샷(대형 카운터) | 투자 판단 근거 없음 |
| 최신 | 최근 소식·공시 | 뉴스룸(필터) + 통합검색 | 최신성 의심 |
| 행동 | 문의·연락 | 문의 폼 | 전환 이탈 |
| 운영 | 새 소식 올리기 | 관리자 CMS | 개발 의존·방치 |

## 3. 역할별 시야 차이
| 데이터 | 방문자(공개) | 운영자(관리자) |
|---|---|---|
| 뉴스·공지 | 필터로 열람·다운로드 | 추가·수정·삭제(국·영) |
| 언어 | KO/EN 토글로 열람 | 국·영 제목 동시 입력 |
| 검색 | 통합검색으로 탐색 | (인덱스는 콘텐츠·뉴스에서 자동 구성) |

→ 관리자에서 뉴스를 추가하면 공개 뉴스룸에 **즉시** 반영(localStorage 실연동). "운영 자립"이 IR 홈의 핵심.

## 4. 기능별 존재 이유
- **이클립스 히어로**: 합병=둘이 하나의 초점. 한 장면으로 통합 메시지 전달.
- **연혁 타임라인**: 합병 정보를 시간축으로 → IR 신뢰.
- **서비스 아코디언(was→now)**: 합병 전 어느 회사 역량이 어느 통합 제품이 됐는지 → 중복·혼란 해소.
- **대형 IR 카운터**: 규모·통합 효과를 숫자로(가상 표기).
- **통합검색**: 25p 규모에서 정보 도달 시간 단축.
- **관리자 CMS**: 소식 갱신 자립.
- **KO/EN**: 대외 IR 영문 수요.

## 5. 비는 구멍 (착수 전 미팅 확인)
공고: "선호 컬러·참고 이미지·IA는 미팅 시 공유". 아래는 임의로 정하지 않고 협의한다.
1. 실제 연혁 연도·합병 공식 일자·법인 구조(가상 데이터 대체 중).
2. IR 실적·재무 수치 공개 범위와 공시 규정 검수.
3. 브랜드 가이드(로고·컬러·톤) — 본 B안 스펙트럼 팔레트는 제안 방향이며 브랜드 확정 시 조정.
4. 25페이지 정확한 IA(하위 페이지 목록)·다국어 범위(전체/핵심).
5. 뉴스·공지 실제 운영 주체·권한(관리자 인증은 실제 구축 시 서버 인증).
6. 개인정보 처리방침·문의 데이터 처리 정책(법무 검수).
