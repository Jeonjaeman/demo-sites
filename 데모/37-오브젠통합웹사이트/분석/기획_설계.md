# 오브젠 통합 기업 홈페이지 기획·설계 (B안 · Confluence)

> 같은 공고에 대한 **두 번째 제안**이다. A안(34번 · Signal Loom)이 통합 플랫폼을 시스템으로
> 증명한다면, B안은 **합병이라는 사건을 브랜드 서사로 전달**한다. 요구사항 커버리지는 동일하다.

## 1. 프로젝트 정의

오브젠과 잘레시아의 합병 이후 새로운 기업 정체성을 대외에 설명하는 공식 통합 홈페이지다.
IR용 공개 사이트로서 고객·투자자·언론·파트너가 "합병으로 무엇이 더 좋아졌는가"를 빠르게
이해하도록 만드는 것이 목표다.

원본 요구사항:

- 반응형 웹, 약 25페이지
- 회사소개, 연혁·합병 정보, 서비스/제품, 뉴스/공지, 문의, 통합검색, 관리자, 다국어(옵션)
- 로그인 없는 공개 기업·IR 사이트
- 기획·디자인·퍼블리싱·개발·QA·오픈 지원, 턴키

## 2. 핵심 문제 (미팅에서 확인할 지점)

1. **합병의 의미가 첫 화면에서 이해되어야 한다.** 회사 정보를 한곳에 모으는 것보다,
   "두 회사가 만나 무엇이 새로 가능해졌는가"를 서사로 전달하는 것이 IR 홈의 본질이다.
2. **제품 나열이 아니라 흐름으로 설명**해야 한다 — 수집→통합→분석→실행.
3. **합병 전 두 회사의 역량과 합병 후 새 역량을 구분**해 보여줘야 신뢰가 생긴다.
4. 공지·IR·보도자료가 검색·필터·다운로드까지 자연스럽게 이어져야 한다.
5. 운영자가 콘텐츠를 수정할 때 화면 전체가 다시 로드되는 인상을 주지 않아야 한다.
6. 다국어(국·영문)는 옵션이나, 실제로는 IR 대상이 해외 투자자를 포함하면 필수가 된다.

## 3. 제안 콘셉트 — 합류(合流) Confluence

두 회사를 두 개의 강물로 보고, 합병을 두 흐름이 하나의 강으로 합류하는 순간으로 전개한다.
스크롤이 곧 브랜드 필름이며, 각 섹션은 챕터다. (상세: `DESIGN.md`)

핵심 메시지:

> 두 개의 흐름, 하나의 오브젠. 데이터에서 다음 행동까지.

## 4. 정보 구조

실 구축 기준 약 25개 상세 페이지를 브랜드 서사 흐름에 맞춘 상위 메뉴로 묶는다.

1. 회사소개 — 통합 법인 소개, 두 회사 강점, CEO 메시지, 조직, 오시는 길
2. 합병 스토리 — 합병 배경·의미, 통합 비전, 시너지
3. 연혁 — 두 회사 각각의 연혁 → 합병 → 미래
4. 서비스/제품 — CDP, 데이터·분석 엔지니어링, AI 의사결정, 실행·거버넌스 (합병 전/후 표기)
5. 뉴스룸·IR — 공지, 보도자료, 공시, IR 자료
6. 문의 — 사업·제품, 파트너십, IR, 연락처
7. (공통) 통합검색, 관리자, 국·영문

데모는 25개의 얇은 화면 대신, 사용자 판단을 검증하는 **공개 사이트 서사·통합검색·문의·관리자**
기능을 깊게 구현했다.

## 5. 화면별 기능 (구현된 데모)

### 공개 홈페이지 (챕터 스크롤)
- 두 흐름 합류 히어로(브랜드 색 SVG 그라디언트 흐름선)
- 두 회사 분리 제시(회사소개) → 합병의 순간 convergence 다크 시네마
- 하나의 오브젠 선언 + 시너지 카운트업(실제 계산)
- 연혁 타임라인(합병 노드 강조, 스크롤 리빌)
- 통합 서비스 아코디언(합병 전/후 라벨, 배타 오픈)
- 뉴스·IR 유형 필터 + 가상 문서 Blob 다운로드(UTF-8 BOM)
- 통합검색 다이얼로그(`/` 단축키, 결과 개수)
- 한국어/영어 핵심 메시지 전환
- 문의 폼 검증 + 개인정보 안내 다이얼로그

### 관리자 데모
- 공지·IR·보도자료 목록, 제목 검색, 유형 필터
- 콘텐츠 등록·수정, 게시/임시 상태
- `localStorage` 저장·초기화, 패널 편집으로 전체 재렌더 방지

## 7. 데이터·사실성 원칙

- 공개 확인 가능한 회사명·제품명·합병 맥락만 실제로 다룬다.
- 실적·재무·연락처·IR 문서·연혁 연도는 임의 생성하지 않고 "제안용 가상 데이터"로 표기한다.
- 실제 구축 시 공시·IR·개인정보·보안 문구는 법무·IR·브랜드 책임자 검수를 거친다.

## 8. 기술 구조

- 순수 HTML/CSS/JavaScript, 빌드 없이 정적 서버 즉시 실행
- SVG·CSS 시그니처 그래픽(브랜드 색 흐름선)
- `dialog`, `Blob`, `localStorage`, `getBoundingClientRect` 스크롤 엔진 사용
- 탭·필터·편집·검색은 해당 DOM만 갱신 (전체 재렌더 금지)
- `prefers-reduced-motion`, 키보드 초점, `aria-live`, 의미 있는 랜드마크 적용

## 9. 실제 구축 권장 단계

1. 이해관계자 워크숍·콘텐츠 감사, 합병 후 브랜드 메시지·명칭 체계 확정
2. 25페이지 IA와 URL·SEO 매핑, 디자인 시스템·핵심 템플릿 승인
3. CMS·검색·문의·IR 배포 파이프라인 개발
4. 데이터 이관과 국·영문 콘텐츠 작성
5. 접근성·보안·성능·크로스브라우저 QA
6. 운영 교육, 모니터링, 오픈 후 안정화
