# OBZEN Integrated — B안 "Confluence" (합류)

오브젠·잘레시아 통합 기업·IR 홈페이지 구축 **제안용 데모 (B안)**.
같은 공고에 대한 A안(34번 · Signal Loom)과 짝을 이루는 두 번째 제안으로,
합병을 **브랜드 서사(챕터형 스크롤 필름)**로 전달한다.

> ⚠️ 본 사이트는 제안 검토용 비공식 데모이며 오브젠 공식 홈페이지가 아닙니다.
> 수치·문서·연락처·연혁 연도는 전부 **제안용 가상 데이터**입니다.

## 화면

| 파일 | 화면 | 핵심 |
|---|---|---|
| `index.html` | 공개 홈페이지 (7 챕터 스크롤 서사) | 합류 히어로 · 합병 convergence · 시너지 카운트업 · 연혁 · 서비스 아코디언 · 뉴스IR · 문의 |
| `admin.html` | 관리자 CMS 데모 | 공지·IR·보도자료 검색·등록·수정·게시상태 (localStorage) |
| `showcase.html` | 디자인 프리미티브 게이트 | 색·타이포·버튼·입력·배지·인덱스 행 |

## 체험 시나리오

1. 첫 화면에서 두 흐름(버건디=오브젠·네이비=잘레시아)이 하나로 합류하는 브랜드 이미지.
2. 스크롤 → "두 회사" → **합병의 순간**(다크 시네마, 두 선이 합류점까지 그려짐).
3. "하나의 오브젠"에서 시너지 수치가 0에서 카운트업(실제 계산).
4. 연혁 타임라인에서 합병 노드(오렌지)가 강조되며 순차 등장.
5. 통합 서비스 아코디언 — 항목을 열면 합병 전/후 역량이 구분되어 표시.
6. 뉴스룸·IR에서 유형 필터 → 다운로드 버튼으로 가상 문서(txt) 생성.
7. 헤더 검색 아이콘 또는 `/` 키로 통합검색, 결과 개수 표시.
8. 헤더 KR/EN 버튼으로 첫 화면 핵심 메시지 전환.
9. 문의 폼 — 필수값 누락 시 제출 차단, 개인정보 안내 다이얼로그.
10. `admin.html` — 콘텐츠 검색·등록·수정, 화면 전체 재렌더 없이 갱신.

## ⚠️ 착수 전 확인 항목 (미팅)

- 기존 고객 이관 안내 페이지 필요 여부 (계약·담당·지원 변경)
- IR 공시 범위·전자공시 연계, 상장 여부
- 합병에 따른 개인정보 이전 고지 문구 (법무 검수 필수)
- 다국어 범위: 핵심 메시지만 vs 전체 25페이지 (번역 분량이 견적 좌우)
- CMS 운영자 권한 등급 필요 여부
- 연혁·시너지 등 실제 수치·문서 제공 (데모는 전부 가상)
- A안·B안 중 방향 선택 또는 절충

## 기술 구성

- 순수 HTML/CSS/JavaScript, 빌드 없음, 정적 서버 즉시 실행
- 브랜드 색 SVG 그라디언트 흐름선, canvas 미사용(코드 네이티브 그래픽)
- `dialog` · `Blob`(UTF-8 BOM) · `localStorage` · `getBoundingClientRect` 스크롤 리빌/카운트/드로우
- 탭·필터·검색·편집은 해당 DOM만 갱신 (전체 재렌더 금지)
- `prefers-reduced-motion`, 키보드 초점, `aria-live`, 시맨틱 랜드마크
