# OBZEN Integrated — 통합 기업·IR 홈페이지 (B안 · SPECTRUM)

오브젠·잘레시아 **합병** 통합 회사의 IR용 홈페이지 제안 데모. A안(34·Signal Loom·다크 시스템맵)과 **같은 요구사항을 정반대 비주얼**(라이트 오로라·이클립스)로 재구축한 두 번째 방향입니다.

- 공개 URL(별칭): `https://jeonjaeman.github.io/demo-sites/obzen-b/`
- 관리자 CMS: `https://jeonjaeman.github.io/demo-sites/obzen-b/admin/`
- 로컬: `python -m http.server 8079 --directory 데모/37-오브젠통합웹사이트`
- ⚠️ 실적·연혁 연도·IR 문서·연락처는 **제안용 가상 데이터**입니다. 오브젠 공식 홈페이지가 아닙니다.

## 화면
| 구분 | 화면 |
|---|---|
| 공개 (`index.html`) | 히어로(이클립스) · 회사소개(정체성) · 연혁·합병(타임라인) · 통합 서비스(아코디언) · 통합 스냅샷(IR 카운터) · 뉴스룸·IR(필터) · 신뢰·거버넌스 · 문의 · 통합검색 다이얼로그 · KO/EN |
| 관리자 (`admin.html`) | 뉴스·IR·공지 CRUD(localStorage) — 공개 뉴스룸 즉시 반영 |
| 디자인 시스템 (`showcase.html`) | SPECTRUM 색·타이포·컴포넌트·시그니처 프리미티브 |

## 체험 시나리오 (2분)
1. 히어로의 **이클립스**(오브젠 원 + 잘레시아 원이 겹쳐 하나의 초점) 확인 — 합병 메시지.
2. 우상단 **KO/EN 토글** → 전체 콘텐츠 언어 전환.
3. **연혁 타임라인**에서 2026 합병 노드(강조) 확인.
4. **통합 서비스** 아코디언 → 합병 전 출처(was)→통합 제품(now).
5. **통합 스냅샷** 대형 카운터·게이지 애니메이션.
6. **뉴스룸** 유형 필터(공지/IR/보도자료) + 항목 클릭 시 자료 다운로드.
7. **통합검색**(우상단 돋보기 또는 `/`) → "합병", "CDXP", "생성형" 검색.
8. **관리자 CMS**에서 새 뉴스 추가 → 공개 뉴스룸에 즉시 반영.

## A안과의 차이 (전혀 다른 스타일)
| 축 | A안 (Signal Loom) | B안 (SPECTRUM) |
|---|---|---|
| 밝기/색 | 다크·버건디/네이비/틸 | 라이트 웜·인디고/마젠타/앰버 스펙트럼 |
| 타이포 | 절제된 산세리프 | 헤비 산세리프 + Fraunces 세리프 |
| 그래픽 | 추상 라인 시스템맵 | 오로라 메시·이클립스 렌즈·스펙트럼 빔 |
| 무드 | 엔지니어링 거버넌스 | 브랜드 매거진/애뉴얼리포트 |

## 기술 구성
- 정적 HTML/CSS/**바닐라 JS**, 빌드 없음. Pretendard·Fraunces·Space Grotesk(오픈 폰트, CDN).
- 콘텐츠·다국어·검색 인덱스·뉴스 CRUD는 `assets/js/data.js`에 집중.
- reveal은 **IntersectionObserver + 450ms 폴백**으로 어떤 환경에서도 콘텐츠 표시(빈 화면 방지). 카운트업은 최종값 선표시.
- 375px 무-가로스크롤, `prefers-reduced-motion` 존중.
- 파일: `assets/css/spectrum.css` · `assets/js/{data,app,admin}.js`
