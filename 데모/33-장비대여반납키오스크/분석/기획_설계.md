# ALLEND 올렌드 — 기획·설계

공공기관 장비 대여·반납 **배리어프리 키오스크 소프트웨어** 제안용 데모
브랜드: **ALLEND**(ALL + LEND, "누구나 빌린다") · 별칭 `/allend`
> ⚠ 모든 장비·대여·카드·기관 데이터는 **가상**입니다.

---

## 0. 한 줄 요약

공고는 "화면 디자인은 클라이언트가 완성해 지급, 개발사는 그 디자인대로 SW만 구현"을 전제하지만,
**공공기관 키오스크의 접근성은 우대 사항이 아니라 법적 강제(지능정보화기본법·장애인차별금지법)**이고,
그 검증 기준(KS X 9211 / 무인정보단말기 정보접근성 검증기준 10원칙·47지표)의 상당수는
**지급될 디자인·하드웨어 단계에서 이미 결정**됩니다. 즉 개발사가 SW를 완벽히 만들어도
**지급물이 기준 미달이면 검증에서 탈락**하고 그 책임이 개발사로 전가될 위험이 있습니다.
→ 이 데모는 그 충돌을 **관리자 화면의 "접근성 검증 진단"으로 실증**하고, 음성·물리버튼·고대비를
**실제 동작**으로 구현했습니다.

## 1-b. 숨은 니즈 (공고 문장에서 도출)

- "기획 상태 = 필요한 내용을 간단히 정리" + "화면 디자인 지급" → **접근성 요건이 디자인에 반영됐는지 미확인**.
  단서: 공고가 접근성을 "우대"로 적었으나 **공공 납품은 접근성이 강제**. → 디자인 사전 검수 필요.
- "재고·상태를 수신하여 전달" → 재고 **원천 시스템이 따로 있음**(키오스크는 표시 단말).
  그 연동 API 규격이 없으면 대여/반납 로직 착수 불가. → 규격 확인이 전제.
- "결제/프린터/물리버튼/음성 = 신호 수신·전달" → **지급 HW의 프로토콜 규격서**가 있어야 개발 가능.
- 우선순위 "[1순위] 일정 준수" + 착수 2주~1개월 후·9월 납품 → **디자인/HW/API 규격 지연이 곧 일정 리스크**.

## 2. 웹 리서치 — 치명적 발견 (근거 URL)

### 발견 ① (치명) 접근성은 "우대"가 아니라 **법적 강제 + 형사처벌**
공공기관 키오스크는 지능정보화기본법 제46조의2 + 장애인차별금지법에 따라 **1단계(2024.1.28) 의무 대상**.
2025.1.28 3단계까지 확대, **2026.1.28부터 기존 키오스크도 접근성 갖춘 것으로 교체 의무**(현시점 이미 발효).
차별행위 시 **3년 이하 징역 또는 3천만원 이하 벌금**.
- 보건복지부: 「장벽 없는 키오스크, 합리적 제도개선」 https://www.mohw.go.kr/board.es?mid=a10503000000&bid=0027&list_no=1487865&act=view
- 에이블뉴스(시행 단계·기존 교체 의무): https://www.ablenews.co.kr/news/articleView.html?idxno=224770

### 발견 ② (치명) "지급 디자인대로 구현" vs "접근성 검증 통과" **계약상 충돌**
KS X 9211:2022 / 무인정보단말기 정보접근성 검증기준(10원칙·47지표)의 핵심 항목 —
**명도대비 4.5:1, 글자높이 12mm, 터치타깃 12mm/150mm², 초점 표시, 저시력 확대 레이아웃** —
은 **화면 디자인 단계에서 이미 결정**됩니다. 공고대로 지급 디자인이 접근성 미고려 상태이면,
개발사가 그대로 구현 → **검증 탈락 → 책임이 개발사로 전가**될 위험.
- KS X 9211 표준: https://standard.go.kr/KSCI/standardIntro/getStandardSearchView.do?menuId=919&ksNo=KSX9211
- 검증 체크리스트(정량 기준): https://uxkm.io/accessibility/a11y/06-a11yCheck/03-checkKioskPrinciple

### 발견 ③ (치명) 검증은 **HW+SW+디자인 통합 평가** — SW 단독 통과 불가
키오스크 접근성 시험평가는 "SW 접근성과 HW(기기) 접근성 **모두를 포괄**". 그런데 공고는
**HW·디자인은 지급, 개발사는 SW만**. 이어폰잭(3.5mm)·물리키패드 배열(전화기+5번 돌기)·
설치높이(400~1220mm) 등은 HW/설치 영역이라 개발사 통제 밖. 지급 HW가 미달이면 SW가 완벽해도 전체 탈락.
- WebWatch 키오스크 접근성 시험평가: http://www.webwatch.or.kr/KA/KA_Intro.html?MenuCD=410

### 발견 ④ 결제는 아무 모듈이나 못 붙임 — **여신금융협회 등록 단말·밴사 규격**
카드결제는 여신금융협회 「신용카드 단말기 시험·인증 및 등록관리 규정」 등록 단말로만 가능.
지급 HW의 밴(VAN)·단말 규격(대개 시리얼/소켓 프로토콜)이 확정돼야 결제 개발 착수 가능.
무료(보증금) 대여면 PG 불필요할 수도 → **결제 범위 확정이 견적·일정의 전제**.
- 여신금융협회 단말기 등록제: https://www.crefia.or.kr/portal/board/boardDataList.do?boardid=bbs067

### 리서치가 데모에 반영된 정량 기준(KS X 9211)
명도대비 4.5:1(큰 글자 3:1) · 글자높이 12mm · 터치타깃 한 변 12mm·면적 150mm²·간격 2.5mm ·
작동력 22.2N 이하 · 응답시간 제한 금지(또는 남은시간 표시) · 깜빡임 3~50Hz 금지 ·
컨트롤 높이 400~1220mm · 개인정보 화면표시·음성낭독 금지 · 이어폰 3.5mm·음량 50dB 조절·최대 65dB.

## 3. 레퍼런스 실측 (2026-07 브라우저 직접 실측)

**이식 가능한 값만** 가져왔습니다 — 헤드라인 자간(−0.02~−0.03em, em 환산) · 타이트 LH · expo-out 이징 ·
**흑백 고대비**(Obys의 #000/#fff는 KS X 9211 4.5:1을 자연히 초과 → 고대비 모드에 그대로 활용).
KS X 9211이 **깜빡임 3~50Hz·자동변경 콘텐츠를 금지**하므로 장식성 모션은 원천 배제하고
`prefers-reduced-motion`을 존중했습니다.

**4축 채움 확인**: 디자인시스템(색토큰·타이포스케일·radius·spacing) / UI·UX(레이아웃 골격·빈상태·에러·모바일 전환) /
인터랙션(이징·지속시간·포커스·스크롤 리빌) / 그래픽 소스(아이콘 스타일·이모지 픽토그램) — 모두 채움.

## 4. 화면 구성

### 사용자 키오스크 (`index.html`) — 세로형 키오스크 프레임
- **접근성 툴바(상시)**: 음성안내(TTS) · 고대비 · 글자확대(3단계) · 화면낮춤(휠체어) · 물리버튼 모드
- **대여**: 홈 → 분류(이동보조/정보학습/행사회의) → 장비 선택(재고·품절·무료/유료) → 기간(1/3/7일) →
  (유료: 카드 결제 시뮬·마스킹) → 완료(대여번호·영수증)
- **반납**: 대여번호 키패드(전화기 배열·5번 촉각 돌기) 또는 최근 대여 선택 → 반납 확정 → 완료(재고 복구)
- **응답시간 제한**: 남은시간 표시 + "시간 연장" 버튼, **음성·물리버튼 모드에선 제한 해제**(KS X 9211)

### 관리자 콘솔 (`admin.html`)
- KPI(가용/대여중/품절/**검증 통과율**)
- **KS X 9211 접근성 검증 진단(핵심)**: 지급 디자인 시나리오 A/B 토글 → 대표 10지표 **실판정**,
  명도대비 실시간 계산, 통과율 게이지(dpr 대응 canvas), 탈락/통과 경고
- **명도대비 계산기**: 전경·배경 hex → WCAG 대비비 실계산 → 4.5:1 / 3:1 판정
- **책임 분계표**: 디자인(지급)/SW(개발)/HW(지급) 항목 매핑 → SW 단독 통과 불가 실증
- 재고 현황(키오스크와 실연동) · 대여 내역 + **CSV(UTF-8 BOM)** · 하드웨어 신호 상태 · 실시간 로그

## 5. 제안 스택 & 일정 (견적)

## 6. 착수 전 반드시 확인(미팅 안건)

1. **지급 디자인의 접근성 적합성** — 명도대비·글자크기·터치타깃이 KS X 9211을 만족하는가? (미달 시 재디자인 주체·비용)
2. **접근성 책임 경계** — 검증 탈락 시 디자인/HW(지급) vs SW(개발) 책임 분계를 계약에 명시.
3. **재고 원천 시스템** — 재고·상태 API 규격(있는가/신규 구축인가).
4. **결제 범위** — 유료 대여인가(밴·단말 규격) 무료·보증금인가(PG 불필요).
5. **지급 HW 규격서** — 물리버튼(HID/GPIO)·프린터(ESC-POS)·이어폰잭·음성 앰프 프로토콜.
6. **시험·검증 일정** — 지정 시험기관 현장 평가 리드타임(일정 1순위와 직결).
