# ALLEND 올렌드 — 배리어프리 장비 대여·반납 키오스크 (데모)

공공기관 장비 대여·반납 **배리어프리 키오스크 소프트웨어** 제안용 데모.
음성안내(TTS)·물리버튼 조작·고대비·저시력 확대가 **실제로 동작**하고,
KS X 9211 접근성 검증을 관리자 화면으로 **실증**합니다.

> ⚠ 모든 장비·대여·카드·기관 데이터는 **가상**입니다.

**공개 URL(별칭)**
- 사용자 키오스크 — `/allend/`
- 관리자·검증 — `/allend/admin/`

---

## 화면

| 화면 | 파일 | 핵심 |
|---|---|---|
| 사용자 키오스크 | `index.html` | 대여·반납 흐름 + 접근성 툴바(음성·고대비·확대·낮춤·물리버튼) |
| 관리자 콘솔 | `admin.html` | KS X 9211 검증 진단 · 명도대비 계산기 · 책임 분계표 · 재고 실연동 · CSV |

## 체험 시나리오

1. **대여** — 홈에서 "장비 대여" → 분류 선택 → 장비(재고·품절 표시) → 기간(1/3/7일) →
   무료면 확정, 유료(빔프로젝터 등)면 카드 결제 시뮬 → 완료(대여번호·영수증).
2. **반납** — "장비 반납" → 대여번호 입력(또는 최근 대여 선택) → 반납 확정 → 재고 복구.
3. **접근성** — 상단 툴바에서:
   - **음성** — 화면·초점을 한국어로 낭독(Web Speech API).
   - **물리버튼** — 하단 4버튼(이전/다음/선택/취소)으로 화면을 만지지 않고 조작. 초점이 이동하며 음성이 읽음.
   - **고대비** — 흑배경·노랑 액센트로 전환. **글자** — 3단계 확대. **낮춤** — 휠체어용 하단 정렬.
4. **관리자**(`admin.html`) —
   - **검증 진단**의 시나리오를 **A(지급·접근성 미고려) ↔ B(접근성 반영)**로 토글하면
     명도대비·글자·터치·타임아웃 지표가 **실제로 통과/미달**로 바뀌고 통과율 게이지가 움직입니다.
   - **명도대비 계산기**에 색을 넣으면 WCAG 대비비를 실시간 계산.
   - 키오스크에서 대여·반납하면(다른 탭) 재고·로그가 **실시간 반영**됩니다.

## ⚠️ 착수 전 확인 (미팅 안건)

1. 지급 디자인의 **접근성 적합성**(명도대비·글자·터치) — 미달 시 재디자인 주체·비용
2. 접근성 검증 탈락 시 **디자인/HW(지급) vs SW(개발) 책임 분계** 계약 명시
3. **재고 원천 시스템** API 규격(기존/신규)
4. **결제 범위** — 유료(밴·단말 규격) vs 무료·보증금(PG 불필요)
5. 지급 HW 규격서 — 물리버튼(HID/GPIO)·프린터(ESC-POS)·이어폰잭·음성

  × 정부24(Pretendard GOV·17px·#1e2124) → 공통 = 큰 본문·near-black 고대비·단순 위계
- **디자인(어워드)**: Obys Agency(Awwwards SOTD 2026.07.28) — 흑백 고대비 #000/#fff·헤드라인 자간 −0.030em·
  이징 cubic-bezier(.19,1,.22,1) / Linear — h1 자간 −0.022em

  KS X 9211 깜빡임·자동변경 금지 준수, `prefers-reduced-motion` 존중.

## 기술 구성

- 순수 HTML/CSS/JS(외부 런타임 의존 없음), Pretendard(CDN).
- `assets/js/core.js` — 목데이터·재고 실연산·**WCAG 명도대비 실계산**·KS X 9211 스펙·TTS 래퍼·CSV(BOM).
- `assets/js/kiosk.js` — 화면 라우팅·접근성 토글·로빙 포커스·응답시간 제한.
- `assets/js/admin.js` — 검증 진단·명도대비 계산기·책임 분계·게이지(dpr canvas)·CSV·재고 실연동(localStorage).
- 접근성: 음성(speechSynthesis)·키보드/물리버튼 조작·고대비·확대·초점 표시·개인정보 낭독 예외.
