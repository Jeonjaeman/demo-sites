# GYEOL 결 — 다국어 iPad 설문·메뉴판 웹앱 (데모 77)

프리미엄 미용의원의 원내 iPad 컨설테이션 데모. 4개 국어(한/영/일/중) 설문 → 추천 → 럭셔리 카탈로그 메뉴판 → 상담실장·관리자까지 세 표면.
**모든 병원·시술·가격·인물은 가상 데이터입니다.**

| 표면 | 파일 | 설명 |
|---|---|---|
| 고객 iPad 앱 | `index.html` | 어트랙트 → 언어 → 동의 → 정보 → 설문 3문항 → 추천 → 메뉴판 → 상세 → 완료 |
| 상담실장 뷰 | `consult.html` | PIN `0000` · 제출 목록·정규화 요약·마스킹/열람 로그·상담가 |
| 관리자 | `admin.html` | 대시보드·제출·시술(초안/발행)·설문/매핑·B&A·수명주기·준수·기기 |

## 체험 시나리오 (입력 없이 클릭만으로)

1. **고객 앱** — TOUCH TO BEGIN → `日本語` 선택(폰트 지연 로드) → 동의 2개 체크 → 정보는 **프리필** 그대로 다음 → 고민 카드 2~3개 → 추천 희망 → 「오늘 바로 일정이 있어요」 → **다운타임 0 시술만 추천**되는 것 확인 → 메뉴판 → 시술 상세(패키지 3단·B&A 슬라이더는 루미너스 토닝/포어 프락셔널)
2. **우하단 ⚙ 데모 컨트롤** — 「세션 타임아웃 시연」 켜고 8초 대기 → 카운트다운 → 전량 소거 / 「오프라인 시뮬」 켜고 설문 제출 → 큐 적재 → 끄면 자동 전송 / 「유치 등록 해제」 → 언어 화면 日/中 잠김
3. **상담실장 뷰** — 佐藤 結衣(일본어 응답)를 열면 **한국어로 정규화**된 요약 + 원문 병기, 「전체 보기」 클릭 → 열람 로그 적재, 시술별 상담가(최저 승인가) 확인
4. **관리자** — 시술 관리에서 가격 수정 → 「초안 저장」 → **미리보기(고객/상담 2분할)** → 「발행」 → 고객 앱 메뉴가 v13으로 갱신 / 이벤트가 켜고 3필드 비우면 저장 잠김 / 설명에 "최고" 입력 → 금지표현 밑줄 / B&A 게이트 3개 체크 전 저장 비활성 / 준수 체크에서 등록번호 삭제 → 고객 앱 日/中 잠김 / 공개 범위 「외부 공개」 → 심의 경고 모달

## ⚠ 착수 전 확인 (미팅 안건)

1. 설문 데이터 최종 저장 위치 — 공고 「과업 범위=프론트엔드」와 「관리자·제출 확인」의 범위 모순 (정적 JSON 2안 vs 경량 백엔드)
2. 상담실장 확인 기기·인증 방식
3. 고객 노출 가격 범위(정가/이벤트가) 정책
4. 외국인환자 유치기관 등록 여부 (미등록이면 日/中 오픈 시점)
5. 동의문 법무 검토 · B&A 기존 동의서 보유 여부 · 보유기간 내규
6. 홈페이지·SNS 콘텐츠 재사용 계획(있다면 의료광고 심의 대상 전환)

## 디자인 실측 명세 (근거: 분석/레퍼런스_실측.md)

- 팔레트 5색: bone `#f4f3ec` · paper `#fff` · ink `#150600` · deep `#322d25` · gold `#BFA072` + 잉크 알파 사다리(60/38/16/8%)
- 규율: border-radius 0(버튼 pill 예외) · box-shadow 금지 · 순백/순흑 금지 — Aesop·Genesis·ERA 3사 실측 공통
- 타이포: Pretendard + Marcellus(영문 디스플레이) · 언어별 분기 — 국문 lh 1.30/ls −0.03em/w500 ↔ 영문 lh 1.10/−0.016em/w400 · JA/ZH는 Noto Sans 지연 로드
- 모션: 화면 전환 800ms `cubic-bezier(.76,0,.24,1)`(ERA) · 리빌 600ms `(.25,1,.5,1)` stagger 40~80ms · 이미지 슬로우 줌 1.5s(더가든) · 성공만 오버슈트(MIU MIU) · `prefers-reduced-motion` 대응
- 가격 표기: 본문 크기 17px w400 (Genesis `Starting MSRP` 문법 — 크게·굵게·빨갛게 금지)
