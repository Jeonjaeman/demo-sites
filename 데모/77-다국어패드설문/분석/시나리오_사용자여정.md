| 7 | 중간 이탈 | 40% 채운 데이터 소멸 | 미완료도 진행률과 함께 보존(별도 짧은 보유기간) |

## 3. 역할별 시야 차이 (권한 설계의 핵심)

| 데이터 | 고객 iPad | 상담실장 뷰 | 관리자 |
|---|---|---|---|
| 가격 | 고지 기준가 1개 + "패키지는 상담 시" | + 패키지가·최저 승인가·대안 시술 | + 변경 이력(누가·언제·얼마→얼마) |
| 설문 결과 | 내가 고른 것만 | 정규화 요약 + 미완료 진행률 | 기간 집계(관심사 TOP·언어 분포) |
| 개인정보 | 입력값(제출 후 소거) | **마스킹 기본** · 열람 시 로그 적재 | 보유기간·파기 대상·열람 로그 |
| B&A | 3중 게이트 통과분만 | 동일 | 업로드 게이트·공개 범위 토글 |
| 콘텐츠 | 발행 버전 | 발행 버전 | 초안 + 발행 + 2분할 미리보기 |

## 4. 기능별 존재 이유 전수 매핑

리서치 발견 21건(A-1~D-5) → 데모 기능 매핑 전수표는 [리서치_상세.md](리서치_상세.md) 4장에 있다. 요지:
- **A-1 가격 노출 충돌** → 공개가/상담가 2필드 + 관리자 2분할 미리보기
- **A-2 세션 리셋 부재** → 유휴 소거 + 시연 모드(8초)
- **A-3 Fullscreen API 부재** → 설치 가이드 3스텝 + 키오스크 상태 실측 패널
- **B-1 원내=비심의/외부=심의** → 공개 범위 토글 + 심의 대상 건수 경고 + B&A 3중 게이트 + 금지표현 검출
- **B-2 유치기관 등록** → 등록번호 비우면 日/中 버튼 실제 비활성
- **B-3 민감정보 별도 동의** → 동의 스텝 신설 + 수명주기 패널 + 마스킹·열람 로그
- **B-4 14세 미만** → 만 나이 자동 분기 + 보호자 동의
- **B-5 비급여 고지** → 고지 뷰 + 인쇄 + 가격 변경 이력
- **B-6 유인·알선 경계** → 이벤트가 3필드(대상·기간·할인폭) 필수 잠금 + 기간 만료 자동 복귀
- **B-8 전자 동의 효력** → 동의 버전·해시 저장 + 「동의서 원본 재현」
- **C-1 CJK 폰트 16MB** → 언어별 지연 로드 + 관리자 실측 표시
- **C-2 오프라인** → 로컬 큐 + 자동 재전송 + 시뮬 토글
- **C-3 다중 iPad 동기화** → 초안/발행 + 기기별 버전
- **D-3 고민→시술 매핑** → 관리자 편집형 가중치 매트릭스 → 추천 실계산

## 5. 비는 구멍 — 미팅 확인 필요 (16건)

원문은 [리서치_상세.md](리서치_상세.md) 1-5절. 핵심 8건:
1. 설문 데이터의 최종 저장 위치(서버 유무) — 공고 「과업 범위=프론트엔드」와 「관리자·제출 확인」의 **범위 모순**
2. 상담실장이 결과를 보는 기기(전용 iPad? 데스크 PC?)와 인증 방식
3. 고객 노출 가격의 범위(정가만? 이벤트가도?) — 데모는 "정가+조건 명시 이벤트가"로 제안
4. 외국인환자 유치기관 등록 여부 — 미등록이면 日/中 오픈 시점 조정
5. 동의문 법무 검토 주체 — 데모 문구는 구조 제안이며 최종 문구는 법무 확인 필요
6. B&A 사진의 기존 동의서 보유 여부
7. 문진·동의 데이터 보유기간 정책(병원 내규)
8. 홈페이지·SNS 재사용 계획 유무(있다면 심의 대상 전환)

## 6. 검증에서 발견해 고친 버그 (자기 검증 증거)

1. 캔버스 차트가 레이아웃 확정 전 측정돼 backing 28px로 그려짐 → 크기 확정 대기 가드 추가
2. 백그라운드 탭에서 rAF가 멈춰 차트·카운트업이 중간 상태로 정지 → 최종 상태 보장 폴백
3. 생성 이미지 1장(눈가)에 AI 텍스트 아티팩트 → 재생성 교체
4. 같은 카테고리 시술들이 동일 이미지 반복(템플릿 냄새) → 시술별 개별 이미지 재배정
5. 데모 컨트롤 버튼(⚙)이 하단 CTA와 겹침 → 푸터 우측 여백 64px
6. 국문 카드 라벨 어절 중간 줄바꿈 → `word-break: keep-all`
