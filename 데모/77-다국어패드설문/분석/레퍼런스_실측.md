### 4-6. 자기 검열 체크(4단계 완료 전)

- [ ] 배경이 `#ffffff` 순백인가? → **실패**. `#f4f3ec` 웜 본이어야 한다
- [ ] 잉크가 `#000` 순흑인가? → **실패**. `#150600`
- [ ] box-shadow가 하나라도 있는가? → **실패**. 3사 모두 0건
- [ ] 색이 5개를 넘는가? → **실패**. Aesop 2 / Genesis 3 / ERA 5
- [ ] 디스플레이 line-height가 1.0 이상인가? → 영문은 **0.88~0.90**이어야 한다
- [ ] 가격이 제목보다 크거나 굵거나 빨간가? → **실패**. Genesis·Aesop 모두 본문 동급
- [ ] 국문/영문 line-height를 한 값으로 통일했는가? → **실패**. 1.30 vs 1.10 분기 필수
- [ ] 터치 타겟이 44px 미만인가? → 실패
- [ ] 카드 3열 반복으로 섹션을 채웠는가? → 양끝 정렬 디스플레이·풀블리드 패널로 교체
