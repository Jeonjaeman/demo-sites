## 3. 웹 리서치 발견 (요약 — 근거 URL 전문은 리서치_상세.md)

**우선순위 P1 (그대로 만들면 작동하지 않음)**
- **A-1** 고객 iPad 정찰가 전면 노출은 상담실장 실무와 충돌, 감추면 의료법 45조 위반 → 정가는 고지 / 패키지는 상담 뷰
- **A-2** 공용 iPad 세션 리셋이 명세에 없음 → 다음 고객이 앞 고객 개인정보를 봄
- **A-3** iPad Safari에는 Fullscreen API가 없음 → "URL 접속 후 전체화면"은 홈 화면 추가 + Guided Access 운영 세팅이 실답

**우선순위 P2 (법 위반 소지)**
- **B-1** 원내 iPad는 의료광고 사전심의 대상 매체가 아님(의료법 57조 매체 목록·불특정 다수 기준) — **홈페이지에서 못 하는 B&A·상세가를 원내에서는 할 수 있다.** 단 외부 공개 순간 56·57조로 전환
- **B-2** 4개 국어 = 외국인환자 유치 의사 → 유치기관 미등록 시 3년 이하 징역(의료해외진출법)
- **B-3** 피부 고민 = 건강정보 = **민감정보** → 별도 동의 필수(개보법 23조 · 위반 시 5년 이하)
- **B-4** 만 14세 미만 법정대리인 동의(22조의2) · **B-5** 비급여 고지 의무(45조) — 이 앱이 고지 수단이 됨 · **B-6** 이벤트가는 대상·기간·할인폭 명시 시 제한적 허용(27조 3항 해석) · **B-7** 장비 브랜드 표기 경계(의료기기법 24조) · **B-8** 전자 동의는 "당시 형태로 재현"돼야 서면 효력(전자문서법 4조의2)

**우선순위 P3 (운영 중 터짐)** — C-1 CJK 폰트 16MB(서브셋·지연 로드), C-2 오프라인 큐, C-3 다중 iPad 동기화(초안/발행), C-4 100svh, C-5 터치 44px, C-6 언어 선택기 국기 금지, C-7 중간 이탈 보존, C-8 보존기간 병원 자체 정의
