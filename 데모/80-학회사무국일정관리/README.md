# BUREAU 뷰로 — 학회 사무국 일정·미팅 관리 (데모 80)

의학 학회 사무국 직원 10명이 매일 쓰는 내부 일정·미팅 시스템 데모. **좌측 내비 / 중앙 콘텐츠 / 우측 작업 패널** — 중앙의 무엇을 눌러도 화면 이동 없이 우측에서 바로 보고·고치고·저장합니다. 디자인 시스템은 사용자 지정 **X 웹(Mobbin)** 을 픽셀 실측해 그대로 이식했습니다.
**학회·인물·일정은 전부 가상입니다**(대한가온의학회 · 아바타는 Higgsfield 생성 가상 인물).

| 표면 | 파일 | 설명 |
|---|---|---|
| 앱 | `index.html` | 홈(나의 하루·사무국 전체·사무국 소식) · 캘린더(월·주·목록) · 미팅(예정·지난·회의실) · 마감 · 팀 현황 · 알림 · 검색 · 관리(관리자) · 제안 검토 |
| 로그인 | `login.html` | 아이디·비번 → 인증 앱 6자리 · 체험 계정 3종 · 5회 실패 잠금 · 자동 로그아웃 안내 |

공개 별칭: `/bureau/` (앱) · `/bureau/login/` (로그인)

## 체험 시나리오 (입력 없이 클릭만으로)

1. **우측 빠른 등록** — 「이렇게 써 보세요」 예시 클릭 → 날짜·시간·장소·사람이 칩으로 나뉨 → Enter → 캘린더에 깜빡이며 등록, 우측은 바로 편집 상태
2. **캘린더** — 빈 날짜 클릭 → 우측 새 일정(날짜 채움) · 제목을 치면 분류 자동 선택 + 캘린더에 점선 초안 칩 · 주 보기에서 빈 칸을 끌어 시간 범위 선택 · 일정을 끌어 옮기기(되돌리기)
3. **제안 검토 › F8** → 「2027 춘계학술대회 등록해 보기」 → 외부 마감 5건(제약사 D-90·평점 D-20/D-5/D+28·결과보고 D+90)이 담당자·근거와 함께 펼쳐짐 → 저장
4. **F9 동시 예약 재현** → 저장 → 거절 + 빈 시간·다른 회의실 칩 → 하나 누르고 저장
5. **F10 동시 수정 재현** → 제목 고쳐 저장 → 필드별 병합 시트
6. **F3 주간회의 회차** → 시간 바꿔 저장 → 이 일정만/이후 모두/전체 (영향 회차 깜빡임) · 10월 달력에서 10/5(대체공휴일) 회차 자동 제외 확인
7. **계정 메뉴(좌하단)** → 박서연(직원)으로 전환 → 「직원 인사평가 면담」이 비공개 회의로 보임 · 관리 메뉴 사라짐
8. **관리(관리자)** → 접속기록 CSV · 월간 점검 · 공휴일 추가 → 겹치는 일정 알림 · 운영 상태 복원 리허설 · 퇴사자 이관 마법사 · 로그인 보안 › 자동 로그아웃 재현

## ⚠ 착수 전 확인 (미팅 안건)

1. 분류 체계 최종안(데모: 학술대회·교육·위원회·연구비·국제교류·행정 + 부재)과 확정 주체
2. 정례 회의가 공휴일과 겹칠 때 관행 — 순연 / 건너뛰기
3. 알림 채널(메일 / 알림톡) · 외부 위원에게 시스템 메일 발송 가능 여부
4. 외부 캘린더 연동 필수 여부 (구독은 보기용 + 지연 안내로 제안)
5. 국장의 비공개 회의 열람 여부 · 삭제 권한 범위
6. 후원 협회(KRPIA·의료기기)별 실제 신청 기한 · 사무국 자체 휴무일
7. 회의실 수 · 외부 대관 장소 관리 여부 · 올해 남은 일정 이관 건수
