## 6. 비는 구멍 — 미팅 확인 질문

1. 정례 회의가 공휴일이면 관행은 **순연**인가 **건너뛰기**인가? (데모는 건너뛰기 + 회차만 옮기기)
2. 알림 채널 — 메일? 카카오 알림톡(유료)? 외부 위원에게도 시스템 메일을 보내도 되나?
3. 퇴사자 과거 일정 보존 방식 — “(퇴사) 이름” 표기로 충분한가?
4. 한 일정을 여러 명이 고치는 일이 잦은가? 삭제 권한은 작성자만? 국장도?
5. 사무국 자체 휴무일(창립기념일 등)이 있는가?
6. 외부인 연락처를 이 시스템에 둘 필요가 있나(주소록 별도?) · 보관 기간은?
7. 회의실 몇 개? 외부 대관 장소도 관리하나?
8. 분류 최종안 확정 주체 (킥오프 1주 산출물로 제안)
9. 국장이 비공개 회의를 볼 수 있어야 하나?
10. 외부 캘린더 연동이 필수인가, 모바일 웹으로 충분한가? (구독은 보기용 + 지연 안내로 제안)
11. 구글 워크스페이스·네이버웍스 계정 사용 여부 (SSO 가능성)
12. 올해 남은 일정 이관 기간·건수 (CSV 일괄 등록 템플릿 제공)
13. 계약직·인턴 계정 계획 (10명 초과 시)
14. 이사회 공식 의사록이 별도 양식(서명)인가?
15. “전체 시스템 기능 목록” 공유 가능? (스키마에 업무관리·결재 자리 확보)
16. 마감 알림 시점 · 영업일 기준 여부
17. 월 유지비 상한 · 결제 계정 명의
18. 후원 협회(KRPIA·의료기기협회) 실제 신청 기한

## 7. 검증에서 발견해 고친 버그

| # | 증상 | 원인 | 수정 |
|---|---|---|---|
| 1 | “내일 오전 10시반~12시”가 10:30~11:30으로 저장 | 범위 끝 시각에 시작의 “오전”이 상속돼 12시 → 0시 → 1시간 기본값으로 덮임 | 끝 시각은 오후만 상속, 0시 이하이면 정오 이후로 보정 |
| 2 | 동시 수정 병합표에 “외부 참석자 없음 → 없음” 같은 가짜 차이 | 빈 배열과 undefined를 다르게 비교 | 필드별 기본값 정규화 후 비교 → 실제 변경 4건만 표시 |
| 3 | 패널 저장 버튼이 하단 “데모” 꼬리표에 가려짐 | 고정 배치 겹침 | 꼬리표를 좌측 내비 하단으로 이동 |
| 4 | 팀 현황 첫 행(정혜원)이 머리글 뒤로 숨음 | 가로 스크롤 컨테이너 안 sticky가 헤더 높이만큼 내려옴 | 머리글 sticky 제거 · 주간 머리글은 실제 헤더 높이로 계산 |
| 5 | 마감 행 안 체크박스가 버튼 안에 중첩(무효 HTML) | `<button>` 안 `<input>` | 행을 `role=button` div + Enter/Space 키 처리 |
| 6 | 홈 요약 숫자를 누르면 중앙 화면이 바뀜 | 사용자 원칙(“화면 이동 없이 우측”) 위반 | 요약 칸 → 우측 패널 목록(오늘·응답 대기·마감·부재) |
| 7 | 주간 격자에서 한지우 외근(4시간)이 열을 차지해 다른 일정이 반토막 | 부재도 일반 일정처럼 겹침 열 계산 | 부재는 칸을 차지하지 않는 빗금 띠로 |
| 8 | 월간 칩·마감 행의 작은 아이콘이 화면 크기로 커짐 | 아이콘 크기 규칙이 칩 안에만 있음 | 인라인 아이콘 공통 크기 14px |
