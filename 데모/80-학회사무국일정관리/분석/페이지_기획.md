# 80 BUREAU — 화면 기획 (사이트맵 · 화면별 목적)

> 성격: **업무형 웹앱(그룹웨어 일정 모듈)** — 브랜드 사이트가 아니므로 CLAUDE.md 「멀티페이지 원칙」의 브랜드 섹션(풀블리드 히어로 등)은 적용하지 않는다. 대신 **사용자 지정 구조**를 따른다:
> **좌측 내비 / 중앙 콘텐츠 / 우측 작업 패널** — 중앙의 어떤 항목을 눌러도 화면 이동 없이 우측 패널에서 조회·수정·저장.
> 메뉴는 해시 라우팅(`#/cal/month` 등)으로 각각 딥링크되는 독립 화면이고, 로그인은 별도 페이지(`login.html`)다.

## 사이트맵

```
login.html                     로그인 (아이디·비번 → 인증 앱 6자리) · 체험 계정 3종 · 5회 실패 잠금 재현
index.html (앱 셸)
├─ 좌: 내비 9 + 「일정 등록」 + 계정 메뉴(체험 계정 전환 · 단축키 · 초기화 · 로그아웃)
├─ 중:
│   #/home        홈 — 나의 하루 / 사무국 전체 / 사무국 소식(변경 피드)
│   #/cal/month   캘린더 월 (다일 막대 · +n 더보기 · 공휴일)
│   #/cal/week    캘린더 주 (시간 격자 · 끌어서 범위 선택·이동·길이 조절 · 부재 빗금 띠)
│   #/cal/list    캘린더 목록 (30일)
│   #/mtg         미팅 — 예정 / 지난 미팅 / 회의실 현황(시간축 타임라인)
│   #/due         마감 — 외부 기관 마감 · 학회 자체 준비 (D-day 그룹)
│   #/team        팀 현황 — 직원 × 요일 (부재·외근·출장·마감)
│   #/noti        알림 — 초대·변경·마감 임박 (바로 응답)
│   #/search      검색 — 제목·참석자·장소·회의록 본문
│   #/admin       관리 (관리자만) — 설정 목록 10
│   #/review      제안 검토 — 발견 16 / 성공 기준 8 / 스택·스키마
└─ 우: 작업 패널 (스택형 · ← 뒤로 · 작성 중 이탈 방지)
     빠른 등록(기본) · 일정/미팅 폼(새로·상세=곧 편집) · 회의록 · 할 일 · 이력
     날짜 · 사람 · 요약 목록 · 관리 상세 10 · 발견 상세 · 성공 기준 · 단축키 · 주간 요약 메일 · 퇴사자 이관
```

## 화면별 기획

| 화면 | 목적 | 방문자가 여기서 할 일 | 구성 | 다음 행동(→ 우측 패널) |
|---|---|---|---|---|
| 로그인 | 10명 계정 + 외부 접속 대비 | 아이디·비번 → 인증 앱 코드 | X 로그인 모달 문법(600px r16 · 31px 제목 · 52px 알약 버튼) | 앱 진입 |
| 홈 · 나의 하루 | 출근 직후 오늘 파악 | 오늘 일정·응답 대기·마감·부재 확인 | 요약 4칸(카운트업) · 오늘 타임라인(지금 선) · 내 할 일 · 다가오는 마감 | 요약 칸 → 패널 목록 / 항목 → 상세 |
| 홈 · 사무국 소식 | 메일로 돌던 “일정 바뀌었어요”를 대체 | 누가 무엇을 바꿨는지 훑기 · 초대에 응답 | X 타임라인 셀(아바타·이름·시간·본문·첨부 카드) | 카드 → 상세 · 참석/미정/불참 |
| 캘린더 월·주·목록 | 사무국 전체 일정을 한곳에서 | 분류·내 일정 필터 · 이동 · 끌어 옮기기 | 7분류 칩(X 강조색 6 + 부재) · 월 다일 막대 · 주 시간 격자 | 빈 칸 → 새 일정(날짜·시간 채움) · 칩 → 상세 |
| 미팅 | 내부 미팅 등록·조회 | 응답 대기 확인 · 회의록 열기 · 회의실 비는 시간 | 날짜 박스 목록 · 참석 n/m · 회의록 배지 · 회의실 시간축 | 행 → 미팅 상세(정보·회의록·할 일·이력) |
| 마감 | 외부 기관 마감을 놓치지 않기 | 완료 체크 · 근거 확인 | 지남/7일/30일/이후 그룹 · 법정 기한·영업일 당김 표기 | 행 → 마감 상세(근거 링크·행사로 이동) |
| 팀 현황 | 누가 어디에 | 부재·외근 확인 · 퇴사자 일정 경고 | 직원 × 5일 격자 | 사람/칸 → 개인 일정 |
| 알림 | 내가 포함된 변화 | 초대 응답 · 변경 확인 | 아이콘 + 본문 + 첨부 카드 | 상세 |
| 검색 | 메일 검색을 대체 | 단어 하나로 찾기 | X 검색칸 · 추천 칩 · 결과(매칭 위치 배지) | 결과 → 상세 |
| 관리 | 개발자 없이 운영 | 계정·권한·접속기록·공휴일·백업·휴지통 | X 설정 목록(아이콘·제목·보조) | 목록 → 우측 상세 (X 설정 화면과 같은 구조) |
| 제안 검토 | 의뢰자가 우리 발견을 근거와 함께 확인 | 발견 → 체험 버튼 · 성공 기준 체크 · 스택·스키마 | 우선순위 원형 번호 · 태그 | 상세 + 「데모에서 확인」 |

## 우측 패널 설계 원칙

1. **입력은 언제나 우측에서** — 새 일정·수정·회의록·응답·관리 설정까지 같은 자리.
2. **스택 + ← 뒤로** — 날짜 → 일정 → 행사로 이동해도 뒤로 돌아감. 같은 종류를 연달아 열면 크로스페이드(180ms)만, 새 종류는 16px 슬라이드(320ms `(.2,.715,.205,.99)`).
3. **작성 중 이탈 방지** — 다른 항목을 누르면 「저장하고 이동 / 저장하지 않고 이동 / 계속 작성」 시트. 새 일정 초안은 자동 보관.
4. **필수 3개(제목·일시·분류)** — 분류는 제목에서 자동 선택, 나머지는 「세부 옵션」에 접음.
5. **저장 = Ctrl+Enter**, 저장 후 중앙 캘린더의 해당 칩이 한 번 깜빡이고 토스트에 「되돌리기」.
6. 모바일(≤699px)에선 하단 바텀시트(500ms `(.32,.72,0,1)`), 태블릿(≤1023px)에선 우측 오버레이.

## 견적 기준 화면 수

로그인 1 + 앱 주요 화면 11(홈 2탭 · 캘린더 3 · 미팅 3탭 · 마감 · 팀 · 알림 · 검색 · 관리) + 우측 패널 뷰 14 = 실제 구축 범위. 제안 검토 화면은 데모 전용(실서비스 미포함).
