### 업계 공통 문법 (3곳 + 보조에서 반복 확인된 것)
1. **3단 골격** — 좌측 사이드바(237~274px: 생성 CTA → 미니 월력 → 캘린더 레이어 체크 목록) / 중앙 시간 그리드 / 상세(우측 패널·팝오버). 상단 툴바 순서는 `오늘 · ‹ › · 기간 제목 · (보기 전환)`.
2. **생성 진입은 두 갈래** — 사이드바 상단 primary 버튼 + 그리드 빈 칸·날짜 클릭. 클릭 즉시 **임시 칩**(잔디 "제목 없음")이 그리드에 먼저 보인다.
3. **필수는 제목·일시뿐, 나머지는 기본값** — 시작 = 다음 슬롯/현재시각, 종료 = +30분(Proton)·+1시간(잔디). 잔디는 제목 전 저장 비활성. (경쟁 지원자 댓글의 "입력 3~4개로 등록 완료"와 일치)
4. **아이콘이 앞서는 한 줄 필드** — 세 서비스 모두 좌측 16px 아이콘 + 필드 1행 구조, 라벨 없이 placeholder로 의미 전달. 필드 순서는 `제목 → 일시(종일) → 반복 → 캘린더(색) → 참석자 → 장소 → (알림) → 설명 → 공개범위`.
5. **상세는 화면 이동 없이** — 우측 패널(Rise·Calendly) 또는 팝오버(Proton·잔디). 페이지 이동형은 3곳 모두 없음. 패널형은 **그리드를 밀어내고(push)** 같은 자리에서 바로 수정·저장.
6. **저장 = 토스트 + 칩 즉시 반영** — 토스트 위치는 하단 중앙(Proton)/상단(잔디), 문구는 "결과를 말하는 한 문장".
7. **참석자는 주최자 표시 + 응답 상태** — `Organizer / 주최자` 라벨, `pending` 수, 참석여부 선택.
8. **이벤트 칩 = 연한·진한 배경 + 좌측 3~4px 컬러 바 + 제목(굵게)/시간(보조)**. 현재시각은 빨간 선 + 점.
9. **회의실은 별도 마스터가 아니라 "참석자/자원" 입력에 섞이거나(Rise) 자유 텍스트**(Proton·잔디) — 중복 예약 방지 기능은 세 곳 화면 어디에도 보이지 않는다(→ 데모 차별점 후보).
