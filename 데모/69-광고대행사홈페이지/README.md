# UNFRAME 언프레임 — 광고대행사 브랜드 홈페이지 (데모 69)

> 위시켓 「아임웹 기반 광고대행사 반응형 홈페이지 구축」(500만원·45일) 대응 제안용 데모.
> **전략: 자체제작(커스텀 개발) 제안** — 아임웹 문제점을 공식 문서 근거로 지적하고,
> 무료 호스팅(연 유지비 0원)과 커스텀 포트폴리오 관리 프로그램을 데모로 증명한다.
> UNFRAME은 가상 브랜드이며 모든 실적·수치·고객사는 시연용 가상 데이터입니다.

## 체험 시나리오 (입력 없이 클릭만으로)
1. 메인에서 스크롤 — 히어로 영상이 스크롤을 따라 재생되고 4단 캡션 후 settle
2. Works → 「퍼포먼스」 필터 → TERRA 카드 → 상세에서 성과·근거 확인
3. 관리자 → 포트폴리오 → 드래그로 순서 변경 → 「아임웹 방식 체험」 토글 → 날짜를 미래로 바꿔보기(차단 경고)
4. 관리자 → 비용·트래픽 → SSL 체크 토글로 연간 비용 변화 확인
5. 관리자 → 버전 이력 → 저장 → 포트폴리오 순서 바꾼 뒤 → 롤백

## 기술 구성
- 정적 HTML/CSS/JS — 프레임워크·빌드 없음 (10k-websites 스킬 워크플로)
- 히어로: Higgsfield 시작 프레임(2k) → Seedance 2.5 image-to-video 6s 1080p → ffmpeg 재인코딩(키프레임 6프레임 간격, 2.3MB) → **Blob fetch + rAF lerp 스크럽 + seek 게이트**. 모바일·reduced-motion은 포스터 폴백
- 이미지 11장 Higgsfield 생성(무텍스트·무로고·실존 IP 없음), Pillow webp 최적화(전부 100KB 이하)
- 데이터 단일 소스 `assets/js/data.js` — 공개 사이트·관리자 공유. 관리자 상태는 sessionStorage/localStorage
- 캡처·검수용 `index.html?flat=1` (스크럽 스페이서 제거·settle 고정)
