[프로젝트 개요]
광고대행사 홈페이지 리뉴얼

[프로젝트 배경 및 목표]
기존 홈페이지의 노후화로 인해 다양한 타겟층(기업 고객, 일반 소비자, 구직자 등)에게
당사의 포트폴리오와 비전을 효과적으로 전달할 수 있는 새로운 웹사이트가 필요합니다.
한정된 예산을 고려하여 아임웹(I'm web) 솔루션을 활용하되, 템플릿의 단순 복사가 아닌
당사의 브랜드 아이덴티티가 돋보이는 맞춤형 디자인 세팅을 목표로 합니다.

[과업 범위]
1. 수행 범위
- 기획 및 디자인: 사이트맵 구성, 아임웹 기반 UI/UX 디자인 기획, 반응형(PC/Mobile) 퍼블리싱 세팅
- SW 개발: 아임웹 솔루션 내 기능(게시판, 입력폼, 팝업 등) 세팅 및 도메인 연결

2. 상세 기능 요구 사항
2-1. 사용자 화면 (프론트엔드)
- 메인 페이지: 히어로 배너 구성
- 메인 페이지: 주요 포트폴리오 슬라이드 노출
- 메인 페이지: 제공 서비스 요약 안내
- 회사 소개: 비전 및 연혁 안내
- 회사 소개: 오시는 길 지도 API 연동
- 포트폴리오: 그리드 형태의 작업물 목록 제공
- 포트폴리오: 카테고리별 필터링 기능
- 포트폴리오: 상세 이미지 및 영상 뷰어 제공
- 이벤트 안내: 진행 중 및 종료된 이벤트 목록 제공
- 이벤트 안내: 메인 화면 팝업 배너 노출
- 고객 문의: 상담 요청 입력 폼 제공
- 고객 문의: 개인정보 수집 및 이용 동의 체크 기능

2-2. 관리자 화면 (아임웹 기본 기능 활용)
- 대시보드: 방문자 통계 확인
- 포트폴리오 관리: 신규 작업물 이미지 및 링크 업로드
- 포트폴리오 관리: 노출 순서 변경 기능
- 이벤트 관리: 이벤트 게시글 작성 및 팝업 기간 설정
- 문의 관리: 접수된 문의 내역 리스트 조회
- 문의 관리: 관리자 이메일 및 문자 알림 수신 설정

3. 비기능적 요구사항
3-1. 성능/규격: PC, 태블릿, 모바일 환경에 모두 최적화된 반응형 웹으로 구축되어야 합니다.
3-2. 보안/인증: 아임웹에서 제공하는 기본 SSL 보안 인증서를 적용해야 합니다.
