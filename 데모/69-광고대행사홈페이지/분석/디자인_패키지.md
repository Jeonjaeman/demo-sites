# UNFRAME 언프레임 — 디자인 패키지 (Tier 1 · 10k-websites)

> 카피사이트(기준): **emotion.co.kr** — 재현하고 능가한다.
> 능가 수단: emotion에 없는 **스크롤 스크럽 시네마틱 히어로**(6s·1080p) + Noomo 다크 팔레트 설계 + nk.studio clip-path 리빌.
> 데모 표면 분리: index.html(브랜드 공개 사이트, 이 패키지) / admin.html(커스텀 포트폴리오 관리자, 대시보드 UI — 별도).

## 1. 브랜드 전제
- **UNFRAME 언프레임** — 가상 풀서비스 광고대행사(브랜드 캠페인·퍼포먼스·콘텐츠). 푸터에 가상 브랜드 고지.
- 서사: "틀(템플릿) 밖에서, 흩어진 메시지를 브랜드로 정렬한다" — 공고의 "템플릿 복사가 아닌 맞춤형" 요구와 자체제작 제안 서사에 정확히 겹침.
- 단 하나의 CTA: **프로젝트 문의** (모든 섹션이 이곳으로 퍼널)

## 2. 팔레트 (잉크 월드에서 추출 · 순검정/순백 금지 — Noomo 법칙)

## 3. 타입 트리오 (전부 무료 폰트 — 유료 폰트 가정 금지)
- **디스플레이**: Archivo (w800, 국문 혼용 시 Pretendard w800) — 킹콩애드 실측 계승. 히어로 clamp(56px, 9vw, 132px) / ls −0.04em / lh 0.95
- **본문**: Pretendard — 17px/1.7
- **라벨·수치**: IBM Plex Mono — 12~13px / ls 0.08em / uppercase
- 스케일: 대략 emotion 실측 계승 — display 124/72/48, h3 28, body 17, overline 12

## 4. 모션 언어
- 전역 이징: `cubic-bezier(.455,.03,.515,.955)` .5s (emotion 실측) / 강조 리빌: `cubic-bezier(.86,0,.07,1)` .6s (nk.studio)
- 리빌: **clip-path inset + opacity 이중 마스크** (nk.studio 실측 .3s/.45s), 라인 단위 stagger 60ms
- 히어로 타이틀: 글자 분할 `.char` stagger (킹콩애드)
- 카운트업 rAF easeOutCubic / 카드 호버: 이미지 줌 1.06 + radius 10px (emotion)
- prefers-reduced-motion: 스크럽 → 정지 히어로, 리빌 → 즉시 표시

## 5. 히어로 스크럽 (6s · 16:9 · 1080p · 모바일은 정지 폴백)
**월드**: 칠흑(#0A0A14) 공간, 코발트 잉크 플룸·발광 입자가 흩어져 부유 → 카메라 전진 → 입자·잉크가 점점 **정돈된 발광 격자/프레임으로 정렬** → 마지막 1초 완전 정지(settle).
**밴드 맵** (스크롤 진행률 기준, 시작점 — 플릭 테스트로 검증):
| 구간 | 영상 | 캡션 (확정 카피 — 그대로 시공) |
|---|---|---|
| 0–15% | 흩어진 잉크 | `수많은 메시지가 흩어져 있습니다` |
| 25–45% | 입자 이동·수렴 | `문제는 크리에이티브가 아니라, 정렬입니다` |
| 55–75% | 격자 형성 | `타깃·채널·메시지를 한 축에 놓으면` |
| 85–100% settle | 정지된 프레임 | **`틀 밖에서, 브랜드를 정렬하다`** + `UNFRAME` + CTA 버튼 |
- 엔지니어링: Blob fetch(로딩 링) → rAF lerp 스크럽(rest 시 정지) → seek 중복 게이트 → 캡션 밴드 스크림 → 영상 실패 시 포스터 정지 히어로로 완결
