# HOMEWARD 홈워드 — 동물구조단체 홈페이지 + 자체 CMS 데모

위시켓 158999 「동물구조단체 공식 홈페이지 개발」(예산 1,000만 원 · 60일 · RFP 15쪽 첨부 · 지정 레퍼런스 Dogs Trust) 제안용 데모.
가상 단체 **홈워드(HOMEWARD)** — 실존 의뢰 단체의 이름·브랜드·사진·수치는 쓰지 않았다. 모든 개체·소식·접수·통계는 가상.

- 공개 별칭: `https://jeonjaeman.github.io/demo-sites/homeward/` · 관리자 `https://jeonjaeman.github.io/demo-sites/homeward/admin/`
- 로컬: `python -m http.server 8042 --directory 데모/79-동물구조단체홈페이지` (launch.json `homeward`)

## 체험 시나리오 (입력 없이 클릭만으로)

1. 관리자 → 최고관리자 → 개체 관리 → **감자(심사 중)** → 상태를 '입양 완료' → 공개하기 → 「공개 사이트에서 보기」 → 완료 배지, 신청 버튼 없음, 변경 이력에 오늘 날짜
2. 관리자 → + 개체 등록 → 「샘플 사진 넣기」(또는 실제 사진 끌어놓기 — 브라우저에서 진짜 변환) → 용량 절감 표시 → 글 쓰기 → 공개하기 → 입양 목록에 등장, 이름이 용어집에 자동 추가
3. 관리자 → 보안·비공개 → 「직접 URL로 열기」(사망 호두 / 임시저장 소식) → 비공개 화면
4. 공개 사이트 헤더 **EN** → 안내 바 · 영문 UI · 동물 이름은 그대로 → 「Show glossary」 하이라이트 → 「한국어로 보기」
5. 관리자 → 데이터 이전·301 → 「상세 (쿼리스트링형)」 「순서 바뀜 + 검색 꼬리」 칩 → 같은 301 결과
6. 봉사 신청 → 출생 연도 2015 → 보호자 동의 칸 등장 → 접수 → 관리자 접수함에 '보호자' 필드
7. 역할 전환 '운영진' → 메뉴 4개만, 사망 처리 비활성 · 「쉬운 모드」 → 큰 글씨·큰 버튼·고급 항목 숨김
