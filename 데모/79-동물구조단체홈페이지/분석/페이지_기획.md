# 페이지 기획 — 홈워드 HOMEWARD (동물구조단체 홈페이지 + 자체 CMS 데모)

> 공고 158999 / RFP 6쪽 "메인과 6개 상위 메뉴"를 그대로 사이트맵으로 쓴다. 가상 단체 **홈워드(HOMEWARD)** — 실존 의뢰 단체의 이름·브랜드·사진을 쓰지 않는다. 모든 개체·소식·수치는 가상.
> 공개 사이트 표면은 Dogs Trust(지정 레퍼런스)를 재현·능가하고, 관리자 표면은 대시보드 UI(절제된 모션)로 분리한다.

## 영문 변환 (RFP 7쪽 그대로)
- 모든 페이지·모바일에서 헤더의 「영문 변환」 버튼 노출. 누르면 ① 상단에 "자동 번역된 페이지입니다…" 안내 바 + 「한국어로 보기」 복귀 버튼 ② UI·제목·본문이 영문으로 ③ **동물 이름·단체명은 `translate="no"` 용어집으로 번역 제외**(관리자 용어집에서 단어 추가/삭제 → 즉시 반영, 안내 바의 「용어집 보기」로 제외 단어 하이라이트).
- 데모 구현: UI 문구·제목은 사전(data-en), 개체·소식 본문은 데이터의 `_en` 필드(실제 구축에서는 번역 API 또는 Google 웹사이트 번역기 — 지원서에 방식·비용 비교).

## 관리자 화면 (RFP 4·8·9·10쪽) — "초등학생도 쓸 수 있는" 3단계

| 메뉴 | 역할 | 화면 · 실제로 동작하는 것 |
|---|---|---|
| 대시보드 | 전체 | 오늘 할 일(미확인 접수 N·심사 중 N·임시저장 N·검진 예정), 개체 현황(보호중/모집중/심사중/완료/임보 중), 최근 변경 이력, 이번 달 이미지 절감·방문 피크, 저장소 |
| 개체 관리 ★ | 전체 | 목록(검색·상태 칩·공개 여부) · **등록/수정 = 3단계 위자드(① 사진 올리기 ② 글 쓰기 ③ 공개 누르기)** — 사진 끌어놓기·여러 장, **브라우저에서 실제 리사이즈·WebP 변환(원본 → 결과 용량 표시)**, 갤러리 순서 드래그, 영상 URL, 정해진 칸만(이름·구분·성별·추정 생년월·체중·중성화·접종·검사·구조일·장소·프로젝트·보호 장소·함께 살 수 있어요·성격 태그·주의·건강·구조 배경), **임시저장 / 공개 / 숨김 버튼**, 보호 상태(보호중/사망 — 사망은 최고관리자만·공개 사이트 즉시 제외)·입양 상태(모집 중/심사 중/입양 완료)·임보 상태 변경 → **변경일·변경자 자동 기록 타임라인**, 「공개 사이트에서 보기」(새 탭) |
| 소식·공지 | 전체 | 카테고리 7종, 정해진 칸(제목·요약·본문 단락·대표 사진·관련 개체), 임시저장/공개/예약, 목록·검색 |
| 접수함 ★ | 전체 | 입양·임보·봉사·문의·제보 **5종을 한 곳에서**: 상태(미확인/확인/답변 완료)·담당 배정·메모·답변 템플릿·개체 연결·보유기간(접수일+12개월, 파기 예정 표시)·CSV 내보내기(UTF-8 BOM, 실제 파일) · 구글시트 동기화는 설정에서 켜는 **선택 기능** |
| 이미지·트래픽 | 전체 | 업로드 기준(장변 2000px·품질 80·WebP·썸네일 3종)·이번 달 원본 1,431MB → 저장 68MB·CDN 적중률·p95·피크 방문·최근 부하 시험 카드(500명·p95 212ms·오류 0)·장애 안내 페이지 미리보기·백업 현황 |
| 데이터 이전 | 최고관리자 | 콘텐츠 유형별 건수·방식(자동/반자동/수동)·5단계 진행 바·대조(원본 vs 이전 건수)·**301 리디렉션 맵 테이블 + 「테스트」(구 URL 입력 → 새 URL)**·대조표 CSV |
| 영문 변환·용어집 | 전체 | 번역 제외 단어 추가/삭제 → 공개 사이트 EN 모드 즉시 반영, 안내 문구 편집 |
| 권한·계정 | 최고관리자 | 10명 한도 게이지, 역할(운영진/최고관리자) 메뉴 노출 차이표, 역할 전환 스위치(헤더)로 메뉴가 즉시 바뀜 |
| 보안·비공개 | 최고관리자 | **「비공개 글 직접 URL로 열어 보기」** → 공개 사이트가 '비공개 안내'를 보여줌(실제 구축: 서버 렌더 시점 권한 확인·DB 행 수준 정책), 로그인 이력, 2단계 인증 토글, 일 백업·스냅샷 복구 절차 |
| 설정 | 최고관리자 | 단체 정보, 외부 결제 링크, 구글시트 동기화(선택) on/off, 데이터 초기화(데모) |

공개 사이트와 관리자는 **같은 저장소(localStorage `hw79:*`)**를 읽으므로, 관리자에서 숨김/상태 변경 → 공개 사이트에 바로 반영된다(데모의 핵심 체험).

## 체험 시나리오 (입력 없이 클릭만으로)
1. 메인 → 「입양 대기 친구들」 → 필터 '고양이' → 나비 상세 → 「입양 신청」(프리필) → 접수 완료
2. 관리자 → 개체 관리 → 감자(심사 중) → 상태를 '입양 완료'로 → 타임라인에 오늘 날짜 기록 → 「공개 사이트에서 보기」 → 완료 배지·신청 버튼 없음
3. 관리자 → 개체 등록 위자드 → 샘플 사진 3장 끌어놓기(또는 「샘플 사진 넣기」 버튼) → 용량 절감 표시 → 공개 → 목록에 등장
4. 헤더 「영문 변환」 → 안내 바·영문 UI·이름은 그대로 → 「용어집 보기」 하이라이트 → 「한국어로 보기」
5. 관리자 역할 전환 '운영진' → 메뉴 4개만 남음 → 사망 처리 버튼 비활성
6. 관리자 → 보안 → 「비공개 글 직접 URL로 열기」 → 비공개 안내 화면

## 기술 구성 (데모)
정적 HTML 12 + `assets/css/style.css`(공개) · `admin.css`(관리자) + `assets/js/data.js`(시드) · `core.js`(저장소·공통 UI·영문 변환·리빌) · `site.js`(페이지 컨트롤러) · `admin.js`. 외부 라이브러리 0. 이미지 WebP(Higgsfield 생성 → Pillow 최적화, 카드 720px·히어로 1600px).
