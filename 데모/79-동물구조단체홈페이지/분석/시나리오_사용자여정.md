## 2. 여정 ① 개체 생애주기 — 구조 → 치료 → 공개 → 심사 → 완료 → 후기

상태 모델(데모 구현): 보호 상태 `보호중 / 사망(관리자만)` × 입양 상태 `모집 중 / 심사 중 / 입양 완료` × 임보 `없음 / 임보 가정 모집 / 임보 중` × 공개 `공개 / 숨김 / 임시저장`. 상태를 바꾸면 `history[]`에 날짜·항목·값·담당자가 자동 추가된다. RFP가 정의하지 않은 값(심사 중·임보 중·파양)은 [확인].

| 단계 | 상태 전이 | 기록 지점 | 쓰는 화면 | 없으면 벌어지는 일 |
|---|---|---|---|---|
| 1 구조·입소 | 보호중 · 임시저장 | 구조일·장소·프로젝트 | 개체 등록 위자드 1~2단계 **[데모]** | 동명 개체 혼동, 통계 불일치 |
| 2 치료·회복 | 보호중 유지, 치료 소식 선택 공개 | 건강 메모 | 소식 쓰기(개체 연결) **[데모]**, 학대 현장 체크 → 목적 표시 자동 **[데모]** | 학대 촬영물 게재 위법 소지, 후원자에게 경과 미전달 |
| 3 입양 공고 | 공개 · 모집 중 | 공개일 | 공개 버튼, 공유 미리보기(OG) **[데모]** | 공유 썸네일 누락, 실수 공개 |
| 4 신청 접수 | 모집 중(신청 n건) | 접수일·보유기한 | 신청 폼 → 접수함 **[데모]** (→ 구글시트 선택 사본) | 구글폼·카톡에 흩어져 누락 |
| 5 심사 | 심사 중 → 신청 버튼 숨김 | 변경일·담당자 | 상태 선택 **[데모]** | 신청이 계속 들어와 민원 |
| 6 입양 완료 | 입양 완료(배지) | 입양일 | 상태 선택 **[데모]**, 동물등록 변경신고 안내 [구축] | 완료 개체가 모집 중으로 남음 |
| 7 후기 | 후기 ↔ 개체 연결 | 후기 등록일 | 개체의 review 필드 **[데모]** | 후기와 개체가 분리 |
| 예외 A 사망 | 사망 → 공개 사이트 전 경로 차단 | 사망일 | 최고관리자만 가능 **[데모]**, 사진 비공개 저장소 이동 [구축] | 목록에 남아 신청 유입, 사진 URL 노출 |

## 6. 비는 구멍 — 미팅 확인 (상위 12)

1. 보안·권한: 공고 "선택" vs RFP "필수" — 기본 차단은 필수 포함 제안
2. 구글시트: 공고 "필수" vs RFP "선택" — DB 원본 + 시트 사본, 시트 소유 계정
3. 전체 데이터 이전이 1월 오픈 범위에 포함되는지, 유형별 건수(후기 300~440건 추정)
4. 상태값: 심사 중·임보 중·파양(반환) 정의, 임보 모집과 입양 모집의 구분
5. 사망 공개 정책: RFP "관리자만" vs 대형 단체 관행(추모 공개)
6. 영문 변환 범위: 게시판 본문 포함 여부, 용어집 제공 시점, noindex 정책
7. 카페24 FTP·DB 접근권(착수 1주 내) — 시험 이전의 선행 조건, 해지일
8. 사진 저작권·초상권: 봉사 작가 사진, 후기 속 얼굴 노출 동의
9. 후원자 실명이 월별 기부내역에 있는지 → 이전 시 마스킹
10. 공익법인 지정·모금 등록 여부 → 공시 링크·법정 게시 박스 적용
11. 미성년 봉사 최소 연령, 해외 이동봉사 정보(여권·항공편) 국외 제공 여부
12. 마감일: RFP "10/22(월)"은 실제 목요일 · 위시켓 지원 + 이메일 PDF 병행 여부
