# HUELAB 휴랩 — 페인트 브랜드 기업 소개 홈페이지 (제안용 데모)

친환경 종합도료 브랜드 소개 홈페이지 제안 데모. **삼화페인트(spsamhwa.com)를 실측**해
프리미엄 에디토리얼 톤(딥틸 #00393c·크림·오렌지팝·Inter 대형 디스플레이)을 이식하고,
**AI 생성 그래픽·영상**으로 고퀄리티 비주얼을 구성했습니다.

> ⚠️ 제안 검토용 **비공식 데모**이며 실제 서비스가 아닙니다. 브랜드·제품·색코드·시공 이미지·
> 사업자정보는 전부 가상이며, 시공 이미지·히어로 영상은 실존 브랜드·글자·로고 없이 생성했습니다.

## 화면
| 파일 | 화면 | 핵심 |
|---|---|---|
| `index.html` | 공개 사이트 | 영상 히어로 · 브랜드/미션 · **COLOR INSPIRATION**(팔레트+색코드+실색 고지) · 제품 라인업 · 시공 사례 갤러리 · 연락처/오시는 길 |
| `admin.html` | 관리자 | 제품·시공 사례 등록·수정·삭제 + 게시 상태 (localStorage) |

## 체험 시나리오
1. 히어로 **영상**(딥틸 인테리어 시네마틱)으로 첫인상.
2. COLOR INSPIRATION에서 테마 탭(청량/따뜻/무채/자연) 전환 → 팔레트·색코드 확인.
3. ★ **실물 컬러칩 신청** 버튼 → "화면 색 ≠ 실제 색" 고지(색 재현 리스크 대응).
4. 제품 카드의 친환경/인증 배지 — **근거 있는 인증만 ✓** 표시.
5. 시공 사례 유형 필터(주거/상업/외벽) + 카드 클릭 → 라이트박스.
6. 헤더 검색(또는 `/`)으로 제품·컬러·시공 검색.
7. `admin.html` → 제품/시공 사례 등록·수정·삭제, 게시/비공개 전환(화면 전체 재렌더 없음).

## ⚠️ 착수 전 확인 (미팅)
- 실제 사명·로고·시그니처 컬러·색코드 체계
- 친환경·인증 표시 근거(시험성적서 등) — 표시·광고 책임
- 실제 제품 목록·시공 사진·저작권, 회사 정보·연락처·대리점
- 빌더(아임웹·카페24) 축소안 vs 커스텀 고퀄 — 삼화 수준은 커스텀 필요

## 리서치 핵심
- 화면 색 ≠ 실제 도장 색(색영역·조명·메타머리즘) → 실물 컬러칩 고지·신청
- 근거 없는 "친환경" = 부당광고(환경성 표시·광고 규제) → 인증(✓) 구분 표시
- 빌더로는 삼화 수준 그래픽·인터랙션 재현 불가 + 데이터 종속
- 도메인 IA: 제품·컬러·시공·대리점·고객센터(KCC·삼화·노루)

## 레퍼런스 실측
- **SP SAMHWA**(spsamhwa.com, 사용자 지정) — 딥틸 #00393c·크림 #f0eedf·오렌지 #ff4e1c·
  Inter 700 64px·COLOR INSPIRATION·BUSINESS AREA. 프리미엄 에디토리얼 톤 이식.
- 그래픽/영상: Higgsfield 생성(nano_banana_pro 이미지 4 · kling3_0_turbo 영상 1), 최적화(영상 194KB).

## 기술 구성
- 순수 HTML/CSS/바닐라 JS, 빌드 없음. Inter(Google Fonts)+Pretendard(CDN).
- 영상 히어로(mp4, muted/loop/playsinline·poster 폴백), 이미지 최적화(58~137KB).
- 스크롤 리빌·카운트업·컬러 탭·시공 필터·라이트박스는 `getBoundingClientRect` 기반.
- 관리자 제품·시공 CRUD는 `localStorage`. 375px 무-가로스크롤, `prefers-reduced-motion` 존중.
- 파일: `assets/css/huelab.css` · `assets/js/{data,app,admin}.js` · `assets/img/*`
