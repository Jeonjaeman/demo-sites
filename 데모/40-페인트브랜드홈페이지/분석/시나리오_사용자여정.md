# 시나리오 · 사용자 여정 — HUELAB 휴랩

페인트 브랜드 홈페이지를 누가·왜 방문하는지 시간순으로 재구성한다. 핵심은
"색을 화면으로 고르되, 실제 공간에서 실패하지 않게" 잇는 것.

## 1. 등장인물
| 역할 | 누가 | 무엇을 원하나 | 무엇을 불안해하나 |
|---|---|---|---|
| **일반 소비자/셀프시공** | 집을 칠하려는 사람 | 어떤 색·어떤 제품이 맞는지, 어디서 사는지 | 화면 색과 실제 색이 다를까, 냄새·유해성 |
| **인테리어·시공업자** | 현장에 쓸 도료 선택 | 제품 스펙·시공 사례·대리점 | 내구성·품질, 재고·납기 |
| **건축주·설계사** | 프로젝트 마감재 검토 | 친환경 인증·시공 레퍼런스 | 인증이 진짜인가, 근거 있나 |
| **운영 담당자** | 제품·사례 갱신 | 코드 없이 등록·수정·삭제 | 개발자 없이 못 바꾸면 방치 |

★ 같은 "컬러"를 소비자는 감성으로, 시공업자는 스펙으로 본다. 그래서 컬러 → 제품 → 시공으로
자연스럽게 이어져야 하고, 색의 한계(화면≠실물)를 솔직히 안내해야 신뢰가 쌓인다.

## 2. 시간순 여정
| 단계 | 상황 | 쓰는 화면 | 없으면 |
|---|---|---|---|
| 발견 | 브랜드 첫인상 | 영상 히어로 | "그저 그런 페인트 회사"로 스킵 |
| 영감 | 어떤 색이 좋을까 | COLOR INSPIRATION(팔레트) | 색 선택 막막, 이탈 |
| **주의** | 이 색이 실제로도 이럴까 | 실물 컬러칩 고지·신청 | 화면만 믿고 골라 시공 후 클레임 |
| 탐색 | 어떤 제품을 쓰나 | 제품 라인업(인증 배지) | 스펙·친환경 근거 불명확 |
| 확신 | 실제로 잘 나오나 | 시공 사례 갤러리 | 레퍼런스 없어 판단 불가 |
| 행동 | 사거나 문의 | 연락처·대리점·문의 | 전환 지점 없이 이탈 |
| 운영 | 제품·사례 갱신 | 관리자 CRUD | 개발 의존·방치 |

## 3. 역할별 시야 차이
| 데이터 | 방문자(공개) | 운영자(관리자) |
|---|---|---|
| 제품·시공 사례 | 게시된 것만 열람 | 등록·수정·삭제, 게시/비공개 |
| 컬러 | 팔레트 열람 + 컬러칩 신청 | (색 체계 관리는 실구축 시) |

→ 관리자에서 '비공개'로 두면 공개 사이트에 노출되지 않는다(게시 상태 분기).

## 4. 기능별 존재 이유
- **영상 히어로**: 3초 안에 "프리미엄 브랜드"라는 첫인상(삼화 톤 이식).
- **COLOR INSPIRATION**: 색 선택의 진입점. 감성 팔레트 + 정확한 색코드.
- **실물 컬러칩 고지·신청**: 화면≠실물 문제를 솔직히 안내하고 클레임을 예방.
- **제품 인증 배지(✓)**: 근거 있는 친환경만 인증 표시 → 부당광고 회피 + 신뢰.
- **시공 사례 갤러리·필터·라이트박스**: 실제 결과로 판단하게.
- **관리자 CRUD**: 제품·사례를 스스로 갱신 → 운영 자립.

## 5. 비는 구멍 (착수 전 미팅 확인)
1. **실제 브랜드·색 체계** — 사명·로고·시그니처 컬러·색코드 체계(데모는 가상).
2. **친환경·인증 근거** — 환경마크·시험성적서 등 표시 근거 확보 여부(표시·광고 책임).
3. **제품 목록·시공 사진** — 실제 제품 라인업, 시공 현장 사진·저작권(데모는 AI 생성 가상).
4. **연혁·회사 정보·연락처·대리점** — 실제 데이터.
5. **빌더 vs 커스텀** — "삼화 수준 고퀄"을 원하면 커스텀, 예산·속도 우선이면 빌더 축소안.
6. **다국어·SEO·성능** — 필요 범위(영상·이미지 최적화 포함).

## 6. 데이터·사실성
브랜드·제품·색코드·시공 이미지·사업자정보는 전부 가상이며, 시공 이미지·히어로 영상은
실존 브랜드·글자·로고 없이 AI로 생성했습니다. 실제 서비스는 실제 콘텐츠·인증 근거로 교체합니다.
