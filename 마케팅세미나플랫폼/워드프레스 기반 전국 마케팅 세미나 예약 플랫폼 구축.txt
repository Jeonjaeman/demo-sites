[프로젝트 개요]
전국 마케팅 세미나 예약 플랫폼 구축 (워드프레스 기반)

[프로젝트 배경 및 목표]
전국 56개 지역을 순회하며 진행되는 마케팅 세미나의 온라인 모객, 예약, 결제 과정을 자동화하기 위한
브랜드 홈페이지를 구축하고자 합니다. 기존 아임웹 기획안에서 워드프레스 기반으로 변경하여,
테마와 플러그인을 적극 활용해 예산 내에서 효율적으로 예약 시스템과 알림톡 연동을 구현하는 것이
목표입니다.

[과업 범위]
1. 수행 범위
- 기획 및 디자인: 워드프레스 프리미엄 테마 선정 및 브랜드 톤앤매너에 맞춘 디자인 커스터마이징,
  반응형 웹 구현
- SW 개발: 워드프레스 호스팅 세팅, 예약/결제 플러그인 설치 및 설정, PG사 연동,
  카카오 알림톡 API 연동

2. 상세 기능 요구 사항

2-1. 프론트엔드 및 콘텐츠 구성
- 메인 페이지 및 브랜드 소개 페이지 퍼블리싱
- 세미나 커리큘럼, 강사 소개, 수익 계산 폼 등 상세 페이지 구성
- 모바일 예약 전환율을 고려한 반응형 웹 디자인 적용
- 채널톡 상담 위젯 스크립트 삽입 및 연동

2-2. 예약 및 결제 시스템
- 지역 및 회차별 세미나 예약 상품 등록 기능
- 정원 60명 도달 시 해당 회차 자동 마감 및 품절 처리
- 달력형 예약 위젯 또는 리스트형 예약 UI 적용
- 국내 PG사 연동을 통한 신용카드 및 가상계좌 결제 지원
- 가상계좌 입금 대기 시간 초과 시 자동 취소 로직 적용
- 취소 시점별 환불 규정 사전 설정 및 관리자 환불 처리 기능

2-3. 알림 및 관리자 기능
- 예약 확정 및 입금 완료 시 카카오 알림톡 자동 발송 API 연동
- 예약자 명단 관리 및 현장 확인용 엑셀 다운로드 기능
- 지역별 세미나 페이지 생성을 위한 마스터 템플릿 1개 구축
- 내부 인력이 직접 페이지를 복제하고 수정할 수 있는 구조 세팅 (미팅 시 상세 협의)

3. 비기능적 요구사항
3-1. 성능/규격: 워드프레스 최신 버전 유지 및 플러그인 간 충돌 방지 최적화
3-2. 보안/인증: SSL 인증서 적용 및 관리자 페이지 보안 설정

[기술/제조 스택]
- WordPress, WooCommerce (또는 예약 전용 플러그인), PHP, MySQL, 국내 PG사 플러그인,
  카카오 알림톡 API

[클라이언트 준비 사항]
- 문서 및 자료: 세미나 커리큘럼, 브랜드 로고, 텍스트 콘텐츠, PG사 가입 정보
- 투입 인력 및 조직: 프로젝트 총괄 대표(방향 결정),
  행정/운영 담당자(산출물 검수 및 복제 교육 이수)

[주요 일정]
- 희망 착수일: 계약 완료 후 즉시 착수
- 완료일: 미팅 시 협의

[지원 자격 및 우대 사항]
- 지원 자격: 워드프레스 기반 예약/결제 사이트 구축 포트폴리오 보유자
- 우대 사항: 워드프레스 플러그인 커스터마이징 및 알림톡 API 연동 경험이 풍부한 자

[산출물]
- 워드프레스 관리자 계정 및 소스코드 원본
- 마스터 템플릿 복제 및 기본 관리자 운영 매뉴얼

[계약 관련 특이 사항]
- 본 프로젝트의 예산은 마스터 템플릿 1개(지역 페이지 포함) 구축 및 시스템 세팅을 기준으로
  책정되었습니다. 56개 전체 지역 페이지에 대한 단순 복제 및 생성 작업은 본 과업 범위에서
  제외되며, 완료 후 당사 내부 인력이 직접 수행할 예정입니다.
  (단, 파트너사에서 56개 페이지 전체 제작을 원스톱으로 진행할 경우의 추가 비용은
  미팅 시 별도 협의 가능합니다.)
  워드프레스 유료 테마 및 플러그인 구매 비용 발생 시 실비 정산 또는 당사에서 직접 결제하여
  제공합니다.
